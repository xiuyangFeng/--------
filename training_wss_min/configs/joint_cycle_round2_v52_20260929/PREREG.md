## 2. 具体模块与可识别范围

时间模块放在原任务解码器 FiLM 和 hidden 之后、输出投影之前，输入特征已随相位变化。TCN 瓶颈 32、kernel 3、dilation 1/2/4/8、四层，感受野 31 帧；采用 reflect 边界，一次并行预测全部 80 相位。逐相位 FFN 不读取其他时刻特征，自动调整有效宽度配平新增参数。只把残差末端投影置零，其余模块正常初始化；不采用真值历史、teacher forcing、递归 rollout、差分或周期闭合训练损失。

U0/U1 使用相同 5,000 support 与 k=16 邻居、相同可得几何输入。U0 为边特征 MLP 与均值聚合，U1 为 query/key/value 跨注意力，处理臂 hidden64、4 heads。W0/W1 在相同位置加入残差，W1 使用相同 support 中的 k=16 patch，hidden64；W0 使用点式特征。控制臂有效宽度由实现按实际维数配平，不新增完整壁面采样，不读 CFD 输出作为输入。几何欧氏邻域可能跨分支／跨腔，这属于该方法的局限，不按真值流场筛边。

四对控制／处理的**新增可训练模块参数**差要求不超过 5%：`abs(n_control−n_treatment)/max(n_control,n_treatment)`。既记录新增量也记录全模型量，不用大主干稀释差值。准备冻结时 CPU 构建模型，记录实际宽度、参数与配平结果，再做真实数据 GPU 冒烟；参数合格不等于同 FLOPs、同显存或同壁钟成本。

P1 的空间 token 数 128、hidden64、4 heads 与 J1 相同；它检验压力收益是否需要联合监督，不将新增容量与交互收益完全分离。J2 的 PCGrad 只处理共享几何和共享交互参数：对每任务共享梯度检测负点积，按 seed 确定的任务顺序投影，再平均。任务专用头保持原等权 mean 目标梯度。AMP 缩放需正确还原，投影后再裁剪和更新，保持有限梯度门槛。记录任务对投影前 cosine、范数、冲突频率、裁剪及额外计算成本。负迁移本身并不能证明梯度冲突。

## 4. 评价：峰值、谷底和整周期同时报告

所有模型使用相同55个开发留出单元、原查询行和聚合公式。单元内部体积／面积加权，再单元等权。该留出集已参与下一轮研究设计，应称开发留出集，不能再称盲测集。

| 层次 | 固定指标／相位 |
|---|---|
| 三个主要段 | 峰值17–26、谷底5–9及43–57、整周期0–79：R²、MAE、RMSE、relative-L2 |
| 其他分段 | 加速10–16、减速27–42、平台0–4及58–79，同一指标 |
| 单帧与时间 | 固定第21帧；全部80帧曲线；首尾帧；物理单位一阶时间差分误差，明确是否除以 dt |
| 速度 | 向量与幅值分别评价、方向余弦、真值速度≥0.01m/s的覆盖率；预测零向量计cosine0 |
| WSS | 分段空间Spearman、80帧TAWSS误差；没有切向WSS向量，不计算OSI |
| 稳健性 | 逐单元配对差、改善比例、R² P10及负值单元数 |
| 成本 | 有效参数、峰值显存、训练时间、固定查询推理中位/P95；三专用模型成本按实际合计 |

所有索引0-based。峰值窗R²是整段时空变异上的指标，不是单帧21，也不是逐帧R²平均。向量R²分量分别中心化，保持旋转不变。低能量段同时检查绝对误差，不能只依赖R²／relative-L2。

旧基线既有六个阶段指标直接复用；新增单帧／差分缺项显示“—”，本次不附带旧基线的批量离线重算。后续若补齐，可用匹配的旧预测和查询行按相同公式离线计算，无需重训。缓存、行号或旧预测无法匹配时标记缺失，不混用异构指标。先对配对容量控制，再对既有任务强基线；报告峰值／谷底／周期取舍，联合模型不能以压力改善掩盖速度／WSS下降。单 seed 细小差异不作为确定机制或临床有效性结论，不自动扩展后备矩阵。
