日期：2026-09-29。配置 schema：`joint_cycle_v52_v1`。本轮固定 **patient-group CV5 的 fold0、seed1234、四种结构、六次实际训练**。本文与同目录 `matrix.json`、六个配置文件共同规定首轮试验；实际启动、冻结源码、Slurm ID 和完成状态以实验目录的提交记录为准，写入本文件不表示已经训练或取得性能结果。

## 1. 要回答的问题与证据边界

输入病例几何、原 CFD 规定的已知边界条件和相位，直接并行预测一个周期的速度三分量、相对压力 p′ 与标量 WSS。首轮依次检验：共享几何表示是否有利于三个任务；新增全局空间交互是否有利；将相位放进空间注意力是否进一步有利。

所有模型均可解码全部 80 个相位。J1 的注意力在**每个相位内部沿空间 token 计算**，相位之间没有自注意力，也没有递归 rollout。该对照不能直接验证“跨时间 Transformer 的收益”“记忆闭合”“任意时间间隔预测”或“周期外长期稳定性”。全场时间低秩可重建性也不等于仅从几何与边界条件可预测性；本轮不提供真值场潜变量或 CFD 初始场。

本轮属于内部工程试验：只有一折、一个 seed；不构成完整 CV5、多 seed 稳健性、外部验证或临床有效性证据。模型收益与运行时间均待真实结果确定。

## 3. 输入、监督与采样

### 输入

- 每病例 5,000 个几何 support 点，27 维壁面几何特征；速度／压力 query 各 20 维体内特征，WSS query 27 维壁面特征。所有臂共享采样规则。
- 四个相位通道：`q_norm, dq_norm, t_sin, t_cos`。使用源周期前 80 帧，移除第 81 个相位重复端点；其数值并非严格等于帧 0，源数据端点差已单列记录，不施加严格周期闭合损失。物理时间来自固定原始协议。
- 20 维已知条件由对应原始 `case.h5` 的 `conditions.attrs` 读取：四个具名出口 `out-le/out-li/out-re/out-ri` 各自的 log R1、log R2、log C（12 维）；周期和密度（2 维）；Carreau 参数 `mu_inf_pa_s, mu_zero_pa_s, lambda_s, a, n`（5 维）；`A_inlet_udf_m2`（1 维）。原导出的 RCR 阻力单位为 **Pa·s/kg**，顺应性为 **kg/Pa**，不写成体积流量形式的单位。
- 这些条件是原 CFD 已规定的输入；不从输出标签反推。入口波形由逐病例审计确认同一模板，本轮条件化不意味着已验证任意入口波形泛化。
- 不输入速度／压力／WSS 真值、CFD 起始场、真值低秩系数；不使用 teacher forcing。Murray 分流特征来自已有几何先验。

### 监督

- 速度：对齐坐标系中的三分量，单位 m/s。
- 压力：每帧减去原始全体积均值参考的 p′，单位 Pa。参考值只定义监督的压力规范，不作为输入；不据此宣称可恢复绝对压力。
- WSS：直接标量幅值，单位 Pa；不含切向向量或方向监督。因此可计算 80 帧 TAWSS，**不能计算 OSI**。

### 采样与归一化

训练候选池为体内 8,192 点、壁面 8,192 点；评价候选池为体内 16,384 点、壁面 8,192 点，与同病例训练候选池行号互斥。点数不足时按可用点数缩减并保持互斥，缓存记录实际数目。

正式训练开始前，依据 GPUprobe16148 的 train-only 资源探针（同一个训练病例重复组成 batch4、support5000、各任务 query512、全部 80 相位，J1 峰值已分配显存约 1,691 MiB、热步约 0.30 s），将正式 query 数从初定 512 调整为各任务 1,024。该探针使用部分训练统计，仅用于资源／数值稳定性检查，不提供精度结论；正式 1,024 的显存与速度仍须由完整统计下的正式配置 smoke 验证，该修改未使用留出结果。

每个训练 epoch 每病例从训练候选池采样各任务 1,024 个 query；速度与压力使用同一批体内行号。support 与 query 的随机流由 seed、病例、采样类型及 epoch 确定；所有臂保持相同暴露规则。评价使用固定 support 与固定 query 行号，忽略 epoch。评价覆盖的是固定子样本，**不是原始全点云**。

几何与已知条件的归一化仅拟合 206 个训练单元。曲率先做 signed-log1p，再使用训练候选池的绝对值 99% 分位进行截断；归一化坐标保留原定义。速度与 p′ 采用训练候选池点汇总、**逐相位／逐分量**的均值与标准差；WSS 先做 `log(max(WSS, 0.05 Pa) + 1e-6)`，再逐相位 z 标准化。这不是每病例单独拟合，也不是按体积／面积加权拟合统计。物理评价保留并使用未截断的原始 WSS 真值，不能把 0.05 Pa 的训练下限施加到评价真值。

## 4. 六次训练与配对初始化

| 臂 | variant | 监督任务 | 几何编码器 | 新增空间交互 | 交互中的相位 |
|---|---|---|---|---|---|
| Iu | I | velocity | 单独训练 | 无 | 不适用 |
| Ip | I | pressure | 单独训练 | 无 | 不适用 |
| Iw | I | wss | 单独训练 | 无 | 不适用 |
| J0 | J0 | velocity / pressure / wss | 三任务共享 | 无 | 不适用 |
| J1c | J1c | velocity / pressure / wss | 三任务共享 | 128 空间 token，64 hidden，4 heads | 四个相位通道置零；已知条件保留 |
| J1 | J1 | velocity / pressure / wss | 三任务共享 | 与 J1c 同参数结构 | 真实相位与已知条件 |

四种结构对应六次独立优化，Iu／Ip／Iw 不是同一模型的三个输出。所有最终任务头均接收真实相位与已知条件，包括 J1c。J1c 只消融空间交互中的相位，不移除最终解码器的相位。

`geometry_x5d.json` 仅摘录既有 `X5Dcap_asym2_s1234.json` 的 `model` 对象，用于复用 PointNet++ 空间编码结构；**不加载 X5D 权重，不加载 donor checkpoint，不继承其数据划分、统计、损失或选模规则**。新模型显式禁用旧输出头与 query refiners；本轮统一 `local_branch_directional=false`、新任务头 hidden=128。不要把本轮称为已训练 X5D 的迁移学习。

几何初始化固定 seed1234，独立臂与联合臂使用相同初值；每个任务头采用固定的 `seed + 100 + task_index` 随机流。J1c 与 J1 的交互模块采用相同 `seed + 1000` 初值，其输出投影零初始化，使加入交互的初始功能与 J0 对齐。相位直接进入注意力 Q/K 前的非线性条件变换，允许空间权重随相位改变。

本轮没有速度梯度推导 WSS、一致性损失、Navier–Stokes 残差或跨时刻周期闭合损失；三个物理量的联系仅通过共享表示与联合监督学习。

## 5. 固定训练预算与损失

每臂：150 epoch，batch=4 病例，AdamW，初始标称 lr=0.001，weight decay=0.0001；前 5 epoch 线性 warmup，随后 cosine 到 lr 比例 0.01；梯度裁剪 1；AMP 开启，初始 GradScaler scale=1,024，训练 TF32 开启；DataLoader worker=2，Torch 线程=4。按 206 训练单元计算每 epoch 52 步、每臂 7,800 次优化更新。所有 80 相位均参与每次损失，`phase_chunk=8` 仅控制计算分块，不表示只采样 8 相位；不使用 activation checkpointing。

任务损失为 z 空间平方误差：先平均相位与分量，再按每病例所采 query 的物理权重归一加权（速度／压力为体积，WSS 为面积），再等权平均病例。速度的三个分量合起来仍只算一个任务。独立臂优化单任务损失，联合臂等权平均三个任务；因此联合目标中各头梯度尺度与单任务臂不同，这是本轮联合目标的组成部分，不宣称完全隔离了所有优化效应。

各臂相同病例、相位暴露和 epoch 数；参数量、FLOPs、训练耗时并不相等。必须报告实际参数、峰值显存、耗时，不以“相同 epoch”替代算力匹配。后续若需相同 FLOPs／壁钟预算对照，应另行定义。

每 5 epoch 保存恢复 checkpoint；**唯一评价模型为第 150 epoch 的 last checkpoint**。无验证集、无早停、无 best checkpoint、无留出结果调参。出现 NaN、AMP 跳步或输入指纹改变时停止并保留错误证据，不静默改预算或绕过失败。

## 6. 评价与预先指定的比较

训练完成后，正式评价 fold0 的 55 个 `test` 数据单元；该命名只表示本折留出分区。工程 smoke 限于训练分区，最多 3 个训练 batch、2 个训练单元的评价，不访问留出病例来调试或选模。

每个数据单元先用物理单位预测与原始真值计算以下指标，再对数据单元等权求均值：

- 全周期及预定相位段的体积／面积加权 RMSE、MAE、relative L2、R²。速度分量 RMSE 与向量 RMSE分别列出，后者为前者乘 √3；R² 在向量分量分别中心化后计算。不汇总成 pooled R²。
- 速度另报告速度幅值误差、方向 cosine。方向评价仅由真值速度 ≥0.01 m/s 决定掩码，预测零向量保留并计 cosine=0；报告掩码覆盖率。
- WSS 另报告逐相位空间 Spearman 后的相位均值（空间相关系数不做面积加权）、80 帧 TAWSS 的面积加权误差。常量场无定义相关系数记缺失，不伪造为有效相关。
- 所有逐病例指标与 query 行号保存，便于按同一数据单元配对。该聚合不是按独立患者求的置信区间；本轮不提供跨 seed 不确定度或确认性显著性结论。

预定相位段为 0-based 帧：`cycle=0:80`，`peak=17:27`，`accel=10:17`，`decel=27:43`，`plateau=0:5 + 58:80`，`trough=5:10 + 43:58`；区间右端不含。分段不根据本轮误差曲线修改。

预先指定逐任务配对比较：

1. Iu／Ip／Iw 与 J0：任务共享及联合目标的净变化，同时检查负迁移。
2. J0 与 J1c：新增参数容量和不含相位的全局空间交互的合并效应，不把差异全部归因于相位。
3. J1c 与 J1：同交互结构下，真实相位进入空间注意力的增量。

报告三个任务的改善／退化及逐病例分布，不用事后挑选单一指标宣布胜者，不预设缺乏依据的临床阈值。结果不足以支持机制时按不足报告；额外消融、新 seed、其余 CV 折或外部集不自动加入本矩阵。
