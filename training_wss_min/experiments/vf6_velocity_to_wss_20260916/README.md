## 三种半径来源

冻结算子的多尺度近壁深度用每个壁面节点的局部半径 `local_radius_mm` 设定。三种来源只改这一列，壁面、法向、速度、算子与校准器完全相同：

| 来源 | 定义 | 目的 |
|---|---|---|
| legacy | VELWSS1 原口径：旧 `data_wss_min` bundle 的 `wall_local_radius`，按旧 `wall_coords_raw` 最近邻配到 V5 毫米壁面。旧坐标按病例 unit_factor（926.4–1087.8）缩放而非 1000，配对残差最大 38.56 mm | 与 VELWSS1 逐位可比 |
| legacy_exact | 同一旧半径场，但旧坐标先乘 1000/unit_factor 再配对：逐节点精确对应（最大残差 1.2e-04 mm）。legacy/legacy_exact 半径比：逐例 p50 中位 0.990，p95 最大 2.471，偏差 >20% 的节点均值 24.06% | 只去掉映射错位，量化映射误差本身的影响 |
| v5atlas | V5 bundle `wall_local_radius`（V5 atlas 帧，自适应 SG 窗），与节点一一对应、无映射。legacy/v5atlas 半径比：逐例 p50 范围 0.999–1.075，偏差 >20% 的节点均值 6.57% | 换成当前部署输入的半径定义 |

校准器训练时看到的是 legacy 半径；后两种来源下校准器输入分布有偏移，因此同时报告未校准物理核。
