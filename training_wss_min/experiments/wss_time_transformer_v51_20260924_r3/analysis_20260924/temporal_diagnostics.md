# Temporal Transformer r3：训练轨迹与时间响应诊断

本诊断只汇总已验收的 12 个正式 r3 run：cv3、seed1234、60 epochs × 30 steps、last checkpoint；不训练、不推理、不重选 checkpoint。所有差值均为前者减后者。三折为算术平均，holdout 病例数依次 46/46/44。

主要结果：warm 相对 raw 的时间相关、ln 幅值误差、病例内峰时 median/p90 的病例均值，在 full 与 diagonal 对照中均为三折同向改善；full 的全周期 Pa R² 却三折略低。这支持“额外冻结几何特征对时间形态有收益”，尚不支持“物理 Pa 全面更优”。跨帧 attention 的增量混合且很小：warm 的周期 Pa/ln 均值下降，raw 的 Pa 略升而 ln 下降。

## 指标聚合口径

- `ts_corr_ln`：逐壁面点计算 81 帧的 Pearson 相关，排除分母 ≤ 1e-12 的退化点；病例内对有效点平均，再对有效病例取 nanmean。有效点数没有落盘。
- `amp_err_ln_med`：逐点计算预测与真值 ln 峰谷范围的绝对差，病例内取中位数，再对病例平均。不是所有点的总体中位数，也不是 Pa 幅值误差。
- `peak_time_err_med_frames / peak_time_err_p90_frames`：逐点计算 ln 曲线 argmax 的循环帧距，分别在病例内取 median / p90，再对病例平均。报告 p90 是“病例内点级 p90 的病例均值”，不是总体点级 p90，也不是病例之间的 p90。
- log 真值与预测都使用 `ln(max(WSS, 0.05 Pa) + 1e-6)`；Pa 主指标真值保留原始值。全局 ln 指标并未按空间低 WSS 区域分层。
- `trough` 是协议 Q 最低的 20 个时间帧，不能等同于空间低 WSS 区域。
- 帧间隔 0.01 s、Fluent physical step 增量 2；81 个样本包括首尾同相位，循环帧距在实现中为 `min(d, 80-d)`。
- 每帧 R²_cb 使用病例等权全局真值均值，不是病例 R² 均值；cycle 对 81 帧算术平均。本诊断再对三折算术平均。

## 现有产物与证据边界

每个正式 run 仅保存 `history.jsonl`、`metrics.json`、`queue_acceptance.json`、`ckpt_last.pt`。冻结实现评估时构造逐病例逐点的 truth/predictions，但未将这些数组、逐病例时间指标或有效点计数保存；metrics 中的病例 ID 只用于 context 索引哈希。因此目前无法判断改善由多少病例贡献，也无法定位到空间壁面区域。读取预训练缓存中的峰值锚不能替代 r3 全周期预测。

本结果属于单 seed、已有开发 fold 的描述性证据；full/diagonal 只能检验本表示与预算下的跨帧交互增量，不能证明物理记忆或新波形泛化。现有 loss 没有验证曲线，不能判断过拟合或充分收敛。
