# 时间建模复核：老师的 Transformer 思路、数据边界与优化顺序

日期：2026-09-27。范围：复核 `02-时间建模` 的既有实验、正式 r3 指标/实现和数据诊断。没有新训练、推理、测试集评估或 CFD。下述优化是建议，不是已经验证的增益或已启动的实验。

## 1. 核心判断

**老师提出的“几何编码 + 时间条件 + 全周期解码”有合理性，当前实验也支持学习几何与相位的交互；尚未得到支持的是这版跨帧注意力在 Pa 主指标上稳定的额外收益。** 峰值锚定是已验证的工程收益。隐藏特征对时间形态有小幅一致改善，不能笼统判为没有价值。

**全周期约 0.50、谷底约 0.30 是当前模型族在 v5.1、单 seed 和既定预算下的实测平台，不是已经证明的数据可预测性上限。** 共享波形限制了可验证的边界条件泛化；它不妨碍学习固定驱动下、由几何决定的非稳态响应。没有逐帧速度/压力输入也不自动导致不可学习。

原 09-24 综述的三个表述需纠正：

1. “TAWSS 没有任何时间臂超过 T-null”不符合原始结果：T0 为 0.7164，T-null 约 0.6960；P0.10–P0.12 新增锚定臂未超过这个基线。
2. “跨帧相关 0.96 证明几何可预测性天花板”不成立；它是跨相位的关联，不能识别不可约误差。
3. “其他帧没有新观测，所以 Transformer 理论上无效”混淆了信息量与学习方法；没有新增信息仍可能改变归纳偏置、正则化及有限样本效率。

T-null 的 0.4613（阶段 2）与 0.4616（缓存探针/r3 历史参照）是轻微口径差异，不能把同一基线写成精确相同的数。早期 D2 的 0.4535 又用了不同汇总/预测来源；本表不混用。

**同期四臂是最清楚的结构对照。** r3 的 12 份实际指标/历史记录与验收一致：各臂 120769 参数、同折相同初始张量与输入统计、同一 context、1800 次更新，均选 last。`noattn` 是相同 Transformer 加对角 mask，测的是跨帧交互的增量。它不是无参数对照，也不是普通小 MLP；对角条件下 Q/K 不再产生跨帧权重变化，名义参数相同不意味着完全相同的有效计算能力。

**跨批次数字只能定位实用性能。** C-raw 训练点序列预算为 4000×8×2048，r3 为 1800×4×1024，前者约 8.9 倍；T0 端到端训练 400 epoch，按 train-loss EMA 选 best，r3 为冻结缓存选 last。TL-random 的 stem/sa 是随机且冻结，仅解冻后段，不等价于充分训练的从零端到端基线。不能据此做“Transformer 天生差”或“预训练必然优于从零训练”的结论。

**形态收益要保留。** 全注意力下 warm 对 raw：时序相关 0.8496→0.8533，ln 幅值误差 0.5861→0.5460，峰时误差病例内 P90 的均值 8.947→8.754 帧；对角组方向一致。但 Pa 主指标没有随之改善，且 ln 改善不能直接当成低 WSS 区域改善。一个 seed 未估计当前配置的随机性，不能用别的实验“±0.04”宣布等效或落在噪声内。

体场线提供的旁证也有边界：PT0 的 best/last 全周期为 0.4771/0.5335，差异主要来自 fold0 的选模不稳定；PTB8/16 约 0.539，却牺牲峰值约 0.05–0.06。速度臂未得到推进依据。体场的 T-null/peak_freeze 使用**真值峰值场**，WSS 的 T-null 使用**预测峰值场**，两者不能合成同一种可部署基线，更不能据此证明速度的可预测上限。

## 3. 老师的思路在当前数据上实际是什么

刚性壁 CFD 中几何不随 81 帧变化。编码器只需运行一次，重复编码同一几何不会产生新动态观测。相位输入为 `(q_norm, dq_norm, sin, cos)`，来自所有病例共同的协议波形。

实际 r3 的数据流是：

```text
逐点几何/隐藏特征 → 点投影 → 1024 个 context 点均值 → 一个病例几何向量
                                                        + 81 个相位编码
                                                        ↓
                                               81 个时间 token 做注意力
                                                        ↓
逐点特征 ─────────────────────────────────────→ 逐点解码残差
                                                        ↓
                                             T-null + 峰值锚定差分
```

所以时间模块没有直接看到每个局部部位的流动演化；它先产生全病例共享的时间上下文，再由逐点解码器使用。这是一个可用的小模型，但对瘤腔、狭窄射流、分叉回流等不同局部时间响应，归纳偏置可能偏弱。逐点信息仍在解码器里，不能说整个模型完全丢掉了局部信息。

对于固定波形、已固定或由几何确定的边界条件和充分发展的周期状态，目标可以写成 `τ(x,t)=F(几何, x, 相位)`。几何不同仍可产生不同相位滞后、反向时段和 WSS 波形。求解 CFD 所需的内部速度/压力状态，不必作为监督代理模型的额外输入；代理可以直接近似这个解映射。相位查询 MLP、低秩解码器和 Transformer 都是可能的表示方法。

完整周期的相位/规定入口波形在推理前已知，非因果 attention 本身不构成未来标签泄漏。它对应全周期条件生成；若以后改成在线状态预测，才需要另外定义因果输入和评估协议。

## 4. 数据与机理的真实限制

**单一驱动的限制主要是泛化范围。** 现有数据无法检验新心率、新入口波形、新流量幅值或真实患者专属出口条件下的响应。增加同一周期的帧数增加监督密度，却没有增加独立的几何或边界条件样本。v5.2 已有 261 个病例单元、202 个患者组的 CV5，每折训练 206/204/211/211/212 个病例单元；当前这些时间实验仍是 v5.1。峰值模型随数据增多而改善，不能直接当成时间模型已改善的证据。

**RCR 的情况比“缺失患者状态”更具体。** 已有出口审计显示，大部分 R1/R2/C 由出口面积及共同协议公式生成，分流规则为 Murray r³。因而未显式输入 RCR 不等于该信息独立于几何。需要先核对部署几何是否保留相关出口尺寸、模型是否有效表示全局分支、队列协议差异/遗留例外是否仍存在。审计记录还包含不同队列公式常数与少数异常，不能反过来断言全部边界条件已由当前 27D 特征完全确定。仅凭这些材料尚不能定量分摊隐藏边界条件、几何表示、标签误差各自造成多少损失。

**减速/谷底确实更难，但不是“低值天然不能学”。** 真值诊断显示，峰值窗到谷底：与峰值场的空间相关 0.950→0.418，相对峰值方向反向的点份额 0.030→0.404，小尺度空间方差份额 0.240→0.374。只匹配到的一对相近入口流量相位，真值峰值场相关在加速/减速分别为 0.817/0.355，符合惯性滞后、流动分离和回流改变空间结构的解释；一对匹配不能代表整个参数空间。

这些证据说明简单“峰值图 × 流量”的近似不足，也提示局部空间结构需要更好建模。`c_peak` 是与真值峰值场的相关，`c_murray` 是与一个简化几何先验的相关；二者都不是完整几何包含信息的测度。跨 81 帧的 Spearman 0.961 还有强时间相关，不能作为因果证据或全模型的预测天花板。诊断中的 `r²_fit` 与主表未经重标定的 Pa `R²_cb` 也不是同一指标。

**时间基 oracle 说明可压缩，不说明可预测或不可预测。** K=8 的谷底重建 R²=0.9738，是把留出真值投影到训练折时间基、得到真实系数后再重建。它说明时间形状可用少量模态表示；实际模型还必须从几何预测每点系数图。现有 TB 失败说明这一步与训练配方尚未做好，不能推出系数原则上无法由几何预测。

**数据质量与目标定义应先处理。** 既有 5 例抽查中，2 例周期首尾同相位的 |τ| 相差 14–16%，另 3 例逐位一致；这是探索性检查，不能外推成全库比例，也未排除导出/帧身份原因。81 帧含两个周期端点，等权均值与梯形积分的单点 TAWSS 最大差为 6–11%（同一小样本）。应先审计稳态/导出和积分合同，再添加硬周期一致性约束。标量 WSS 与向量模长中位接近但近零点相对误差较大，训练目标还有 0.05 Pa floor，需对低 WSS 与方向任务分别审计，不能笼统称逐点严格一致。

**损失与主指标不完全对齐。** 当前优化逐帧标准化 log MSE，主指标评估未裁剪 Pa。log 空间的小误差经指数变换会在高值端放大；训练 loss 更低不必对应 Pa R² 更高。谷底相关性也明显下降，所以只做幅值校准不太可能解决全部问题。

**标量 WSS(t) 无法唯一确定 OSI。** 相同的幅值序列可以全程同向，也可以半周期反向，OSI 会不同。若需要从时间模型积分得到 OSI，必须引入向量/方向信息；若只交付 OSI，可继续直接回归其标签，两条任务的成本与证据要求不同。

03 块在 09-25 已完成平均向量派生/辅助头 V1 与反向份额辅助头 V2，均未通过其门槛；这不是完整逐帧向量 WSS 模型，但足以提醒“加方向辅助就会提高 OSI”并无现成依据。完整向量路线应由输出需求驱动，不能仅为换结构重开。

## 5. 优化优先级与可区分的实验

| 顺序 | 建议 | 用来区分什么 |
|---|---|---|
| 1 | 统一帧身份、周期首尾、标量/向量与积分定义；历史成绩保持原口径，新协议对所有对照一致重建 | 标签/评价问题与模型问题 |
| 2 | 同一稳定数据版本、同折峰值供体，重建 T-null、C-raw 式锚定 MLP、对角 Transformer 和全注意力 Transformer；先配平训练暴露量并报告耗时，作小规模预算敏感性检查 | 结构收益与历史预算/选模差异 |
| 3 | 保留峰值锚；在便宜头上先检查 log/Pa 目标取舍、相位与区域误差，再比较少量 loss 改动 | 幅值校准瓶颈与空间形态瓶颈 |
| 4 | 若帧级场确有交付需求，比较“全局 context/局部 patch context × 对角/跨帧注意力”的小矩阵；共享同一解码器与预算 | 局部表示的收益与时间 attention 的独立收益 |
| 5 | 目标包含反向/OSI 时，再做向量输出及周期指标一致性；一般化到新驱动时，补多工况数据与可获得的条件输入 | 输出信息缺失与输入工况覆盖不足 |

峰值锚可保持已有形式：

`ln τ̂(x,t) = L0(x,t) + R(h(x),φ(t)) − R(h(x),φ(t_peak))`。

它在数值容差内保证指定峰值帧与供体相同，但也锁定了供体误差，不保证每个点真实最大 WSS 的时刻/幅值正确。下一步首先保留这个便宜、清晰的工程约束。

低秩方案若复议，建议预测**锚定残差系数**，而非原 TB 从头同时重建整个周期：`R(x,t)=Σ a_k(x)[b_k(t)−b_k(t_peak)]`。先核查残差的训练折基、留出 oracle 与可预测系数，不能直接把原全场 K=8 当成残差最优 K。它是一个待验证的低成本候选，不是由高 oracle 分数保证成功的方案。

局部 token 可沿血管/分叉/瘤腔保留位置和邻接，让不同部位拥有自己的时间上下文；空间交互与时间交互可分开计算，避免把全部点×81 帧展开成巨大 attention。这里值得检验的是“网络能否利用局部、上游和分支几何解释不同时间响应”，而不是单纯增加层数。若改局部 token 后有效，还须由同局部 token 的无跨帧对照识别 attention 是否贡献收益。

损失上可比较训练折尺度归一的 Pa 项与 log 项、难相位权重、向量切平面误差等少量候选，权重与选模只在训练/内层验证确定；更大权重可能损害其他相位，需报告取舍。周期平滑/首尾一致性只在数据确认支持时加入，不能把真实快速反向或未收敛标签强行抹平。

当前仓库另有基于几何与共同波形的 Womersley/Carreau 物理先验路线。若把它扩展为逐帧模板，可作为便宜的结构化基底候选，与 T-null 做同合同对照；其直管近似不能保证描述瘤腔回流，现有峰值结果也不能冒充全周期收益。

若只需要峰值、TAWSS、OSI，优先验证直接多头路线即可，无需为三个汇总量先重建全部 81 帧。若研究目标是帧级场，则主指标应预先包含全周期/减速谷底 Pa R²、峰值保持，辅以 MAE、形态/方向误差及病例区域分布。

## 6. 下一轮的证据标准

- 使用实际可部署输入。RCR、真值速度/压力和后验分流不因分析建议而自动加入；先审计它们是否有可从几何推导的协议成分。
- 按患者/重复几何分组；同一病例全部帧与同源变体留在同一折。至少用多 seed 检验成对差异，不把三折当三次独立训练随机性验证，也不把 81 帧当 81 个独立样本。
- 统一归一化、峰值供体、采样、query 序列预算与选模规则。若补新 donor，所有同期对照一起更换，不能用旧 v5.1 T-null 给 v5.2 设门。
- 保存病例/相位/区域误差与代表点轨迹，定位均值收益是否来自少数病例。病例配对不确定度与 seed 波动分开呈现。
- 在内层训练/验证协议选模型；已多轮暴露的 cv3、test34 与回收病例不能称作未触碰外部确认。扩数据后的峰值表现不能直接外推到时间任务。
- 是否继续由帧级用途与预先定义的实际改善门槛决定。当前证据不足以优先扩大 Transformer，也不足以永久关闭所有几何条件时间模型。
