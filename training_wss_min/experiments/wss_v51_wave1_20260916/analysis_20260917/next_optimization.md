# v5.1 后续优化建议（2026-09-17）

当前保留 **X5D_v51 五 seed、Pa 均值集成**。下一步优先验证协议版 cap 的患者分组泛化，并围绕 ILO 极端病例和区间内部局部形态寻找增益；不再扩展已经否定的 T3n，也不把双尺度/噪声增广当作正常部署精度升级。

本次只读既有配置、指标与预测缓存，新增 CPU 汇总；未训练、未模型推理。复现：[脚本](analyze_current_residuals.py)、[完整诊断 JSON](current_residuals.json)。以下实验均为建议，未启动。

## 证据合同

- 数据 v5.1，train136/test34；峰值 WSS 标量，Pa 主指标，`legacy_vertex`；`ckpt_best` 来自 train_loss/top3，并非验证集选模。
- test34 底座 seed = 1234/7/2025/11/2026；cv3 每折只有 seed1234、训练例数 90/90/92、留出 46/46/44。Pa 集成按预测 Pa 均值；结构诊断另用 log_z 均值，不把两者混为同一预测。
- cv3 患者交集核对为空；目标统计中的 train_units 与对应折训练集合相等，特征统计按该折 train 分区计算。实际 run 保存的统计与源文件一致。
- 0.7749（test34 五 seed）与 0.7100（136 例折外、单 seed/折）的差混有训练量、集成、病例构成；不能据此直接估算过拟合或五 seed 的新病例精度。test34 已多轮暴露，cv3 也已经用于筛选，均不是新的独立确认队列。
- 缓存复算逐个核对 5 个全训练 run 与 3 个折 run 的 Pa R²_cb、正式 high-WSS R²；ensemble 各 seed 的 row_index/真值逐点相同；136 例折外每例出现一次。

**“局部型态仍难”现在有 v5.1 折外证据。** 4 mm 区间是“分支 ID × 轴向区间”，区间内部包含轴向变化，70.13% 不是纯周向误差份额，也不是 Pa SSE 份额；它支持进一步诊断局部空间结构，不能单独证明某个架构必然有效。分支均值残差份额中位数仅 8.15%，继续只加强分支/截面整体尺度的预期较小。

ILO 有 32 例，三折组内 R²_cb = 0.7653/0.5346/0.6801；整体下降集中于少数高幅值病例，不能概括为全部 ILO 都失败：

| fold1 病例 | Pa R² | 真值 P99 / Pa | top10 幅值比 | top10 IoU |
|---|---:|---:|---:|---:|
| ILO/WANG_JIN_MING-0/before | 0.3752 | 106.87 | 0.2997 | 0.3256 |
| ILO/ZHAO_CHANG_SHAN-0/before | 0.4499 | 75.46 | 0.4263 | 0.3807 |

两例 MSE 合占 ILO 病例等权平方误差的 **52.16%**，占全 136 例的 **21.82%**；各自高 WSS 区占自身平方误差约 93.15%/85.02%。这既有幅值低估，也有热点形态/定位不足。应检查这两例及同类几何的近狭窄、分叉和下游热点，不能通过删掉病例改善报告，也不应直接给整个 ILO 队列增加统一权重。

队列中位数不能替代难例机制：上述两例的分支均值残差份额仍有 **35.13% / 13.99%**，区间内部份额为 **50.30% / 64.85%**。因此应同时检查逐支尺度与局部热点；“总体局部残差占70%”并不意味着最难病例只剩局部问题。

## 后续顺序

### 1. 协议版 cap 先做 cv3，再决定补五 seed

同 seed 三组 cap 相对底座 ΔPa R²_cb = +0.01491/−0.00937/+0.00282；均值 +0.00279，样本 SD 0.01214。归一化三组全正，pooled MAE 分别降低 3.66%/3.79%/1.39%，热点 IoU 增加 0.01793/0.02036/0.00604。三 seed 集成 0.777045 vs 0.773582，净增 **0.003463**，尚不能称为稳定的物理主指标改善。

建议新增 **3 个 cap 折模型，seed1234**，沿用已有 cv3 划分、初始化与评价合同，对照已有 wave2a 三折底座，折内重算目标/特征统计。先看合并 Pa R²_cb，再看 MAE、热点 IoU、病例 P10 和 ILO，保留全部逐折/逐例结果。若整体与保护指标共同支持，再补 seed11/2026 检查部署五 seed 集成。若只有 MAE/IoU 改善，按目标权衡记录，不能以此宣称 R² 底座已被替代。数值晋级门槛应在启动前冻结，此处没有事后定义通过线。

这比先补两个 test34 seed 多解决一个问题：病例泛化。补 seed 主要减少训练随机性/集成构成的不确定性。

**术语澄清**：当前 X5Dcap 输入为 `log_q_branch_murray_cap/log_tau0_murray_cap`，使用盖面半径 r³ 的 Murray 份额，没有拟合参数；旧 X5A 才是 train138 拟合的 capfit。旧 v5.0 的 ILO 分流解释度 0.65–0.67 不是修正数据上的理论上限。

### 2. 主要新方向：在 query patch 中保留局部空间结构

现有 K16 query patch 是逐邻居 MLP、共享 FiLM、mean 池化、线性输出，含相对坐标但没有显式邻居间交互（`training_wss_min/local_refinement.py:240`）。X7/X8/X9 试过坐标架/标量注意力池化/K32，X11 试过截面均值 token；这些结果不等于已经检验了保留周向分区后的局部交互。

先用当前折外缓存检验：残差是否形成稳定的空间斑块、热点偏移是否沿流向、周向低阶模态在患者分组验证下是否仍可解释。真值只参与诊断和训练监督，不作为部署输入。只有出现对应信号，才做一个小改动候选：**轴向 × 周向分区 token，保留位置后做少量局部交互，再汇总到 query**。固定现有先验、损失与密度增广，配对已有底座；输入仍只用部署可得的表面和中心线。零初始化新增分支并不替代训练后验证。

若主要剩余是幅值偏差而缺少稳定空间结构，应转向有界、病例均衡的幅值目标实验，而非直接上该结构；过去 Pa-MSE/加权/排序/近邻差分等已有失败记录，不能原样重扫。第二种更远的候选是保留周向相位的上游几何条件，但必须先证明其超出局部信息的折外解释力。

### 3. 暂不投入的方向

- T3n：test34 三 seed 全负，cv3 三折全负、合并 −0.020，停止推进原配方。
- 双尺度 patch / 噪声增广：保留针对粗点云/噪声表面的用途；在现行约 0.5 mm 重采样、1 mm 平滑条件下，没有一致的净精度收益。
- 继续加 ensemble 数量：底座三 seed 0.7736 → 五 seed 0.7749，当前边际收益有限；保持已有五 seed 即可。
- 速度→WSS、大范围加深加宽/全局注意力：现有证据不支持作为直接 WSS 主线的优先投入。
