# X5D 与 WSSNet 的空间 Pearson 相关系数对照

日期：2026-09-21。仅汇总已有预测缓存，无训练、模型推理或 checkpoint 重选。

## 计算口径

- v5.1，峰值步 1162，WSS 幅值的 **Pa 空间**。输入为既有 `eval/ckpt_best/predictions/test/**/predictions.npz` 的 `true_pa`、`pred_pa`。
- 每例在全部已保存壁面点上计算 `np.corrcoef(true_pa, pred_pa)[0, 1]`，再对病例的 r 做算术平均；± 表示病例间样本标准差（ddof=1），不是置信区间。
- 壁面点采用原评估的 `legacy_vertex` 权重，不是面积加权；没有 log 变换，也没有先校准预测。
- 五 seed 为 1234/7/2025/11/2026；确认病例、真值、`row_index` 完全一致后，在 Pa 空间逐点算术平均，再计算 r。
- 三折采用每折 seed1234 的留出预测，46/46/44 例合并，每例只出现一次。三折配置按患者分组。
- 读取实际 run 配置确认数据根、目标与单标量输出。八个 run 的物理病例等权/pooled 预测 R² 与原 `metrics.json` 一致（误差 <1e-8），Pearson r² 与已有拟合 R² 一致；集成与三折合并 R² 也复现旧离线报告。

主表的 r 是逐病例空间相关的均值，不能由表中预测 R²_cb 开平方得到。辅助聚合口径如下：

| 配置 | 对全场按病例等权计算一个 r | 拼接所有壁面点计算一个 r |
|---|---:|---:|
| 五 seed 集成 | 0.8875 | 0.8696 |
| cv3 合并折外 | 0.8460 | 0.8329 |

这两列回答跨病例全场相关性，不替代逐病例空间模式的主口径。对应拟合斜率、截距、MAE 和预测 R² 均保留在 `summary.json`，不以相关性代替幅值准确性。

## 与论文的关系

Ferdian et al., *WSSNet: Aortic Wall Shear Stress Estimation Using Deep Learning on 4D Flow MRI*, 2022，DOI：[10.3389/fcvm.2021.769927](https://doi.org/10.3389/fcvm.2021.769927)。PDF 第8页说明逐帧计算 WSS 幅值的空间 Pearson r；第10页 Table 1 报告 6 个 CFD 验证/测试病例、每例72帧，r=0.92±0.05。第10页和第13页 Table 2 报告 2.4 mm 合成 MRI 加噪声时 r=0.79±0.10。

本分析对齐了“物理 WSS 幅值、逐例空间相关”的定义，但 X5D 仅有峰值帧，不能完全复现论文全周期的相位组成。病例集合、解剖区域、CFD、空间采样和输入信息均不同；不作统计显著性或模型优劣结论。test34 已用于开发筛选；cv3 也已参与方法筛选，并非新独立确认。0.8975 与0.8665之差含训练量、病例组成、集成等混杂，不能单独归因于过拟合。

X5D 的27维输入由几何、中心线与解析 Murray 参考特征组成，不需要实测近壁速度，因此在数据获取和推理部署上比需要4D Flow MRI速度的 WSSNet 更方便。它仍需几何分割/表面处理/中心线和特征构建，其预测适用性受训练CFD边界条件分布约束；相同几何下未作为输入提供的患者流量变化不能被主动区分。这里的便利性不是已测得的端到端耗时优势。

## 产物与复现

- `analyze_pearson.py`：只读原预测缓存并输出本目录的复算脚本。
- `summary.json`：实际 run 路径、协议、各聚合口径和核对结果。
- `per_case_pearson.csv`：逐病例 Pearson r、原始预测 R² 和点数。

在仓库根目录运行：

python3 training_wss_min/experiments/wss_v51_wave1_20260916/analysis_pearson_20260921/analyze_pearson.py
