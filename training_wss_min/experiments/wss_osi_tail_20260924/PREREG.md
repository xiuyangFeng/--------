# OSI 尾部矩阵（wss_osi_tail_20260924）——预注册

来源：跟踪 §34.11（09-24 零训练探针）：OSI 误差 43% 在真值 ≥ 0.3 的 12.5% 点上，是幅值压缩（真值 ≥ 0.3 的点预测均值 0.24）；分辨率不是瓶颈；体场特征无增量。用户 09-24 指示在 node04 空余显存上做实验；P0b 阈值部署暂不做。

## 设计
底座 = 已部署模型族 M1 三头（`configs/wss_cycle_m1_20260921/M1_f{k}_s1234.json`），cv3_v51 三折 × seed 1234，每臂只改一处，配对初始化与 M1 相同（参照 = 同折 X5D_v51 配置）。

| 臂 | 唯一改动 | 机理 |
|---|---|---|
| M1r | 无 | 同硬件对照；与已存 M1 的差 = node04 对 master 的硬件/非确定性抖动 |
| K1 | `loss_osi_mask_lambda=0.1`，OSI > 0.2 / 0.3 软掩膜 BCE，温度 0.25（归一化 z） | 直接惩罚阈值两侧判错，推高真高 OSI、压低真低 OSI |
| K2 | `loss_osi_tail_alpha=2.0`，OSI 通道平方误差 × (1 + 2·1[OSI > 0.2])，批内均值归一 | 让高 OSI 区的误差更贵，对抗向均值回归 |
| K5 | 追加 8 个分离相关几何输入（F3 上游历史 5 个 + bif_angle_cos + carina_cos + log_r_over_rdistal），新列零初始化 | P0c：主要缺口在粗尺度信息 |

超参先验写死，不做 λ/α 扫描；K1 若方向对再议第二个 λ。

## 执行
冻结副本 `GNN_osi_tail_frozen_20260924`；node04（2×A100-40GB，Slurm 之外）用 `tools/run_local_train_queue.py`，每卡 3 槽、派发前要求空闲显存 ≥ 9000 MiB；每臂 train（400 epoch）→ eval best → eval last，全部 `--save-predictions`。预检：锚点重评（M1_f0 best，新代码，输出到新目录，与已存 metrics 逐字段比）+ 各臂配对构造 + 2-epoch 冒烟。

## 读数（只读各臂留出折；test34 不用）
逐臂三折留出均值，对照 = 同折 M1r（同硬件）。指标脚本复用 `experiments/wss_cycle_osi_probe_20260924/offline/p0_common.osi_summary`。

- **主指标**：OSI IoU@0.3（原始阈值 0.3）、OSI R²_cb。
- **校准后指标**：每臂用其余两折的本臂折外预测在训练折上标定 > 0.3 的预测阈值（P0b 的 thr_iou 法），再读留出折 IoU@0.3——用来区分「损失真的改善」与「只是把阈值附近整体抬高」。
- **护栏**：峰值通道、TAWSS 通道归一化 R²_cb 各 ≥ 同折 M1r − 0.01（三折均值）。
- 其余只报：IoU@0.1 / 0.2、滞留区 IoU、CCC 中位、面积份额误差、真值 ≥ 0.3 点的预测均值、分队列 R²。

## 判据
- **Go（进三 seed + test34 确认）**：原始 IoU@0.3 ≥ M1r + 0.03 且 3/3 折同号；校准后 IoU@0.3 ≥ M1r 校准后 + 0.02；OSI R²_cb ≥ M1r − 0.01；> 0.3 面积份额误差不劣于 M1r + 0.02；两个护栏都过。
- **只改标定（不值得换模型）**：原始 IoU 过门但校准后 IoU 不过。
- **No-Go**：原始 IoU@0.3 < +0.03 或护栏不过。
- 抖动：若 |M1r − 已存 M1| 的 OSI R²_cb 三折均值 > 0.02，所有 < 该抖动的臂间差按噪声处理。
