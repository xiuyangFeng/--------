**归一化 R²_cb 的增益从 2 列到 32 列基本是平的**（+0.0060 / +0.0063 / +0.0065），全部落在归一化 seed 噪声带（±0.004）内。
物理 R²_cb 看似随列数递增，但**全 32 列的 s1234 恰是它三 seed 里最高的那个**（三 seed 0.7705/0.7564/0.7566，均值 0.7612）；
把参照取成三 seed 均值（Δ +0.0049）后，**所有剪枝档都不低于它**。
阶梯还是非单调的（L8 好、L5/L2 差、L1 又好），这本身就说明**各档之间的差别由运行噪声主导，不是信息量差别**。

这正是 §29.7 预测的机制：列越多、缺失点越多，模型在缺失区付的容量代价越大。

## 4. 结论：保留 `geom_ref_roundness` 一路（2 列）

| 判据 | 证据 |
|---|---|
| 归一化增益 | 2 列 +0.0060 ≈ 32 列 +0.0065（差值在 ±0.004 噪声带内） |
| 折外边际增量 | roundness 单独 0.00250，占 16 通道天花板 0.00473 的 **53%**，排名两个半分都第一 |
| 覆盖率 | **0.788**，全阶梯最高（全 32 列只有 0.651） |
| 缺失区代价 | 唯一为正（C +1.34% / D +1.86%），其余各臂都是 −1.3% ~ −4.6% |
| 全场 ln-MSE | **+3.74%**，优于全 32 列的 +3.07% |
| 新颖度 | 被原 27 维线性预测的比例只有 0.18（log_area 是 0.984） |
| ref/pc 重复 | roundness 是唯一不重复的字段（corr 0.726，其余 0.93–1.00） |

**保留集 = `geom_ref_roundness` + `geom_ref_roundness_valid`（2 列）。**
备选 = L8（ref 8，16 列），只有在后续证明确实需要高 WSS 尾部时才值得（high-WSS 0.373 vs L1 0.359，
但这个差仍在全 32 列三 seed 自身的 0.341–0.415 区间内，单 seed 分辨不了）。

## 5. 与下一步（局部形态优化）的衔接

roundness = 截面圆度，本来就是**截面内型态的粗粒度代理**；
§28.9 已确认 70% 的残差在"分支 × 4 mm 区间内部"，即截面内型态。
所以这轮的结果可以这样读：**沿程这条线上真正有用的那点信息，本质是截面形状而不是沿程尺度**，
沿程方向可以收口了；后续应该把力气放在截面内型态的细粒度表征上，而 roundness 作为 2 列的先验一起带走。

## 6. 口径与限制

- 单 seed；配对 Δ 的噪声带 ±0.014（物理）/ ±0.004（归一化）。各档之间的物理 R² 差别**不可分辨**。
- 结论依据的是三条互相独立的证据（折外边际增量 + 覆盖率 + 同桶 ln-MSE），不是单靠 test34 的 R² 排名。
- 若要把 L1 提为正式候选进底座，仍须补 seed 并过 cv3 折外（§28.7 的 T3n 教训）。
