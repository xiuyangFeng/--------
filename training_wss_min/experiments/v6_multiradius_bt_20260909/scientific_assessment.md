## 4. 分支有学习变化，但不等于有贡献优势

MS4的三块融合权重Frobenius范数为 **5.636 / 17.725 / 8.264**，起始为 **0 / 16 / 0**。三支attention γ为 **0.01475 / 0.06351 / −0.02458**，FFN γ为 **−0.03325 / −0.18619 / 0.17022**，都已偏离0.001。八例训练集诊断中三支token RMS均非零。没有依据把这次阴性物理结果解释成“外侧分支一直停在零初始化、没有参与学习”；范数和γ也不能用于声明各尺度的因果重要性。

八例MS4注意力熵均值为 **0.128 / 1.076 / 0.227 nats**，相对32token均匀分布的log(32)=3.466明显集中；注意力加权欧氏距离均值约 **106 / 114 / 124 mm**（包含自身权重，非沿中心线距离）。它描述对少量远处token的集中选择，不能直接称为获得了更有效的血流信息，也不能仅凭此诊断定义“注意力坍塌”。

MS6的RMS来自FFN之后；三支FFN γ约 **0.0583 / 0.1748 / 0.2254**。MS4/MS5参数相等，MS6全模型仅少333参数，容量差约−0.0114%。分支诊断checkpoint的SHA均与独立best分析一致。

## 5. 建议

**保留原M2作为物理主指标基线，暂不自动展开MS7–MS9。** 完整MS4方案未超过M2，也未胜过相同容量的重复半径或近容量逐token对照，按这轮预定问题还不足以支持继续扩大独立BT/共享BT/门控融合组合。MS3可作为较简单的热点定位候选保留；MS4可作为MAE候选保留，不能替换物理主模型。

若后续重新研究老师方向，应围绕明确的新假设安排，而不把更多分支或Transformer默认视为进步。几何G/M6仍待用户验收，不由本轮结果解除。所有结论限于单种子和已暴露test34；best/last是相关checkpoint，不能作为两次独立重复。
