# X5D 后续优化方向与证据核查（2026-09-15）

本次回应“X5D 后还有什么优化方向”。读取已有训练、密度扫描与预测缓存，补做同点残差汇总；没有新训练或模型推理。以下为研究建议，不是已启动的实验矩阵。保持壁面点云＋中心线可得量作为部署输入。

**建议顺序：先验证固定毫米范围的全壁面 patch，再验证密度一致性；提高正常密度精度时，优先考虑 X5D 条件残差细化，之后才是保留周向位置的局部结构。** 现有证据支持 X5D 提高采样鲁棒性，但主要精度瓶颈基本未变。

## 1. 本次新增：X5D 的精度瓶颈仍是截面内型态和高值收缩

读取 X5/X5D 相同 seed 1234/7/2025、`ckpt_best`、test34 全壁面缓存；best 为 train-loss 选模，非 validation-best。数据为 V5 train138/test34，`legacy_vertex`，每例点等权。逐 seed 的 Pa R²_cb 与原始 `metrics.json` 一致，跨 seed/模型真值及 `row_index` 逐位相同。脚本按缓存行索引读取几何，未用位置猜测对齐。

来源：[缓存汇总 JSON](cached_residual_analysis.json)、[复现脚本](analyze_cached_residuals.py)。JSON 含六个 run 的原始评估路径、34 例结果与指标定义。

## 2. 候选优先级与最小区分证据

| 优先级 / 目的 | 具体改法 | 现有依据 | 最小验证与风险 |
|---|---|---|---|
| **1：进一步降低密度损失** | 全壁面 query patch 改为固定毫米范围；范围内覆盖或分层取点，保留 token 上限，稀疏处用有效点 mask | X5D 在25%抽稀下，重算特征损失−0.068，冻结仍−0.061；当前 patch 为含 self 的K16 | 与同期X5D做3个配对seed；先只改patch，保持support方向分支、曲率、损失与宽度不变。检查实际半径、邻居数、cap饱和率和稀疏mask |
| **2：降低同一表面不同采样的预测漂移** | 在现有监督上加入成对密度视图一致性；粗/密云共享保留节点时约束同点预测，进一步覆盖局部非均匀抽稀 | 现增广只有整例70/50/35/25%四档、p=0.6；1.2 mm STL仍损失约0.047 | 先保持抽稀分布不变，只加低权重一致性，随后才单独改采样分布。粗视图不能把密视图热点拉平；可用停止梯度的密视图教师，Pa/log指标和IoU共同保护 |
| **3：提高高值与正常密度精度** | 在X5D上验证全域条件残差细化（T3n思路），验证残差收缩或基座混合 | 旧T3n−X5三seed Pa增量−0.003/+0.019/+0.027，均值+0.014、sd0.016；但归一化全负、多数病例变差 | 必须用患者组折外一阶段预测训练二阶段；嵌套CV避免二阶段看到拟合过本例的一阶段预测。先确认尾部收益，不原样重做T3硬门控；两阶段训练/部署成本更高 |
| **4：突破截面内型态瓶颈** | 全分辨率局部残差分支保留沿程s与周向θ位置，例如周期周向窗口或沿壁面局部图 | 本次X5D残差份额69.56%、型态R²0.5999；整截面token X11没有稳定整体增益 | 先检查周向/局部空间残差结构，再选择架构；显式处理θ周期、分支相容与分叉，防止跨壁混邻。优先级低于上面可直接复用的候选 |
| **并行：验证部署输入与泛化** | 检查局部覆盖、表面/中心线/切口误差敏感性；补X5D患者分组CV并逐例检查密度退化 | 当前STL实验只改变同一表面的点采样；仍有个别病例在0.5mm下降约0.1 | 同几何采样不变性与真实几何改变分开。几何扰动会改变真实WSS，原CFD标签只支持输入误差敏感性解释；真实新几何精度需对应真值 |

**固定毫米 patch 的实施关键：** [next_geometry.py](../../../next_geometry.py:109) 先做KNN，再把相对坐标乘尺度变成mm；这还不是固定物理范围。[local_refinement.py](../../../local_refinement.py:211) 使用固定K和mean pooling。仅改为“半径内最近16点”，在密云cap饱和时仍会缩小实际范围；复制self补齐也会改变中心点权重。应复用现有树和FiLM，改变范围内采样与有效点聚合。半径从train138的真实邻域分布确定，不能用test34最优档反推。

support方向分支目前是归一化球邻域＋点数上限，不是纯KNN；可在patch验证后独立测试物理尺度。历史E5的2.5/5 mm＋0.5R发生在另一底座的support分支，Pa较同期对照下降0.0138，说明毫米尺度并非必然有效，也未否定当前全壁面patch假设。曲率虽然输出物理单位，但拟合仍是K32/K128；X5D已消掉大部分重算误差，暂不应同时重写曲率。

密度方向第一批建议只保留三臂：同期X5D、仅物理patch、仅密度一致性，各3个配对seed；若两项分别有支持再组合。精度方向另立T3n复核，避免把尾部取舍和密度改善混在一起。以上是建议，未执行。

## 3. 先统一验收，再决定是否晋级

- 全密度、CFD抽稀100/50/25/10%、STL中位间距0.5/0.8/1.2 mm分开报告；每档对同点全云参照做差，不能拿不同点集的绝对R²当增益。
- 固定相同seed与Pa均值集成；同一Pa预测转回log_z计算归一化指标。原日志中log均值作为诊断保留。主指标之外同时看病例MAE/P10、逐例胜负、AG/AAA/ILO、top10幅值与IoU。
- 25%与1.2 mm档的目标是缩小既有损失，同时保护全密度/0.5 mm和热点；具体通过阈值需在新实验启动前按用途冻结，本次不补造预注册门槛。
- test34已被反复用于开发。新超参在训练内部固定验证协议上确定；既有cv3也已有方案比较暴露，只能作为更强内部复核。若要声称独立泛化，仍需未参与选择的患者数据。
- wave6b补seed11/2026已启动：本次本地读取的`queue_status.json`记录job14283、2026-09-15 14:03启动、两臂仍为train；history已超过220/400轮，尚无评估。应在完成后验收五seed，不重复启动。

## 4. 不值得原样重做的方向

继续Murray指数/狭窄列、capfit替换、X11截面token、全局校准、PF6预测压力梯度、普通Pa-MSE/Huber权重扫参，以及仅把patch转切平面/加attention/增K，都已有零效应、负结果或明显取舍。它们不是被证明在任何底座上都无效，但缺少比上述候选更强的新机制依据。扩大骨干或增加全局Transformer也没有直接对准本次定位的局部型态瓶颈。

T3n证据直接取自[原始配对报告](../../wss_local_wave5_20260913/offline/analyze_wave5.json)；X11、分流与历史局部结构见[训练跟踪§18–22](../../../../docs/02-推进与变更/WSS_PINN/WSS_V5_训练实验跟踪.md)。

## 5. 对原§22措辞与比较口径的补充

1. **采样间距不等于分割分辨率。** STL模拟使用同一源表面及原有atlas/中心线，仅重建点特征。1.2 mm点间距的成功不能直接证明1.2 mm临床分割可靠；把粗表面加密也不能恢复已经丢失的几何。
2. **0.5 mm是全云中位间距建议。** 采样程序没有验证“处处不粗于0.5 mm”；还需局部孔洞或高分位覆盖检查。
3. **剩余误差不能唯一归因为邻域半径。** 冻结特征仍会改变support覆盖、编码传播、插值和patch；毫米patch是优先假设，不是已证明的唯一解决办法。
4. **原STL表为X5D三seed对X5五seed，且是log均值。** 从既有JSON提取共同三seed的单模型配对，0.5mm的Δ为−0.0174/−0.0032/+0.0054（均值−0.0051），1.2mm为+0.0825/+0.1196/+0.0653（均值+0.0891）。粗密度改善稳定；最密档差异不应确定解释为“容量代价”。
5. **high-WSS有两种区域定义。** 正式`evaluate._regional_field`先取各例p90再pool；密度和历史offline helper先pool所有点再取p90。因此两种high-WSS R²不能交叉比较。本报告优先使用定义一致的幅值比/IoU。
6. **正常密度归一化数字也须对应实际集成。** 原§22的0.7382/0.8720分别来自Pa均值的Pa R²和log均值的log_z R²；本次同一Pa预测的对应值为0.7382/0.8718，X5为0.7368/0.8684，主结论不变。
