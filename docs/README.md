### 当前结论（2026-09-15）

- V5 母库已构建 172 例，当前视图为 train138/test34 的峰值帧直接 WSS 任务；RCR 修复将影响 26 例（22 train、4 test），正式论文数据尚未重新冻结。
- X5D 五 seed 已完成。修正前开发集上，Pa 均值集成 R²_cb=`0.7465`，X5 对照=`0.7402`；来源是 [`five_seed_ensemble.json`](../training_wss_min/experiments/wss_local_wave6b_20260915/five_seed_ensemble.json) 的 `ens_pa`。不要把不明口径的 `ens_norm` 与该 Pa 集成拼写为同一成绩。
- 密度增广的主要开发信号来自粗采样稳定性：STL 同源采样模拟中，1.2 mm 档 X5D 的 log 均值集成 R²_cb=`0.7208`，X5=`0.6135`；真值来自最近 CFD 节点，不能称真实临床分割验证。
- PF6（压力）和 VF6（速度）是独立 single-head 模型，不是联合 PINN；其结果属于跨输出支持证据。历史 V1/V2/V3、旧 PINN、velocity→WSS 与外部 baseline 不与 V5 主表混合。
- 目前最优先级是 CFD 修复验收→刷新母库/统计/sidecar→修正数据重训与患者验证。提交作业或中途分流检查不等于最终标签完成。

## 维护规则

1. 新实验事实先写对应路线跟踪，再在推进记录文首补指针；策略变化更新总纲，导航只保留入口和边界。
2. 旧路线、失败实验和历史图件不删除，但必须标明日期、数据版本、开发/测试暴露和是否可进入论文主表。
3. 结果引用必须能回到 `data_version + split + seed + config + checkpoint 选择 + metrics 字段 + 原始路径`；图件另存 source data、脚本、病例选择、单位和色标合同。
4. 不把提交作业当成完成，不把单帧标量当成周期指标，不把点云插值外观当成精度，不把 geometry-only 固定 CFD 协议写成临床生理泛化。
5. 修改代码、配置或实验文档后更新对应推进记录；只修改汇报 PPT/PDF 不必追加代码推进条目。
