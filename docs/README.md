### 当前结论（09-24摘要；09-30补记完整三场周期结果；10-02同步数据、底座与部署）

详细表格与出处见[实验设计总纲 §1.1](实验设计总纲.md)。

- **数据**：RCR 出口面积修复已闭环 → v5.1 = 170 例（train136 / test34）；回收 91 个历史排除单元全部过门 → **v5.2 = 261 例**。09-30 库内 9 个边界条件不合协议的单元按协议重算后换入 → v5.2c 统一根；10-01 母库全量审计后合并为 **现行唯一数据版本 v5.2d**（`data_wss_v5/views_v5_2d_20261001` + `anatomy_pointcloud_v5_2d_20261001`，332 单元 = 273 真实 + 59 合成；HAN_JIAN_FU 重算、WANG_TIAN_QING-1/after 重建、16 例出口命名修正，见[母库全量审计 §11](./02-推进与变更/04-数据处理与CFD/_archive/04块过程文档_2026-10-02/母库全量审计_2026-10-01.md)；v5.2c 根目录已改名。以下括号内是 v5.2c 当时的说明：IND / CV5 / syn / full265 分区都在其中；旧根、旧缓存和库内 processed/ 已按用户批准删除；v5.2 / v5.2p4 上的数字标「标签修正前」，见[数据统一与旧版本清理](./02-推进与变更/04-数据处理与CFD/_archive/04块过程文档_2026-10-02/数据统一与旧版本清理_2026-09-30.md)、[标签核查 §6](./02-推进与变更/04-数据处理与CFD/_archive/04块过程文档_2026-10-02/库内标签问题核查_RCR挂错与入口除数_2026-09-30.md)）。
- **部署发布包（峰值 / 三头 2026-10-02 起，体场 10-03 起；wss_deploy v0.16.4）**：默认 `X5Dcap_asym2_v52d_3seed_20261002`（v5.2d 全量 265 例三 seed，峰值 WSS），三头 `M1cap_v52d_3seed_20261002`（峰值 + TAWSS + OSI），体场 `PF6_VF6_v52d_3seed_20261003`（10-03 起，v0.16.4；旧 v5.0 体场包已下线）。recover8 的 STL 走部署链路，同链路旧 → 新包峰值 0.830 → 0.854、三头 TAWSS 0.809 → 0.850（8 例，只作描述）。09-16 至 10-01 的部署底座 X5D_v51 五 seed（test34 `0.7749`、cv3 折外 `0.713 ± 0.006`）已下线，数字只作历史参照；v5.0 的 `0.7465` 已作废。见 [01 块跟踪 §42](02-推进与变更/01-X5D主线与新数据/X5D主线_实验跟踪.md)、[05 部署工具](02-推进与变更/05-部署工具/README.md)。
- **训练底座（2026-10-02 起）**：v5.2d 数据（母库全量审计后的版本）+ X5Dcap_asym2 配方。CV5（261 例患者分组五折）折外三 seed 均值 `0.7761 ± 0.0017`、三 seed 集成 `0.7926`；全量 265 例 → recover8（8 例）集成 `0.8393`。此前 v5.2 上的中途读数和选型过程见 [01 块](02-推进与变更/01-X5D主线与新数据/README.md)。91 个回收单元入库时读过预测并据此查因修数据，**不是未触碰集**；CV5 折外是开发口径。
- **已有的结论**：数据量仍是瓶颈（每翻倍约 +0.03）；精度主要来自输入信息（分流尺度先验）而非网络容量；X5D 对粗采样稳健，部署合同为「重采样 0.5 mm + 先平滑 1 mm」；TAWSS / OSI 直接回归可交付，三头已部署（10-02 起是 v5.2d 全量训练的 M1cap，recover8 TAWSS 0.849、OSI 0.542）；早期逐帧时间模型按原门槛多轮不过，不能代替下面新三场周期实验的判断。
- **09-30完整三场周期更新**：V5.2第二轮十次单seed实验全部完成，患者分组fold0/55开发留出单元/150轮/last/80相位。保留U0速度、P1相对压力、W1标量WSS候选，周期R²分别0.7480/0.9033/0.7911；P1对Ip周期MAE降低16.44%，W1对Iw周期R²提高0.0094，速度谷底尚未改善。TCN三段R²未胜FFN，PCGrad未恢复三任务共同收益。这是数据单元等权口径的内部筛选，非旧R²_cb、非临床或部署确认。见[结果分析](../training_wss_min/experiments/joint_cycle_round2_v52_20260929/analysis_20260930/analysis.md)与[时间建模记录](02-推进与变更/02-时间建模/时间建模_实验跟踪.md)。
- **09-30速度难段8臂结果**：全部完成，G11峰/谷/减速/周期R² 0.8167/0.3159/0.6876/0.7571，对U0谷底+0.0157、减速+0.0094；D1方向改善但精度增量小，D2/A1未获支持。G11未满足对G10的全部预注册条件，固定查询推理1.654×U0，保留研究候选、不改部署。原206/55、fold0、seed1234，指标为速度向量与数据单元等权；见[完成分析](../training_wss_min/experiments/velocity_phase_v52_20260930/analysis_20260930/analysis.md)和[工作簿](03-汇报材料/WSS_PointNet实验矩阵与结果汇总last.xlsx)。
- **最缺的证据**：同协议外部基线、边界条件变化实验、真实分割面验证、未触碰确认集——四项都未开始，是投稿前的主要工作。
- **体场 PF6 / VF6（10-03 起）**：v5.2d 重训完成（01 块 §43）：CV5 折外三 seed 集成压力 R²_cb `0.808`、速率 `0.843`（261 例）；同一批单元、同一套 v5.2d 标签上一致好于旧 v5.0 权重（test34 压力 0.82 → 0.85、速率 0.82 → 0.85）。10-03 全量 265 例权重上线为 `PF6_VF6_v52d_3seed_20261003`，旧 v5.0 体场包下线（§44）。
- **边界**：PF6 / VF6 是独立 single-head 模型，不是联合 PINN；体域 PINN 已停止。历史 V1/V2/V3、旧 PINN、velocity → WSS 与外部旧 baseline 不与 V5 主表混合。提交作业或中途读数不等于最终结果。

## 维护规则

1. 新实验事实先写所属块的实验跟踪（[推进与变更导航](02-推进与变更/README.md)，节号全局递增），再在推进记录文首补指针；策略变化更新总纲，导航只保留入口和边界。
2. 旧路线、失败实验和历史图件不删除，但必须标明日期、数据版本、开发/测试暴露和是否可进入论文主表。
3. 结果引用必须能回到 `data_version + split + seed + config + checkpoint 选择 + metrics 字段 + 原始路径`；图件另存 source data、脚本、病例选择、单位和色标合同。
4. 不把提交作业当成完成，不把单帧标量当成周期指标，不把点云插值外观当成精度，不把 geometry-only 固定 CFD 协议写成临床生理泛化。
5. 修改代码、配置或实验文档后更新对应推进记录；只修改汇报 PPT/PDF 不必追加代码推进条目。
6. **多个 AI 会话并行时**（2026-10-02）：开工先从[知识库整理规范 §6.5](00-规范与记录/项目知识库整理规范.md)登记表的规范位置读现状；占用共享资源或依赖别的线的文件时在受影响块 README 留告知；任务完成做收尾同步（块跟踪 → 块 README → 跨文档事实及其副本 → 推进记录 → 撤销告知）；别人的块只追加补记。根 `AGENTS.md` 是给各类 AI 的摘要。
