# 尾部非对称损失：证据链与论文写法（2026-09-27）

> 起因：用户问「三头模型与纯峰值模型对比，是不是说明尾部加权有意义、实验能表现出来，能否写进论文」。本文把现有证据按强度排好，给出能写的主张、不能写的主张、写在哪里，以及把它做成论文级证据还差哪些补实验。所有数字注明数据版本、协议、seed 数；一手来源见每行「来源」列。

## 0. 结论先行

- **能写，但定位是「有消融支撑的设计选择」，不是方法创新。** 分位数回归 / 非对称损失是现成方法（Koenker & Bassett 1978 [M9]，见创新性辨析 §6），我们能写的是：**峰值 WSS 的误差是「重尾 + 单向低估」，所以对低估施加不对称惩罚有效，而单纯给高值加权、调更高分位都无效**；并且给出适用边界（OSI 这类有界比值量上无效）。
- **三头对纯峰值的对比只能当旁证**：三头模型同时改了两件事（多任务 + 关掉 q90 pinball），尾部差距不能单独归给 pinball。
- **目前最干净的证据是 §36 的 T2（低估逐点损失 ×2）**：v5.2 IND 三 seed 配对 +0.012、3/3 同向，四道预注册门全过；CV5 三 seed 确认正在跑（队列 15785）。**CV5 结果出来之前，论文里只能写 IND 数字并注明「CV5 确认中」。**

## 1. 问题：峰值 WSS 的误差是重尾且单向低估

- X5Dcap CV5 折外集成（R²_cb 0.777）的误差 **64% 落在每例最高 10% WSS 的点上，其中 72% 是低估**；78% 的 SSE 在髂支叶段；幅值 oracle 只能 +0.03 → 结构性的髂支高剪切低估。来源：[X5D 主线跟踪 §36 起点分析](../02-推进与变更/01-X5D主线与新数据/X5D主线_实验跟踪.md)。
- 对照 OSI：误差 43% 在真值 OSI ≥ 0.3 的 12.5% 点上，但偏差是**对称压缩**（真值 < 0.05 的点被高估到 0.05，真值 ≥ 0.3 的点被低估到 0.24）。来源：[TAWSS/OSI 跟踪 §34.11 P0c](../02-推进与变更/03-周期量TAWSS_OSI/TAWSS_OSI_实验跟踪.md)。
- 这两种误差形态决定了「尾部损失」在两个目标上的效果完全不同（见 §2 E5）。

## 3. 论文里怎么写

**位置**：Methods 的损失函数一节给出定义；Results 或 SI 放一张「尾部目标消融表」（E1 + E2 各行，E5 作边界行）；三头模型那一节在报 M1 峰值通道精度时引用 E3，并注明差距来源待 §4 补实验确认后再下结论。

**可以写的主张**（按证据强度）：

1. 「峰值收缩期 WSS 的预测误差集中在每例最高 10% 的点，且以低估为主（72%）。」——有取证数据，直接写。
2. 「对低估施加 2 倍逐点惩罚，在独立测试集上三 seed 配对提升 R²_cb 0.012（3/3），同时改善射流子集与最高 10% 点的幅值比；而按真值幅值加权或提高分位数均无效。」——**CV5 确认通过后**写；未通过则只写 IND 并标「未在交叉验证中复现」。
3. 「去掉该尾部项的多任务模型，其峰值通道在 Pa 空间低 0.012，差距全部来自最高 10% 的点。」——现在只能写成观察；把原因写成 pinball 需要 §4 的 2×2。
4. 「对 OSI 这类有界比值量，尾部加权只相当于重新标定阈值，不带来判别力。」——可写，作为方法适用边界（单 seed，写明）。

**不能写的**：

- 「提出了新的尾部损失」——分位数回归 / 非对称损失是现成方法 [M9]，我们的贡献是诊断（误差形态）+ 消融归因 + 适用边界。
- 用 E4 的 +0.056 说明 pinball 的作用——混了 ln 半径输入。
- 用 E3 单独证明 pinball 有效——混了多任务。

**英文句式草稿**（CV5 确认通过后替换数字）：

> Errors in peak-systolic WSS were heavy-tailed and one-sided: 64% of the squared error fell on the top 10% of wall points of each case, 72% of it as under-prediction. Doubling the point-wise loss for under-predictions improved the case-balanced R² on the independent test set by 0.012 (three paired seeds, 3/3 positive) and raised the predicted-to-true magnitude ratio in the top decile from 0.82 to 0.88, whereas weighting points by target magnitude or raising the pinball quantile did not help. The same asymmetric treatment did not transfer to OSI, where the error is a symmetric compression of a bounded quantity and tail weighting only re-calibrated the threshold.
