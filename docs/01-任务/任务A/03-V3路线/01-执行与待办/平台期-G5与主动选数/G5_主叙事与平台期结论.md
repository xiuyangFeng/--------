## 1. 阶段性结论（对外可述）

V3P 在路径 A–F 单变量耗尽、路径 G（G0–G4）与 M-E 结构探针（E-J、G4-c）全部封口后，进入**表示与信息瓶颈平台期**：

1. **点级 WSS 带宽**：`wss_r2_wss` 稳定 **0.42–0.45**（I6-diag **0.429**；I6-a 两阶段冻结最高 **0.446** 弱 No-Go）。
2. **压力仍可学**：I6-diag `r2_p=0.930`；但压力梯度 oracle 未能迁移为网络收益（E-J GPU **0.401**）。
3. **横向分量未打开**：I2-PC local circ **0.014**；pooled R² 主要由轴向/主分量贡献。
4. **临床区域 surrogate 有信号**：5311 Pa p95 Spearman **0.559** vs AsymW-a 4957 **0.294**（病例级排序，非壁面 R² 达标）。
5. **M-E 工程部署未达标**：R²_wss 目标 ≥0.85 与当前 **0.43** 量级差距 **~0.42**；E-J + G4-c 结构 GPU 线 **全部封口**。

**诚实边界**：G5 叙事完成 **≠** 数字孪生可替代 CFD；对外须区分 **M-N（叙事）** 与 **M-E（工程）**。

## 7. 平台期收口补充（2026-07-01 · oracle A–G → J4 → Phase1/L3）

> 本节为 **J4 No-Go**、**AG 扩池封顶**、**L3 子集 eval** 后的对外可述段落；区分 **M-N（叙事）** 与 **M-E（工程）**。

### 7.1 实验链摘要

| 阶段 | 关键结果 | 判读 |
| --- | --- | --- |
| **Oracle A–G**（CPU） | A/B/C/D No-Go · E/F weak · **G Go** | 仅 Idea G（V3D-lite 近域补数）值得 GPU 短训 |
| **J4 MixedProbe**（5872 · +1 `slow/ZHAO_XIU_XUAN`） | best_wss **0.423** · Δi6 **−0.006** · `r2_p` **0.935** | ❌ **No-Go** · V3D-lite 线封口 |
| **Phase1 v4 + J5 ActiveData**（5881 · +6 AAA Batch-1） | best_wss **0.433** · Δi6 **+0.004** · L3 fast **+0.145** · CHEN **−0.241** | ❌ **弱 No-Go**（Go **0.459** 未过）· **J5 线封口** |

### 7.2 对外可述段落 · M-N（论文 / 阶段汇报）

在 AG-only、`split_AG_v1` 与 FieldPointNeXt + AsymW-a 共享 head 表示空间内，V3P 点级壁面剪切应力（WSS）的 pooled R² 稳定于 **0.42–0.45** 带宽，母版 I6-diag 为 **0.429**（post5463 band **0.425±0.012**）。路径 G（G0–G4）与 M-E 结构探针（E-J、G4-c Phase1）均已封口，表明当前瓶颈不是单一 loss 或 head 容量，而是**表示与信息瓶颈**：横向/周向 WSS 分量未打开（local circ R² **~0.014**），pooled 指标主要由轴向低频分量贡献。

2026-06-30 平台期 oracle（Ideas A–G）进一步证伪坐标系换轨、branch latent、谱重构等短期 GPU 方向；唯一 Go 的 Idea G（V3D-lite 近域 +1 病例 MixedProbe，Job 5872）亦 **No-Go**（best_wss **0.423**，相对 I6-diag **−0.006**），说明**在现有 AG 图数据池内再加病例不足以突破平台**。主动选数审计（Phase1 v3）显示 split 外仅 **1** 例 QA 可入训且已被 J4 消耗，**4** 例因 WSS 全零或 local frame 异常列入 denylist；failure_cluster 五例 fast 已在 train 且无 AG 外近邻可补——**AG-only 数据路线已封顶**。

子集评估（L3）表明：J4 在 fast 子集略优于 I6-diag（**+0.023**），但 **CHEN 病例 pooled R² 仍为负**（J4 **−0.785**），slow 子集反而 **−0.042**；即 +1 训练病例未系统性改善已知失败簇。与此同时，**病例级压力峰值排序**（5311 Pa p95 Spearman **0.559** vs AsymW-a 4957 **0.294**）与 **压力场 R²**（I6-diag **0.930**）仍具临床 surrogate 叙事价值。

**M-N 结论（可写入主文）**：在当前输入条件与 AG-only 数据覆盖下，点级 WSS R² 已接近该架构可学带宽；结构性改造方向（G1–G4、E-J、V3D-lite MixedProbe）已穷尽短训探针；主叙事应诚实报告平台并强调**区域/病例级 surrogate**（压力排序、部分 slow 病例），而非宣称点级 WSS 工程达标。

### 7.3 对外可述段落 · M-E（数字孪生 / 高精度部署）

M-E 目标（如 R²_wss ≥ **0.85**）与当前 **~0.43** 量级仍存在 **~0.42** 差距，**不可**将 G5 叙事等同于 CFD 替代或壁面 WSS 工程可用。E-J（GPU **0.401**）与 G4-c（CHEN merged **0.406**）已证明 oracle/ patch 内信号**未能迁移**为稳定 3D merged 收益；J4 证伪「近域 +1 病例即可抬 test」假设。

Phase1 v4 **`phase1_pass = true`**（Batch-1 六例 AAA 并入 · neighbor **5/5**）后立项 **J5**（5881 · +6 AAA · 40 ep seed1）。J5 best_wss **0.433**（Δi6 **+0.004**），**未过 Go 0.459**；L3 显示 fast/CHEN 子集改善（CHEN **−0.241** vs I6 **−0.825**）但 CHEN 仍为负、全 test band 未破。**J5 线封口**，不扩 seed。若仍追求 M-E 突破，下一跳是 **Batch-2 CPU 采购**（见 [采购_batch2.md](采购_batch2.md)）+ Phase1 v5 重评，或 **target/坐标系/branch condition** 级改造（见 [平台期复盘](../V3P_精度平台期复盘与下一轮想法_2026-06-30.md) Ideas A–F），不能靠现有训练脚本小改硬冲。

**M-E 结论（对内/立项用）**：工程精度未达标；AG 图内扩池已封顶；CHEN/fast 失败簇与横向 WSS 仍是硬下限；后续必须**主动选数 + pipeline 采购**或接受 **target/坐标系/branch condition** 级改造（见 [平台期复盘](../V3P_精度平台期复盘与下一轮想法_2026-06-30.md) Ideas A–F），不能靠现有训练脚本小改硬冲。
