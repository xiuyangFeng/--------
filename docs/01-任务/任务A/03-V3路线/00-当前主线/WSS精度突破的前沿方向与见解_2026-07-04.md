## 0. 一页纸结论

本项目精度平台**不是超参问题，而是「表示 + 信息 + 数据」三重瓶颈**——路径 A–G 已用大量消融闭环验证。因此真正有希望的突破**不是在「点云 → 直接回归逐点 WSS」范式内继续加特征，而是换掉这个范式的三个隐含假设之一**：

| 隐含假设 | 为什么是瓶颈（本项目证据） | 前沿替代 | 本文章节 |
| --- | --- | --- | --- |
| ① WSS 可从点云直接端到端回归 | WSS $=\mu\,\partial u_t/\partial n\|_{wall}$ 是近壁微分算子输出；直接回归让网络凭空重建从未显式表示的梯度。VelGrad/vel_diff 有限差分全 No-Go（噪声放大） | **两阶段可微 WSS**：学光滑近壁剖面系数，可微物理层解析求导 | §3 |
| ② 局部 kNN 特征足以决定逐点 WSS | 横向/周向 `wss_x/y` 长期≈0；CHEN/fast、hotspot 系统性失败；G4-c patch 内可拟合但 merged 不稳——都是**长程/全局信息**缺失 | **算子学习 + 长程注意力 + 全局 token**（Transolver / GINO / centerline virtual node） | §4 |
| ③ 60–179 高保真 case 足够 | 高频 case-specific 二次流小样本下只能记忆；J4/J5 盲目扩池弱 No-Go；G3 纯几何 SSL No-Go | **PDE 基础模型 + 合成多保真预训练 + 生成式先验 + 主动学习** | §5、§6、§7 |

**投产比排序（建议执行顺序）**：§3 可微 WSS head 与 §4 换 processor 是**低成本、复用 backbone、最该先做**；§5/§6/§7 是结构性但重工程的第二波；§8 给出完整分阶段路线图，§9 给出更多创新想法，§10 是工程化 checklist。

**贯穿全文的纪律（沿用项目共识）**：每条 GPU 线先过 **0 重训 oracle**；oracle 只看 GT 相关性不够，必须证明**推理期可得的中间量**有信号（E-J 教训）；pooled `wss_r2_wss` 之外**必须**报横向分量、hotspot、L3/CHEN/fast 与压力不退化。

## 1. 瓶颈：三条被实验反复印证的硬约束

在谈方法前先固定三条用实验换来的结论，否则任何新方向都会重蹈「oracle 高 ≠ 网络可用」的覆辙：

1. **压力可学、横向 WSS 不可学**：`r2_p≈0.93`（低频、体域主导）可重建；`wss_x/y` 长期≈0。不是学得不够久，而是**决定横向剪切的信息没进入表示**。
2. **GT-oracle 屡屡不迁移**：E-J（GT `|∇p|` oracle 强）、POD、时间谐波、G4 patch 都出现「用真值算 oracle 很好，接进网络就崩」。纪律：新方向必须证明**推理期可得的中间量**本身有信号。
3. **patch 内可拟合、merged 3D 不稳**：G4-c 单 case（GUO）0.633，CHEN merged 0.406。**局部可重建、全局缝合/覆盖不足**——即长程一致性缺失。

筛选条件（很紧）：**能同时缓解「近壁算子缺失」「长程/全局信息缺失」「小样本」中至少两条、且推理期可用的方向，才值得烧 GPU。**

## 2. 通用 Go/No-Go 节奏框架（所有方向共用）

本项目已有分层门禁的雏形（L1 点级 / L2 hotspot / L3 病例）。这里把它固化为一个**五级闸门**，每个方向都套用同一节奏，避免「一上来就全量长训 + 多 seed」的空耗。

```text
Gate-0  0 重训 oracle（CPU）      ── 证明"表示天花板更高"，产物入 f0_decision/*.json
   │  过：中间量对 GT WSS 有信号（尤其横向/hotspot）
   ▼
Gate-1  seed1 短训 40ep（1 GPU）  ── 只看能否复现母版带宽 + 不崩
   │  过：wss_r2_wss ≥ I6-diag(0.429) 且 r2_p 不退化(>0.90)
   ▼
Gate-2  横向/hotspot 专项判读     ── 这是本项目真正缺的层，必须单独过
   │  过：wss_x 或 wss_y test R² > 0.10（历史从未达到）
   │      或 hotspot top-k Dice / p95 Spearman 明显改善
   ▼
Gate-3  L3 病例级不退化           ── CHEN/fast/slow 分层，禁止"pooled 涨、病例退"
   │  过：CHEN/fast 不退化，最好有改善；无任一域 Strong No-Go
   ▼
Gate-4  扩 seed(2/3) 稳定性        ── 三 seed CI 上界过 Go(0.459) 才升母版候选
   │  过：wss_r2_wss 三 seed 稳定 > 0.45
   ▼
升母版候选 → 临床/区域 eval → M-E 立项
```

**No-Go 的判定与动作**（关键：No-Go 不等于全线放弃，而是**降级**）：

| 卡在哪一级 | 判读 | 动作 |
| --- | --- | --- |
| Gate-0 不过 | 中间量对 GT 无信号 | 直接封口，**不进入训练**（省 GPU） |
| Gate-1 不过 | 复现不了带宽/崩了 | 查实现 bug/训练动力学；两次修不好则封口 |
| Gate-2 不过 | pooled 持平但横向/hotspot 没开 | **弱 No-Go**：转失败病例叙事，不扩 seed |
| Gate-3 不过 | pooled 涨但 CHEN/fast 退 | **No-Go**：不升母版；记入失败档案 |
| Gate-4 不过 | 单 seed 好、三 seed 抖 | 记为「边际信号」，并入下一个方向做协同，不单独升母版 |

> 每个方向的 Go/No-Go 阈值在各自章节里给出，但**节奏统一走这五级**。产物统一写 `outputs/field/f0_decision/`（oracle）与实验跟踪日志（训练），不覆盖历史 F0/G0 json。

## 3. 方向一（最高优先）：两阶段可微 WSS head

### 3.1 核心思想

当前 head 让网络**直接**吐 WSS 向量，等于要它内部隐式重建近壁速度梯度。历史 oracle 指向 WSS 与近壁速度/压力梯度强相关（5265：近壁差分 Spearman ~0.61–0.63、`|∇p|` 0.73），但「预测场 → 有限差分」会**逐点放大噪声**（VelGradB1 5170、vel_diff 全负）。

**升级点**：不做差分，改为让网络在每个壁面点输出一个**光滑近壁速度剖面的低维系数**，再由**可微物理层**解析求导得 WSS。求导发生在光滑基上而非噪声采样上，噪声放大被结构性抑制。

用内法向坐标 $\eta\in[0,\delta]$ 上的切向速度剖面 $u_t(\eta)=a_1\eta+a_2\eta^2+a_3\eta^3$（或 log-law / Falkner–Skan 型基），则

$$\mathrm{WSS}=\mu\,\frac{\partial u_t}{\partial \eta}\Big|_{\eta=0}=\mu\,a_1.$$

网络学 $(a_1,a_2,a_3)$ 与切向方向 $\hat t$，物理层输出 $\mathrm{WSS}=\mu a_1\hat t$。这与代码里已预留的 `wss_boundary_layer_context` / `wss_output_mode` 同源——但关键区别是**让物理层"输出 WSS"，而不是"输入一个 context 特征"**。

### 3.2 Gate-0 oracle（先做，CPU，1–2 天）

新增脚本 `training/scripts/run_v3p_profile_wss_oracle.py`（仿 `run_v3p_post_plateau_probes.py`）：用 **GT 近壁体点速度**拟合剖面基，检查 $\mu a_1$ 对 GT WSS 的可恢复性，**尤其横向分量**。

```python
# training/scripts/run_v3p_profile_wss_oracle.py (骨架)
import numpy as np, json
# 对每个壁面点：取其内法向 ray 上 GT 体点 (eta_i, u_t_i)，最小二乘拟合 a=[a1,a2,a3]
def fit_profile_wss(eta, u_t, mu):
    A = np.stack([eta, eta**2, eta**3], axis=1)          # (K,3)
    a, *_ = np.linalg.lstsq(A, u_t, rcond=None)          # 光滑基拟合，不做逐点差分
    return mu * a[0]                                      # WSS = mu * a1

# 判据：对 stream/cross 两个切向分量分别评 R²；写 f0_decision json
result = {
    "wss_axial_r2": ...,      # 轴向（预期已可学）
    "wss_cross_r2": ...,      # 横向（关键：现母版≈0）
    "vs_finite_diff_r2": ..., # 对照有限差分（应显著更高，证明光滑基抑噪）
    "decision": "Go" if wss_cross_r2 > 0.10 else "No-Go",
}
json.dump(result, open("outputs/field/f0_decision/v3p_profile_wss_oracle_20260704.json", "w"))
```

**Gate-0 Go**：`wss_cross_r2 > 0.10`（横向比现母版≈0 明显高）**且** `vs_finite_diff_r2` 明显高于有限差分（证明光滑基抑噪成立）。不过则封口，避免重演 Idea B（stream/cross oracle No-Go）。

### 3.3 核心代码修改片段（Gate-1 落地）

**(a) 新增可微剖面头** `training/core/wss_profile_head.py`：

```python
# training/core/wss_profile_head.py
import torch
import torch.nn as nn
import torch.nn.functional as F


class DifferentiableWSSHead(nn.Module):
    """两阶段可微 WSS：网络出近壁剖面系数 (a1,a2,a3) + 切向 t_hat，
    物理层解析求导 WSS = mu * a1 * t_hat。求导在光滑基上，抑制噪声放大。
    输出 [wss_mag, wss_x, wss_y, wss_z] 与现 WSS_TARGET_NAMES 对齐。"""

    def __init__(self, hidden_dim: int, n_basis: int = 3, mu: float = 1.0):
        super().__init__()
        self.mu = mu
        self.coef_head = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim), nn.LayerNorm(hidden_dim), nn.GELU(),
            nn.Linear(hidden_dim, n_basis),          # a1..an
        )
        self.dir_head = nn.Linear(hidden_dim, 3)     # 切向修正（相对中心线切向）

    def forward(self, h: torch.Tensor, tangent: torch.Tensor) -> torch.Tensor:
        coef = self.coef_head(h)                      # (N, n_basis)
        a1 = coef[:, 0]                               # d u_t / d eta |_0
        wss_mag = self.mu * a1                        # 解析 WSS 幅值
        # 方向：以中心线切向为基，允许小幅可学偏转，再单位化保证在切流形附近
        t_dir = F.normalize(tangent + 0.1 * self.dir_head(h), dim=-1, eps=1e-8)
        wss_vec = wss_mag.unsqueeze(-1) * t_dir       # (N, 3)
        return torch.cat([wss_mag.unsqueeze(-1), wss_vec], dim=-1)
```

## 4. 方向二（高优先）：算子学习 + 长程注意力

### 4.1 核心思想

横向 WSS、hotspot、CHEN/fast 失败本质都是**长程依赖**：某壁面点剪切取决于上游几何历史、分支流量分配、入口剖面。局部 kNN 池化**结构上**无法把这些稳定传到壁面点。前沿的几何/算子 Transformer 正为此设计：

- **Transolver（ICML 2024）**：learnable slices 把无序点软聚类成少量物理 token，token 上做全局注意力再散射回点，多个 CFD benchmark SOTA，点数近线性。
- **GINO / GNO（NeurIPS 2023）**：几何编码到规则 latent grid 上做 FNO，大规模汽车气动表面压力/WSS 验证，天然处理任意几何 + 全局算子。

### 4.2 与本项目现状的关系

- **与 K1（当前唯一在跑 Job 5886）**：K1 是手工分支特征 concat，历史接近 GeomB1 No-Go；Transolver/GINO 是**让网络自学全局 token/latent**，同一动机（补长程/分支）的更强实现。若 K1 再弱信号，这是更根本的替代，而非继续 concat。
- **与等变（路径 G）正交可叠加**：等变解决坐标系负担，注意力解决长程耦合。

### 4.3 核心代码修改片段：把 processor 换成 physics-attention

最小改动是**在 `FieldPointNeXt._encode` 的残差块之间插入一层全局 slice-attention**（复用现 kNN 块做局部、slice 做全局），而非重写整套 pipeline：

```python
# training/core/wss_slice_attention.py
import torch, torch.nn as nn, torch.nn.functional as F


class PhysicsSliceAttention(nn.Module):
    """Transolver 风格：点 -> M 个 learnable slice token -> 全局注意力 -> 散射回点。
    对点数近线性；提供局部池化拿不到的长程/上游耦合通道。"""

    def __init__(self, hidden_dim: int, n_slices: int = 32, n_heads: int = 4):
        super().__init__()
        self.slice_proj = nn.Linear(hidden_dim, n_slices)          # 点->slice 软分配
        self.attn = nn.MultiheadAttention(hidden_dim, n_heads, batch_first=True)
        self.norm = nn.LayerNorm(hidden_dim)

    def forward(self, x: torch.Tensor, batch: torch.Tensor) -> torch.Tensor:
        out = torch.zeros_like(x)
        for g in batch.unique():                                    # 逐图（图内全局，图间隔离）
            m = batch == g
            xg = x[m]                                               # (Ng, D)
            w = F.softmax(self.slice_proj(xg), dim=0)               # (Ng, M) 软分配
            slices = w.t() @ xg                                     # (M, D) 物理 token
            slices = slices + self.attn(slices[None], slices[None], slices[None])[0][0]
            out[m] = xg + w @ slices                                # 散射回点 + 残差
        return self.norm(out)
```

在 `_encode` 中每隔一个残差块调用一次 `PhysicsSliceAttention`（config 开关 `wss_slice_attention: bool`）。单目标 WSS、seed1 短训，对照 I6-diag 0.429。

## 5. 方向三（解小样本根因）：PDE 基础模型 + 合成多保真预训练

### 5.1 为什么这次不同于 G3 No-Go

G3 失败在「点云几何 SSL」与「WSS 物理目标」间**没有物理桥梁**。PDE 基础模型/多保真的关键是**预训练数据本身就是流场/剪切**，学的是**算子**而非几何特征。

- **Poseidon（NeurIPS 2024）**、**MPP（2024）**、**DPOT（2024）**：多物理预训练，下游样本效率提升一个数量级。
- 路径 G 已引用的**多保真 CFD 代理（GeoPT 类）**：低保真预训练 → 高保真微调，标注需求降 20–60%。

### 5.2 最务实入口：合成多保真预训练

用参数化理想分叉/弯管几何 + 快速低保真 CFD（甚至 1D/降维模型）批量生成**成千上万** `(几何, 入口 BC) → (WSS, p)` 样本，预训练算子网络（配 §4 骨架），再用 60–179 高保真 case 微调。

**工程分解**：

1. 参数化几何生成器（半径、分叉角、曲率、狭窄度）→ 批量网格；
2. 低保真求解（稳态/降阶）→ 廉价 WSS/p 标签；
3. 预训练：与真实 pipeline **同一 `data.x` 布局**（16 维节点 + 6 维全局），只是标签来自低保真；
4. 微调：`init_checkpoint` 加载预训练权重（注意现有代码对多数新 head 禁 warm-start，需为「同结构预训练」单独放开）。

### 5.3 Go/No-Go 节奏

| 闸门 | 阈值 |
| --- | --- |
| Gate-0 | 合成域内自测 R² 高（证明预训练学到算子） |
| Gate-1 | 微调后真实 test `wss_r2_wss≥0.429` few-shot 不退 |
| Gate-2 | 横向/hotspot few-shot 提升 |
| 回退 | 合成域偏移大导致微调不收敛 → 只做「近壁算子先验」窄目标预训练 |

## 6. 方向四（补 hotspot + UQ）：条件扩散/流匹配残差头

### 6.1 核心思想

回归模型在多峰/高频 hotspot 上会**回归到均值**——正解释本项目 hotspot 系统性偏低、pooled R² 被低频轴向掩盖。**条件扩散/流匹配**学**条件分布 $p(\mathrm{WSS}\mid\text{几何,BC})$** 而非均值，保留高频峰值，并**天然给校准 UQ**。

- Shu et al. 2023（物理约束扩散超分）、"From Zero to Turbulence"（NeurIPS 2023）、Flow Matching（2023–2024）：扩散/流匹配在高频湍流谱保真上优于确定性回归。

### 6.2 务实用法：混合头（不必一步到扩散主模型）

确定性 backbone 出低频均值 $\bar{\mathrm{WSS}}$，轻量条件扩散 head 只补高频残差 $\Delta$：

```python
# training/core/wss_diffusion_head.py (骨架)
class ResidualDiffusionWSSHead(nn.Module):
    """确定性均值 + 条件去噪残差；推理时多次采样得 ensemble -> 均值(精度)+方差(UQ)。"""
    def __init__(self, hidden_dim, wss_dim=4):
        super().__init__()
        self.mean_head = nn.Linear(hidden_dim, wss_dim)            # 低频均值
        self.denoiser = nn.Sequential(                            # 预测残差噪声 eps
            nn.Linear(hidden_dim + wss_dim + 1, hidden_dim), nn.GELU(),
            nn.Linear(hidden_dim, wss_dim),
        )
    def loss(self, h, wss_target):                               # 训练：均值 MSE + 去噪 MSE
        mean = self.mean_head(h)
        res = wss_target - mean.detach()
        t = torch.rand(h.size(0), 1, device=h.device)
        eps = torch.randn_like(res)
        noisy = (1 - t) * res + t * eps
        eps_hat = self.denoiser(torch.cat([h, noisy, t], -1))
        return F.mse_loss(mean, wss_target) + F.mse_loss(eps_hat, eps)
    @torch.no_grad()
    def sample(self, h, n=8):                                     # 推理：n 次采样
        mean = self.mean_head(h)
        samples = [mean + self._denoise(h) for _ in range(n)]
        s = torch.stack(samples)
        return s.mean(0), s.std(0)                                # (pred, uncertainty)
```

## 9. 更多创新想法（补充池，低成本先验证）

> 以下是超出主线的发散想法，均**先做 0 重训 oracle 或极小改动**，过 Gate-0/Gate-2 才升级。

1. **中心线虚拟节点（global token 的轻量版）**：给每个分支/中心线段加一个虚拟节点，与其覆盖的壁面点全连接。这是 §4 长程耦合的**最省实现**——不改 backbone，只在 `edge_index` 里加虚拟节点边。Gate-0：检验 branch-level 聚合特征能否解释 >30% WSS 平方误差（K1 已给 0.683 正信号，可直接复用）。
2. **物理残差 + 解析 WSS₀**（路径 G G2 的延伸）：先用 Womersley/Poiseuille 近似算解析 $\mathrm{WSS}_0$，网络只学 $\Delta\mathrm{WSS}$。Gate-0：`Var(WSS−WSS₀)/Var(WSS)<0.7` 且残差仍与几何相关（对应 G0-d，但配新剖面基）。
3. **hotspot-aware / 谱域 loss**：在 `losses.py` 现有 `wss_topk_ranking_loss` 基础上，加**曲面图 Laplacian 谱域 loss**（低频保结构、高频保峰值），缓解均值回归。极小改动，可与任何 head 叠加。
4. **per-case 校准头（test-time adaptation）**：网络出无量纲模式 $\hat w$ + case 尺度 $S_{case}$（双头），$\mathrm{WSS}=S_{case}\hat w$。Idea D 的 oracle 是 K3 No-Go（量纲不是主瓶颈），但**若与 §4 长程 token 联合**，$S_{case}$ 可由全局 token 预测，值得作为组合再试一次。
5. **廉价等变：旋转增强蒸馏**：既然全等变头（VNHead）已 No-Go，可用**旋转数据增强 + 一致性 loss**近似等变（同一 case 多个随机旋转，预测旋转后应一致）。零架构改动，纯训练技巧，验证坐标系负担是否可用增强缓解。
6. **CFD ensemble 蒸馏**：若能拿到同一 case 多解（不同湍流模型/网格），用其分布做软标签蒸馏，给模型 hotspot 不确定性先验。
7. **难度课程学习（curriculum）**：按 K1/UQ 给出的 case 难度排序，先易后难训练，缓解 CHEN/fast 这类难例主导梯度。改动仅在 sampler。
8. **多任务：联合预测近壁速度剖面**：把 §3 的剖面系数同时监督到 GT 近壁速度，作为 WSS 的辅助任务，给 $a_1$ 更强约束（§3.3(d)）。

## 10. 系统性优化方向补充（数据 / 预训练 / 消息传递 / 残差 / PINN）

> 本章把「训练系统」拆成六个可独立调的子系统，每个都给出：**是否已被本项目验证**、**差异化新做法**、**Go/No-Go**、**代码/配置钩子**。原则不变：已 No-Go 的不换名重跑；新做法先过 Gate-0/Gate-2。

### 10.1 数据增强（Data Augmentation）

现状：本项目基本**没有系统性做几何/物理增强**（60–179 case 直接喂），而增强是小样本最便宜的杠杆。关键是**增强必须保物理**——不能破坏 WSS 与几何/BC 的因果关系。

| 增强 | 做法 | 是否保物理 | Go/No-Go |
| --- | --- | --- | --- |
| **随机旋转/反射（SO(3)）** | 对 `data.x[:,:3]` 坐标、`Tangent_XYZ`、WSS 向量目标**同步**旋转 | ✅ WSS 随坐标系等变旋转 | 训练 loss 稳定下降且 test 不退 → 保留；这也是 §9.5 旋转蒸馏的基础 |
| **各向同性缩放 + BC 缩放** | 几何缩放 $\lambda$，按 Poiseuille/Womersley 标度同步缩放 `BC_Inlet` 与 WSS | ✅ 若标度律成立 | Gate-0：先验证标度律在 test case 上近似成立（Spearman） |
| **弹性/流保持形变** | 中心线保持、半径小扰动的平滑形变；用低保真快速重算 WSS | ⚠️ 需重算标签 | 与 §5 合成多保真同源，作为廉价样本 |
| **近壁点抖动 / 重采样** | 对内部点做小幅位置抖动 + kNN 重建，模拟采样噪声 | ✅ | 提升鲁棒性，Gate-1 不退即保留 |
| **Graph Mixup / CutMix** | 同域两 case 特征/标签线性混合 | ❌ WSS 非线性，慎用 | 默认不做（可能引入非物理标签） |

#### 10.1.1 是否需要重跑 Fluent？——不需要（对刚体旋转/反射）

**结论先行：刚体旋转和反射一律不需要重跑 Fluent，也不需要任何 CFD 重算。** 原因是 Navier–Stokes 方程在**欧几里得群（旋转 + 反射 + 平移）下等变**：如果把几何、边界条件、以及所有场按同一个变换 $R$ 变换，得到的仍然是**变换后几何的精确解**。所以你只需要对已有的 GT 场做**解析变换**（矩阵乘 / 变号），零 CFD 成本。

| 增强类型 | 要不要重跑 Fluent | 为什么 |
| --- | --- | --- |
| **旋转（proper, $\det R=+1$）** | **不用** | NS 旋转等变；场随 $R$ 旋转即为精确解 |
| **反射/镜像（improper, $\det R=-1$）** | **不用** | 镜像血管是一个物理上合法的血管，其解就是原解的镜像；但**赝量要额外变号**（见 §10.1.3） |
| **平移** | **不用** | 本项目坐标已归一化，通常无需 |
| **各向同性缩放** | **理论上不用，但有条件** | 需满足动力学相似（同 Re/Wo）并对 `BC_Inlet`、速度、WSS 按相似律同步缩放；是**近似**，须 Gate-0 验证标度律，否则宁可不做（见 §10.1.4） |
| **弹性/几何形变（改半径、分叉角）** | **需要（低保真即可）** | 改变了几何 → 改变了解，属于 §5 合成多保真数据生成，不是"免费增强" |

> 一句话：**刚体变换是"免费午餐"（只变换标签，不重算）；非刚体变换会改物理（要重算或近似）。** 你担心的时间成本只发生在后者，而旋转/反射恰恰是前者。

#### 10.1.2 逐字段变换规则（对齐本项目 `data.x` / `data.y` / `data.y_wss` 布局）

变换的正确性完全取决于**每个量属于哪一类**：真标量、真矢量（极矢量）、赝矢量（轴矢量）、赝标量。搞错一个就会"数据对不上、越训越差"。下表按本项目 `pipeline/config.py` 的确切索引给出规则（$R$ 为旋转或反射矩阵）：

| 存储位置 | 字段 | 物理类型 | 旋转（$\det=+1$） | 反射（$\det=-1$） |
| --- | --- | --- | --- | --- |
| `data.x[:,0:3]` | x, y, z 坐标 | 真矢量 | $Rx$ | $Rx$ |
| `data.x[:,3]` | Abscissa（弧长） | 真标量 | 不变 | 不变 |
| `data.x[:,4]` | NormRadius | 真标量 | 不变 | 不变 |
| `data.x[:,5]` | Curvature（曲率 κ≥0） | 真标量 | 不变 | 不变 |
| `data.x[:,6:9]` | Tangent_XYZ | 真矢量 | $Rt$ | $Rt$ |
| `data.x[:,9]` | is_wall | 标记 | 不变 | 不变 |
| `data.x[:,10]` | dist_to_bifurcation | 真标量 | 不变 | 不变 |
| `data.x[:,11]` | branch_id | 标记 | 不变 | 不变 |
| `data.x[:,12]` | dR_ds | 真标量 | 不变 | 不变 |
| `data.x[:,13]` | **torsion（Frenet 扭率 τ）** | **赝标量** | 不变 | **变号 ×(−1)** ⚠️ |
| `data.x[:,14]` | d_tangent_ds | 真标量 | 不变 | 不变 |
| `data.x[:,15]` | dist_to_wall | 真标量 | 不变 | 不变 |
| `data.global_cond` | t_norm, BC_Inlet, BC_O1..O4 | 真标量（流量/压力） | **全部不变** | 全部不变 |
| `data.y[:,0:3]` | u, v, w（速度） | 真矢量 | $Ru$ | $Ru$ |
| `data.y[:,3]` | p（压力） | 真标量 | 不变 | 不变 |
| `data.y_wss[:,0]` | wss（幅值） | 真标量 | 不变 | 不变 |
| `data.y_wss[:,1:4]` | wss_x/y/z（全局矢量） | 真矢量 | $R\,\tau$ | $R\,\tau$ |

**若使用 local 坐标系 WSS 目标**（`wss_target_frame="local"`，`data.y_wss = [wss, wss_axial, wss_circ, wss_rad]`）：

| 字段 | 类型 | 旋转 | 反射 |
| --- | --- | --- | --- |
| wss（幅值） | 真标量 | 不变 | 不变 |
| wss_axial（沿切向 $\tau\cdot\hat t$） | 投影标量 | **不变** | 不变 |
| wss_rad（沿法向 $\tau\cdot\hat n$） | 投影标量 | **不变** | 不变 |
| **wss_circ（沿周向 $\tau\cdot\hat b$, $\hat b=\hat t\times\hat n$）** | 投影赝标量 | **不变** | **变号 ×(−1)** ⚠️ |

> **关键洞察**：local 分量在**旋转下全部天然不变**（因为 WSS 矢量和局部基底一起转，投影不变）——所以**旋转增强时绝不能再去旋转 local 分量**，否则就错了。这正是"全局 frame 要转、local frame 不转"的分水岭，也是最容易搞反的地方。

#### 10.1.3 反射（镜像）的三个陷阱

反射能把有效样本量翻倍，但比旋转更危险，因为它触发**赝量变号**。三个必查项：

1. **torsion 变号**：Frenet 扭率是赝标量，右手螺旋镜像成左手螺旋 → `data.x[:,13]` 必须 ×(−1)。忘了它，几何先验就和镜像后的场对不上。
2. **local 周向分量 wss_circ 变号**：如上表，$\hat b=\hat t\times\hat n$ 是叉积（赝矢量），镜像后周向投影反号。
3. **任何叉积/涡量类特征变号**：若将来往特征里加 vorticity $\omega=\nabla\times u$、helicity $u\cdot\omega$、或用叉积构造的 binormal，都要按 $\det R$ 处理（涡量 $\omega'=\det(R)\,R\,\omega$；helicity 是赝标量，反射变号）。

> **最稳妥的工程做法**：反射时**只在全局 frame 上做变换（坐标、Tangent、速度、全局 WSS 全乘 $R$），然后从镜像后的几何"重新计算"所有派生几何量（torsion、局部基底、local WSS 分量）**，而不是手工给每个量记变号。重算比记符号更不容易错——一次算对，永久免维护。

#### 10.1.4 归一化与 kNN 图的两个隐蔽坑

- **归一化必须"各向同性"或"变换前施加"**：如果对速度/坐标的 x/y/z **分量各自**用不同 mean/std 归一化，旋转会**混合三个轴**，导致归一化统计与数据不再一致 → 训练崩。对策：① 增强在**物理（未归一化）空间**做，再归一化；或 ② 对三个空间分量用**共享**（各向同性）归一化，使旋转与归一化可交换。**先确认现有 pipeline 的 WSS/速度归一化是否按分量独立**——若是，必须改成共享或调整增强顺序。
- **kNN 图无需重建**：刚体变换保距，`edge_index`（按距离建的 kNN）拓扑完全不变，可直接复用。但**边上如果带方向属性**（§10.3 的 `diff/dist`、切向投影），这些是在 forward 里从变换后的 `pos` 现算的，会自动跟着变——不用手动改。

#### 10.1.5 稳健代码钩子（区分旋转 vs 反射，处理赝量）

```python
# training/core/augment.py —— 在 Dataset.__getitem__ 里对 data 就地增强
# 索引对齐 pipeline/config.py：coords 0:3, tangent 6:9, torsion 13
def rigid_augment(data, allow_reflection: bool = True):
    R = random_orthogonal_matrix(device=data.x.device, allow_reflection=allow_reflection)
    det = torch.det(R)                                    # +1 旋转 / -1 反射

    # 真矢量：坐标、切向、速度、全局 WSS —— 一律右乘 R^T（行向量约定）
    data.x[:, 0:3] = data.x[:, 0:3] @ R.T                 # 坐标
    data.x[:, 6:9] = data.x[:, 6:9] @ R.T                 # Tangent_XYZ
    data.y[:, 0:3] = data.y[:, 0:3] @ R.T                 # 速度 u,v,w（p 不变）

    if getattr(data, "y_wss", None) is not None:
        if data.wss_frame == "global":
            data.y_wss[:, 1:4] = data.y_wss[:, 1:4] @ R.T # wss_x/y/z（wss 幅值不变）
        else:  # local frame：旋转下不变；反射下仅 wss_circ 变号
            if det < 0:
                data.y_wss[:, 2] = -data.y_wss[:, 2]      # wss_circ（axial/rad/幅值不变）

    # 赝标量：反射时变号
    if det < 0:
        data.x[:, 13] = -data.x[:, 13]                    # torsion
    # 标量（Abscissa/NormRadius/Curvature/dist_*/BC/p/wss 幅值）与 is_wall/branch_id 全部不动
    return data
```

> 更稳的替代（推荐）：反射时**只转全局矢量**，`torsion`、local 基底、local WSS 分量一律**从镜像几何重算**（调用现有几何预处理），避免手工符号维护。

> 关键纪律：**只旋转/反射（免费），缩放需先验证标度律，不 mixup**；每个增强**单独消融**（Gate-1 不退才保留），并**在验证/测试集上关闭增强**（只增强训练集）。上线前务必做一个自检：对同一 case 施加已知 $R$，确认「变换后再预测」与「预测后再变换」一致（等变一致性检查），能一次性抓出所有矢量/标量搞反的 bug。旋转增强还能**间接验证坐标系负担**（§1 约束1）——若显著提升横向分量，说明坐标系是可用增强缓解的软瓶颈。

### 10.2 预训练（Pretraining）

现状：G3 纯几何点云 SSL **No-Go**（+0.012/−0.002）。原因是几何自监督与 WSS 物理目标无桥梁。差异化做法是**让预训练目标带物理**：

| 预训练范式 | 目标 | 与 G3 的区别 | Go 判据 |
| --- | --- | --- | --- |
| **掩码场重建（MFM）** | 随机 mask 部分点的**速度/压力**，重建之 | 目标是物理场而非几何坐标 | 微调后 few-shot `wss_r2_wss` 不退且横向提升 |
| **跨时间步对比** | 同 case 不同 `t_norm` 的表示应连续/可插值 | 利用时间维（当前浪费的信号） | 时间一致性 probe 过线（注意 K5 时间 No-Go，先 Gate-0） |
| **V3D 跨域预训练 → AG 微调** | AAA+AG+ILO 上预训练算子，AG 上微调 | 不是混训（J4/J5 No-Go），是"预训练→微调" | AG test 不退、横向/hotspot 提升 |
| **合成多保真预训练** | §5 的低保真大数据 | — | 见 §5 |
| **外部 PDE 基础模型微调** | Poseidon/MPP 权重迁移 | — | 见 §5 |

### 10.3 网络的消息传递（Message Passing）

现状：`FieldPointNeXt` 用**各向同性 kNN mean/max 池化**（`_local_pool_mean_max`），边上**不带方向/几何信息**。这正是横向分量学不到的结构性原因之一——池化把邻居"打平"了。改进方向按 ROI 排序：

| 改进 | 核心 | 为什么可能帮横向 WSS | 代码位置 |
| --- | --- | --- | --- |
| **各向异性 / 方向消息（EdgeConv 风格）** | 消息带相对位移 $x_j-x_i$、法向、切向投影 | 保留邻居**方向**结构，横向剪切依赖方向 | 改 `_local_pool_mean_max` → 带 edge feature 的聚合 |
| **注意力聚合（GAT/Transformer 风格）** | 邻居加权而非均值/最大 | 让上游/高剪切邻居权重更高 | 项目已有 `FieldTransformer`，可作对照 |
| **门控更新（GRU/gMLP）** | 用门控代替残差相加，稳定深层 | 深层 message passing 不弥散 | block 内 update 换 GRUCell |
| **层次多尺度（BSMS-GNN）** | bi-stride 下采样 → 上采样，多分辨率 | 补长程（与 §4 同目标，图域实现） | 新 backbone，中成本 |
| **动态图（DGCNN）** | 每层按特征空间重建 kNN | 让"邻居"随语义而非仅几何 | `_build_pool_edge_indices` 里按特征算 knn |
| **中心线虚拟节点** | §9.1 全局 token 最省实现 | 长程/分支耦合 | 只加 `edge_index` |

**代码钩子（各向异性消息，最小改动）**：把 `_local_pool_mean_max` 升级为带边特征的聚合：

```python
# training/core/models.py · 新增 _local_pool_directional
def _local_pool_directional(x_norm, pos, tangent, edge_index, edge_mlp):
    row, col = edge_index
    diff = pos[col] - pos[row]                            # 相对位移（方向）
    dist = diff.norm(dim=-1, keepdim=True).clamp_min(1e-8)
    t_proj = (diff * tangent[row]).sum(-1, keepdim=True)  # 沿切向投影（区分上/下游）
    edge_feat = torch.cat([x_norm[col], diff / dist, dist, t_proj], dim=-1)
    msg = edge_mlp(edge_feat)                             # 方向感知消息
    out = torch.zeros_like(x_norm)
    out.scatter_add_(0, row.unsqueeze(1).expand_as(msg), msg)
    deg = torch.zeros(x_norm.size(0), 1, device=x_norm.device).scatter_add_(
        0, row.unsqueeze(1), torch.ones_like(row, dtype=x_norm.dtype).unsqueeze(1))
    return out / deg.clamp_min(1.0)
```

**Go/No-Go**：Gate-1 复现带宽不崩；Gate-2 横向分量或 hotspot 改善（否则又是只涨轴向）。各向异性消息与 §4 slice-attention **正交可叠加**（局部方向 + 全局耦合）。

### 10.4 残差连接与深度（Residual / Depth）

现状：`FieldPointNeXt` 已是 pre-norm 残差块，但**较浅**（`num_layers` 默认小），且残差为**直接相加**。小样本下加深容易过拟合，需配正则：

| 技术 | 做法 | 收益 | 风险/对策 |
| --- | --- | --- | --- |
| **LayerScale** | 残差乘可学小标量 $\gamma$（初始 1e-4） | 稳定加深，深层不弥散 | 几乎零成本，建议默认加 |
| **Stochastic Depth** | 训练时随机丢整块残差 | 深层正则，防小样本过拟合 | drop_rate 0.1 起 |
| **DenseNet 式跳连** | 跨多层 concat 特征 | 保留多尺度信息 | 显存增；配 1x1 降维 |
| **物理残差（WSS₀）** | §9.2 学 $\Delta\mathrm{WSS}$ | 降目标方差 | Gate-0 验证残差方差降 >30% |
| **加深 + 上述正则组合** | `num_layers` 6→12 + LayerScale + StochDepth | 容量↑ | 必须 Gate-3 看是否过拟合退病例 |

**代码钩子（LayerScale，最小改动）**：在 `FieldPointNeXt` block 里给残差加可学标量：

```python
# block 内：x = x + residual  →  x = residual + self.gamma * x
self.blocks.append(nn.ModuleDict({
    "norm": nn.LayerNorm(hidden_dim),
    "mlp": nn.Sequential(...),
    "gamma": nn.Parameter(torch.full((hidden_dim,), 1e-4)),   # LayerScale
}))
# forward: x = residual + block["gamma"] * self.dropout(block["mlp"](...))
```

> 注意：**EMA/SWA 已 No-Go**（TODO-20 Δ−0.040），不重复；这里的深度/残差改动是**结构容量**而非事后选优，属不同类别。

### 10.5 PINN 的「矫正式」使用（Corrective PINN）

现状与教训：纯物理约束（E-J `|∇p|`、G2 kernel、VelGrad）**GPU 全 No-Go**；`lambda_wss` 加权 MSE 也已耗尽。核心教训是**不要把物理残差当主损失或把 GT 物理量当输入**。但 PINN 仍有一种**未被本项目系统尝试**的用法——**矫正式/后验式**：

**关键区分**：
- ❌ **主损失式 PINN**（已 No-Go）：把 PDE 残差作为大权重训练目标，小样本下与数据项冲突、噪声放大。
- ✅ **矫正式 PINN**（建议）：数据驱动网络先出场，PINN 只作**软正则**或**推理期精修（test-time refinement）**，权重小、且只约束**推理期可得**的一致性。

三种矫正用法：

| 用法 | 机制 | 为什么可能不同于历史 No-Go | Go/No-Go |
| --- | --- | --- | --- |
| **软物理正则（低权重）** | 主 loss=数据 MSE；加 $\lambda_{phys}\ll1$ 的 no-slip / 连续性残差 | 权重极小（1e-3），只做正则不主导；约束速度场自洽而非直接约束 WSS | Gate-1 不退 + 物理残差下降 → 保留 |
| **推理期精修（TTR）** | 训练后固定网络，对单 case 在物理残差上做少步梯度下降微调预测 | 无需重训；每 case 自适应，直接改善该 case 一致性 | Gate-3：CHEN/fast 等难例改善且不破其他 |
| **可微物理层耦合（§3）** | 近壁剖面 + 解析求导，本身就是"硬 PINN 约束" | 把物理写进结构而非 loss，天然抑噪 | 见 §3 |

**代码钩子（软物理正则，加在 `losses.py`）**：

```python
# training/core/losses.py · 低权重连续性/no-slip 软正则
def physics_soft_regularizer(field_pred, pos, is_wall, edge_index, lam=1e-3):
    # no-slip：壁面点速度应≈0（若数据口径如此）
    wall = is_wall.squeeze(-1).bool()
    no_slip = field_pred[wall, :3].square().mean() if wall.any() else field_pred.new_zeros(())
    # 连续性 proxy：邻域速度散度应小（有限体近似，仅作软约束）
    row, col = edge_index
    div = ((field_pred[col, :3] - field_pred[row, :3]) *
           (pos[col] - pos[row])).sum(-1)
    continuity = div.square().mean()
    return lam * (no_slip + continuity)     # 极小权重，只做正则不主导数据项
```

> 纪律：PINN 项**权重必须小到不与数据项竞争**（先 1e-3，扫到 1e-2 上限）；且**只约束推理期可得量**（速度自洽、no-slip），不引入 GT 压力梯度。若加正则后 Gate-1 就退，立即降权或关闭——这正是历史物理约束失败的红线。

### 10.6 其他系统级杠杆（损失 / 归一化 / 优化 / 集成）

| 子系统 | 已 No-Go（不重跑） | 差异化新做法 | Go/No-Go |
| --- | --- | --- | --- |
| **损失** | AsymW、WSS-only、PWeak、MagCons、Rank loss、EMA/SWA | **谱域 loss**（§9.3）；**分布匹配 loss（Sinkhorn/OT）** 对齐 WSS 分布尾部；**focal 加权**放大 hotspot | Gate-2 hotspot 改善 |
| **归一化** | per-domain norm（+0.003）、val15 扩（No-Go） | **per-case instance norm**（去 case 尺度，配 §9.4 尺度头还原）；**RevIN** 可逆实例归一 | Gate-3 病例方差下降 |
| **优化器** | lr/dropout 微调、EMA/SWA | **SAM（sharpness-aware）** 找平坦极小提升泛化；**多任务梯度手术 PCGrad**（WSS vs 压力 vs 剖面冲突） | Gate-1 泛化 gap 缩小 |
| **位置编码** | — | **Laplacian 特征向量 PE**（曲面图谱）作为节点特征，注入全局位置 | Gate-0：PE 对 GT WSS 有增量解释力 |
| **集成/蒸馏** | 事后 ensemble 选优（No-Go） | **训练期多头蒸馏**（§9.6 CFD ensemble）；**snapshot ensemble** 作 UQ 来源喂 §7 | 只作 UQ，不作精度主张 |
| **图重连（rewiring）** | — | 缓解 over-squashing：加少量长程随机边 / expander 边，改善长程信息流 | 与 §4/§9.1 同目标，择一 |

**多任务梯度手术钩子**（本项目同时学速度/压力/WSS，天然多任务，梯度可能冲突）：

```python
# training/core/trainer.py · PCGrad 思路：投影掉冲突梯度分量
def pcgrad(grads):                        # grads: list of per-task flat grads
    import random
    out = [g.clone() for g in grads]
    for i, gi in enumerate(out):
        for gj in random.sample(grads, len(grads)):
            dot = (gi * gj).sum()
            if dot < 0:                    # 冲突：投影掉
                gi -= dot / gj.square().sum().clamp_min(1e-12) * gj
    return sum(out)
```

### 10.7 各优化方案的通用注意事项与坑（务必先读）

> 数据增强之外，其余方案也各有"看起来无害、实则让效果更差"的坑。逐条列出，落地前对照检查。

**预训练（§10.2 / §5）**
- **域偏移优先于数据量**：V3D 跨域预训练若 AAA/ILO 与 AG 分布差异过大，微调会被带偏（对应 J4/J5 混训 No-Go 的根因）。先做分布审计，**只预训练近域**。
- **只加载 encoder、不加载 head**：head 随机初始化重训，否则把预训练任务的偏置带进 WSS 任务。
- **微调 lr 要小 + 分层学习率**：encoder 用小 lr（如 1e-4），新 head 用大 lr（1e-3），避免灾难性遗忘预训练表示。
- **归一化口径必须一致**：预训练与微调的输入/目标归一化统计要么共享，要么在微调时重新对齐，否则分布错位。

**消息传递（§10.3）**
- **各向异性消息要平移不变**：只能用相对位移 `pos[col]-pos[row]`，**绝不能**直接喂绝对坐标 `pos`，否则破坏平移不变性、过拟合到坐标（复用 5303 审计 H5 结论）。
- **动态图开销与不稳定**：DGCNN 每层重建 kNN 显存/时间翻倍，且早期特征噪声会让图抖动；建议只在后几层用。
- **注意力/虚拟节点要按图隔离**：batch 内多个 case，全局注意力/虚拟节点**必须按 `data.batch` 分图**，跨 case 泄漏是隐蔽 bug（§4 代码里已用 `batch.unique()` 逐图处理）。
- **over-smoothing**：加深消息传递层数会过平滑，横向高频信息被抹掉——与"补横向分量"的目标相悖；配残差/门控，并盯 Gate-2。

**残差 / 深度（§10.4）**
- **小样本加深先过拟合**：60–179 case 下盲目加深会 train↑ test↓。加深必须同时上 Stochastic Depth / dropout / 权重衰减，并用 Gate-3 盯病例级是否退化。
- **LayerScale 初始值要小**：$\gamma$ 初始 1e-4 才有"渐进式加深"效果；初始过大等于没加。
- **不要与 EMA/SWA 混谈**：那是事后选优（已 No-Go）；深度/残差是结构容量，别在同一次实验里混入 EMA 掩盖归因。

**PINN 矫正式（§10.5）**
- **权重红线 $\lambda_{phys}\le$ 1e-2**：一旦物理项与数据项竞争（Gate-1 就退），立即降权或关闭——这正是历史主损失式 PINN 失败的原因。
- **只约束推理期可得量**：no-slip、速度连续性可以；**禁止**把 GT 压力梯度/GT 涡量当约束或输入（E-J 教训：GT oracle ≠ 网络可用）。
- **连续性 proxy 只是近似**：点云上的散度是粗略有限差分近似，别当硬约束；它放大噪声的风险和 VelGrad 同源，务必小权重。
- **TTR（推理期精修）要设早停**：对单 case 过度精修会拟合物理残差而偏离数据，精修步数（如 ≤20 步）和步长要保守，且**只在难例上用**。

**损失 / 归一化 / 优化（§10.6）**
- **per-case instance norm 必须配尺度还原**：去掉 case 尺度后，评估时要把尺度乘回来，否则 pooled R² 口径不一致（对应 Idea D 的 mode-scale 双头）。
- **谱域/OT loss 是辅助项**：低权重叠加在数据 MSE 上，不能替代主监督；且谱基（图 Laplacian 特征向量）要缓存，否则每步重算太贵。
- **SAM 训练成本翻倍**（两次前反向）；PCGrad 在任务梯度频繁冲突时才有收益，任务不冲突时是纯开销——先测任务梯度余弦相似度再决定。
- **Laplacian PE 有符号歧义**：特征向量方向不唯一（±），需做符号随机化或用 SignNet，否则引入伪特征。

**通用（所有方案）**
- **一次只改一个变量**：本项目全线纪律。增强 + 换 head + 加深同时上，赢了也无法归因、输了不知怪谁。每个改动单开 config、单独对照 I6-diag 0.429。
- **验证/测试集不加增强、不做 TTR 之外的训练期技巧**：任何只应用于训练的技巧（增强、StochDepth、dropout、SAM）在 eval 时必须关闭。
- **警惕 val 假阳性**：小样本下 val 波动大，单 seed 涨不算数，按 §2 五级闸门走到 Gate-4 三 seed 才升母版。
- **归因四层不可省**：pooled 之外必看横向分量、hotspot、L3/CHEN/fast + 压力不退化，否则又是"只涨低频轴向"的假突破。

## 13. 诚实的边界与「不建议再做」

1. **不要把已 No-Go 的方向换名重跑**：AsymW/lr/dropout/WSS-only/PWeak、`dist_to_wall+branch_id` concat、有限差分近壁梯度、纯几何 SSL、G4-c 全量、盲目 V3D 混训——路径 A–G 已闭环。前沿价值在**换范式**而非换特征。
2. **可能存在物理不可约上限**：横向 WSS 依赖入口剖面、时间相位、二次流细节；若采集/标注/回插链本就不可靠（Idea A 的 13 例 basis QA 未修），任何模型都有天花板。**所有方向应与标签地板审计并行**，否则把数据噪声当模型不足去冲。
3. **M-N 与 M-E 分轨**：论文/汇报（M-N）继续用 G5 叙事（`r2_p≈0.93`、病例 Pa p95 排序）收口；本文方向针对 M-E（工程替代 CFD、逐点 WSS），二者不混表。
4. **投产比现实排序**：§3（可微 WSS head，复用 backbone）与 §4（slice-attention）是低成本高相关，先做；§5/§6 是结构性但重工程，在 §3/§4 拿到 Gate-2 正信号后作为第二波。

---

## 14. 一句话总结

本项目已在「点云 → 直接回归逐点 WSS」范式内把超参、loss、局部特征、坐标系几乎穷尽。**下一步突破更可能来自换范式：把近壁微分算子写进结构（可微 WSS head）、把全局/上游耦合交给算子注意力（slice-attention / GINO / 中心线虚拟节点）、用物理基础模型预训练解小样本、用生成式补 hotspot 并给出可驱动主动选数的校准不确定性。** 其中「可微 WSS head」与「slice-attention processor」是投产比最高、最该先验证的两条，且都能在现有 `FieldPointNeXt` + `ModelConfig` 体系里以低成本落地。
