## 1. 当前判断：数据已修好并扩充，缺的是外部证据

第一篇论文的主张不变：**在固定 CFD 协议下，用解剖几何加分流尺度先验预测峰值 WSS，并且能从表面点云直接部署。** 09-21 的路线图把问题进一步收紧为三件事：精度由什么决定、需要多少数据、能不能从分割面直接部署。压力 / 速度（PF6、VF6）和周期积分量（TAWSS、OSI）作为同一套表示的扩展证据；该段为09-24原主张；09-29起完整时间序列已进入优先研究，现状见§1.1a，临床风险闭环仍需后续证据。

与 09-15 版相比，三件事已经落地：

1. **RCR 修复闭环**：26 例按协议重算、验收、剔除 2 例重复病例，得到 v5.1（170 例，train136 / test34），X5D 在修正标签上**重新训练**（不是只换标签重评），五 seed 集成成为部署底座。
2. **数据扩充**：learning curve 显示数据量仍是瓶颈，于是回收 91 个历史排除单元并全部过门入库，得到 v5.2（261 例）；v5.2 基线重训正在跑。

## 2. 论文问题与可证伪假设

中心问题：**在给定仿真协议内，什么决定几何驱动 WSS surrogate 的精度，它需要多少数据，能否从表面点云直接部署，失效边界在哪里。** 按问题组织证据，不按 V1 → V6 的实验顺序讲故事。

| 假设 | 现有支持 | 下一步关键区分实验 |
| --- | --- | --- |
| H1：分支尺度先验与局部壁面信息互补，精度主要来自输入信息而非网络容量 | X5 Murray 先验 +0.069；信息 / 结构 / 容量拆分；多项结构探索无增益 | 同协议外部基线（原版 PointNet++、LaB-GATr 或 GEM-GCN、带全部特征的 MLP）与解析基线（Murray + Poiseuille）；v5.2 上的组件开关 |
| H2：显式处理采样变化使部署输入稳定 | X5D 在粗采样下显著好于 X5，全密度持平；部署合同已定 | 真实分割面（10–20 例从 CT 重新分割）走部署链路，对比 CFD 导出面 |
| H3：数据量仍是精度瓶颈 | learning curve 每翻倍约 +0.03、未饱和 | v5.2（261 例）的 CV5 折外是否落在外推线上 |
| H4：总体拟合能传递到区域与病例级描述量 | 失效三族分析；热点 IoU、top10 比 | 冻结模型上的分支均值 / p95、热点定位；低方差族改用 MAE |
| H5：同一表示对其他输出有效 | PF6 / VF6（v5.0）；M1 的 TAWSS、OSI | PF6 / VF6 在修正数据上复验；OSI 尾部矩阵 |

**关键解释边界**：X5 的 `log_q` 是按几何分配的相对份额，`log_tau0 = log_q − 3 log(R_mm)` 是尺度代理，都不是测得的患者流量或真实 WSS。RCR 审计证实 CFD 出口分流本身就是按出口面积的 Murray r³，X5Dcap 用开口半径更贴近这条协议。因此当前优势应解释为「模型利用了已知协议结构」，尚未证明它能从几何恢复任意患者的真实生理条件；要界定这条边界，需要边界条件变化实验。

**部署可得性硬约束**（用户 09-13 / 导师 09-05 裁定）：模型输入只能是壁面点云、VMTK 中心线及其派生量；RCR、出口通量、壁压、速度等 CFD 真值只能作标签或残差分析，不作输入，也不做 oracle 上限实验。

当前模型属于**几何与物理启发先验增强的监督学习**，不是 PINN；也不应把离线 surrogate 表述为已完成动态更新与临床闭环的数字孪生。

### 4.2 开发集与独立验证

- **test34**：名称保留，明确是**开发暴露集**（结构筛选、诊断、密度选择都用过）；五 seed 只衡量训练随机性，不恢复独立性。
- **cv3（v5.1）与 CV5（v5.2）**：患者分组的内部验证；CV5 覆盖 261 例、同名病例和 ILO 术前术后同折、按队列分层。配方在跑 CV5 之前已固定，但属于在本队列上开发的方法，须如实披露。
- **IND（170 训 / 91 测）**：91 个回收单元没有参与训练，但**不是未触碰集**。入库时对每个新单元读了冻结 X5D_v51 的预测，低分病例触发了查因，并据此修了真实的数据错误（端点半径膨胀导致 18 例重建、AN_GUANG_JIE 的 RCR 小数点错位）；X5Dcap 在 v5.1 上已是候选，但把它纳入 v5.2 的直接理由来自新单元里的术后分流失败。所以 IND 读数是「独立于训练、不独立于开发决策」，X5Dcap 对 X5D 在 IND 上的差不能当盲比较。查因修的都是有独立证据的真错误，但「只在低分处找错」会让读数偏乐观，写论文时要说明。
- **确认集**：09-21 路线图计划把回收的 A 层 73 例冻结为开发期不碰的确认集；这批单元已并入上面的 91 例并被读过预测，**该计划作废，目前没有未触碰集**。后续需要：新到的病例或外部中心数据，名单在看任何预测前冻结，入库只过几何 / CFD 质量门，模型和分析全部定稿后只评一次。拿不到的话，论文明确写成内部验证。
- AG / AAA / ILO 是数据分组，未经来源核实不得称为多中心外部验证。

### 4.3 主指标、尾部与统计单位

WSS 主指标是 Pa 空间的病例等权场 R²_cb：每病例权重为 1，病例内点等权，

`R²_cb = 1 − mean_i[mean_j((pred_ij − true_ij)²)] / mean_i[mean_j((true_ij − μ)²)]`，其中 `μ = mean_i[mean_j(true_ij)]`。

它不是逐病例 R² 的均值；`legacy_vertex` 也不是面积加权指标。

| 层次 | 主报告 | 防止误读 |
| --- | --- | --- |
| WSS 整体 | Pa R²_cb、归一化（log_z）R²_cb、病例等权 MAE、逐病例 R² 分布 | pooled、case mean、log_z、拟合后 R² 分开命名；归一化 R² 噪声小、适合判别，Pa 作汇报口径 |
| 稳健性 | 逐病例配对差、P10 与低分病例比例、队列分层 | 数百万点不等于数百万独立样本；低方差病例（失效族 B）看 MAE，不只看 R² |
| 高值区域 | 各病例真值 p90 区域的误差、幅值比、热点 IoU | 逐例 p90 与全点 pooled p90 不混用；top10 IoU 不是临床风险识别 |
| 周期量 | TAWSS / OSI 的 R²_cb、CCC、掩膜 Dice / IoU、分段误差、Bland–Altman | OSI 掩膜阈值（0.1 / 0.3）在分布中的位置会主导 IoU，阈值预先固定 |
| 区域与病例 | 预定义分支均值 / p95、左右差 | 临床阈值需独立依据；点比例不写成表面积比例 |
| 速度 / 压力 | 向量分量与速率分开；壁面 / 体内压力分开；压降和流量单列 | 高速率 R² 不代表方向正确，高压力 R² 不代表压降准确 |
| 集成 | 单模型 mean ± SD 与集成分开，写明 seed 数和 Pa / log 平均方式 | 不拼接不同集成空间的数值 |
| 文献对照 | 按文献口径重算的逐例 R²、相对 L2、NMAE_max | 只和同口径比较：例如 Rygiel 2025 是 21 帧三维向量误差，我们是标量峰值帧，不能直接排名 |

**判别的噪声带**（R4 三 seed 标定）：物理 R²_cb 单 seed 对单 seed 的 95 % 带 ±0.045，三 seed 均值对三 seed 均值 ±0.026；归一化分别为 ±0.011 / ±0.006。参照取三 seed 均值；物理和归一化两个口径同向且各自超过自己的带才下结论；单 seed 臂只列数字、标「不判定」。

统计以患者为独立单位，主对比报告患者配对差和患者级 bootstrap 区间；同患者多侧 / 多帧用分组重采样。预先指定一个主要对比，其余标为探索性或做多重比较处理。新阈值只在训练 / 验证阶段确定，不能用已看过的结果倒推 Go/No-Go 线。
