## 1. 推荐定位及目前离高水平投稿的距离

建议第一篇写成**限定仿真协议的血流计算方法论文**：以 X5D 的 WSS 预测为主体，证明几何与分流尺度先验的价值，并重点验证点云采样变化下的稳定性。PF6/VF6 可扩展到压力和速度；临床风险模型不作为本篇必需环节。

已有工作足以开始写问题定义、方法与验证方案，并搭建图件。当前还不足以锁定“一区顶刊已具备投稿条件”：26 例 CFD 标签正在修正，test34 已参与开发，X5D 尚缺自身患者分组验证，当前协议的现代强 baseline 与真实输入验证也未完成。决定上限的是这些证据，而非把更多历史模型或漂亮云图放进正文。

**拟议中心论点，须由补实验验证：** 在固定 CFD 边界协议下，解剖几何、分支尺度先验与局部壁面表示可以构成有效的 WSS surrogate；显式密度增广有望缓解从 CFD 网格节点到不同采样表面的性能下降。论文需同时回答这种有效性可否推广到未参与开发的患者，以及何种输入变化会使它失效。

### 1.1 候选题目

建议工作题目：

**Geometry-informed learning for wall shear stress prediction under surface sampling variation**

中文：**面向表面采样变化的几何先验增强壁面剪切应力预测**。

若完成修正后患者和真实表面验证，可改为：

**Robust wall shear stress prediction from vascular geometry with protocol-informed flow priors**

中文：**结合协议分流先验的血管几何驱动稳健壁面剪切应力预测**。

“robust”需由预定义扰动范围支撑；“patient-specific”须说明只个体化几何还是同时个体化生理边界。当前题目不宜加入“临床风险预测”“实时数字孪生闭环”“通用 PINN”或“全周期血流重建”。

### 1.2 期刊选择应由最终证据决定

下表是研究方向匹配建议，**未实时核验 2026 年中科院/JCR 分区、TOP 标签或投稿要求**，不构成一区身份保证。用户尚未指定分区体系，先按较高标准的方法/医学工程定位准备。

| 目标方向与候选 | 需要怎样的论文 | 当前最关键的差距 |

### 2.2 统一术语

| 术语 | 本篇固定含义 | 避免的混用 |
| --- | --- | --- |
| WSS | 壁面剪切应力；当前主要预测峰值帧标量幅值，Pa | 单帧 WSS ≠ TAWSS/OSI/RRT |
| 几何/协议先验 | 中心线、半径、局部壁面几何；相对分支份额与 `log_q−3logR` | 不是实际患者流量测量；不是新发现的血流定律 |
| X5D | X5 结构与输入加密度增广；单模型或明确指定的集成 | 不是 X5X11，也不是 PF6/VF6 联合网络 |
| R²_cb | 病例等权、例内点等权的场 R² | 不是病例 R² 均值，也不是面积等权或线性拟合后 R² |
| 采样鲁棒性 | 同一表面上的点密度/分布变化 | 不等于表面分割误差、中心线误差或生理边界迁移 |
| 生理/临床验证 | 实测条件、实际输入或临床终点的独立验证 | 固定协议 CFD 对照不能覆盖这些含义 |

## 3. 主张—证据—补实验

| 拟议主张 | 当前状态 | 让它成为可发表结论所需的证据 |
| --- | --- | --- |
| 几何与分支先验能提升 WSS 预测 | 开发结果支持，需修正后确认 | 同数据/同 seed 的无先验、仅尺度、完整先验和解析尺度基线；强架构对照 |
| 局部壁面表征与分支先验互补 | 有组合设计与历史消融，尚需严格拆分 | 去 patch、去方向、去分支先验；预算匹配；检验哪些区域受益，避免只比较模型大小 |
| 密度增广减小采样改变导致的性能下降 | 当前最清晰的方法线索 | 新标签、共同 seed、相同集成方式的密度扫描；非均匀抽稀、缺点与新的表面输入 |
| 模型对未见患者有效 | X5D 证据缺失 | 未暴露患者优先；否则完整分组嵌套 CV 并说明队列曾用于开发 |
| 预测保留有用的区域血流描述量 | 需补当前合同验证 | 面积加权区域均值、p95、左右差/热点定位与 CFD 的一致性及可接受误差依据 |
| 方法适用于不同输出场 | PF6/VF6 有开发支持 | 新标签下独立任务复验、各自基线；不把跨任务数值拼成一个综合准确率 |
| 真实临床风险或治疗获益 | 未建立 | 临床终点、随访、事件数、适用人群、独立验证；本篇默认不作该主张 |

**最有区分力的补实验**：在代表性几何上改变合理范围内的边界条件，比较无条件几何模型与条件模型/参考 CFD 的变化。这能明确“固定协议有效”与“患者生理泛化”的边界，比增加一个注意力模块更能回答审稿问题。它是额外 CFD 工作，先确定论文是否要承担跨协议主张，再决定范围；不与 26 例纠错混为一类实验。

**修复的论文位置**：说明 CFD 参考标签如何核查及其对结果解释的影响；详细 26 例过程放 Methods/SI，主要结论受影响之处在正文说明。录入错误修复本身不宜被包装为算法创新。

## 4. 全文写作顺序与章节提纲

先写 Methods 和图件框架，再写确认后的 Results，最后定摘要、题目和期刊。以下小节标题是拟议论证任务，最终需随证据调整。

| 部分 | 读者需要得到的答案 | 拟写内容 |
| --- | --- | --- |
| Introduction 第 1 段 | 为什么关心壁面血流而不只看全局流场 | WSS 的空间异质性与计算代价；临床关联必须补文献，避免直接推成预测终点 |
| Introduction 第 2 段 | 现有 surrogate 具体缺什么 | 几何表示、条件协议和网格/点采样依赖；通过已核查文献形成对照，不泛称“所有方法都忽视” |
| Introduction 第 3 段 | 本研究提出什么可检验改进 | 协议先验与局部表示、密度增广；限定峰值和 CFD 协议范围 |
| Results 1：任务与可信参考 | 数据、目标和验证是否可信 | 修正后的队列/患者流程、标签与选择协议；主要数据限制 |
| Results 2：公平比较 | 在同条件下是否有效 | 主模型对简洁及现代强基线；患者分布与主要效应区间 |
| Results 3：表示的作用 | 改善来自哪里 | 先验/局部信息的受控消融、解析基线、区域误差；保留不支持的关键结果 |
| Results 4：泛化与鲁棒性 | 换患者或采样后是否仍有效 | 独立/外折患者验证、密度曲线、几何/切口敏感性；局限不能埋入附录 |
| Results 5：用途与代价 | 预测有什么可用价值、成本多大 | 区域描述量、典型与失败病例、全流程时间；PF6/VF6 按篇幅作为扩展 |
| Discussion | 结论为何成立、在哪里不成立 | 协议匹配的解释；与文献具体区别；标签/测试暴露、真实输入与生理变化的限制 |
| Methods / SI | 能否复现与审查 | CFD 设置与收敛、患者划分、特征计算、训练/选模、指标、统计、全部关键对照与版本记录 |

摘要结构预留为五句：①具体问题；②方法与限定输入；③最终独立或内部验证设计；④主要比较的效应与不确定性；⑤适用范围。第③④句暂用 `[待填：修正后验证病例数、比较效应和置信区间]`，不把开发集最高分提前锁进摘要。

全文不要按 R1、R4、C1、X5、X11、T3n 的先后顺序复述日志。主文用可读的方法名称，实验代号放方法映射表；旧 PINN、失败 loss 扫描、完整 seed 明细和诊断过程以 SI 保存。

### 5.2 制图合同

- 主文云图使用相同病例、相同视角和共同的物理单位色标；误差图使用独立且统一的误差色标。预测与真值各自 selfmax 只作补充形态展示，并明确分母。
- 定量优先原始同点。Gaussian 面片/插值用于展示时说明方法与误差；平滑外观不代表热点或精度改善。PF6 若展示壁面，图注不能让混合域指标被误认为壁面指标。
- 病例按事先确定的分层或中位/分位规则选择；主图必须包含失败病例。若按集成选例而展示单 seed，应明确标出，不能把集成分数贴到单模型图上。
- 患者是统计单位。箱线/散点图标注独立患者数、重复训练数及区间含义；不靠大规模点云制造过窄置信区间。
- 方法示意用可编辑 SVG/PDF 或代码绘制；结果图来自真实数组与脚本。现有 PPT 是汇报资产，投稿图应按最终期刊宽度检查字号，保存矢量版和必要的高分辨率位图。
- 每图交付源数据、生成脚本、图注、模型/数据版本和匿名病例 ID；公开图避免显示患者姓名。不能仅提供一张无法追溯的截图。

SI 放 CFD 网格/时间步/周期收敛及 RCR 质控、全部基线实现与适配、逐 seed/逐患者结果、历史路线选择、全部扰动档位、原生壁面与映射对照、全周期探索、PF6/VF6 详细分项指标。影响主结论的标签修复、test34 暴露、泛化失败和关键消融负结果仍须在正文可见。

## 6. 补实验优先级与停止扩张条件

| 优先级 | 工作包 | 完成标准 |
| --- | --- | --- |
| **必须先做** | CFD 修复→母库/视图/sidecar/stats 刷新；患者映射与新数据冻结 | 26 例逐例验收，训练/测试受影响清单可追溯；旧/新标签版本清楚 |
| **决定论文可信度** | 修正后 X5/X5D 与关键 baseline 重训；患者验证 | 选择规则先冻结；旧 test34 清楚标开发暴露；X5D 不借用 X5 的 CV |
| **决定方法新意** | 解析先验、现代点云、壁面 mesh/等变强对照；最少关键消融 | 架构、信息量、调参预算分开；明确新增方法超出简单协议拟合的部分 |
| **决定应用深度** | 非均匀采样/真实表面、区域统计、全流程计时 | 同点参照、临床输入与点采样分开、成本包含五模型和预处理 |
| **条件允许再做** | PF6/VF6 扩展、毫米邻域、边界协议变化 | 修复后仍有明确问题，且能改变中心论点；不做无限模块组合 |
| **后续论文** | 完整周期与临床结局 | 足够时间/方向数据，真实终点与随访，独立临床验证合同 |

达到主线验证后停止扩大结构搜索。若 X5D 只在粗采样有优势，就围绕鲁棒性写；若强基线消除优势，应收缩或重新定位方法贡献；若修复后高值困难明显减轻，应修改原尾部机制叙事。任何情况下都不通过挑测试 seed、删除困难病例或换聚合指标制造胜出。

## 7. 可并行的阶段安排
