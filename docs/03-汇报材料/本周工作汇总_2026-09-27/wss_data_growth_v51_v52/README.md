# WSS 数据增益与学习曲线（2026-09-27）

面向导师汇报的两张图，来源为已有实验结果；未训练新模型，未重新运行推理。

## 可直接用于汇报的说明

V5.1 的固定三折交叉验证学习曲线显示，随着每折训练病例从约 23 例增加到 91 例，X5D 的病例等权 R² 从 0.647 提升到 0.713。数据版本扩充至 V5.2 后，每折训练病例约 209 例；在相同 136 例折外病例上，X5D 的 R² 进一步达到 0.752，MAE 从 1.501 Pa 降至 1.377 Pa，下降 8.3%。X5Dcap 在该队列上的 R² 为 0.760，MAE 为 1.346 Pa。跨版本结果同时包含 CV3→CV5 和几何修复的影响，不能把全部增益单独归因于样本量。

| V5.2 X5Dcap | 208.80 | 同136例 | 0.7601 ± 0.0016 | 1.3459 ± 0.0055 |

1. 三个 seed 为 1234、7、2025；每个 seed 先汇总各折的折外预测，再计算指标，最后报告三个指标的均值和样本 SD。没有先平均模型预测，未混入集成收益。SD 不是置信区间。
2. 每例仅使用其留出折的模型预测。R² 采用病例等权的全局真值均值为中心；MAE 为病例内点平均后再对病例等权平均，均在物理 Pa 空间计算。
3. V5.1 总队列为 170 例，旧学习曲线在原 train136 上进行 CV3；V5.2 总队列为 261 例，CV5 每折训练病例分别为 206、204、211、211、212。横轴使用实际每折训练数，不能直接写成 136→261 或 170→261。
4. 本图 V5.1 为三 seed 的 0.7129，区别于此前单 seed 的 0.7100；V5.2 为共同 136 例的结果，区别于此前全 261 例的 0.7538／0.7608。因此数值有意与先前全队列表格区分。
5. 主图实线是 V5.1 的固定 CV3 嵌套子集；虚线仅表示跨版本进展，无拟合或外推。主图横轴为对数刻度，分层附图横轴为线性刻度，均明确标注。
6. MAE 细线只连接同 seed 编号，不表示新旧模型使用相同的交叉验证分区，也不构成统计显著性检验。
7. 射流分层定义为病例真值 WSS 的 p99 > 40 Pa；射流 25 例，非射流 111 例。

## 复现

在项目环境中运行 `plot_data_growth.py` 即可从随附 JSON 重绘。若要重新整理原始实验数据，可先运行 `prepare_source_data.py`；它只读取已有预测与指标，不进行训练或推理。源实验的绝对路径已保存在 `source_data.json`。

本目录保留原实验和旧图的独立副本式输出；未修改原实验或跟踪文档。
