## 1. 正文 P19–P36

### P19 部署形态是怎么定下来的

**本页问题**：把模型交出去的时候，输入到底长什么样？这个形态是怎么定的，不是拍脑袋？

图：[部署决策链](figures/01_deployment_decision.png)（六步，每步一个数字）

| 步 | 做了什么 | 结论 |
| --- | --- | --- |
| ① 先量训练数据自己的密度 | 172 例壁面节点最近邻间距 | p10/p50/p90 = **0.41 / 0.94 / 1.28 mm**；AG 1.17、AAA 0.47、ILO 0.46 —— "训练密度"没有单一数值 |
| ② 部署模拟不是抽稀 CFD 网格 | 34 例从原始 STL 面积加权重采样，中心线 / 解剖架 / PCA 法向 / 曲率族 / flowref **从零重算** | 真值取最近 CFD 节点，Δ 一律对"同一 checkpoint 全云预测限制到同一批点"的同点参照 |
| ③ 损失出在哪 | support × patch 2×2 邻域分解 | 25% 抽稀：thin/thin −0.061、只抽 patch −0.054、**只抽 support −0.009** → 代价几乎全在 K16 query patch |
| ④ 密度增广训练 X5D | 70/50/35/25% 四档随机密度 | STL 1.2 mm 档 −0.147 → **−0.047**；全密度不变（0.7331 → 0.7333） |
| ⑤ 几何保真合同 | 平滑 / 噪声 / 粗糙 / 切口逐项扰动 | 重采样 0.5 mm 甜点；平滑 1 mm 几乎免费；噪声 0.2 mm −0.053；亚毫米粗糙 −0.092，先平滑收回到 −0.038 |
| ⑥ 部署底座 | 五 seed Pa 均值集成 | 旧数据口径 0.7465；重采样 TTA 5 次只换回 +0.004，不值得 |

**部署合同**：壁面点云重采样到中位间距 ≈0.5 mm → 先做 1 mm 平滑 → X5D 五 seed Pa 均值集成；髂动脉切口须与 CFD 取同一解剖层面（±5 mm 可容忍）。

**讲稿一句**："部署形态不是选出来的，是先量训练数据自己的密度、再把损失拆到哪一层、最后用训练侧增广把曲线压平定下来的。"

### P22 RCR 出口面积录入核查（为什么要重跑 CFD）

**本页问题**：为什么这一批数据要推倒重算？

图：[录入核查](figures/04_rcr_audit.png)

方法：用 `R1 = 8μτ/(πr³)` 从 UDF 反解出"表格里隐含的出口半径"，与网格出口面质心半径比较。**协议本身没问题** —— CFD 的分流就是按出口盖面半径的 Murray；错的是把面积抄进表格这一步。

| 项 | 数字 |
| --- | --- |
| 全部出口 | 688 个（172 例） |
| 录入错误 | **39 个出口 / 23 例**（AAA 10、AG 6、ILO 7） |
| 错误类型 | 小数点错一位 14、左右 / 内外互换 10、面积不符（未归类）15 |
| 落在 test34 | **4 例**（SUN_SHU_MING、SUN_XU_XIA-1、ZHANG_JIN_CHUN-1、ZHANG_YONG_SHENG-0）—— 这 4 例的 WSS 标签已经变了 |
| 重算 | 23 + 补改 3 = **26 例**重跑 CFD；26/26 分流复核通过；旧导出 52 个目录 248.2 GB 已删 |
| 同期去重 | 扫出 2 例重复病例（LIU_WEN_QI = ZHU_ZI_HAI；HOU_SHEN_QIAN 与 KANG_XI_MING 同一张面）一并剔除 |
| 数据口径 | 172 例 → **170 例（train136 / test34）** |

**讲稿一句**："这不是模型问题，是边界条件表格的录入问题；我们把它反查出来、重算了 26 例，并顺手去掉两例重复病例。"

### P29 为什么沿程通道没有把整体 R² 抬起来

**本页问题**：不是"模型没用这些特征"，那是什么？

图：[四组只读诊断](figures/11_longitudinal_why.png)

1. **最强的通道是旧信息的重述**：`geom_ref_log_area` 能被原 27 维预测到逐例 R² **0.984**（面积 ≈ 半径²，底座已有 `log_local_radius`），而它恰恰是 32 个通道里与目标相关最高的（−0.799）。真正"新"的圆度、偏心率、上下游最窄距离（可预测度 0.18–0.28）恰恰与目标相关最弱。
2. **一半通道互为重复**：ref 与 pc 同名通道相关 —— log_area 1.000、eccentricity 0.996、area_slope 0.992、上下游面积比 0.98、距离 0.93–0.95，只有 roundness 是 0.726。回归掉原 27 维后，16 个 value 的**有效维数只有 7.16**（满分 16）。
3. **新信息解释不了底座的错**：16 个 value 对底座残差的 OLS 只解释 **R² 0.0059**（逐例去均值 0.0070）；沿程臂训练后残差里只剩 0.0050，残差 sd 0.4728 → 0.4671 —— 模型把能用的都吃掉了，本来就只有那么多。
4. **收益真实存在，但被摊薄**：32 通道全有效的 65% 点上 ln-MSE 改善 **+4.67%**，WSS 90–99% 分位 **+9.51%**；但 35% 有缺失通道的点上**反而差 1.65%**，占一半点数的低 WSS 区差 1.32%。

**讲稿一句**："模型确实把这些通道深度接进了表示（推理时屏蔽掉会掉 0.074），但其中'新'的那部分与底座的误差几乎正交 —— 再往同一方向堆沿程标量，天花板就是千分之几。"

图：[残差结构](figures/12_residual_structure.png)

| 指标（log_z 残差，分支 × 4 mm 区间，逐例中位） | test34 五 seed | cv3 折外 136 例 |
| --- | ---: | ---: |
| 区间内型态份额 | **69.66%** | **70.13%** |
| 区间均值份额（其中分支均值） | 30.34%（7.30%） | 29.87%（8.15%） |
| 区间均值轨迹 R² | 0.9447 | 0.9306 |

**讲稿一句**："区间内部（截面内型态）占了七成残差，而沿程轨迹已经解释到 0.93 以上 —— 剩下要攻的就是这一块。"

**讲稿一句**："Murray 先验是唯一一次 +0.10 量级的效应，之后每一轮加输入都在 seed 噪声里；这类信息的天花板已经量出来了，是千分之几。"

**讲稿一句**："换了三代底座、换了数据、换到患者分组折外，这个比例一直是七成；沿程那一维已经做到 0.93，卡住的是截面内的局部型态和幅值。"

### P34 为什么说"局部形态还没被真正试过"

**本页问题**：局部结构不是早就试过了吗（X7/X8/X9/X11）？

- **现行 query patch 的结构**：K16 邻居 → 逐邻居 MLP → 共享 FiLM 调制 → **mean 池化** → 线性输出（`training_wss_min/local_refinement.py:240`）。含相对坐标，但**没有邻居之间的交互**，mean 池化把周向位置抹平了。
- **波 1 的结构类候选全部落在同配置抖动带 ±0.034 内**：X7 切平面坐标架 +0.037、X9 坐标架+注意力+K32 +0.025、X8 注意力池化 +0.012、X12 MoE +0.034。**"读不出来" ≠ "已被否定"** —— 那一轮是单 seed 预算。
- **X11 截面 token +0.053 是超带的**，但它做的是"截面整体的上下文"，不是截面**内部**的型态；且只兑现了预登记理论上限（≈+0.06 归一化）的五分之一。
- **方向是对的**：沿程臂的收益恰好集中在 WSS 90–99% 分位（+9.51%）与热点 IoU（3/3 升）——**给一点局部结构信息是有用的，只是标量形式不够**。
- V6-A5 的**壁面局部微分几何**曾是当时最好的一档（0.623 / 0.820），但没有接到现在的底座上。

**讲稿一句**："真正对着'截面内型态'去改的结构，只有在单 seed 预算下扫过一遍，没有一次是在现在的底座上、用三 seed 配对认真做的。"

**决定：保留集 = `geom_ref_roundness` + 其 valid mask（2 列）。** 除了上面的「归一化持平」与「全场 ln-MSE 最好」，另有四条互相独立的判据同向：折外边际增量占 16 通道天花板的 **53%**（两个病例半分都排第一）；逐点覆盖率 **0.788**（全阶梯最高，全 32 列只有 0.651）；被原 27 维预测的程度只有 **0.178**（对照 `log_area` 0.984）；ref/pc 重复度只有 **0.726**（其余 7 项中位 0.982），是唯一不重复的字段。备选 = L8（ref 8，16 列），只有在后续确实需要高 WSS 尾部时才值得。

**两条边界**：(1) 单 seed；要把 L1 提为正式候选进底座，仍须补 seed 并过 cv3 折外（P30 的 T3n 教训：test34 与折外可以异号）。(2) 单 seed 下"门控混合"全面劣于等权平均（L1 门控 0.7556 vs 等权 0.7594），而三 seed 集成时相反（0.7844 > 0.7821）—— **门控是方差敏感操作，要用就必须配集成，单模型上不要用**。

**和后续方向的衔接**：roundness 就是**截面圆度**，本来就是截面内型态的粗粒度代理；P33 已确认 70% 的残差在"分支 × 4 mm 区间内部"。所以这轮可以这样读 —— **沿程这条线上真正有用的那点信息，本质是截面形状而不是沿程尺度；沿程方向可以收口了**，力气应该放到截面内型态的细粒度表征上（P35 的候选 A / C），而 roundness 作为 2 列的先验一起带走。

**讲稿一句**："剪枝的结论不是'省了 30 列'，而是'这 32 列里唯一真正有用的那一列是截面圆度'—— 它和我下一步要做的截面内形态是同一件事。"
