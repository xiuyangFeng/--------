# WSS 启发式实验汇报提纲（2026-09-13）

## 汇报要回答的一句话

我比较了三条得到 WSS 的路径，并把输入、监督、物理约束和后处理拆开：直接在壁面预测 WSS 已有稳定的三 seed 结果；体场数据驱动路线能把速度/压力做到约 0.79–0.80，但“速度预测好”经过近壁梯度和 WSS 算子后会明显掉分；物理约束路线的主要问题已经定位到损失竞争和权重饱和，下一步需要用分项 loss、局部场图和一组受控实验验证修复方案。

这份 PPT 的主线是“现象 → 证据 → 可能机制 → 区分实验”，每页只回答一个问题。旧实验只作为决策证据，不再按时间顺序堆成结果长表。

## 正文建议：18 页（约 20 分钟）

### 1. 封面：这次汇报要解决什么困惑

副标题写成三个问题：哪个模块真的有用？速度高分为什么不等于 WSS 高分？物理约束究竟在哪一步失效？不要放总指标表。

### 2. 三条路线总图：同一个 WSS，三种误差链

画三行流程：

* A：壁面几何/局部特征 → 直接 WSS；
* B：体几何 → `u,v,w,p` → 近壁梯度/冻结算子 → WSS；
* C：体几何 → `u,v,w,p` + BC/PDE loss → 近壁梯度/冻结算子 → WSS。

在箭头上标“模型直接输出什么、哪一步是后处理、哪一步会放大误差”。右侧列本轮每条路线的代表 run：X5/X5X11、VF6/PF6、历史 V4 PINN。

### 3. 统一条件与不可统一项

只放一张小表：病例/split、峰值帧、输入字段、query/support、目标、checkpoint、seed、指标。用灰色标出不能直接比较的项：V4 历史 test35、V5 test34、不同目标和不同 WSS 算子。把“以前表格混乱”的原因在这一页一次讲清。

### 4. 结果导航：先给三条路线的“现象”，不下因果结论

用三张卡片：

* A：X5 三 seed Pa `R²_cb=0.7173±0.004`；X5X11 为 `0.7261`，整体小幅提升且尾部指标同步改善；
* B：PF6 压力 `0.7894±0.005`，VF6 速度 `0.7964±0.004`，相对同 seed 对照分别约 `+0.045/+0.027`；
* C：历史 PINN 中加入 BC/PDE 后速度/WSS没有同步变好，已有 loss/梯度证据指向优化冲突。

页脚写“这些数回答做到了什么，不回答为什么”。另加一条数据质量底线：旧路线中 10 例压力异常/壁面不匹配修复后 base 明显回升，说明数据质量必须作为独立影响因素展示，不能把修复收益写成网络模块收益。

### 5. A 路线：架构/局部几何为什么有用

用同一 seed、同一 split 的小型消融图，按“容量 → 邻域/局部几何 → 注意力/尾部 → F6 先验”分组。每组只保留父臂、子臂、配对 Δ 和病例 P10。不要把不同数据版本的最高行连成曲线。

### 6. A 路线：F6 先验到底贡献了什么

画三 seed paired Δ（X5 vs C1 或同期父臂）及 AG/AAA/ILO 分域柱状图。结论写成：Murray 分支流量先验在三 seed 上方向一致，支持“分支流量分配是有用条件信息”；X5X11 的 section-token 对整体 R² 增益小但 high-WSS/top10/p99 一致改善，暂定为尾部候选，不能说已解决局部特征。

### 7. A 路线：不是只展示最好病例

三行病例：最好、中位、最差，各放 CFD / Pred / signed error 三联图，另放逐病例 R² 排名和 P10。病例按正式预测 R² 选，三例共用视角、色标、单位。图旁回答“低分病例丢的是幅值、热点位置还是分叉/端区局部结构”。

### 8. A 路线小结：目前学到了什么、还没学到什么

左侧放已证实：局部几何和分支先验有配对增益；右侧放待验证：狭窄、分叉、弯曲、端区和高 WSS 尾部是否仍被平滑化。X5X11 三 seed 的 p99 预测/真值约 `0.733±0.011`，说明整体 R² 上升后极值仍有系统性低估。每个待验证项配一张所需局部图，不写成确定因果。

### 9. B 路线：速度/压力场的整体结果

PF6、VF6 各放 test34 逐病例 R² 分布（均值±std、P10、high-speed/high-WSS 子域），并列同 seed 对照。说明压力和速度是不同目标，不能用一个“体场 R²”概括。

### 10. B 路线：为什么速度约 0.80，WSS 仍可能差

画误差链：预测速度 → 壁面法向/切向剖面 → 梯度 → WSS。正文可用已有同 test34 的 R5V 审计作机制证据：预测速度经冻结 Profile-Secant 得 WSS `R²_cb=0.491`，换 CFD 真值速度为 `0.965`，预测速度经未校准物理核为 `0.468`。结论只写“误差主要在速度输入/梯度放大/算子链中的一个或多个环节”，不能仅凭这组结果断言全是近壁层。

### 11. B 路线：需要补做的最新 VF6 → WSS 闭环

这一页明确标“待补，不把旧 R5V 数字冒充 VF6”。在相同 VF6 checkpoint、step 1162、test34 上，用同一冻结 WSS 算子输出：CFD velocity oracle、VF6 predicted velocity、未校准物理核三列，并报告 WSS Pa R²、high-WSS R²、top10 IoU、峰值比。只有这页完成后，才能回答老师问的“速度 0.75 为什么 WSS 不好”在当前底座上是否仍成立。

### 12. B 路线：最好/最差体场和局部误差

压力与速度各选 best / median / worst，显示 3D 点云或合法 slab；同时显示 `Pred−CFD` signed error。标注点云投影/slab 不是连续截面；若要连续截面，另导出带真实体单元的 VTU。

### 13. C 路线：物理约束的原始现象

用 DATA、DATA+BC、BC+PDE-FIXED、BC+PDE-EMA 的同协议小表：速度、压力、WSS，以及数据项/物理项。不要用 total loss 横排“谁最低谁最好”。注明这是 pre-Centerline-V2 历史机制证据，formal V5 PINN 尚未形成可与 PF6/VF6 并列的正式结果。

### 14. C 路线：loss terms 诊断（老师要求的核心页）

画 raw 与 weighted 两套曲线，至少包括 `u/v/w/p data`、no-slip、inlet/BC、continuity、momentum x/y/z（及 momentum group）。曲线旁写采样点、单位/归一化和权重。关闭的 loss 不画成“0 残差”。

### 15. C 路线：梯度冲突与权重控制器

放 `cos(∇L_data,∇L_no-slip)`、`cos(∇L_data,∇L_momentum)`、梯度范数、clip 比例、EMA λ 及 `lambda_bound_fraction`。已有历史证据是 no-slip 与 data 末 500 轮约 `−0.9` 到 `−0.97`，EMA 约 99.76% 记录时刻贴近上限；这支持“优化配置没有真正检验到 EMA 控制器”，不支持“物理方程错误”。

### 16. C 路线：物理场到底没有学到什么

为 best/median/worst 选择同一病例和同一视角，分别放速度、压力、WSS/近壁误差；再放物理残差空间图。重点看入口、分叉、近壁、低压异常病例。把每个现象写成“现象—候选机制—区分证据—下一实验”。

### 17. 三条路线横向决策页

用矩阵而不是排名：

| 路线 | 当前支持 | 主要缺口 | 下一 Gate |
|---|---|---|---|
| 直接 wall→WSS | 三 seed 稳定；F6/局部先验有配对证据 | 尾部与局部结构仍需解释 | 最新 best/median/worst + 分域/尾部闭环 |
| volume data-only | VF6/PF6 三 seed 底座已晋级 | 尚无 VF6→WSS 同协议闭环 | 完成 velocity-oracle / predicted-velocity / WSS 三联审计 |
| volume + physics | loss/梯度冲突已定位 | 物理项是否带来可部署收益未证实 | 先修权重/尺度或硬约束，再做小矩阵 |

### 18. 讨论与请求老师帮助

只留三个可回答的问题：

1. 对直接 WSS，优先补“高 WSS 尾部/分叉局部特征”还是先做跨 seed/病例稳定性？
2. 对 volume→WSS，先审近壁采样和梯度算子，还是先修预测速度的局部结构？
3. 对 PINN，是否同意先以梯度冲突和 λ 控制器 Gate 为准，暂不把低 WSS 数值当成路线 No-Go？

### 每张后处理图的验收条件

* 图注写 run、checkpoint、病例、split、seed、step、变量、单位和聚合方式；CFD 与 Pred 共用几何、插值、视角和色标。

* V5 壁面 WSS 默认峰值 1162；历史 V3/V4 图不得混写帧号。压力保留相对压力参考零点。
* 每批图旁保存 manifest：源文件、哈希、映射覆盖率/距离、色标范围、导出脚本和生成时间。
