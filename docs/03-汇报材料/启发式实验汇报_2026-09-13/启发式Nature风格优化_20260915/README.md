## 模块图的证据边界

- **X5**：27D 输入由 17D 基础量、8D 微分几何和 2D Murray 先验组成。方向性局部分支读取 Stem 特征，在 FP 后加到 support；patch 残差加到 `log_z` 输出。
- **X11**：按 segment×4 mm 截面分箱，从 support 聚合并用 Transformer 交换上下文；查询得到的上下文残差与 coarse context 相加后进入 FiLM，不能画成直接加到 WSS。
- **PF6 / VF6**：PF6 为普通 SA3 后的全局 BT；VF6 的 BT 在 SA3 内，单半径 0.20，并保留普通三尺度局部分支。QAD-lite 为输出残差结构，不是 PDE 约束，也不等于已证明修复了速度梯度。
- 主干与结构页解释设计意图。收益以实际配对消融为依据，未独立消融的部件不单独宣称净增益；三 seed 同向不作为统计显著性结论。

## 指标与病例口径

当前分布固定 test34、peak 1162、各 run 的 `ckpt_best`；一个散点是一病例在 seed 1234/7/2025 上的 R² 算术均值，横须为样本 SD，不是置信区间。病例 R² 均值不等于 `R²_cb`。全部病例和负值保留；test34 曾参与开发筛选，不是独立泛化集。

空间图沿用已交付的 9 个 Best / Median / Worst 病例，按三 seed 均值选例，画的是 **s1234 的场与对应原物理量 R²**。Median 是已有包的中位代表，不能改称最高频区间的 Most。X5X11 展示 Gaussian 壁面 WSS；VF6 展示完整体内点云；PF6 展示 Gaussian 壁面相对压力，但其标注 R² 来自壁面∪体内的完整同点评估域。

物理量页每病例的 CFD/Pred 共用色标，误差为 Pred−CFD、使用对称色标；不同病例可用不同范围，比较时须读色条。selfmax 使用原包固定的 Pred/Predmax、CFD/CFDmax，各自分母来自该例所选帧原始完整同点域；插值后不重求 max。WSS/速度 selfmax 共用 0–1；压力保留 `p_ref` 和负值，按带符号 max 归一化。selfmax 消除了幅度差，不能代替物理量精度评价。

新速度页绘制全部 426,057 / 367,250 / 463,947 个体内点，无绘图抽样。点云是正交投影，会有遮挡，不能称作连续截面。旧病例包 VTP、CSV、指标和预览未被修改；其旧速度预览曾抽样 30,000 点，与本版图件不同。

V4 保持历史 test35、单 seed、未收敛诊断边界；旧 R5V→WSS 的 0.491 / CFD 速度参照 0.965 属于旧冻结管线，含既有监督校准及旧半径映射问题。VF6→WSS 闭环已于 2026-09-16 补齐（VELWSS2：三 seed 0.547 ± 0.003，CFD 速度 0.965；半径三臂差 ±0.003；见训练跟踪 §27），本页图件仍是旧 R5V 链。10 项 loss 展示已有 epoch 0–9984 的全部 raw 数据，叠加 51 轮移动均值；各项的数量级不能解释为加权贡献。
