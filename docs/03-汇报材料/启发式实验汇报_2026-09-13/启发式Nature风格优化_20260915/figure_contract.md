# 图件设计合同

用途：中文组会汇报与导师讨论；16∶9画布，矢量PDF/SVG、高清PNG及汇报PPT。Nature风格指信息层级和科研图规范，不宣称满足某本期刊的投稿要求。

核心问题：三个方向分别输出什么？新增模块把什么信息放到哪里？整体收益在哪些病例失效，下一步如何区分原因？

论证次序：共同问题/合同 → 模块信息流 → 同条件收益与取舍 → 全病例分布 → Best/Median/Worst空间误差 → 历史物理诊断及下一步可区分验证。设计意图与实验证据单独标识。

图类型：模块采用信息流示意；量化采用配对变化与横向分布；病例采用实际网格/点云图。原始R²不以插值后或selfmax的R²替代。

数据映射：分布复用已冻结summary.json中每例三seed R²均值/样本SD，保留全34例或历史35例和负R²；病例图复用已核验s1234完整场，角色仍为三seed分数选例。Most与Median分开，本次空间图使用已导出的Median。V4与旧R5只作历史诊断，不能排进当前同条件冠军。

画图后端：沿用现有Python素材工作流，Matplotlib绘制，Python组装PDF/PPT。无新训练、推理、全测试评估或生成人工实验数据。图中不放长本地路径；相对源数据与溯源说明另列。

视觉约定：白底；深灰文本；蓝=骨干/压力，青绿=局部/WSS，紫=截面/上下文，赭色=物理/待验证。标题24–28pt，正文14–18pt，审计小字>=9pt。关键证据占主体，正文每图只推进一个问题。

验收：每图导出前测量实际axes并运行1.5pt对齐检查，导出PDF运行文字字号和碰撞检查；修复FAIL，人工复核WARN；逐图查看。统计图提供源数据；案例保留单位、同色标、signed error约定、selfmax分母及选例口径。
