## 2. 处理方式（老师需要听到的合同，不是代码细节）

原始每例都有：Fluent 壁面 ASCII（WSS/压力）、体域 ASCII（u,v,w,p）、STL、中心线、入口波形、四出口 RCR。预处理要解决的是：**单位、实体身份、解剖框、中心线拓扑、标签同源**。下面按时间说明做过什么，以及**现在还用哪一套**。

### 2.1 原始量怎么读

| 对象 | 来源 | 注意 |
| --- | --- | --- |
| 壁面节点 | `ascii/` | 坐标原单位 m；WSS / 壁面压力 Pa。不是体域 cell。 |
| 体域 cell | `ascii_in/` | 速度 m/s、压力 Pa；与壁面节点不是同一套点。 |
| 峰值帧 | 入口波形定位 | 训练常用 step 1162（5.81 s）；母库仍存 81 帧。 |
| 真实毫米 | Fluent m × 1000 | 旧 bundle 里曾出现 810–1088 的“单位因子”，**不是物理 mm**，V5 已废弃。 |

### 2.2 几何坐标配准（PPT 简化口径）

汇报时可以把方法概括为：**基于解剖关键点和中心线 atlas 的刚性配准，再进行等比例归一化。**

1. 先把 STL、CFD 点云和中心线统一到真实毫米单位。
2. 以主动脉分叉点为原点，以近端主动脉方向为 +Z轴，由左右髂动脉方向确定横向轴。
3. 通过平移和旋转把不同病例放到同一解剖坐标系，该过程不改变血管形状。
4. 训练视图再使用各向同性的 max-abs 缩放到 `[-1,1]`，保留原始形状比例。
5. 同一变换同步作用于坐标和矢量场，然后通过 STL 同框、点云同框和病例组同框图进行可视化质控。

本节 3 张汇报图均显示**刚性配准后、归一化前**的真实毫米坐标，坐标范围统一为 X/Y ±125 mm、Z ±200 mm。

**PPT 可直接使用的中文注释：**

> 采用解剖关键点与中心线图谱驱动的刚性配准；以主动脉分叉点为原点，统一主干和左右髂动脉方向；随后通过等比例归一化消除病例间的整体尺度差异，并使用 STL 与 CFD 点云同框叠加图检查配准一致性。

V5 母库 `case.h5` 仍保留 Fluent 原始坐标；上述解剖刚性配准与缩放发生在派生训练视图中。

### 2.3 中心线（Centerline V2 → atlas → V5）

2026-08-28 对 173 例重提中心线，合同是：

- 先冻结权威 STL 与单位，中心线不得反向决定表面；
- 开口身份用 CFD 入口/四出口几何，不用世界坐标 `max Z`；
- 图必须 5 端点、3 分叉、连通无环；路径 0.5 mm 重采样，带半径、曲率、`dR/ds`、到分叉距离；
- 硬 Gate 173/173；20 例仅软阈值，标 `pass_review`。

V5 不直接读 V2 的 VTP，而是读 09-06 的 7 段 atlas，再派生 RMF 标架、管道坐标 `(s, ρ, θ)` 和分段语义。8 例出口命名按最近解剖接口重对应（几何位置对、名字曾互换）。

### 2.4 权威表面、曲率、标签

- 三例 STL 与 CFD 壁面不是同一张皮 → 从网格解剖壁面重提中心线。
- 瘤腔伪折：固定 SG11 平滑不够，改为半径自适应窗；端点 1R 内曲率持值，去掉端部假峰。
- 压力/WSS：低值簇与部分长尾按同源 raw 重算，避免壁面–体域不同源。

### 2.5 V5 母库现在存什么

母库范围：解剖池全部 cell 的 81 帧 `u,v,w,p` + 解剖壁面全部节点的 81 帧 WSS/压力 + 静态几何 + 5 切面。字段带依赖标签：`model_feature` / `label` / `audit_only` / `quadrature_only`。RCR、入口面积、协议表只审计，**默认不进网络**。法向由裸点云 PCA + MST 定向（部署可复现，不依赖 Fluent 网格法向）。
