# 病例图资产说明与检查

本组图使用既有真实几何和既有计算结果，说明“从血管形态到局部壁面剪切应力”的研究对象与输出形式。图片不是 AI 概念图。图中文字与文件名均只使用“匿名示例 A”。

## 建议使用

| 文件 | 用途 |
|---|---|
| `geometry_hero.png` | 透明灰色完整血管；可用于封面、意义页 |
| `wss_prediction_hero.png` | 同角度的预测 WSS 透明图；定量解读时搭配色标 |
| `wss_cfd_hero.png` | 同角度的 CFD 透明图；定量解读时搭配色标 |

| `case_cfd_vs_prediction.png` | 匿名 CFD/预测对照，含标签、单位、版本边界 |
| `deployment_pair.png` | 7.25 × 3.95 inch 白底“血管形态 → 壁面剪切应力”图，可直接放入 PPT |

透明单图和并列图另有 SVG；文字保持文本。彩图反映的是 WSS，不是临床危险等级。封面若不配色标，需说明只是示例预测可视化，不能据此读取数值。

## 证据边界

- 模型为 **X5D v5.1、seed 1234、既有最佳验证检查点**，峰值时刻 step 1162。不是 v5.2 结果，不是五 seed 集成，不是本次新评估。
- 此例沿用已有“按五 seed 病例 R² 均值距测试集中位数最近”规则选出的中位病例；不能代表全部测试病例。
- 16,448 个原始同点数据与 32,694 个原始 STL 三角面全部保留，无裁切、无抽样。经已有坐标变换后，字段与几何顶点一一对应，最大距离为 0.0000214573 mm。
- 原始 WSS 字段逐顶点渲染，三角形内部使用 Gouraud 颜色插值；本资产不使用 Gaussian 平滑。颜色为 CFD/预测共用 0–11 Pa 完整范围，无百分位截断、无各自归一化。
- 几何灯光只用于灰色形态图；定量 WSS 色彩不加灯光明暗修饰。
- 仅重绘已有数据，没有运行训练、推理、新测试集评估或新增模型指标。
