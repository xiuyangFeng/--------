## 0. 给老师的一页结论

（措辞按 2026-09-03 汇报稿改写；细节与证据见 §1–§4，逐问解释见 §6。）

1. **验证**：2 时间模式（准稳态 peak / 瞬态 81 帧 autograd）× 2 backbone（PointNet / PointNet++）× 4 训练模式
   （DATA / DATA+BC / BC+PDE-FIXED λ=1 / BC+PDE-EMA）× 3 seeds。条件输入为入口/出口面积、`Q_actual_peak`、四出口 R1/R2/C；
   入口 Dirichlet 与出口 RCR 关系以残差进 loss（"输入参数"与"残差进 loss"的区别见 §6 Q2）。
2. **简单结果**：16 臂 primary endpoint `E_rel_l2` 全在 **0.89–1.18**。跨 seed 标准差 0.004–0.039，排序可复现，
   但没有一臂实质性重建速度场；与 V3 同类臂比是退步（speed R²_cb 0.23 → −0.28；跨代对比一律用同口径 R²，见 §2.4 与 §6 Q3/Q7）。
3. **原因分析**：三层叠加。协议层取消 validation 训满 10000 epoch，后续做了 epoch 补评证明 DATA 臂在 epoch 1000 时 E 0.80 是
   全矩阵最好点、之后单调退化到 1.12（图 4 / 图 9）；数据层旧注册帧的几何通道错位、曲率失真、瞬态池只有 2000 点；
   物理层 no-slip 梯度与数据梯度近乎反向（cos ≈ −0.9，图 11）、PDE 残差靠降低压力满足、EMA λ 动态调整的权重一开始就触发上限，
   从未进入主动调节、瞬态 RCR 强形式残差在标签上本身不成立。物理臂在 E 上的"改善"全部是幅值压缩（图 6 / 图 12）。
4. **λ 动态调整带来的影响**：没有真正生效。无量纲化后 PDE loss 比 data loss 小 2–5 个数量级，比值目标 600–80000 被 λ_max=10 限制，
   实际跑的是"λ≡10 固定"；瞬态下直接打开 u≡0 平凡解。代码设定有 bug（撞限比例最大只能 0.02，门限 0.5 永不触发）。逐步解释见 §6 Q5。
5. **后续边界**：2026-09-03 曾提出“去 RCR/A_out、硬约束
   `u=d_wall·g`、直接 WSS 头、强形 PINN 降为确认臂”的诊断方案；这是
   **历史提案，未被 09-04 formal 合同采纳**。当前只冻结了 train138/test34
   与 P2V / D2 `c125-k128`，仍只输出 `u,v,w,p`、不使用 WSS loss。下一步是
   完成 formal 172 例 anatomy-only bundle、病例条件/interface BC、连续 query 与
   near-wall sampler 合同，再从随机初始化的 DATA 基线开始配对验证。

## 1. V4 分别做了什么验证

### 1.1 设计动机（相对 V3 的根本变化）

| 项 | V3 | V4 |
| --- | --- | --- |
| 出口条件 | CFD 求解后的 `p-out*` monitor 压力作输入（部署时不可得，属泄漏） | 只输入求解前参数：`A_in`、`Q_actual_peak`、四出口 `A_out/R1/R2/C`（18 维 BCEncoder） |
| 入口 | monitor 派生 | UDF 实际施加的 `Q_nom/A_udf` 速度 Dirichlet 残差进 loss |
| 出口物理 | 无 | 瞬态模式加质量流量口径的 RCR 一致性残差（`R2C·dP/dt + P − (R1+R2)ṁ − R1R2C·dṁ/dt = 0`） |
| 物理无量纲化 | 无 | momentum / `ρU_c²/L_c`，continuity / `U_c/L_c`，BC / `U_c`，RCR / `(R1+R2)ṁ_c` |
| 训练模式 | DATA / DATA+BC / DATA+BC+PDE 三臂 | DATA / DATA+BC / BC+PDE-FIXED(λ=1) / BC+PDE-EMA 四臂，分离 BC 与 PDE 贡献 |
| 时间模式 | 只有准稳态 peak | 准稳态 peak + 瞬态 81 帧（autograd `du/dt`，时间编码 `t, sin, cos, Q_wave(t)`） |
| split / 选模 | train123 / val15 / test35，`best_validation_data` | val15 放回 → train138 / test35，无 validation，train-only plateau 停止，主 checkpoint `last_converged` |
| primary endpoint | speed R²_cb | 病例等权速度向量相对 L2 `E_rel_l2`（1.0 = 零预测器），预注册 4 个 contrast + Holm（含义见 §6 Q3、Q8；E 只用于 V4 内部排序，跨代对比用 R²） |

### 1.2 矩阵与执行

- 2 时间模式 × 2 backbone × 4 训练模式 × 3 seeds = 48 run，Slurm 数组 `11972`/`12210` + node04 直启，2026-08-08 启动，至 2026-08-31 已完训 44/48、已评 38/48。
- 配对约束：同时间模式/backbone 的四臂共享初始化 SHA、采样序列、optimizer/scheduler（lr 1e-3 → 1e-5，warmup 100，grad clip 1.0，weight decay 1e-4）；PN/PNPP 参数量比 1.0008。
- 采样：每例每 epoch 5000 support + 5000 query（重采样），PDE 512 点、wall 512 点、inlet 256 点；瞬态每例每 epoch 1 个时相。
- 停止：`min 1000 / max 10000 epoch`，200-epoch 窗口相对变化 <0.5% 连续 3 窗，且 lr 到底。实际 **14/16 臂以 `max_epochs` 停止**，DATA 臂 plateau 也在 9859/9871 epoch，即停止规则退化为"跑满预算"。
- 评估：test35 official；准稳态 query = 全体域非壁面点（每例 53 万–224 万点）；瞬态 query = eligible 缓存点（每例 1609–5296 点）× 81 帧。**两种模式的评估宇宙不同，TR 与 SP 的 E 不可直接比。**
- 下游：冻结 Profile-Secant V3 × 每例全部壁面节点（full-wall，9704–96719 点），只用 peak 全场预测速度。

### 1.3 预注册的四个对比问题

`DATA+BC − DATA`（BC 监督增益）、`BC+PDE-F − DATA+BC`（固定权重 PDE 增益）、`EMA − FIXED`（老师的动态调权 vs 固定）、`PNPP − PN`（backbone 增益）。

读数：

- 无一臂实质性重建速度场；已评最低 0.894（`TR-PN-BC-PDE-F`），只比零预测器好 10%。
- 臂间差 0.05–0.25，seed 间 sd ≤ 0.04：**排序是可复现的**，只是所有臂都在失败区。
- 四个 contrast 的方向（探索性，未 Holm）：
  - BC − DATA：准稳态 **更差** +0.03～+0.05；瞬态 **更好** −0.08～−0.10。
  - PDE-F − BC：两模式 E 都下降（−0.04～−0.21），但见 2.2，这不是"更正确"。
  - EMA − FIXED：准稳态 E 再降 −0.03～−0.05；瞬态 **更差** +0.04～+0.07。
  - PNPP − PN：|差| ≤ 0.03，与 seed sd 同量级 → **inconclusive**。

| TR-PN-PDE-F | **0.171** | 0.103 | 0.12 | – | 中位 +0.87 | 0.119 | 0.19 |
| TR-PN-PDE-EMA | −0.134 | **0.000** | **3e-4** | – | 中位 ≈ +0.8 | 0.062 | 0.0009 |

（PNPP 同臂差 ≤ 0.05，方向一致，见主表行 23–26、31–34。**near-wall** = 距最近壁面节点 ≤ 1.5 mm 的内部 cell 中心、
每例按距离最近优先上限 40000 点，near-wall speed R²_cb 只在这些点上算；瞬态旧 bundle 没有这一标记，故为 "–"。定义细节见 §6 Q11。）

- 准稳态：DATA → BC → PDE-F → EMA，speed R²_cb 单调变差（−0.10 → −0.51），方差比单调压向零（0.39 → 0.04），
  但 E 单调"变好"、wall RMS 单调下降、continuity RMS 下降 27 倍。**E 与 R² 方向相反，说明 E 的改善是"预测更保守（更接近零场）"而不是"预测更正确"。**
- 瞬态 PDE-F 是唯一 speed R²_cb 明显为正的臂（PN 0.17 / PNPP 0.12；35 例中 94% / 89% 为正），但 linear-fit 斜率只有 0.05–0.22，高速段被系统压低（代表病例图：worst `WANG_FU_SHUN` a=0.05，best `BAI_WEN_JIE` a=0.22）。
- 瞬态 EMA：`TR-PN-BC-PDE-EMA` 方差比中位 3e-4、拟合斜率 0.000、u 通道训练 MSE 0.99、continuity 残差在 3200–5600 epoch 掉到 1e-12——**这是 u≡0 的平凡解**。
- 压力：准稳态 p R²_cb 0.30–0.44，EMA 掉到 0.11–0.15（见 §3.4 机制）。瞬态 R̄² = −20 是两例 gauge 异常病例
  （`ZHANG_YONG_SHENG-0` 真值 196 Pa、`WANG_FU_SHUN` 688 Pa，全库主流 13–16 kPa）拉爆的均值假象，35 例中位 +0.87、29 例 >0，
  去掉这两例后病例等权均值 +0.36。机制：R² = 1 − RMSE²/σ²，两例真值压力标准差只有 0.55 / 0.99 kPa，而模型按全库 13–16 kPa
  的绝对水平预测、RMSE ≈ 12.9 / 12.6 kPa（其余 33 例 RMSE 中位 0.31 kPa），所以 R² 变成 −552 / −159（图 7 重绘版
  `V4汇报/V4_汇报图件重绘_2026-09-03/fig7_pressure_outliers_v2.png`）。这也是 C0 改相对 gauge 的直接理由。
- E 与 R² 在 V4 里方向相反（图 12 `fig12_E_vs_speedR2.png`）：准稳态物理臂 E 最低（0.91–0.97）但 speed R²_cb 最负（−0.42～−0.51）；
  全矩阵唯一同时 E 较低、R² 为正的点是 DATA 臂 epoch 1000。两者必须并列报告，原因见 §3.8 与 §6 Q3。

## 3. 为什么得到这些结果（按证据强度排序）

### 3.1 协议层：无 validation + 10000 epoch → 系统性过拟合（最主要）

- 图4（重绘版 `V4汇报/V4_汇报图件重绘_2026-09-03/fig4_overfit_trajectory.png`，按准稳态/瞬态分两幅，画出每臂 epoch 1000→2500→5000→7500→10000 的轨迹）：
  DATA / DATA+BC 臂训练 `data_total` 一路降、test `E` 一路升（SP-DATA 0.81→1.12，TR-DATA 0.89→1.04），PDE 臂几乎不动；
  训练末段 DATA 臂训练最好（0.19）测试最差（1.12）。
- 图5：准稳态 8 臂 epoch 7500 的 E 都优于 10000（−0.01～−0.07），泛化仍在随训练变差；瞬态 PDE 臂基本持平。
- 停止规则：14/16 臂跑到 `max_epochs`；LR 衰减到地板后 200-epoch 窗口 <0.5% 的判据必然满足，设计文档 §11 自己预警过"平台判据退化为跑满预算"。
- 只评了 7500 / 10000 两个 milestone；1000 / 2500 / 5000 的 checkpoint 都在，但从未评估，"最优 epoch 在哪"至今没有零成本地回答。
- 设计 §4.3 预留的 train138 内部 5-fold CV（split 文件已带 fold）从未执行。

### 3.2 数据层：旧注册帧数据合同缺陷（8-30 审阅，P0 六项）

- steady 与 transient 的第 2 个几何通道不是同一物理量（mm 半径 vs 无量纲径向比），且 stats 用 transient 的比值去标准化 steady 的半径——同一输入位置在两种模式里含义不同。
- 旧曲率按 VTP 全局点顺序求导：18% 点 |κ|>1、最大 3e11，train138 clip 阈值 116434；V2 重算后 p99 只有 0.27/mm。几何先验被污染。
- 瞬态空间池：123/173 例恰好只有 2000 点，5000 support/query 是有放回抽样——"每 epoch 重采样空间点"对瞬态基本不成立，瞬态模型只见过 2000 个空间位置。
- WSS-only 的 wall scale 复用到体域：22.6% 内点 |coord|>1，入口面 173/173 超界。
- 4 例左右镜像、8 例压力低值簇（含 test 的两例 gauge 异常）、3 例旧 bundle 已裁剪。
- 这就是 48-run 被降级为 historical screen 的原因；也是 V4 不能与 V3 直接归因比较的原因（V3 数据线不同）。

### 3.3 no-slip 与数据项梯度几乎反向（解释准稳态 BC 臂为什么更差、幅值为什么被压）

日志 `training_progress.jsonl` 每 50 step 记录的梯度诊断（末 500 epoch 中位数）：

| 臂 | cos(∇L_data, ∇L_no-slip) | cos(∇L_data, ∇L_momentum) | ‖∇L_data‖ | 梯度裁剪触发比例 | no_slip_raw |
| --- | ---: | ---: | ---: | ---: | ---: |
| SP-PN-BC | −0.876 | – | 3.38 | 82% | 0.253（不降） |
| SP-PN-PDE-F | −0.968 | −0.221 | 3.05 | 30% | 0.241 |
| SP-PN-PDE-EMA | −0.969 | −0.288 | 2.80 | 26% | 0.225 |
| TR-PN-BC | −0.334 | – | 0.33 | 41% | 0.026 |
| TR-PN-PDE-F | −0.611 | −0.058 | 0.46 | 52% | 0.017 |

- 准稳态下 no-slip 梯度与数据梯度 cos ≈ −0.9～−0.97，等于每一步都在互相抵消；no-slip 残差整个训练过程停在 0.22–0.25（`U_c²` 单位）不下降。
  形象化见图 11（`V4汇报/V4_汇报图件重绘_2026-09-03/fig11_gradient_conflict.png`，四联：向量示意 / 日志实测曲线 / 一维剖面演示 / 末 500 epoch 分布）：
  准稳态三臂从 epoch 0–200 起中位就是 −0.87～−0.89，末 500 epoch −0.88 / −0.97 / −0.97，71–99% 的诊断 step 低于 −0.8；
  瞬态两臂开局 ≈ 0（不冲突），末段才到 −0.33 / −0.61。逐问解释见 §6 Q4。
- 网络是全局 latent + tanh 解码器，没有边界层表达能力：同时要求"壁面为零"和"近壁 cell-center 标签非零"，唯一折中是整体压幅。证据链：wall RMS 0.36 → 0.13 m/s，speed 方差比 0.39 → 0.04，near-wall R² 从 −2.4 "改善"到 −0.2（因为预测趋零后负得少了）。
- 数据梯度范数 ≈ 3 而 clip=1，BC 臂 82% step 被裁剪：更新方向被 BC 稀释后再被截断，训练 `data_total` 从 0.19 涨到 0.49。
- 瞬态冲突弱得多（标签本身在舒张期接近零、no_slip_raw 只有 0.02），所以瞬态 BC 臂反而改善——这与"BC 有物理增益"无关，是冲突强弱不同。

### 3.4 PDE 残差靠"压平压力 + 压小速度"廉价满足（解释 p 通道被牺牲）

- 动量残差各项 RMS（无量纲，末 500 epoch 中位）：SP-PN-PDE-F 压力项 544 > 对流项 344 ≫ 黏性 10.6；EMA 压力 238 ≈ 对流 235。
- 压力梯度项最大，最便宜的降残差路径是让 ∇p→0 与 u→0：p 通道训练 loss 从 DATA/BC 的 0.016 涨到 PDE-F 0.50、EMA 0.80（图2）；test p R²_cb 从 0.44 掉到 0.11。
- 所谓"continuity RMS 从 4.4 降到 0.16 的物理一致性改善"就是这样来的，与 V3 结论一致（V3：continuity/momentum RMS 降 88%/60%，速度 R² 降 0.05）。

### 3.5 EMA 动态权重从未进入工作区（解释老师的方法为何未被真正检验）

- 无量纲化后 `L_pde` ≈ 1e-3～1e-4，`L_data` ≈ 0.5–1；`loss_ratio_raw = EMA(L_data)/EMA(L_pde)` 中位：SP-EMA 654、TR-EMA 7.8e4；λ_target 在 ~100 epoch 内撞 `λ_max=10` 并全程贴死（`lambda_bound` 99.8% epoch，图3a）。
- 时间线（`training_progress.jsonl` 每 50 step 的控制器记录）：EMA(L_data) ≈ 0.85–1.1，EMA(L_pde) ≈ 6e-4～2e-3，
  未夹紧的目标 α·EMA(L_data)/EMA(L_pde) 在 α=0.1 的 warm-up 起点就已是 130–220、ramp 完成后 300–440（SP）；
  瞬态后期 PDE 残差塌到 7e-5，目标升到 1e4。`λ_applied` 经 0.9 平滑从 1.09 起步，每次更新 +0.6～0.9，**epoch 15 即 ≥ 9.9**，
  之后 99.8%（SP）/ 99.5%（TR）的记录 ≥ 9.9，撞限标志 100% / 99.95%。
- 所以 EMA 臂 ≡ λ_pde=10 固定臂，只是 PDE 权重比 FIXED 大 10 倍：准稳态就是 §3.4 的更强版本（方差比 0.07→0.04、p R² 0.38→0.11）；瞬态 λ=10 打开平凡解通道（pde_total 3e-6、对流项 RMS 0.001、continuity 1e-12），E 反而更差。
- 设计 §10.3 写明"若 smoke 表明权重长期撞限，允许改配置重新预注册"，但没有 smoke 这一步就直接进了 48-run。
- **护栏 bug（2026-09-02 核实）**：`wss_pinn/v4/train.py` 第 464 行把撞限比例算成
  `lambda_clamped / steps`，但 `lambda_clamped` 只在每 50 步的控制器更新步上累加，因此该比例最大只能是
  0.02；停止规则的 `lambda_bound_fraction_limit = 0.5` 永远触发不了。`training_summary.json` 里 EMA 臂记录的
  `lambda_bound_fraction = 0.02` 实际含义是 100% 撞限。控制器公式本身（`controller.py`）与设计一致，无 bug；
  问题是量程设错（λ_max=10 对比值 600–8e4）加上护栏失效。
- 结论：老师的 detached EMA 比值法在这组实验里没有得到检验；要检验它，必须先让比值落在 `[λ_min, λ_max]` 内（放开上限或改尺度），并把 `lambda_bound_fraction < 20%` 作为"控制器在工作"的 Gate。

### 3.6 瞬态 RCR 强形式残差在 CFD 标签上不成立（本次新核实）

- Stage 0 stats 已记录 `label_reference.rcr_discrete_normalized_rms = [0.96, 1.09, 1.01, 0.91]`（134 train 例），但当时没有人据此 gate；设计 §5.4 要求的"81 帧标签离散 RCR 残差 Gate 通过"实际未执行。
- 本次用 169 例（134 train + 35 test）outlet monitor 标签重算：
  - 四出口归一化残差 RMS 中位 0.79–0.85（参考尺度 `(R1+R2)ṁ_c` 中位 42.8 kPa，即残差 ≈ 35 kPa）；换成 UDF 同款后向欧拉（Δt=0.01）0.84，加一帧滞后 0.80——**与差分格式无关**；
  - 只有 2/169 例四出口残差都 <0.3；
  - 各项量级：`R1R2C·dṁ/dt` 37.7 kPa > `(R1+R2)ṁ` 20.6 kPa > `R2C·dP/dt` 14.3 kPa > `P` 13.2 kPa。两个导数项主导并互相抵消，残差数值上病态；
  - **周期均值关系 ⟨P⟩ = (R1+R2)⟨ṁ⟩ 成立**：比值中位 0.983，IQR [0.980, 0.988]。说明 RCR 参数、质量流量口径、远端压力为零的 gauge 约定都对，问题只在瞬时强形式。
- 后果：TR-BC / TR-PDE-F 把 `rcr_bc_raw` 压到 1.8e-4 / 2.6e-6，是在逼近一个 0.01 s 导出标签并不满足的关系；瞬态 BC 臂的改善不能归功于 RCR 项。
- 根因待查（不在本次范围）：monitor 报出的 ṁ(t) 与 UDF 内 UDS 递推用的 Q 是否同一量、是否有一步滞后；R2C ≈ 1.4 s 大于 0.8 s 周期，导出周期是否已达周期稳态。

### 3.7 准稳态方程本身与 peak 标签不一致

- 标签级 `du/dt` RMS 1.0–1.5 m/s²（0.01 s 有限差分），即 ρ∂u/∂t ≈ 1.1–1.6 kPa/m，与入口—出口压力梯度同量级；准稳态残差把这一项当作零。
- 这条 V3 已经验证过一次（PDE 改善残差、拉低速度），V4 复现。它决定了准稳态模式下"加 PDE"这条路要么换方程要么换目标。

### 3.8 评估口径提醒

- 瞬态 E 在 1609–5296 点 × 81 帧上算，包含舒张期低速帧，零预测器在这里"更容易接近"；准稳态在全体域 53 万–224 万点上算。TR < SP 不得读作物理增益。
- `E_rel_l2` 对幅值压缩不敏感的方向是有利的（预测缩到零 E→1），R² 对它是惩罚的；两者必须并列报告。
  图 12（`V4汇报/V4_汇报图件重绘_2026-09-03/fig12_E_vs_speedR2.png`）把 16 臂 last 与 epoch 1000 画在 E–R² 平面上：
  E 越低的准稳态物理臂 R² 越负，两者在 V4 里方向相反。

### 3.9 稳态是否受几何通道缺陷影响（2026-09-02 核实）

`train138_stats.json` 第 2 通道 mean=2.92、std=20.59 确实来自瞬态的无量纲径向比（std 被 3 例坏值撑大）。
按 loader 的实际变换重算 173 例后，两种模式真正喂给网络的量：

| 几何通道 | 稳态模型实际收到的 | 瞬态模型实际收到的 |
| --- | --- | --- |
| 第 2 通道（local_radius 槽位） | 物理含义正确（mm 半径，中位 9.3 mm），但被瞬态 stats 压扁：z 中位 0.31，病例内 p5–p95 跨度 0.52σ，病例间中位差 0.10–0.46σ（对照：第 1 通道弧长病例内跨度 3.4σ） | 几乎常数：z ≈ −0.09，病例内跨度 0.03σ；另 3 例（`ZHOU_KE_XUN`、`LIU_WEN_QI`、`YANG_YU_QING-1`）为几百量级坏值 |
| 第 3 通道（曲率） | 同一套按 VTP 全局顺序求导的旧曲率，\|z\| p95 中位 2.6、每例最大值中位 8.8σ | 同一套旧曲率，\|z\| p95 1.9、最大 5.7σ |
| 坐标尺度、4 例左右镜像、3 例裁剪 bundle | 都受影响 | 都受影响 |
| 空间池 | 全体域 53 万–224 万点，每 epoch 5000 新点 | 123/173 例只有 2000 点，有放回抽 5000 |
| 压力 | 逐例中心化，两例 gauge 异常病例不影响 | 绝对 gauge，8 例低值簇直接进标签 |

结论：稳态没有"免疫"，但受影响方式更轻（半径是"弱信号"而非"无信号"，池与压力口径健康）。因此：
(a) 稳态 8 臂 × 3 seeds 内部可比，四个 contrast 与 §3.3–3.5 的机制结论成立；
(b) 与 V3 的比较需加限定，但 V3 用的是同一条旧 bundle 线和同一套旧曲率，几何缺陷不是 V3→V4 退步的原因，
    §2.5 已把退步主要归到协议；
(c) 与 Centerline V2 新数据的结果不可比，只能重跑；
(d) 瞬态实际只拿到 xyz + 弧长 + 坏曲率，半径信息为零，TR 与 SP 的差异又多了一层输入信息量不同。

几何特征是否是历代精度不高的原因：**是重要原因之一，不是全部。** V3 从 xyz 到 xyz+geom 的 +0.19 是历史上最大单项增量，
说明修正后的特征值得期待；但近壁 R² 三代全负、速度斜率三代都在 0.2–0.4、最好 speed R² 停在 0.24，这些指向模型
（全局 latent 表达不了边界层）、loss（标准化 MSE 轻视高速尾部）和样本量。数据修复是必要条件，不是充分条件。


### 3.10 第二轮讨论补充（2026-09-02）

**3.10.1 不输入 RCR / A_out 时，左右镜像还有没有影响。** BC 向量按 out-le/li/ri/re 固定顺序排 4 组
(A_out, R1, R2, C)，4 例镜像病例是"槽位与空间位置对不上"；只去掉 RCR 仍留 A_out 逐出口输入，问题一样；
全部逐出口输入都去掉才不受影响，此时模型不知左右，镜像几何只是另一根血管。瞬态 RCR 残差在每个出口面自身
的点上用自身参数计算，与镜像无关。RCR 的信息量有旧线的 oracle 实验可引
（`WSS_PointNet实验矩阵与结果汇总last.xlsx` · RCR Oracle 表，S3 PointNeXt-R+LocalGeoPE，mixed 138/0/36，seed1234）：

| 臂 | 输入 | WSS R²_cb | 相对 geometry-only |
| --- | --- | ---: | ---: |
| RCR-O0 | 仅几何 6 维 | 0.276 | – |
| RCR-O1a | 几何 + 四出口真实 log(R1/R2/C) | 0.356 | +0.081，病例均值 CI [+0.013, +0.102]，22 胜 14 负 |
| RCR-O2 | 几何 + 打乱的 RCR | 0.272 | −0.003 |

2026-09-03 当时的诊断提案是去掉 RCR 与 A_out（临床不可得；A_out 可由点云推出；每个几何只有一组 RCR，学不到因果响应；
本队列入口波形分子全库统一，"几何 → 标准化流场"良定），代价约 0.08 WSS R²，需明说。保留**单一入口流量标量**：
速度量级不是几何性质，6 例 `A_udf≠A_mesh` 流量差达 35%，不给 Q 即为标签噪声；且临床可测。
该输入删减方案尚未冻结为 formal 合同，须在 anatomy-only 条件审计后重做单变量配对。

**3.10.2 瞬态 2000 点池的来源。** 不是 V4 的决定，是继承的：V4 瞬态 builder 未读 81 帧 raw 体域，而是读旧特征管线
的每帧 CSV（`data_new/processed/features/result_features_merged-*.csv`），该管线每例只抽 2000 个内部点；V4 再筛落在
冻结目标域 5e-5 内的点，因此 123 例恰好 2000、被旧中心线裁剪的病例更少（1569–1835）。support/query 各 5000 只能
有放回抽样。V2 staging 已改为每例 15,000 个唯一 cell。

**3.10.3 绝对 gauge 好不好。** 设计选绝对 gauge 是为了让 RCR 残差锚定压力水平，该理由已不成立（§3.6）；代价是 8 例
低值簇混进标准化分布。不输入 RCR 时绝对水平不可辨识，因此用相对 gauge：准稳态按病例严格体域均值中心化（现状），
瞬态按"病例内全部帧全部点"取一个均值（不逐帧，否则抹掉时间变化）；评估报压降与压力梯度。放弃的是绝对压力
（FFR 类指标）；需要时再加锚点 p_ref = (R1+R2)·ρQ̄，周期均值关系成立（0.983）可支撑。

**3.10.4 速度学不好，是数据还是模型。** 主要是跨病人泛化问题：SP-DATA 末期训练标准化 MSE 0.19，相当于训练病例
R² 约 0.8（epoch 200 附近约 0.7），同一模型 test speed R² 0.1。模型能表达场，从 138 个几何学不到"几何 → 场"的映射。
数据侧：几何条件弱或坏（V3 geom +0.19 是历史最大杠杆；V4 半径压扁、曲率失真）、样本量；模型侧：全局 latent +
5000 support 分辨不了局部（PNPP 一贯优于 PN、近壁最差）。三代都有的斜率 0.2–0.4 是回归到均值的症状，不是原因。
判决性诊断：单病例过拟合测试（容量）、几何最近邻基线（138 例里可预测方差）、学习曲线（Gate E）。便宜改法：
速度按病例 U_c = Q/A 归一，坐标按局部半径无量纲化，让网络学剖面形状、幅值交给 BC。

**3.10.5 为什么要 CV；"小数据不设验证集、收敛即停"对不对。** 前半句对（不浪费数据），后半句被证据否定：V3 验证最优
epoch 92–203；V4 milestone 最优 ≤1000，之后 9000 个 epoch 训练 loss 一直降、test 一直坏，相差 50 倍。停点必须由
held-out 信号决定，CV 恰是不牺牲数据的做法（每例参与 4/5 训练，选定配方后全 138 重训）；可改写为"held-out fold 的
loss 收敛即停"。快速验证可单跑一组，但必须留一个 fold（110/28）每 100 epoch 评一次，一次回答"V2 数据有无帮助"和
"最优点在哪"；不再用 test35 做这件事。

**3.10.6 V3 的 BC 到底是什么。** monitor 压力在 V3 用于两处：BC_O1–O4 条件输入，和 BC loss 里的出口压力监督项
（占 BC 组 96%）。物理上它是 Fluent 实际施加出口压力的近似（与 UDF profile 差约百 Pa），不是"假"；但它是耦合求解的
结果，不是求解前给定的条件（给定的是 Q_in(t)、R1/R2/C、远端压力）。作监督项不算错只是与压力场标签冗余；作输入是
泄漏，部署时拿不到。V4 取消它是对的，V3 上 BC 对速度近中性也说明它本来没带来什么。

**3.10.7 强形式 PINN 的成本与去留。** seed1234 同卡实测：

| 臂 | 准稳态 s/epoch | 瞬态 s/epoch | 10000 epoch 墙钟 |
| --- | ---: | ---: | ---: |
| DATA | 3.2 | 2.4 | 7–11 h |
| DATA+BC | 3.8 | – | 10.5 h |
| BC+PDE（F / EMA） | 11–12 | 18–21 | 31–59 h |

强形式 PDE 让准稳态贵 3.5 倍、瞬态贵 7–9 倍；三代收益：V2 ≤ +0.03，V3 −0.05，V4 仅正则且从 epoch 1000 起压幅，
近壁 R² 在任何物理臂里未转正。**2026-09-03 历史诊断提案**是暂停强形式 PINN，
改用硬约束、物理归一与事后一致性检查，DATA 达标后只留一个 PDE 确认臂。
该提案未随方案 B 自动转为 formal 合同；formal 的硬/软 no-slip、PDE 对照数与
动态调权须在 DATA 基线前另行冻结。

**3.10.8 局部学习的历史证据。** 旧线均为纯监督、按训练 loss 选 checkpoint，但
test27/test36、single/multi-seed 协议不同，必须逐行注明，不能汇总成一个“test36 单 seed”效果：

| 手段 | 可比协议内结果 | 协议与迁移边界 |
| --- | ---: | --- |
| LocalGeoPE 局部几何位置编码 vs xyz-only | aggregate `ΔR²_cb=+0.0671`；逐病例 R² 差均值 `+0.3051`，CI `[+0.1062,+0.5750]` | test36 single seed；`+0.31` 是病例差均值，不是 aggregate R²_cb |

分带和同法线有序剖面；这些与 U_c 归一、CV 早停均须作为独立变量验证。

**3.10.9 路线问题：体域 → WSS 还是直接 WSS，以及 WSS 0.8 的口径。**

- 旧线直接回归壁面 WSS 最好 0.351（★ LSA2 H2 + log(radius)，物理 R²_cb）；体域路线 WSS raw R² 三代为负、fit ≤ 0.29。
  口径与测试集不同，但差距真实：壁面直接回归是二维流形上的平滑目标，不需要近壁速度梯度。
- WSS 是壁面法向导数，导数放大误差：速度 R² 0.9 ≠ 近壁梯度 R² 0.9；近壁 R² 三代全负。落地口径应写成
  **原始病例等权 R² ≥ 0.8 且斜率 ≈ 1**；fit R²（Pearson r²）永远不低于原始 R²，fit 0.8 而斜率 0.3 的模型不可用。
- 算子天花板：Profile-Secant V3 在 CFD 真速度上全壁面 R² 0.96，但逐病例 high-WSS R² 0.77、峰值低估 16%；速度场完美
  也到不了逐病例 0.8，要么改算子，要么让网络直接输出壁面梯度。
- 备选落地研究设想（**尚未冻结，不属于当前 formal V4 合同**）：
  `u = d_wall·g(x)` → 壁面 `∂u/∂n = g(x_wall)`，可令 WSS 成为附加直接输出并用壁面
  CFD WSS 标签监督。当前 formal V4 仍只输出 `u,v,w,p`、不用 WSS loss；若启用该多任务头，
  必须另立路线和配对实验，不能从本次骨干选择 B 自动推出。
- 文献 0.9 级速度 R² 的条件（老师所引）：1000+ 例（参数化变形）、稳态、黏度模型不同、统一 BC、多为 pooled R²。
  我们：138 真实例跨 AG/AAA/ILO、5000 随机点无邻接、逐病例 R²、瞬态 peak、Carreau–Yasuda。对纯监督模型，
  黏度模型烘在标签里不可见，稳态/瞬态只在混用标签时才咬人，BC 去掉 RCR 后已良定——剩下的结构性差距只有数据量。

### Q1 准稳态与瞬态两种模式的具体区别和实现方式

**一句话**：两种模式共用同一套编码器/解码器与四臂配对，区别只在"标签用哪些帧、解码器有没有时间输入、动量方程带不带 ∂u/∂t、
出口有没有 RCR 残差、压力用什么 gauge"；它们的评估宇宙不同，E 不能互比。

| 项 | 准稳态 peak（`steady_peak`） | 瞬态 81 帧（`transient_81`） |
| --- | --- | --- |
| 训练标签 | 每例只用峰值流量时刻（`peak_step`）一帧的 u,v,w,p | 每例 81 帧（0.01 s 导出间隔、0.8 s 周期）；每 epoch 每例随机抽 1 个时相（`transient_phases_per_case_epoch=1`） |
| 解码器输入 | 查询点 xyz + 几何 latent（256）+ BC latent（128） | 同上，再拼 4 维时间编码 `t/T, sin(2πt/T), cos(2πt/T), Q_nom(t)/1e-4`（`models.py: time_features`） |
| 空间点池 | 全体域非壁面 cell（53 万–224 万/例），每 epoch 重采 5000 support + 5000 query | 旧特征管线每例 2000 个内部点（§3.10.2），5000 support/query 有放回抽样 |
| 动量方程 | `momentum_mode=quasi_steady`：ρ(u·∇)u + ∇p − ∇·τ(γ̇) = 0，∂u/∂t 置零 | `transient_autograd`：再加 ρ∂u/∂t，∂u/∂t 由 autograd 对时间输入求导（`physics.py: strong_form_residuals`） |
| 边界项（BC 臂） | no-slip（512 壁面点）+ 入口 Dirichlet（256 入口面点，目标 U_in·n，U_in = Q_nom/A_udf 峰值） | 同上但入口目标随时间 U_in(t)；再加四出口 RCR 一致性残差（下 Q2） |
| 压力口径 | 病例严格体域均值中心化（相对 gauge，`case_strict_volume_mean_centered_pa`） | Fluent 原始 gauge（远端压力为零的绝对水平，`raw_fluent_gauge_pa_distal_pressure_zero`） |
| 无量纲化 | momentum / (ρU_c²/L_c)，continuity / (U_c/L_c)，BC / U_c | 同上，RCR / ((R1+R2)·ṁ_c) |
| 评估 | test35 全体域非壁面点 × peak 一帧 | test35 eligible 缓存点（1609–5296/例）× 81 帧 pooled |
| 每 epoch 成本（PN） | DATA 3.2 s，BC+PDE 11–12 s | DATA 2.4 s，BC+PDE 18–21 s |

设计意图：准稳态是"最简问题"（一帧标签、点池最健康、直接服务 peak WSS 下游）；瞬态是为了让 ∂u/∂t 与 RCR 微分方程有意义。
代价：准稳态动量方程与 peak 标签不一致（§3.7，标签级 ∂u/∂t 与压力梯度同量级）；瞬态实际只拿到 2000 点池 + 绝对 gauge 的低值簇（§3.9）。
两种模式在同一 backbone 下共享初始化 SHA、采样序列与优化器，所以四臂 contrast 在模式内部成立，跨模式不成立。

### Q2 "入口 Dirichlet 与出口 RCR 关系以残差进 loss"是什么意思？出入口数据不是显式输入吗？

**一句话**：显式输入的是**边界参数**（一串数字），残差进 loss 的是**边界条件本身**（预测场必须满足的关系）；输入不能保证网络用对，残差才是强制。

- **显式输入**（四臂都有，包括 DATA 臂）：18 维向量 `[A_in, Q_actual_peak, 4 × (A_out, R1, R2, C)]` 经 BCEncoder（MLP 18→64→128）得到
  `bc_latent`，拼进解码器（`models.py: encode_support / decode_query`）。它只告诉网络"这一例的流量与 RCR 参数是多少"，网络可以完全忽略它。
- **残差进 loss**（DATA+BC / PDE 两臂，`physics.py: _boundary_losses`）：在边界点上检查**网络预测出来的场**是否满足这些参数定义的条件，不满足就罚。
  - 入口 Dirichlet：256 个入口面点，罚 `‖u_pred − U_in·n‖² / U_c²`，U_in = Q_nom/A_udf 是 UDF 真正施加的入口速度（瞬态随 t 变）。
  - 壁面 no-slip：512 个壁面点，罚 `‖u_pred‖² / U_c²`。
  - 出口 RCR（仅瞬态）：对每个出口面，用**预测场**算面积均值压力 P̂ 与法向质量流量 ṁ̂，再用 autograd 算 dP̂/dt、dṁ̂/dt，
    罚 `[R2C·dP̂/dt + P̂ − (R1+R2)ṁ̂ − R1R2C·dṁ̂/dt]² / ((R1+R2)ṁ_c)²`。**这里没有用任何出口压力标签**，出口压力/流量都是从预测场算出来的，
    R1/R2/C 只是系数。
- 与 V3 的区别：V3 把 CFD 求解后才有的 `p-out*` monitor 压力当输入（部署时拿不到，属泄漏）；V4 输入的 A、Q、R1/R2/C 都是求解前给定的量，
  求解后的量只出现在 data loss 的标签里。
- 结果回看：入口残差正常收敛，no-slip 残差 0.22–0.25 不降（与数据梯度反向，Q4），RCR 残差被压到 1e-4–1e-6 但标签本身不满足强形式（§3.6）。

### Q3 `E_rel_l2` 起什么作用？和 V2/V3 比不该用同一个 R² 吗？

**一句话**：应该。`E_rel_l2` 只是 V4 预注册的**内部排序指标**；跨代比较一律用主表里三代同口径的病例等权 R²（§2.4 已按此重写）。

- 定义（`evaluate.py: vector_relative_l2`，设计 §12.0）：逐病例 `E = ‖u_pred − u_true‖₂ / ‖u_true‖₂`，u 是三分量速度向量、
  在该病例全部评估点上取范数（瞬态 81 帧 pooled），再对 35 例等权平均。全零预测器恰好 E = 1。
- 当初选它的理由：PINN 文献常用；三分量联合，不像 v/w 单分量 R² 在某例该分量方差极小时爆成 −10；逐例尺度无关；
  只预注册**一个**主指标配四个 contrast，避免在 16 臂 × 十几个指标里挑好看的（Q8）。
- 它与 R² 的差别只在分母：`R² = 1 − Σ‖e‖² / Σ‖u − ū‖²`（减均值），`E² = Σ‖e‖² / Σ‖u‖²`（不减均值）。
  把预测整体缩小 k 倍：E 从 0 平滑退到 1（缩到零场也只是 1.0），R² 却从 1 一路掉到负值（零场的 R² = −‖ū‖²/var，可以很负）。
  所以 E 对 V4 物理臂的失败方式——幅值压缩——几乎不惩罚，图 12 里 E 与 R² 在 16 臂上方向相反。
- 汇报口径：一页结论与跨代表格用 speed R²_cb / near-wall R²_cb / p R²_cb / WSS fit R²_cb；E 只出现在 V4 四臂排序和 contrast；
  两者并列时要说明"E 低而 R² 负 = 预测更保守，不是更正确"。

### Q4 "no-slip 梯度与数据梯度近乎反向（cos ≈ −0.9）"怎么形象地说？→ 图 11

**一句话**：数据项要把近壁速度拉高（CFD cell-center 标签非零），no-slip 项要把壁面速度压到零；网络分辨不了 1–2 mm 的边界层，
两项在同一批参数上一个往东一个往西，合力很短再被裁剪，最后唯一的折中是把整个速度场整体压小。

- 度量是什么：每 50 step 把 `data_total` 和 `no_slip_raw` 分别对全部参数求梯度向量，算夹角余弦（`physics.py: gradient_diagnostics`）。
  cos = 1 同向，0 互不干扰，−1 完全对拉；−0.9 对应夹角约 154°。
- 图 11 四联（`V4汇报/V4_汇报图件重绘_2026-09-03/fig11_gradient_conflict.png`）：
  (a) 向量示意：两支梯度对拉、合力短、再被 clip=1 截断；(b) 日志实测：准稳态三臂从 epoch 0–200 起就是 −0.87～−0.89，
  末段 −0.88 / −0.97 / −0.97，瞬态两臂开局 ≈ 0、末段 −0.33 / −0.61；(c) 一维剖面演示：钝剖面 + 薄边界层的 CFD 真值，
  平滑低阶网络只拟合数据时壁面残留 0.21，加 no-slip 后壁面归零但峰值只剩 0.95——折中就是整体压幅；
  (d) 末 500 epoch 分布：准稳态三臂 71–99% 的诊断 step 低于 −0.8，‖∇L_data‖ ≈ 3 而 clip = 1，BC 臂 83% 的 step 被裁剪。

  formal 尚未决定采用硬约束还是软 BC loss。

### Q5 为什么 PDE loss 小 2–5 个数量级、λ 被 10 夹死、瞬态打开平凡解、护栏 bug——逐步解释

1. **两个 loss 的"单位"不同，比值没有物理含义。** data loss 是标准化 MSE（标签按全库 std 标准化，训练中 0.2–1.0）；
   PDE loss 是无量纲残差的平方：动量残差除以 ρU_c²/L_c（例：1060 × 0.29² / 0.0217 ≈ 4.1 kPa/m），训练末段残差各项 RMS 几百 Pa/m，
   无量纲后 0.05–0.1，平方就是 1e-3～1e-2；continuity 同理。实测 EMA(L_data) ≈ 0.85–1.1、EMA(L_pde) ≈ 6e-4～2e-3，
   比值 500–3600（SP）；瞬态后期 PDE 残差塌到 7e-5，比值 1e4–1e10。
2. **控制器第一次更新就撞上限。** `λ_target = clip(α · EMA_data / EMA_pde, 1e-4, 10)`，α 从 0.1 ramp 到 1（200 epoch）。
   α = 0.1 时目标已是 130–220 ≫ 10。`λ_applied` 经 0.9 平滑从 1.09 起步，每 50 step +0.6～0.9，**epoch 15 就 ≥ 9.9**，
   此后 99.8%（SP）/ 99.5%（TR）的时间贴在 10。所以 EMA 臂 ≡ "λ ≡ 10 固定臂"，与 PDE-F（λ = 1）只差权重大 10 倍；
   老师方法的核心——随训练动态调整——从未发生（`controller.py` 公式本身与设计一致）。
3. **为什么瞬态下 λ = 10 打开 u ≡ 0 平凡解。** 对 u ≡ 0、p ≡ const：动量与连续性残差恒为 0，no-slip 为 0，只剩 data loss
   （标准化 MSE ≈ 1，即"预测均值"的水平）和入口残差。而认真拟合标签的解要付 λ × PDE 残差的代价：瞬态标签与强形式方程本身不一致
   （RCR 标签级残差 0.8、差分口径）、PDE 点只有 512 个、网络表达受限，残差压不下去。λ = 10 让"什么都不预测"的总 loss 反而更低：
   TR-PN-EMA 的 u 通道训练 MSE 0.99、pde_total 3e-6、continuity 1e-12（图 2 / 图 3）。准稳态 peak 帧标签处处非零，零场的 data loss 太大，
   所以没有完全塌缩，只是幅值压得更狠（方差比 0.04、p R² 0.11）。
4. **护栏 bug（`train.py:403/464`）。** 设计 §11 要求"撞限比例 > 0.5 不判收敛、应报警"。实现里每个 step 都执行
   `lambda_clamped += int(clamped_low or clamped_high)`，但 controller 只在 `global_step % 50 == 0` 的 step 才计算撞限标志，
   其余 step 恒为 False；每 epoch 138 step 里只有 2–3 步可能为 True，分母却用全部 138 → 比例上限 0.02。
   `training_summary.json` 里 EMA 臂的 `lambda_bound_fraction = 0.02` 实际含义是 100% 撞限；门限 0.5 永远触发不了，
   本该在 smoke 阶段报警的护栏失效。修法：分母改为控制器更新步数，或每 step 记录"当前仍在撞限"状态。
5. **要真检验老师的方法需要什么。** 把 PDE 残差换成与 data 同"单位"的度量（按标签级参考带归一），或把 λ_max 放到比值量级；
   按梯度范数而不是 loss 值平衡——loss 相等 ≠ 梯度贡献相等：PDE-F 末段 ‖∇L_data‖ 3.05 对 ‖∇L_pde‖ 0.69，λ = 600 时 PDE 梯度是 data 的
   ≈ 140 倍，会更快掉进平凡解；先做 train-only smoke 确认 λ 在工作区内浮动（修正后的撞限比例 < 20%）再进矩阵。

### Q8 "预注册 4 个 contrast + Holm"是什么意思

- **预注册**：在看到任何 test35 结果之前，设计文档（§12.0，2026-08-08）就写死了要检验哪几个差值、用什么指标、什么检验、怎么校正。
  目的是避免"16 臂 × 十几个指标里挑显著的"这种事后选择。
- **4 个 contrast**（配对差值，各时间模式内分别做）：`DATA+BC − DATA`（BC 监督有没有用）、`BC+PDE-FIXED − DATA+BC`（固定权重 PDE 有没有用）、
  `EMA − FIXED`（老师的动态权重比固定好不好）、`PointNet++ − PointNet`（backbone）。每个 contrast 用 35 个测试病例的逐例 E 差值做
  配对 Wilcoxon 检验（每例先对 3 seeds 取均值）。
- **Holm 校正**：4 个检验同时做，假阳性率会累积。Holm 把 4 个 p 值从小到大排，依次与 α/4、α/3、α/2、α 比较，第一次不通过就停，
  后面的全部判不显著。它把 4 个检验整体的假阳性率控制在 α 以内，比 Bonferroni（全用 α/4）宽松一点。
- **为什么本次不做正式 Holm**：3 seeds 未齐（38/48 已评）；数据侧 8-30 判定 No-Go 把整个矩阵降级为探索性 screen；
  test35 是 development-exposed。做了检验也不能当确认性结论，所以只报方向与效应量（§2.1）。

### Q11 图 8 里"近壁（near-wall）"的定义

- **旧数据（本矩阵）**：内部 cell 中心到最近壁面节点的距离 ≤ 1.5 mm（`pipeline_wss_min/config.py: near_wall_threshold_mm=1.5`），
  按距离最近优先、每例上限 40000 点（`near_wall_max_points=40000`）；173 例全部恰好取满 40000，说明 1.5 mm 层内的点数超过上限，
  实际近壁带比 1.5 mm 更薄且逐例不同。标记存在 bundle 的 `int_type`（1 = near-wall，0 = core），V4 评估直接读它（`evaluate.py: REGION_NAMES`）。
- **near-wall speed R²_cb**：只在这些点上算的病例等权 speed R²；core 是其余内部点。瞬态旧 bundle 没有这一标记，所以瞬态臂的近壁列为 "–"，
  图 8b 只画准稳态 8 臂。
- **2026-08-31 Centerline V2 staging**：存储阈值数值为 `1.5`、不设上限，稳态与
  瞬态都有标记；但后续单位审计证明冻结 `fluent_to_mm_unit_factor` 不是物理 mm 换算，
  因而该 `region` 不是全队列统一的真实 1.5 mm。formal anatomy-only 数据须按 Fluent
  `m×1000` 重算真实壁距，不能直接复用 staging 标记。
- **物理意义**：WSS = μ·∂u/∂n|wall，由最靠壁 1–2 层 cell 的速度差决定；近壁速度对不上，壁面梯度就对不上，所以图 8b 用它作 WSS 的上游代理。
  三代近壁 R² 全负（V2 −1.5、V3 −1.0、V4 −0.7～−2.4），是提出“硬约束/可选 WSS 头”
  与“按到壁距离分层采样”的诊断证据；两者仍是待配对验证候选，不是 formal 已实现项。
