# 从非 PINN 到 PINN：实验全历程与导师汇报准备稿

> 截止日期：2026-09-07。建议用途：15–20 分钟组会，18 页正文，实验明细放附录。
> 本稿核对了历史日志、路线文档、模型代码、配置和代表性结果文件。它是汇报材料，不替代实验真源，也不将历史文档中的待办指令作为本次执行任务。

## 1. 建议向老师讲的主线

**核心问题：怎样从血管几何可靠地预测 WSS，尤其是高 WSS 区域？哪些收益来自网络，哪些问题来自数据、物理约束和评估协议？**

实际过程是：

```text
几何/时间/边界条件 → 非 PINN 速度、压力场
  → 加入 WSS，多任务与壁面/近壁分域预测
  → 简化为几何 → 单帧 WSS，系统排查结构、采样、损失和信息不足
  → 预测体域 u/v/w/p 并加入物理残差，再由速度恢复 WSS
  → PINN 实验暴露近壁、导数、损失冲突、过拟合及数据合同问题
  → 修复 CFD 数据、几何和中心线，建立 V5 母库
  → 原直接 WSS 配方重跑 + 新局部几何特征验证
  → 下一步在统一数据和验证协议下比较直接 WSS 与体域/PINN 路线
```

汇报结论建议这样说：

1. **显式几何信息有持续价值。** 从早期图模型消融到当前 V5 都观察到收益，局部半径、空间位置和邻域表达值得保留。
2. **物理残差下降并不自动带来场预测和 WSS 改善。** 历史 PINN 中出现近壁速度误差、预测幅值压缩、SAME 点导数偏低和动态权重饱和。
3. **数据重建后，旧网络配方的表现明显改善。** 当前最好的 V5 R4 单 seed 物理 WSS 病例等权全场 R² 为 0.5721，但高值幅度仍偏低，尚待独立验证。

特别说明：**9 月 7 日已完成的新结果属于直接 WSS 监督模型，不是新 V5 PINN 成绩。** 旧 BC/RCR V4、field-v4、WSS-min 数据 v4、Centerline V2/V5 是不同命名体系。PPT 每次写版本号都应带任务名。

**最优先补齐的仿真材料：** 一例完整求解设置截图或导出表；入口波形和四出口参数；网格与近壁层放大图；残差与末两周期 Q/p/WSS 一致性图；网格无关性和时间步无关性证据。当前已查到的内迭代敏感性检查，不能代替后两项。

四例20→60内迭代后 WSS p50/p99/max 变化小于1%，支持“这四例高 WSS 不是仅由内迭代次数造成”，不能推广为全队列 CFD 均已收敛。

## 4. 数据输出与预处理：正文讲流程，附录留字段表

### 4.1 输出内容

| 数据 | 实体/物理量 | 单位与用途 |
| --- | --- | --- |
| 原始几何/网格 | STL、.cas 拓扑、中心线 atlas | 几何、区域身份与离线核验 |
| `ascii/` | 壁面节点坐标、WSS 标量/向量、壁面压力 | 原始坐标m，WSS/压力Pa；不是体域速度标签 |
| `ascii_in/` | 体域 cell 中心坐标、u/v/w/p | 速度m/s、压力Pa；逐帧验证身份与坐标 |

壁面节点、cell 中心、面片是三种实体。ASCII 行号不能直接当 .cas 索引；先做空间身份匹配。回插到面片的图用于空间展示，正式误差在原始同点真值/预测上计算。

**V5 R1/R4共同结构与配方（可直接抄入PPT附录）：** width32；SA中心125/125/32、邻域64/16/16；SA1 knn_cover、SA2/3 ball，半径0.05/0.1/0.2；残差块1/1/0，DropPath0.1，SA2 Transformer 4heads；3NN上采样/查询，head64，输出1。400epoch，batch8，AdamW lr1e-3，warmup10+cosine到1e-5，wd1e-4，clip1，AMP；random5000、support=query、每epoch重采样；MSE+q90 pinball λ0.2；按train_loss选best，固定support+全壁面query，legacy_vertex指标。

**R4输入17维：** xyz；归一化弧长、半径、曲率、ln(radius)；管道坐标ρ、sinθ、cosθ；dR/ds；到分叉/端点距离；end_zone；对齐坐标系的PCA法向nx/ny/nz。这里的ρ是径向坐标，不是血液密度。新特征整体有效，不等于已证明每个特征单独有效。

## 7. PINN 物理页应该怎样讲

总损失示意：`L = L_data + λ_BC L_BC + λ_PDE L_PDE`。不同实验打开不同项，不把下面所有项套到每个版本。

- 连续性：`∇·u=0`。
- 动量：`ρ[∂u/∂t+(u·∇)u]+∇p−∇·(2μ(γ̇)D)=0`，`D=(∇u+∇uᵀ)/2`。V1–V3峰值路线省略时间项，属于准稳态正则；旧V4瞬态才显式计算时间导数。
- 边界：壁面无滑移，入口条件，出口条件；旧V4瞬态含质量流量口径的RCR关系。
- WSS来自壁面切向黏性应力。刚性无滑移壁面可用切向速度的法向梯度解释，但实际恢复依赖近壁分辨率、黏度、法向和符号约定。

**必须明确：** 峰值入口流量不意味着每个空间点 `∂u/∂t=0`；监督CFD标签或增加几何特征本身也不构成PDE PINN。

建议用以下证据说明历史PINN的问题，而非笼统说“PINN无效”：

| 观察 | 证据 | 可以支持的结论 |
| --- | --- | --- |
| SAME点残差过低 | V2独立query动量残差约为精确support点331倍 | 需要检查连续查询函数的导数，不能只看训练采样点残差 |
| 训练后期泛化下降 | V3最佳val checkpoint在epoch92–203；V4补评1000/2500/5000等 | 延长训练不是稳定改进策略；历史V4无val协议限制结论 |
| no-slip与data梯度冲突 | 旧V4准稳态部分臂梯度cos约−0.9至−0.97 | 该结构/采样/权重下优化存在明显冲突；不是普适物理矛盾 |
| 残差降但速度被压小 | 方差比、拟合斜率、speed R²和E同时检查 | 近零场可有低残差，不能只报物理loss |
| EMA没有正常调节 | λ迅速贴上限10，撞限统计护栏存在计数问题 | 这组实验不足以评价动态权重方法的有效性 |
| 标签对强形式RCR不一致 | 历史169例monitor诊断，仅2例四出口残差都低于0.3；周期均值关系相对一致 | 必须先核对标签、离散形式和BC定义，再施加对应残差 |

真CFD速度→冻结Profile-Secant V3，全壁面test35的逐病例整体R²均值约0.9604；这说明该输入条件下后处理可行。**它不是几何网络预测精度。** 预测速度输入时，旧V4下游WSS R²仍负或接近0，近壁速度是关键瓶颈之一。

旧V4的near-wall是评估子区：按最近壁面节点距离≤1.5的旧距离口径，再取最近的最多40,000点；旧单位本身受数据合同问题影响。训练的5000体域support/query并未采用近壁分层或法向剖面采样，不能把这张near-wall评估图讲成已经专门加密近壁训练。

### 9.2 指标统一说明

- 直接WSS `field_casebalanced.r2`：每病例总权重相同，在共同加权真值均值下计算全场R²。
- 直接WSS `aggregate.r2_casemean`：先算每病例R²再取算术平均，和上一项不同。
- 旧体域文档常写的speed `R²_cb`，实际实现通常是逐病例R²均值，不能仅凭cb后缀与直接WSS指标混表。
- `R²_fit`允许线性缩放/平移，必须同时报告原始R²、斜率和误差，不能当作绝对预测精度。
- high-WSS和热点分别回答幅值与位置问题；WSS-min区域评估用每病例真值分位阈值，汇总方式也必须保留。
- 当前legacy_vertex是按顶点的指标，不是壁面面积加权误差。V5存储了面积权不意味着本轮已使用面积指标。
- 历史多时相/峰值、test16/27/35/36/34、固定5k/完整点云、真实BC/oracle/几何-only各有区别，不能画成统一模型排名。

| 后续候选 | 固定峰值速度尺度Q_ref/A_in、沿程面积、POD/时间表示、联合输出 | 目前是方案/候选，不应放入完成结果 |

老师可能追问的简答：

- **“为什么不直接一直用WSS模型？”** 直接WSS是有效且必须保留的基线；体域路线希望加入更强物理结构并输出其他流场，但历史结果尚未证明更优。
- **“PINN为什么没有提升？”** 本项目在当前数据、方程近似、查询表示和训练协议下暴露了具体失败机制；不能据此否定PINN一般有效性。
- **“0.57是不是已经能用？”** 它是34例开发集上的单seed整体指标；高值幅度比仅约0.56、缺独立验证和部署鲁棒性证据，尚不能下工程或临床可用结论。
- **“这次改进是中心线造成的吗？”** 数据修订同时含单位、几何、标签与统计变化；新R4几何组增益也尚未拆分，只能先报告整体效果。
- **“真速度算WSS有0.96，为何网络没有？”** 前者已有近壁真实速度；后者先要从几何预测它，导数对近壁误差敏感，两层任务不同。
