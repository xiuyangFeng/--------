## 3. 入口边界

入口采用截面上均匀、随时间变化的速度：

`u_in(t)=Q_nom(t)/A_udf`

`Q_nom(t)=10^-6 × [a0+Σ(k=1…8){ak cos(kωτ)+bk sin(kωτ)}]`，单位m³/s。

其中`τ=t−floor(t/T)T`，`T=0.8 s`，`ω=6.491 rad/s`，`a0=30.38`。

| k | ak | bk |
| --- | ---: | ---: |
| 1 | 3.109 | 30.03 |
| 2 | −25.41 | 0.9296 |
| 3 | −0.8703 | −13.24 |
| 4 | 3.069 | −4.541 |
| 5 | 5.425 | −0.06318 |
| 6 | 0.404 | 2.757 |
| 7 | −0.4276 | 1.827 |
| 8 | −0.8367 | 0.8608 |

按原系数计算，名义峰值约107.27 mL/s，位于周期相位0.20932 s；周期平均约33.50 mL/s，即2.01 L/min。这些是名义输入，不是monitor测得的实际流量。ω不等于2π/T，代码按T强制重置，不应称周期边界严格光滑的正弦波。

入口面积分母因病例而异。例如CHEN_SHI_MING的A_udf=0.0003687632 m²=368.7632 mm²，名义峰值入口速度约0.2909 m/s。所有病例不能共用这个速度。

实际网格面积不等于UDF分母时，`Q_actual=Q_nom×A_mesh/A_udf`。现有审计登记4例面积比：CHEN_SHU_LIN0.888、LIU_YONG_LAN0.911、ZHANG_YAN_SHAN0.934、WANG_CHUN_MING1.009。

## 4. 血液Carreau–Yasuda模型

`μ(γ̇)=μ∞+(μ0−μ∞)[1+(λγ̇)^a]^((n−1)/a)`。

| 参数 | 数值 |
| --- | ---: |
| μ∞ | 0.0035 Pa·s |
| μ0 | 0.16 Pa·s |
| λ | 8.2 s |
| a | 0.64 |
| n | 0.2128 |

剪切率由Fluent的`C_STRAIN_RATE_MAG`取得。黏度随剪切率变化；0.0035是高剪切极限黏度，不能写成全场恒定黏度。

## 5. 四出口RCR

四出口使用三元Windkessel（RCR）UDF，根据流量和历史状态更新压力；R1/R2/C逐病例、逐出口不同。例：CHEN_SHI_MING原始参数如下。

| 出口 | R1，Pa·s/kg | R2，Pa·s/kg | C，kg/Pa |
| --- | ---: | ---: | ---: |
| out-le 左髂外 | 4.6424×10⁵ | 2.2608×10⁶ | 6.5686×10⁻⁷ |
| out-li 左髂内 | 2.6098×10⁵ | 1.0246×10⁶ | 1.3924×10⁻⁶ |
| out-ri 右髂内 | 1.5525×10⁵ | 1.5381×10⁶ | 1.0571×10⁻⁶ |
| out-re 右髂外 | 1.6298×10⁵ | 1.6412×10⁶ | 9.9213×10⁻⁷ |

这里UDF变量虽叫Q，但由`F_FLUX`累加，实为质量流量kg/s，故R/C单位如表。若改成体积流量公式，需同步转换`R_vol=ρR_mass`、`C_vol=C_mass/ρ`。

既有172例协议审计显示：AG四出口并联DC等效阻力约4.368×10⁵ Pa·s/kg，AAA/ILO大多约3.761×10⁵；左右DC电导份额多接近50/50，有登记例外。各出口`(R1+R2)C≈1.79 s`，而真正极点时间常数`R2C`约1.074–1.782 s，不是全队列常数。DC设计份额不等于每一时刻实际流量固定对半。
