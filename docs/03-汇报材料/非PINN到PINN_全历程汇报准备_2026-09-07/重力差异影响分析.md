# 三例重力开关差异：病例、有效方程与影响

> 核验日期：2026-09-07。针对当前V5的172例原始Fluent case、journal、UDF、HDF5和已有模型评估；未重算CFD，未修改样本或训练代码。

## 1. 哪三例不同

当前169例保存的重力为开启，原始坐标g=(0,0,−9.81) m/s²；以下3例关闭，g=(0,0,0)。均为ILO术前。

| 病例 | 当前V5归属 | fold | 既有求解残差分层 |
| --- | --- | --- | --- |
| ILO/LIU_BAO_JUN-0/before | train | 2 | B |
| ILO/LIU_LIAN_YOU-0/before | train | 3 | A |
| ILO/ZHANG_JIN_CHUN-1/before | test34 | 无 | C |

角色直接取各例V5 manifest，不根据病例名称推断。三例journal没有重写重力，均dt=0.005、1280步、每步最多20次内迭代。

## 2. 关键结论：开关不同不等于有效体力必然不同

**按已核实设置和Fluent默认压力定义，当前恒密度、刚性壁面、单相模型中，重力开关对速度、WSS和求解器报告压力的影响预期较小，连续方程层面可能等价。现阶段不支持把三例直接判成坏数据或把其误差归因重力。**

这一判断有明确前提与证据层级：

1. 172/172原始材料卡均为常密度1060 kg/m³；非牛顿只改变黏度，不改变密度。
2. 新增全队列核验：172/172为`use-operating-density? #f`，未启用手动指定操作密度。保存的`operating-density=1.225`不能直接当实际生效的参考密度。
3. 本机Fluent23.1官方帮助确认，单相`operating-density?`控制是否使用“specified operating density”。同文件`operating-density/`与`mp/operating-density/method`属于多相菜单，不用其数值解释当前单相行为。
4. 可访问的ANSYS Fluent用户指南（Release12镜像）说明：默认通过所有cell的平均密度计算操作密度；重定义压力后，动量的体力是`(ρ−ρ_op)g`；常密度并取相同参考密度时，该体力消失；此时static/total pressure报告不显示参考静水项。
5. 当前UDF从`F_P`取出口压力，面积平均后参与RCR递推，再写回`F_PROFILE`；未发现额外的高度或ρgz补偿。最一致的解释是RCR使用Fluent求解器的重定义压力。

尚未直接做Fluent23.1运行时有效ρ_op打印、同例开关重力复算，所以不能把上述预期写成“已证明数值结果逐点完全相同”。

## 3. 为什么理论上可能相同

物理压力记为p，Fluent重定义压力记为p_r。省略共同的常数参考压力，有：

`p_r = p − ρ_op g·(x−x_ref)`。

对应动量方程为：

`ρ Du/Dt = −∇p_r + ∇·τ + (ρ−ρ_op)g`。

在单相常密度1060且默认平均操作密度机制生效时，`ρ_op=1060`，所以剩余体力为0。若入口速度、RCR关系及压力边界都使用同一p_r定义，开启与关闭重力的速度场方程相同；相同速度梯度和黏度也给出相同WSS。

这不等于真实物理压力没有静水变化。恢复真实压力需要补回`ρ_op g·(x−x_ref)`。区分“真实压力”和“求解器去参考静水项的压力”是本问题的核心。

若以后改成手动ρ_op=0或其他值、采用不同物理压力边界定义、可变密度或弹性壁面，上述等价条件就可能失效，应重新核验。当前不能把那些条件下的影响直接套到本数据。

## 4. 对本项目几个输出的具体影响

| 对象 | 当前判断 | 不能据此声称什么 |
| --- | --- | --- |
| 速度u/v/w | 默认操作密度抵消机制成立时，重力开关预计不会单独带来显著改变 | 尚未做同病例数值开关对照，不能报实际百分比 |
| WSS | 依赖近壁速度梯度与黏度；在上述等价条件下预计影响较小 | 不能看到gravity=false就认定高WSS标签错误 |
| 导出pressure | 很可能沿用去参考静水项的Fluent压力变量 | `pressure_pa`文件名不能保证是含静水项的完整物理压力 |
| 真实物理压力/临床压差 | 若要恢复重力下真实压力，应统一高度、参考位置和静水项 | 减病例均值不能去除空间线性静水项；不能把操作压力101325当出口值 |
| 现有PINN残差 | 代码无显式g项；若标签p_r已使有效体力为0，这并不构成遗漏ρg的证据 | 不应未经压力定义核对就加完整ρg，否则可能重复计算 |
| V5 R1/R4直接WSS | 本轮没有PDE项；首先要核对是否存在有效工况差异 | 不能称这些模型“少了重力loss” |
| 数据溯源 | V5母库目前未独立保存g/操作密度/压力定义字段 | 几何特征不能替代仿真条件记录；可在后续数据版本中补元数据 |

已有PINN对压力主要做病例均值去除；V5原样存pressure并另记均压reference，没有代码显式扣ρgz。这里可能是Fluent在导出前已处理了参考静水项，不能仅看Python代码下结论。

## 5. 三例静水势的量级，仅用于理解物理尺度

本次从各例V5真实mm体域坐标计算高度跨度Δz，以1060×9.81×Δz估计潜在真实静水压跨度：

| 病例 | 解剖体域Z跨度 | ρgΔz | 换算mmHg |
| --- | ---: | ---: | ---: |
| LIU_BAO_JUN-0/before | 259.34 mm | 2.697 kPa | 20.23 |
| LIU_LIAN_YOU-0/before | 294.83 mm | 3.066 kPa | 23.00 |
| ZHANG_JIN_CHUN-1/before | 288.22 mm | 2.997 kPa | 22.48 |

**这不是开关重力后的实测差值，更不是当前pressure标签需要统一加减的偏移。** 在去参考静水项的压力定义下，这一量级不会直接显示在导出压力差中。具体数值见[病例与量级核验JSON](/public/newhome/cy/Digital_twin/GNN/docs/03-汇报材料/非PINN到PINN_全历程汇报准备_2026-09-07/重力差异_病例与量级核验_2026-09-07.json)。其中接口为解剖切面，不是远端RCR边界面。

## 7. 建议处理

先保留三例并标注重力开关与压力定义，暂不因为该开关单独剔除病例、修正WSS、批量重跑或更改PINN方程。

如果需要数值确认，最小验证是：选一例，冻结同一case、网格、UDF、时间步/内迭代及初始化；核对23.1运行时操作密度与报告压力定义，然后仅切换g，按相同周期性/残差标准比较u、WSS和p_r。若目的是比较真实压力，应在一致参考高度下恢复静水项再比较。这是后续建议，本次未执行。

PPT可表述为：“发现3例重力开关与其余169例不一致。进一步核对表明全队列采用恒密度、未手动指定操作密度；按Fluent重定义压力机制，预期对当前速度/WSS的直接影响较小。已登记例外，尚待单例开关对照确认。”
