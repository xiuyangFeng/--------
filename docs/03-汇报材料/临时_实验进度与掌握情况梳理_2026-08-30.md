## 2. 实验路线是怎样一步步收敛的

> **命名提醒**：本节的 V1/V2/V3 指 `wss_pinn` 内部的体域 `u,v,w,p`
> 演进，不是任务 A 历史 GNN 的 V1/V2/V3，也不是 velocity→WSS 中的
> Profile-Secant V3。汇报时最好始终带上“WSS-min”“`u,v,w,p` V2”
> “field-v4”“BC-RCR V4”等完整前缀。

### 2.1 先用一条因果链记住整个演变

```text
WSS-min：几何 → 直接 WSS
    ↓ 发现：能学到一部分空间分布，但幅值、高 WSS 和跨病例稳定性受限
V1：几何 → u,v,w,p，引入真正 PDE/no-slip
    ↓ 发现：residual 和压力改善，但速度收益不稳定
V2：长训练 + SAME5K/full-volume 双协议
    ↓ 排除：不是单纯“训练时间不够”
    ↓ 发现：SAME-IDW 导数问题、near-wall 失真、缺少患者 BC、准稳态 PDE 与瞬态 peak 标签错位
V3：连续坐标场头 + 几何 + BC/PDE 拆分
    ↓ 确认：几何是稳定正增量；BC 能改善边界量；准稳态 PDE 会牺牲瞬态 peak 速度
field-v4：暂时拿掉 BC/PDE，只审核场头和结构
    ↓ 排除：position encoding、local decoder 等小结构改动不是主要突破口
    ↓ 收敛判断：主要缺口是 patient-specific boundary conditioning
V4：显式 Q/面积/RCR + steady/transient + DATA/BC/PDE 严格拆分 + 3 seeds
    ↓ 目标：真正回答“BC 有没有用、PDE 有没有额外价值、动态权重是否更好”
```

这条路线不是不断换题，而是每一代都在排除上一代的一个错误解释：

- WSS-min 排除了“只要不断改直接 WSS 网络，高 WSS 问题就会自然解决”；
- V1 排除了“加了物理 loss 就会所有场指标一起变好”；
- V2 排除了“当前精度差只是因为 epoch 不够”；
- V3 排除了“准稳态 PDE 可以直接匹配瞬态 peak CFD 标签”；
- field-v4 排除了“再换一个局部 decoder 或位置编码就是主要突破口”；
- V4 才开始在更完整的因果合同下，检验显式 BC、时间项和 PDE 的真正增量。

### 2.2 分阶段讲解：每一代为什么要变

| 阶段 | 当时要回答的问题 | 关键结果 | 从中得到的决策 |
| --- | --- | --- | --- |
| WSS-min 直接预测 | 几何点云能否直接学会壁面 WSS | 经过 PointNet/PointNet++、采样、局部 Transformer、损失、RCR oracle 等多轮筛查，单 seed 开发锚点达 `R²_cb=0.3506`；高 WSS 和跨病例稳定性仍不足 | 保留直接 WSS baseline，不再继续无限小改模块 |
| `u,v,w,p` V1 | 相同数据和架构下，加 PDE/no-slip 是否稳定提升场重建 | 物理一致性和压力普遍改善，但四组配对中只有 PN+geom 的五个场指标全部提高；最高 speed R² 约 `0.218` | PINN 不能直接宣称全面更好，需要更干净的因果对照 |
| `u,v,w,p` V2 | 延长到 7500 epoch 后，是否只是没训够 | 最佳 PointNet++ + geom + PINN 的 SAME5K/full-volume speed R² 为 `0.238/0.182`；near-wall R² 仍为 `-1.477/-1.575`；训练已平台 | 不能继续靠加 epoch；问题在连续场头、边界可观测性、SAME-IDW 导数和稳态/瞬态假设错位 |
| `u,v,w,p` V3 | 连续 query decoder、几何输入、BC/PDE 各自有什么增量 | 几何在三种 loss 下都稳定提升 speed R² 约 `+0.19`；BC 对整体速度近中性、对边界相关量改善；PDE 明显降低 residual，却使 speed R² 下降约 `0.05` | 物理正则与瞬态 peak 标签竞争；必须显式处理时间和真实 BC |
| field-v4 Stage 0–1 | 在不加 BC/PDE 时，新场头、位置编码、local decoder 是否有效 | G-Raw `S_field^cb=0.5761±0.0075`；G-PE 增量方向不稳定且触发压力/最差队列护栏；local decoder 无增量 | 结构小改不是主要矛盾，转向 patient-specific BC conditioning |
| **V4** | 显式加入 `Q_in/面积/RCR`、区分稳态/瞬态后，BC 和 PDE 能否真正带来可复现增量 | 当前已有方向性信号：物理臂的速度相对 L2 误差普遍低于 DATA/DATA+BC，但绝对场质量和下游 WSS 仍弱 | 等 48 臂、3 seeds、Holm 和次指标完成后再裁决 |

### 2.3 路线切换的核心逻辑

从直接 WSS 转向 `u,v,w,p` 并不是“不做 WSS 了”，而是把问题拆成两层：

1. 先学到物理场：几何 + BC → `u,v,w,p`；
2. 再用已冻结的可靠后处理链：速度 → WSS。

CFD 真速度输入 Profile-Secant V3 时 overall R² 约 `0.9604`，但当输入换成网络预测速度后，V4 当前 WSS R² 仍为负。因此当前主要瓶颈在上游速度场，尤其是幅值压缩、近壁速度和梯度，而不是继续换 WSS 计算公式。

## 3. V4 到底在比较什么

### 3.1 数据与输入输出合同

- 数据：173 例，`train138/test35`，无 validation；Stage 0 硬 Gate 173/173 通过。
- 输入：局部 `xyz+geom`，再加 `A_mesh/A_udf`、`Q_actual_peak`、入口/四出口面积、四组 `R1/R2/C`；瞬态模式再加时间信息。
- 输出：`u,v,w,p`。
- 稳态模式：峰值时刻的准稳态建模。
- 瞬态模式：81 帧，通过 autograd 显式包含 `du/dt`。
- 不使用 CFD 求解后出口压力作为可部署输入。

### 3.2 48 臂矩阵

`2 时间模式 × 2 backbone × 4 训练模式 × 3 seeds = 48 runs`

| 训练模式 | 包含的 loss | 要隔离回答的问题 |
| --- | --- | --- |
| DATA | 只有 `u/v/w/p` 数据监督 | 纯监督基线能到哪里 |
| DATA+BC | 数据 + no-slip/入口/RCR 边界项 | 只加边界监督是否有增量 |
| BC+PDE-FIXED | DATA+BC + continuity/momentum，`lambda_pde=1` | PDE 本身的增量 |
| BC+PDE-EMA | 与 FIXED 相同，但 `lambda_pde` 由 detached EMA `L_data/L_phy` 动态调节 | 老师建议的动态权重是否比固定权重好 |

### 3.3 评估合同

- 主 checkpoint：`last_converged.pt`，只由 train-only 原始分量平台判定；不存在 `best_test`。
- primary endpoint：test35 病例等权速度向量相对 L2 误差 `E_rel_l2`，**越低越好**。
- 预注册 contrasts：`DATA+BC − DATA`、`PDE-FIXED − DATA+BC`、`EMA − FIXED`、`PointNet++ − PointNet`，按时间模式做病例配对 Wilcoxon + Holm。
- 每个病例先对 3 seeds 求均值；单 seed 只能做 screen。
- test35 已经被多轮开发暴露，因此最终检验仍是探索性，不是新 cohort 上的确证性结论。
- WSS 是下游 sanity check，不能用它反选 epoch、权重或架构。

> **指标解读警告**：`E_rel_l2=0.894` 不是“89.4% 准确率”，而是预测误差向量的 L2 范数约为真值速度场 L2 范数的 89.4%，仍属于很大的场误差。

## 4. V4 当前已有结果怎么看

### 4.1 seed1234 完整 16 臂的 primary endpoint

`E_rel_l2`，越低越好：

| 时间模式 / backbone | DATA | DATA+BC | BC+PDE-FIXED | BC+PDE-EMA |
| --- | ---: | ---: | ---: | ---: |
| steady / PointNet | 1.1246 | 1.1756 | 0.9682 | **0.9347** |
| steady / PointNet++ | 1.1054 | 1.1534 | 0.9640 | **0.9096** |
| transient / PointNet | 1.0406 | 0.9370 | **0.8941** | 0.9649 |
| transient / PointNet++ | 1.0366 | 0.9406 | **0.9071** | 0.9512 |

这张表可以说明的只是：

1. 在 seed1234 上，物理臂的 `E_rel_l2` 比 DATA/DATA+BC 低；
2. steady 中 EMA 最好，transient 中 FIXED 最好，动态权重没有表现为全局统一最优；
3. DATA+BC 在 steady 中反而比 DATA 更差，在 transient 中有改善，说明 BC 的作用与时间建模有交互；
4. PointNet++ 不是在所有对照上都明显优于 PointNet。

这张表不能说明：

- PINN 已经具有多 seed 稳定统计优势；
- EMA 或 FIXED 已被正式裁决；
- `u,v,w,p` 四个通道都已达到可用精度；
- 下游 WSS 已经成功。

### 4.2 目前已齐 3-seed 的小部分组

| 组 | n | `E_rel_l2` mean ± std(pop) |
| --- | ---: | ---: |
| steady / PN / PDE-EMA | 3 | `0.9299 ± 0.0035` |
| steady / PN / PDE-FIXED | 3 | `0.9830 ± 0.0117` |
| steady / PN++ / DATA | 3 | `1.1208 ± 0.0109` |
| steady / PN++ / DATA+BC | 3 | `1.1602 ± 0.0391` |
| steady / PN++ / PDE-FIXED | 3 | `0.9643 ± 0.0117` |
| transient / PN / DATA | 3 | `1.0230 ± 0.0126` |

这些数字说明部分趋势可复现，但四类预注册 contrast 还缺完整对照组，不能提前代替最终 Holm 分析。

### 4.3 下游 WSS 的当前结果

- 已评 38 臂中，raw WSS `R²_cb` 最好的是 `V4-TR-PNPP-BC-PDE-F-s1234`，约 `-0.0003`，实质上只是贴近 0。
- DATA 臂特别差：steady DATA 多在 `-6～-10`，transient DATA 约 `-3～-5`。
- PDE 臂的 WSS range-NMAE 多在 `0.07～0.08`，明显优于 DATA 臂的约 `0.13～0.24`；但 raw R² 仍为负或贴近 0。
- 这表明物理臂可能在幅值误差上有帮助，但尚未学会足以恢复 WSS 空间分布的近壁速度/梯度。

**不能只报 NMAE，不报 R²。** 项目历史已经证明，较低 NMAE 可以和较低甚至负 R² 同时出现。

### 4.4 其他不能忽略的次指标问题

- 已评最好臂的 case-balanced speed R² 仅约 `0.176`，说明速度空间分布的解释度仍弱。
- steady 压力 R² 多为小幅正值，而已评 transient 臂的 raw pressure R² 约为 `-19～-27`；压力 gauge、逐帧口径、压力梯度/压降必须单独审计，不能因为速度 primary 改善就宣称 `p` 也成功。
- 历史 V2/V3 和当前 V4 都指向高速段幅值压缩；V4 下游峰值速度拟合 R² 大致仍只有 `0.1～0.21`。
- near-wall 是从 V1/V2/V3 一直留到 V4 的主要失败区，而 WSS 对该区域最敏感。

## 5. 目前可以对外说什么，不能说什么

### 5.1 可以说

1. 已建立 173 例、81 时相、显式面积/RCR/流量条件的独立 V4 数据与训练链路，硬 Gate 173/173 通过。
2. 已建立完整的 DATA、DATA+BC、PDE-FIXED、PDE-EMA 因果拆分矩阵，可以分别检验 BC、PDE 和动态权重。
3. 历史多轮实验稳定支持“几何信息重要”，同时也稳定证明“物理 residual 下降不等于场精度一定上升”。
4. V4 目前物理臂的速度相对 L2 误差和 WSS range-NMAE 存在方向性改善。
5. CFD 真速度经冻结算子能较好恢复 WSS，因此当前 WSS 失败主要指向预测速度场，而不是算子本身。

### 5.2 不能说

1. 不能说 PINN 已经在统计上稳定优于 data-only。
2. 不能说 EMA 权重已经优于固定权重；当前 steady 和 transient 的方向不一致。
3. 不能说 PointNet++ 已经稳定优于 PointNet。
4. 不能说瞬态建模已经同时解决速度和压力。
5. 不能说当前预测速度可以可靠恢复 WSS；目前 raw WSS R² 仍为负或贴近 0。
6. 不能把单 seed 工作簿数字当成正式 3-seed Holm 结论。
7. 不能把 test35 当成未暴露的独立确认集。
8. 不能证明网络已学会“同一几何在不同 RCR 下的因果响应”，因为当前每个几何主要只有一组 BC。

## 6. 目前最需要解决的问题

### 6.1 进度闭环

- 跑完 6 个正在训练的臂和 2 个待启动臂。
- 对剩余 10 臂统一做 official test35 + 冻结 Profile-Secant V3 WSS：其中 2 臂已完训可直接评，8 臂待完训。
- 统一回填工作簿，不要继续形成“有 JSON 、无 xlsx”的中间状态。

### 6.2 统计闭环

- 每病例先对 3 seeds 求均值。
- 按预注册集合执行病例配对 Wilcoxon + Holm。
- 同时报告 effect size、置信区间、seed 离散度和队列分层，不只报 p-value。
- 如果臂间差异小于 seed 间离散度，正式写为 `inconclusive`。

### 6.3 科学瓶颈

- 速度幅值压缩，尤其是高速段。
- near-wall 速度和梯度不可靠，直接导致 WSS 失败。
- transient pressure 的 raw R² 极差，需要单独确认 gauge 和更适合的压力梯度/压降口径。
- BC 输入是否真正被模型使用，还需要 RCR permutation/扰动/counterfactual 诊断。
- test35 是开发暴露集，路线裁决后最好准备新 cohort 作确认。

### 6.4 数据版本边界

Centerline V2 的 173 例修复与审计已完成，但尚未 cutover 重建 `data_wss_min` / `data_wss_pinn` 和旧 bundle。当前 V4 矩阵应按已冻结的现有数据版本完成，不能在剩余臂中途切换中心线口径。

## 8. 五分钟向老师汇报的口径

> 本次汇报采用**完整演进版**：WSS-min → V1 → V2 → V3 → field-v4 → V4。讲述重点是“上一代暴露什么问题，下一代如何只针对该问题修正”，不展开所有 Job 细节。

### 8.1 第一句：我现在在做什么

> 我现在没有继续直接堆 WSS 网络模块，而是把主线收敛到显式边界条件的体域 `u,v,w,p` 重建，再用冻结的 velocity→WSS 算子做下游验证。

### 8.2 为什么这样改

> 历史 V1/V2/V3 显示，几何特征是稳定正增量，但简单 PDE 会改善 residual 而不一定改善速度；同时模型没有显式看到患者特异流量和 RCR，本质上是条件不完整的多解映射。

### 8.3 V4 的设计

> V4 固定 train138/test35，比较 steady/transient、PointNet/PointNet++、DATA/DATA+BC/PDE-fixed/PDE-EMA 和 3 seeds，一共 48 臂；主指标是病例等权速度向量相对 L2 误差。

### 8.4 现在做到哪里

> 当前 40/48 完训，38/48 已完成 official test35 和 WSS；6 臂正在训练，2 臂排队。seed1234 的 16 臂已经完整闭环。

### 8.5 初步结果

> 单 seed 上，steady 的 EMA 臂和 transient 的 fixed-PDE 臂的速度相对 L2 误差较低，已评最低约 0.894。但该误差仍然很大，下游 WSS R² 最好仍只贴近 0，所以还不能宣称路线成功。

### 8.6 希望老师帮忙判断的事

> 等待矩阵齐后，我会按预注册做 3-seed 和 Holm。我希望老师帮忙判断：第一，速度相对 L2 误差约 0.9 是否仍已经足以判定场重建未达标；第二，瞬态压力应以 raw R² 还是压力梯度/压降为主；第三，如果 WSS 失败主要来自 near-wall 梯度，后续是否应当把精力收敛到近壁表示，而不是继续扩大物理 loss 矩阵。
