# WSS 最小路线汇报图表（2026-07-12）

## 建议汇报顺序

1. `01_纯XYZ与XYZ加几何_预测精度对比.png`
   - 回答“几何特征是否有用”。
   - 同为 PointNeXt-S、FPS-2000、seed=1234、400 epoch，仅输入特征不同。
   - test 全场 R²：纯 XYZ `0.053` → XYZ+几何 `0.200`；病例等权 R²：`0.047` → `0.188`。
   - 几何特征是显著增益，但狭窄区和高 WSS 区 R² 仍为负，局部极值预测仍是短板。

2. `06_几何特征增益典型病例_预测云图对比.png`
   - 直观展示同一 test 病例的真值、预测和绝对误差。
   - 该例中病例 R² 从 `0.006` 提高到 `0.352`。
   - 这是“几何特征增益典型病例”，不应表述为所有病例均有同幅提升。

3. `02_纯XYZ与XYZ加几何_训练曲线.png`
   - 左右对照两个特征消融 run 的训练 loss 与 val R²。
   - 纯 XYZ 的病例等权 val R² 波动大且多次跌至负值；XYZ+几何的评估曲线整体更高。
   - 虚线是当时按 val `R²_casemean` 选中的 checkpoint：分别为 epoch 59 和 119。

4. `05_完整壁面与FPS选取点_可视化对比.png`
   - 病例 `fast/RAN_QING_BO`，完整壁面 17,682 点。浅灰为**真实血管壁面（STL 三角面）**背景，红色为不同数量的 FPS 训练采样点。
   - 沿 -Y 侧视，血管长轴（Z）竖直、Y 形分叉展开；三个采样面板用同一 marker 尺寸，点数差异如实呈现为疏密差异：FPS-1000 明显较疏、可见浅灰壁面透出，FPS-6000 接近铺满。
   - 口径：FPS 采样点近似均匀覆盖整根血管壁面，并非只落在局部；训练使用稀疏子集，评估仍在完整壁面点云上进行。
   - 想在汇报现场交互旋转/放大，可用配套的 ParaView 诊断包（见文末“ParaView 采样诊断包”），与本图为同一病例、同一配准坐标系。

5. `03_XYZ加几何_点数与精度选择曲线.png`
   - 第四轮 clean-data / dev1 / seed=1234 的 6 点曲线。
   - 精度随采样点数不单调；1000 和 2000 点的全场 R² 均约为 `0.351`。
   - 默认仍选 2000 点：精度持平时保留更高的表面覆盖。

6. `04_一千点与两千点_三随机种子稳定性.png`
   - 三种子下，1000/2000 点的全场 R² 为 `0.337±0.017 / 0.339±0.020`，基本持平。
   - 1000 点的病例等权 R² 更高（`0.221±0.019` vs `0.188±0.025`），但其他指标未稳定支持更换默认点数。

7. `07_训练病例数与泛化精度_学习曲线.png`
   - 用于补充近期第五轮进展：3 条嵌套病例链 × 3 随机种子。
   - 全场 R² 均值从 13 例的 `0.258` 增长到 40 例的 `0.312`，53 例为 `0.310`；在当前 13–53 例观测范围内，40→53 未观察到可辨识 field 增益。
   - 该图不能外推为“几百/几千例数据无用”；更大规模的高质量独立病例仍可能显著改善精度。

## 口径注意

- 图 01、02、06 是第一轮旧 split 的特征消融，图 03、04 是第四轮 clean-data/dev1 协议，图 07 是第五轮 learning curve。它们用于回答不同问题，不应将绝对 R² 直接并排为同一轮模型排名。
- 开发期主要结果是 val-only；第一轮 test 仅作历史特征消融证据，不作新配置反复选模依据。
- 全场 `R²_field` 会受高 WSS 病例和大点数病例影响；`R²_casemean` 是逐病例 R² 等权平均，建议两者一起汇报。
