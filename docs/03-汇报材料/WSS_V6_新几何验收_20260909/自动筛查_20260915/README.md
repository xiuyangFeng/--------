## 三层检验

| 层 | 检查内容 | 独立于候选算法的依据 |
| --- | --- | --- |
| L1 数值一致性 | 用另一套实现从存储多边形重算面积、周长、质心、圆度、偏心度；平面性；是否包含中心线点；是否自交；Req/圆度恒等式；valid 与 reason 一致；壁面映射面积对截面插值；开口面积对 Fluent 界面面积 | 只用 npz 里的多边形坐标和 h5 里 Fluent 自己算的界面面积 |
| L2 物理尺子 | ① 体网格 dV/ds：把 Fluent 体单元体积按 V5 atlas 的 s 聚合成每毫米体积，即该处的"真实"截面积，与候选截面积比；② A/(πRmis²) 下界（截面积不可能小于最大内切圆）；③ 同段相邻站面积跳变 >1.5×；④ V5 与 V6 壁面投影段归属和 s 一致性 | 体网格单元和 VMTK 内切半径都不经过截面轮廓算法 |
| L3 队列统计 | CIA 长度/曲折度/角度、主干长度、入口面积、有效率、分叉定位 s 等 21 个标量的 robust z（中位数/MAD，\|z\|>3.5）；解剖硬带（CIA 长 20–120 mm、曲折度 1–2、角度 0–90°、开口 5 个、拓扑通过） | 队列自身分布 |

## 结果

**L1 全部通过（172/172）。** 面积/周长重算相对误差 ≤6e-8，质心 ≤1e-4 mm，平面性 ≤6e-5 mm，无一截面不包含中心、无一自交，valid 与 reason 无不一致，壁面映射面积与截面插值 p99 误差 4e-6，开口面积对 Fluent 界面面积最大差 0.13%，V5/V6 壁面段归属 100% 一致、s 差 p95 0.24 mm（即 atlas 半步长）。数值层不需要人看。

## 边界

- dV/ds 用 V5 的最近 atlas 点分配，s 是 0.5 mm 离散值，必须按 slab 宽度加权；动脉瘤颈附近囊体积会被分到颈部 s，导致"截面积 < 体网格"类弱报警偏多，权重已降低。
- 阈值（1.5×、0.6×、3、0.85、20%）只用于排序和分流，不是验收或训练门槛。
