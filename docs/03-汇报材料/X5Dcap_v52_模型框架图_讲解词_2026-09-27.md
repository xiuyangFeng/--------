## 可直接口述的讲解词（约 5–7 分钟）

**开场，先说明任务。**

老师，这张图展示的是我们当前 X5Dcap v5.2 的几何到壁面剪切应力预测模型。主模型的输入是血管壁面几何以及由几何计算的特征，输出是指定峰值帧上，每个壁面点的 WSS 大小。它学习的是现有 CFD 协议下几何与 WSS 的对应关系，推理时不需要再输入真实的速度场或压力场。

整张图可以分成三个层次来理解：第一层是用点云主干提取多尺度几何信息；第二层是补充血管壁面的局部方向和细节；第三层是在具体预测位置，结合局部邻域与病例整体信息，修正最终输出。右上角另外画了一个共享主干的三输出扩展，可以直接预测峰值 WSS、TAWSS 和 OSI。

**指左侧输入，说明 support 和 query。**

左边两组点云来自同一个病例。Support 点负责给网络提供几何上下文，query 点负责指定我们要在哪些位置输出结果。训练时两组各取 5000 个点，而且独立采样、逐轮重采样，目的是减少模型对某一套固定采样点的依赖。这里独立采样不意味着两组点必然没有重合。

实际计算时，是 support 点进入编码器和特征传播主干；query 点从编码后的 support 特征中取得信息，再结合自己的局部几何进行预测。因此部署时，可以固定一组 support，把整个壁面分批作为 query，逐点得到完整 WSS 分布。图中的 B 表示一个批次包含的病例数，27 表示每个点的输入特征数，不是 27 个时间点。

**指左下 27D 特征，解释 cap 和物理先验。**

这 27 个特征大致有三类：一类描述位置和血管尺度，例如坐标、沿中心线位置、局部半径和到分叉的距离；一类描述壁面形状，例如法向、曲率和周向位置；还有一类是从几何推导的流量分配与剪切尺度先验。

X5Dcap 里的 cap，指的是用几何虚拟开口的半径来构造 Murray 分流先验。按当前协议，根部分叉先左右分流，更深层的分支按半径三次方的相对大小分配；再结合局部半径，构造类似 q/R³ 的相对剪切尺度。这样网络不必完全从零学习“分支尺度和剪切强弱之间的关系”。这里用的是几何派生的参考量，不是真实 CFD 分流标签；它作为输入帮助网络学习，并不会在输出端直接再加一次。

**指上方编码器，解释为什么逐级压缩点云。**

接下来，Stem 先把每点的 27 维输入映射成 32 维特征。后面三个 SA 模块逐层聚合邻域信息：从 5000 个 support 点到 125 个中心，再到 125 个中心，最后到 32 个中心；对应特征维度从 32 增加到 64、128 和 256。

这里压缩的是用于聚合的中心数，网络仍会读取这些中心周围的邻域。第二层虽然还是 125 个中心，但邻域范围和特征维度变大，所以它仍然在学习更大尺度的结构。主干以 PointNet++ 的层级结构为基础，加入局部残差块和几何位置编码；SA2 还使用一个局部 Transformer，让同一空间邻域里的特征相互交互。这个 Transformer 的作用对象是空间邻域。

最粗层的 32 个点还会进行一次最大池化，得到 256 维的病例整体描述。它是一个全局摘要，后面用于调节局部修正；这里的最大池化本身不属于注意力。

**指中间特征传播，再指下方方向分支。**

编码器提取了较大范围的结构后，FP 解码部分通过插值和跳跃连接，把粗尺度信息逐级传播回 5000 个 support 点，并恢复每点 32 维特征。跳跃连接的作用，是在恢复分辨率时保留前面较细的局部信息。

下面的方向性壁面分支，是进一步补充小尺度几何的。它从 support 点的浅层特征出发，在三个尺度上构造邻域，并结合局部切向、周向和法向关系组织邻居。这样有助于区分沿血管方向的变化、绕壁面的变化，以及空间上靠近但不应该直接混合的区域。

三个尺度各产生 32 维特征，拼成 96 维，再融合成 32 维修正量，加到 FP 恢复的 support 特征上。图中的 0.015、0.030 和 0.060 是归一化坐标半径，不是毫米。之后，模型才用额外的三近邻反距离插值，把这些增强后的 support 特征传到 query 点。

**指右侧 Query Patch FiLM，解释为什么插值后还要修正。**

Query 点拿到插值特征后，模型还有一次局部修正。原因是 support 是稀疏采样，单靠插值可能把细小几何差别平滑掉。所以对每个 query，我们从完整壁面取 16 个真实几何邻居，组成一个小 patch。这里读取的是邻居坐标和几何特征，不包含真实 WSS 标签。

这个 patch 的局部特征，会由两部分上下文共同调节：一部分是当前 query 的 32 维解码特征，另一部分是前面得到的 256 维病例摘要。两者合起来，用于生成 FiLM 的缩放和偏移参数。

可以把 FiLM 理解为：同样一种局部形状，放在不同位置、不同整体血管结构中，可能对应不同的剪切水平。因此模型用上下文来决定，哪些局部特征应该强调、哪些应该减弱，再输出一个小修正量。这个修正量最终加在基础预测头的输出上。

方向分支和 patch 修正分支的输出层都采用零初始化，所以在训练起点，它们不会额外改变原有网络输出；随后再通过训练学习需要怎样修正。这是初始化设计，不意味着训练后一直保持原预测不变。FiLM 的上下文路径允许梯度回传到主干。

**指右下输出和训练目标。**

基础头输出一个标准化 log-WSS 值，再加上 query patch 的预测修正，最后通过逆标准化恢复为 Pa。采用 log 空间，是为了缓解 WSS 跨度大、少数高值主导训练的问题。

峰值单任务模型使用 MSE 加权重为 0.2 的 pinball 损失，pinball 参数 q=0.90，会让相同大小的低估受到更重的惩罚，目的是缓解预测偏低的倾向。这不等于最终输出是一个经过校准的 90% 置信界限，也不能只看训练 loss 判断物理空间效果，仍需检查 Pa 误差和热点等指标。

**最后指右上角的可选周期量扩展。**

右上角是 M1cap 的多输出扩展。它保留同样的几何主干，把单点输出从一个通道改成三个通道，分别对应峰值 WSS、TAWSS 和 OSI。这三个量共享主干，一次前向即可得到；TAWSS 和 OSI 的训练标签由 CFD 周期数据计算出来，推理时仍然只需要几何输入。

因此，这个扩展学习的是几何与周期汇总指标之间的关系，没有在网络里展开 81 帧时间序列，也不能用它的结果证明模型恢复了完整血流动力学。峰值 WSS 和 TAWSS 使用 log 标准化，OSI 使用适合其有界范围的 logit 标准化；当前三通道损失等权，峰值单任务中的 pinball 项在这版多输出配置里关闭。

## 讲解时可用的简化公式

主模型的逻辑可写成：

`support几何 → 多尺度特征 → support局部方向修正 → query插值 → 基础预测 + query patch修正 → Pa WSS`。

两个修正发生的位置不同：方向分支修正 **support 特征**；patch 分支修正 **最终标准化预测**。

FiLM 的特征调制为：`h' = (1 + γ(context)) ⊙ h + β(context)`，随后池化并输出修正。这里的 γ/β 是神经网络预测的特征调制参数，不是流体物理参数。

当前单任务的物理恢复为：`WSS_pred = exp(σ_train · z_pred + μ_train) − eps`。μ/σ 来自当前训练分区，不使用留出病例拟合统计量。
