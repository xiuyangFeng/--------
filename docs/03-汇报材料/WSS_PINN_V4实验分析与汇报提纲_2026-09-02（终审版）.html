一页结论

  1. 验证2 时间模式（准稳态 peak / 瞬态 81 帧 autograd）× 2 backbone（PointNet / PointNet++）× 4 训练模式（DATA / DATA+BC / BC+PDE-FIXED λ=1 / BC+PDE-EMA）× 3 seeds。条件输入为入口/出口面积、Q_actual_peak、四出口 R1/R2/C。
  2. 简单结果16 组 E_rel_l2 全在 0.89–1.18。与 V3 同类组（输入为XYZ+几何特征）对比是退步（speed R²_cb 0.23 → −0.28）。
  3. 原因分析1.协议层取消 validation 训满 10000 epoch，后续做了 epoch 补评证明 DATA 组在 epoch 1000 时 E 0.80 是全矩阵最好点、之后单调退化到 1.12（图 4 / 图 9）；2.数据层旧注册帧的几何通道错位、曲率失真、瞬态池只有 2000 点；3.物理层 no-slip 梯度与数据梯度近乎反向（cos ≈ −0.9，图 11）、PDE 残差靠降低压力满足、EMA λ 动态调整的权重一开始就触发上限，从未进入主动调节、瞬态 RCR 强形式残差在标签上本身不成立。PINN在 E 上的"改善"全部是幅值压缩（图 6 / 图 12）。
  4. λ 动态调整带来的影响λ 动态调整没有真正生效。无量纲化后 PDE loss 比 data loss 小 2–5 个数量级，比值目标 600–80000 被 λ_max=10 限制，实际跑的是"λ≡10 固定"；瞬态下直接打开 u≡0 平凡解。代码设定有 bug（撞限比例最大只能 0.02，门限 0.5 永不触发）。逐步解释见 Q5。
  5. 下一步处理数据审查新处理 → CV 恢复选模 → 输入只用坐标 + 几何点云 + 单一入口流量、压力相对 gauge、速度按 U_c 归一 → 优先考虑暂停 PINN，直接输出wss。

3 · 原因分析

3.1 协议：无 validation + 10000 epoch最主要 · 图4 / 图5 / 图9
  • 训练末段 data_total 与 test E 完全脱钩：DATA 组训练最好（0.19）测试最差（1.12）。
  • milestone 补评：DATA 组 epoch 1000 最好，之后每个 milestone 都更差；V3 最优在 92–203，V4 训了 50 倍。
3.2 数据：旧数据集问题8-30 审阅 P0 六项 · 整个矩阵降级为 historical screen 的原因
  • 稳态与瞬态的第二几何通道物理量设定出错（mm 半径 vs 无量纲径向比）。
  • 旧曲率按 VTP 全局点顺序求导：18% 点 |κ|>，最大值3e11；数据集算法优化后 p99 只有 0.27/mm。
  • 4 例左右镜像出错；8 例压力值过低（含 test 两例）。

  • 动态调整λ的组别：瞬态 λ=10 打开平凡解通道（pde_total 3e-6、对流项 0.001、continuity 1e-12）。

3.8 体域→WSS 还是直接 WSS
  • 旧线直接回归壁面 WSS 最好 0.351；体域路线 WSS raw R² V2，3，4均小于 0.2，且V4均负。
  • WSS 是壁面法向导数，导数放大误差。
  • 体域-wss算子：Profile-Secant V3 在cfd真实标签上R² 0.92，但逐病例 high-WSS 0.77、峰值低估。
  • 统一方案：WSS 成为网络直接输出，用壁面 CFD WSS 标签直接监督 ；配分层采样与局部几何条件化。

    一句话：数据项要把近壁速度拉高（CFD cell-center 标签非零），no-slip 项要把壁面速度压到零；网络分辨不了 1–2 mm 的边界层，两项在同一批参数上一个往东一个往西，合力很短再被裁剪，最后唯一的折中是把整个速度场整体压小。

    • 度量：每 50 step 把 data_total 与 no_slip_raw 分别对全部参数求梯度向量，算夹角余弦。cos = 1 同向，0 互不干扰，−1 完全对拉；−0.9 对应夹角约 154°。
    • 图 11 四联（3.3 处）：(a) 向量示意；(b) 日志实测：准稳态三组从 epoch 0–200 起就是 −0.87～−0.89，末段 −0.88 / −0.97 / −0.97，瞬态两组开局 ≈ 0、末段 −0.33 / −0.61；(c) 一维剖面演示：只拟合数据时壁面残留 0.21，加 no-slip 后壁面归零但峰值只剩 0.95；(d) 末 500 epoch 分布：准稳态三组 71–99% 的 step 低于 −0.8，‖∇L_data‖ ≈ 3 而 clip = 1，BC 组 83% 的 step 被裁剪。
    • 后果链（准稳态 PN）：wall RMS 0.36 → 0.23 → 0.16 → 0.13 m/s，方差比 0.39 → 0.16 → 0.07 → 0.04，speed R²_cb −0.10 → −0.28 → −0.42 → −0.51。瞬态弱是因为舒张期标签本身近零（no_slip_raw 0.02 对 0.25）。出路：硬约束 u = d_wall·g(x) 让 no-slip 自动成立（Gate C1）。
    Q5 为什么 PDE loss 小 2–5 个数量级、λ 被 10 夹死、瞬态打开平凡解、护栏 bug——逐步解释
    1. 两个 loss 的"单位"不同，比值没有物理含义。 data loss 是标准化 MSE（标签按全库 std 标准化，训练中 0.2–1.0）；PDE loss 是无量纲残差的平方：动量残差除以 ρU_c²/L_c（例 1060 × 0.29² / 0.0217 ≈ 4.1 kPa/m），训练末段残差各项 RMS 几百 Pa/m → 无量纲 0.05–0.1 → 平方 1e-3～1e-2。实测 EMA(L_data) ≈ 0.85–1.1、EMA(L_pde) ≈ 6e-4～2e-3，比值 500–3600（SP）；瞬态后期 PDE 残差塌到 7e-5，比值 1e4–1e10。
    2. 控制器第一次更新就撞上限。 λ_target = clip(α·EMA_data/EMA_pde, 1e-4, 10)，α 从 0.1 ramp 到 1。α = 0.1 时目标已是 130–220 ≫ 10。λ_applied 经 0.9 平滑从 1.09 起步、每 50 step +0.6～0.9，epoch 15 就 ≥ 9.9，此后 99.8% / 99.5% 的时间贴在 10。所以 EMA 组 ≡ "λ ≡ 10 固定组"，老师方法的核心——随训练动态调整——从未发生（controller.py 公式本身与设计一致）。
    3. 为什么瞬态下 λ = 10 打开 u ≡ 0 平凡解。 对 u ≡ 0、p ≡ const：动量与连续性残差恒为 0、no-slip 为 0，只剩 data loss（标准化 MSE ≈ 1）和入口残差。而认真拟合标签的解要付 λ × PDE 残差的代价：瞬态标签与强形式方程本身不一致（RCR 标签级残差 0.8）、PDE 点只有 512 个、网络表达受限，残差压不下去。λ = 10 让"什么都不预测"的总 loss 反而更低：TR-PN-EMA 的 u 通道训练 MSE 0.99、pde_total 3e-6、continuity 1e-12。准稳态 peak 标签处处非零，零场 data loss 太大，所以只是幅值压得更狠（方差比 0.04、p R² 0.11）。
    4. 护栏 bug（train.py:403/464）。 设计要求"撞限比例 > 0.5 不判收敛、应报警"。实现里每 step 累加 lambda_clamped，但 controller 只在 global_step % 50 == 0 的 step 才算撞限标志，其余 step 恒为 False；每 epoch 138 step 里只有 2–3 步可能为 True，分母却用 138 → 比例上限 0.02。training_summary.json 里 EMA 组的 lambda_bound_fraction = 0.02 实际是 100% 撞限；门限 0.5 永远触发不了。修法：分母改为控制器更新步数，或每 step 记录"当前仍在撞限"状态。
    5. 要真检验老师的方法：把 PDE 残差换成与 data 同"单位"的度量，或把 λ_max 放到比值量级；按梯度范数而不是 loss 值平衡——PDE-F 末段 ‖∇L_data‖ 3.05 对 ‖∇L_pde‖ 0.69，λ = 600 时 PDE 梯度是 data 的 ≈ 140 倍，会更快掉进平凡解；先做 train-only smoke 确认 λ 在工作区内浮动（修正后的撞限比例 < 20%）再进矩阵。
