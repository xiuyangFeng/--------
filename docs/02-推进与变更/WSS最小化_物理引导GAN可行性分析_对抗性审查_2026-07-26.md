`pipeline/config.py:170-172` 的归一化白名单本来就列有 `u, v, w, p, vel_mag, wss_x, wss_y, wss_z`——是 WSS-min 精简管线把它们裁掉了，不是数据不存在。

> 原稿路线 D（生成速度/压力场 + PDE 残差）被评为可行性 2/5，理由是"只有保存了可靠速度/压力/BC 后再考虑"。**该前提已满足**：近壁速度梯度可由 `ascii_in` 的 `u,v,w` 与壁面距离重建。路线 D 的可行性评分应上调。
>
> 需同时注意（原稿与我先前草稿均未提及）：UDF 中血液为 **Carreau 型非牛顿流体**（`μ = A1 + (B-A1)·(1+(D·ε̇)^E)^((n-1)/E)`，`A1=0.0035, B=0.16, D=8.2, E=0.64, n=0.2128`）。因此 `τ_w = μ·∂u_t/∂n` 中的 `μ` 是应变率相关的，任何残差校核必须用同一本构，否则会得到系统性偏差。

### 1.3 —— 关键修正 —— "逐例 BC"不存在，且出口量是求解器输出

原稿 §9.5 把"缺少边界条件导致一对多不可辨识"列为风险，控制措施写"优先整理可用流量、RCR、压力或近壁速度条件"。我在审查中期据此提出了"任务欠定"根因假设。**全库核查推翻了这一整条思路，两个方向都推翻**：

**（a）入口 BC 全库统一，没有逐例信息可提取。**

`udf-inlet.c` 是 `DEFINE_PROFILE(my_inlet)`，速度剖面由一条硬编码的 8 阶 Fourier 级数给出：

```c
#define T 0.8      // 心动周期
#define a0 30.38   #define w 6.491   // ... a1..a8, b1..b8 全部硬编码
F_PROFILE(f,t,i) = 1e-6 * (a0 + Σ aᵢcos(i·tt·w) + bᵢsin(i·tt·w)) / 0.0005243612;
```

对全库 **347 个 `udf-inlet.c`** 逐一提取波形常数：

```text
#define T 0.8      → 347/347 一致
#define w 6.491    → 347/347 一致
#define a0 30.38   → 347/347 一致
#define n 0.2128   → 347/347 一致（黏度模型）
```

（文件 md5 分成多组，差异仅来自 UDF 尾部 `Lookup_Thread(d, 4770)` 一类**逐例出口 thread ID**，与波形无关。）

实测入口流量印证：267 个可解析的 `vf-in-rfile.out` 中，**92.1% 的 `Q_peak` 落在中位值 ±1% 内**（中位 `1.0727e-04 m³/s`），抽样的 10 例归一化波形两两相关系数 `min=med=1.000`，`Q_peak/Q_mean` 全部等于 `3.20`。

> **结论：入口边界条件是标准化仿真协议的一部分，逐例完全相同。不存在可加入特征的"患者特异入口条件"。**

**（b）出口 `p-out*` / `vf-out*` 是监视器，不是边界条件。**

从 `.cas.gz` 中读出 report-definition：

```text
(name . "p-outle") (report-definition surface-areaavg (field . "pressure") (surface-names out-le+) ...)
(name . "vf-outle") (report-definition surface-volumeflowrate (surface-names out-le+) ...)
```

即这些 `.out` 文件记录的是**求解结束后在出口面上做面积平均得到的压力/流量**——它们是这次 CFD 求解的**输出**，与 WSS 同源。跨例变异（`p-out*` 时均值 CV ≈ 0.35–0.43，范围 0 至 5.9e4）来自几何差异导致的分流差异，而**不是**来自不同的入口设定。

> **结论：把 `p-out*` 当作模型输入特征是标签泄漏**（用同一次求解的一个输出去预测另一个输出）。原稿 §9.5 建议"整理可用流量、RCR、压力条件"进入生成器条件，若照此执行会引入泄漏。这一条必须在任何后续方案中明确禁止。

**（c）这个修正的正面含义**（比负面含义更重要）：

- 映射 `几何 → WSS` 在标准化协议下是**适定**的，几何是（近乎）充分条件。因此 high-WSS 尾部失败与 ILO 负迁移**不是可辨识性问题**，而是表征/损失/容量问题——这一点反过来**支持**在损失函数上做文章（含 GAN critic 作为候选之一），并排除了"补 BC 就能解决"这条捷径。
- 原稿 §9.5 的控制措施"明确当前任务是'标准化仿真协议下的条件 WSS 先验'，不要宣称患者特异物理生成"——**这个措辞是准确的**，而且核查表明它不是一句免责声明，而是对数据事实的正确描述。这一条应当保留并在论文中如实陈述。
- **路线 C 因此大幅简化**：生成新几何时**不需要生成配套 BC**，直接复用同一条 UDF 与同一份 journal。见 §1.4。

## 2. 第一性原理复核：瓶颈到底在哪

### 2.1 从"信息从哪来"重新数一遍

要学的映射是 `f : 几何 → 壁面 WSS 场(t)`（BC 与流变已由 §1.3 证明为全库常量）。在标准化协议下它是确定性的，因此监督信号总量 = 独立 (输入, 输出) 对的数量。逐条清点：

| 信息源 | 库内存量 | 当前训练用量 | 未用比例 |
|---|---|---|---|
| 病例（几何） | 174 eligible | 138 train | — （这是真正稀缺的一维） |
| 心动周期时相 | 每例 81 相 | 每例 1 相（peak） | **98.8% 未用** |
| WSS 分量 | 3 矢量分量 + 模长 | 仅模长 | **方向 100% 未用** |
| 壁面压力 | 81 相全存 | 0（`target="pressure"` 是独立任务，不作辅助监督） | 100% 未用 |
| 内部流场 | 81 相 `u,v,w,p` | 0（dataset 明确丢弃 `int_*`） | 100% 未用 |
| 逐例 BC | **不存在（全库统一）** | — | 不适用；出口量为输出，用作输入即泄漏 |
| 壁面点采样 | 中位 21.5k 点/例 | 每 epoch random5000 重采样 | 已充分利用 |

原稿 §1.3 的判断是"当前协议已经通过重采样得到大量不同点子集……真正缺少的是新的病例级几何"。**这一步只清点了表格的最后一行。** 结论"缺病例级信息"本身正确，但它被用来论证"所以要造新数据"；正确的下一步是**先把中间四行已在磁盘上的真实物理监督用起来**，同时把"造新病例"交给路线 C（其成本已被证明远低于原稿评估）。

### 2.2 时相：原稿自己的论证反过来指向它

原稿 §1.3 写：

> 若同一几何、同一峰值时相、同一边界条件对应确定性的 CFD 解，那么人为制造多个不同 WSS 版本，可能是在注入标签噪声。

推理正确，**但它恰好说明了正确做法**：同几何上的多个 WSS 版本不需要"人为制造"——81 个心动时相已经存在，每一个都是 Fluent 解出的、物理精确的，并且由**全库统一、完全已知**的入口波形 `Q(t)` 唯一区分。GAN 试图用随机噪声 `z` 伪造的"同几何多状态分布"，其真实版本就在库里，条件变量不仅已知，而且**跨例含义完全一致**（同一 `T=0.8s` 波形、同样 81 步）——这比任何逐例 BC 都更干净。

**这 81 帧的物理含义已完全确定**（核查见附录 A）：`steps = 1120, 1122, …, 1280`（步长 2），配合 `2.jou` 的 `time-step 0.005` 与 `dual-time-iterate 1280`，对应 `flow-time 5.600 – 6.400 s`。而 `T = 0.8 s`、总时长 `6.4 s = 8` 个周期——因此：

> **81 帧恰好是第 8 个（最后一个）完整心动周期，均匀采样 `Δt = 0.01 s = T/80`，首尾同相位。** 已远离启动瞬态，是一段干净、周期完整、相位完全已知的时间序列。

多数病例的 `peak_step = 1162`（索引 21），即周期内相位 `0.21 s ≈ 0.26 T`——收缩期峰值，与波形吻合。少数索引为 40（相位 `0.40 s = 0.50 T`）等的病例属异常，应进入第 0 级审计。

这些时相是否只是彼此的缩放副本？实测（6 例随机抽样，log 空间逐点空间相关）：

```text
每相 WSS 空间型态 vs peak 相的相关系数
  中位数：0.415 – 0.820（跨例）
  与 peak 相关 > 0.99 的相占比：约 4%（81 相中仅约 3 相接近冗余）
  逐相全场均值幅度跨度：约 20 倍（例：0.32 → 5.38）
```

热点位置的差异更直接（5 例随机抽样，各相自身 top-1% 点集 vs peak 相 top-1% 点集）：

```text
top1% IoU 中位数：0.38 / 0.49 / 0.53 / 0.55 / 0.73
IoU < 0.5 的相占比：28% – 59%
部分例中非 peak 相的 p99 略高于 peak 相（如 18.08 vs 17.24）
```

> **含义**：非 peak 相**不是** peak 相的等比缩放；它们提供的是"同一几何在不同流量状态下**热点位置本身会移动**"的监督——而热点幅值与位置学不好（high-WSS `R²` 恒为负）正是原稿 §1.4 认定的头号未解问题。这批监督目前 100% 未使用，接入代价是 dataset 层数十行改动。

**对本条建议的自我攻击（不豁免）：**

1. **评估口径仍在 peak 相**。引入非 peak 相会造成训练/评估分布不一致。必须以 `Q(s)/Q_peak` 与相位显式条件化，并仍在 peak 相评估；若不条件化，等价于把低流量样本当噪声混入，很可能**反而压低 peak 相幅值**——这与我批评 GAN 的机制是同一个机制。
2. **有效样本量增益不是 81 倍**。81 相共享一个几何，病例级有效样本量仍是 138。它增加的是"给定几何下 WSS 随流量如何变形"的条件结构密度，**不增加解剖多样性**。原稿 §9.1 对 GAN 提的"有效样本量被高估"批评，**同样约束时相扩增**，必须同样按病例等权、同例同 fold。
3. 因此这是一个**必须实验裁决的假设，不是免费午餐**。它与 GAN 一样必须接受下游 No-Go。它的优势只在于成本、物理正确性与可解释性各低/高一到两个数量级。

### 2.3 —— 自我证伪 —— "输入欠定"假设不成立

审查中期我提出：当前特征 `(x, y, z, abscissa_norm, local_radius, curvature)` 不含任何血流条件，若病例间流量差异大则任务欠定，最优解退化为条件均值；其可观测后果恰好是当前三个症状（幅值压缩 → high-WSS `R²` 恒负；新域拉动条件均值 → AG/AAA 回落；只改归一化口径只能在域间搬运偏差 → 与根因矩阵观测一致）。

**§1.3 的全库核查证伪了这个假设的前提**：入口波形 347/347 完全相同，`Q_peak` 92% 落在 ±1% 内，出口量是求解输出而非输入。**病例之间不存在未被观测的血流条件差异。**

保留这段的原因，是它的证伪结论比它本身更有价值：

- 既然几何在标准化协议下（近乎）充分决定 WSS，那么 **high-WSS 尾部失败与 ILO 负迁移就是货真价实的表征/损失/容量问题**，没有"补一个缺失输入"的捷径。
- 这**削弱了我对路线 A 的一条主要反对意见**。原稿 §8.2 列的 No-Go"生成器输出不同 `z` 时差异很大，却与真实物理条件无关"——在欠定假设下我曾判断路线 A 会高概率直接撞上它；证伪后，这条风险回落为普通的 GAN 训练风险，而非结构性必然。路线 A 的排序仍应落后于 §4 的第 1、2 级，但理由改为**成本与归因难度**，不再是"前提不成立"。
- 它也说明原稿 §9.5 的措辞（"标准化仿真协议下的条件 WSS 先验"）是对数据事实的准确描述，应在论文中如实陈述，而不是当作免责话术。

> 唯一残留的、值得一查的相关线索：入口是 velocity-inlet 且 UDF 除以**固定参考面积 `0.0005243612`**，而实测 `Q_peak` 跨例几乎不变，说明各例入口截面积高度接近。若存在少数入口面积明显偏离的病例，其入口平均流速会偏离标准协议——这批例子值得单独审计（`Q_peak` 偏离中位 >1% 的约 8%，以及 4 个无法解析的文件）。这是审计项，不是特征项。

### 2.4 GAN 在这个问题里到底提供什么

剥掉命名，conditional WGAN-gp 在确定性回归任务上只提供一样东西：**一个学出来的、对空间结构敏感的损失函数**（判别器）。它不创造信息。原稿 §4.1 的"局限"里点到了这一层（"对固定几何生成多个 WSS，不等于增加独立病例"），但随后仍把路线 A 放在"数据扩增可行性"框架里推进，并在 §7 安排了 `A1/A2/P1` 三个合成回灌臂。

第一性原理下应这样归类：

| 原稿臂 | 实质 | 正确的对照组 |
|---|---|---|
| `G1` 对抗正则 | 学到的结构损失 | 手写结构损失：空间梯度损失、谱损失、分位数回归、CRPS、tail-weighted loss |
| `G2` + tail loss | 同上 + 显式尾部项 | **tail loss 单独（不带 GAN）——原稿未设此臂** |
| `A1/A2` 合成回灌 | 自蒸馏 / 标签平滑 | **真实的同几何多状态数据（= 81 时相）——原稿未设此臂** |
| `P1` ε 课程 | 按"与真值接近"筛样本 | 见 §3.3，方向与尾部目标相反 |

> **矩阵层面的硬缺陷**：`G2` 若优于 `B1`，无法区分收益来自"对抗"还是"tail loss"。原稿 §7 没有 tail-loss-only 臂，`G1→G2` 的因果解读不成立。这与 GAN 本身是否可行无关，是实验设计问题。

## 3. 对原稿推荐方案的对抗性攻击

### 3.1 判别器的样本复杂度高于生成器，而数据稀缺恰在判别器这一侧

原稿 §5.3 提议双层 critic（local/patch + case-level），§14 只把"174 例是否足以稳定训练条件 critic"列为待定。对抗性地讲：case-level critic 每 epoch 至多见到 138 个真实"整例"样本；WGAN-gp 的 critic 每次生成器更新前要做多步（典型 5 步）更新，138 个样本的真实分布会在极少 epoch 内被记住，此后 critic 输出退化为"是不是训练集里那 138 个之一"，其梯度对生成器不再是结构信号而是记忆信号。patch critic 情况稍好，但 patch 间高度相关，有效样本量远小于名义数量。

> **后果**：`G1` 高概率给出"判别器准确率很高但生成器无增益"——正是原稿 §8.2 自列的 No-Go 之一。**一个在事前就有高概率触发的 No-Go，应当影响立项排序，而不只是写进验收表。**

### 3.2 `z` 的语义在原稿内部自相矛盾

原稿 §5.2 提议 `G-stochastic`，并说"如果它在相同几何和相同条件下产生很大差异，但没有真实多状态 WSS 可以校准，应立即降级为 deterministic"。同时 §1.3 已论证同几何同时相的解是确定性的。两者合起来：**在当前条件集下 `z` 的正确后验是退化的，`G-stochastic` 在设计上就注定被降级**——花预算验证一个由自身前提蕴含的结论。

而"真实多状态 WSS 可校准"这个被认为不存在的前提**实际存在**（81 相 + 全库统一的已知 `Q(t)`，§2.2）。正确做法不是删掉随机性，而是**把 `z` 换成可观测的物理相位 `Q(s)/Q_peak`**；此时"多状态"有监督、可校准、可评估，GAN 也就不必要。

### 3.3 §5.5 版本 1 的 ε 课程与尾部目标方向相反

原稿接受度量：

```text
Q = a·归一化逐点误差 + b·raw Pa 误差 + c·p99 幅值误差 + d·热点错配 + e·空间梯度错配
接受 Q ≤ ε，逐步收紧 ε
```

项 `a`、`b` 是逐点平均误差，在样本级被**大量中低 WSS 点按点数计权主导**（正是原稿 §1.4 诊断 log-MSE 失效的同一机制）。因此 `Q` 的排序主要由中低区拟合决定；收紧 ε 会**系统性淘汰敢于预测高幅值的样本**——高幅值预测一旦位置错，平均误差更大。项 `c`、`d` 试图补偿，但其权重要战胜按点数计权的 `a`、`b`，权重本身成为未标定超参。

> **后果**：这是一个朝均值收缩的选择算子。它把"接近真值"定义为"平均误差小"，而长尾任务里两者不等价。**原稿希望用它解决尾部，其数学形式却会加剧尾部压缩。** 若要保留，接受度量必须改为**纯尾部/排序度量**（top-k IoU + p99 比值 + Spearman），并明确接受"中低区变差"作为代价。
>
> 补充：原稿 §12.2 自己写了"不建议用 S3 自己筛选 S3 风格的伪标签并宣称 physics-guided"，而版本 1 用的是真值误差而非 S3 预测，形式上避开了循环自证，原稿也诚实标为"监督质量引导"。我的补充是：它不只是"不够物理"，它在统计上**方向有害**。

### 3.4 统计功效：+0.015 门槛在 GAN 臂上不成立

已知 S3 三种子 `0.2924 / 0.2743 / 0.2713`，sd ≈ `0.0114`：

- 3 种子单臂均值 SE ≈ `0.0114/√3 ≈ 0.0066`；
- 配对差 SE（同 split 同种子配对可消部分方差，但 GAN 自身训练方差不被消掉）保守 ≥ `0.008–0.012`；
- 门槛 `+0.015` ≈ 1.3–1.9 个 SE → 双侧功效大致 30%–50%。

即：**真实增益恰为 +0.015 时也有约一半概率测不出来；纯噪声跨过门槛的概率同样不可忽略。** 原稿 §1.1 已观察到"继续叠加轻正则、attention 时改善通常只有 0.005–0.009，已接近种子波动"——项目已进入**效应量小于噪声**的区间，但这一观察没有被转化为对 GAN 臂的样本量要求。而 GAN 的 run-to-run 方差（对抗动力学、critic/generator 平衡、gp 系数敏感性）**显著大于**监督训练，沿用为架构臂标定的 3 种子 + `+0.015`，会系统性高估证据强度。

> **建议**：GAN 臂若要做，最少 5 种子，并**预注册**最小可检测效应与检验方法（配对 bootstrap 项目内已在用），报告中给出功效数字。否则结论不应进入 Go/No-Go。

### 3.5 内部 grouped CV 的方差未被估计

原稿 §6.1 正确冻结 test36、改为 train138 内 grouped 开发。但 138 例做 grouped CV，每折验证约 27 例，案例级 `R²_cb` 的病例间方差下，单折 CI 宽度很可能 `> ±0.03`——**远大于要检测的效应**。原稿未指定折数、未给预期 CI 宽度、未说明折间聚合方式。

> **后果**：泄漏风险确实降低，但若不同时提升统计功效，只是把"有偏但低方差的集合上选择"换成"无偏但高方差的集合上选择"，后者同样会选出噪声。**这两个问题必须一起解决，原稿只解决了前一个。**

### 3.6 缺少阴性对照

原稿 §7 没有任何一臂能回答"收益是否来自'对抗'本身"。至少需要：

- **打乱条件的 critic**：喂随机配对的（几何, WSS）；若 `G1` 增益不消失，说明收益来自额外正则化噪声而非条件对抗；
- **等强度随机扰动增广**：对真实 WSS 加匹配幅度的结构化噪声当作"假合成数据"，与 `A1` 对比；若增益相当，则合成器本身无贡献。

没有这两个对照，`G1` 为正也无法归因。

### 3.7 成本不对称从未被量化

| 方案 | 代码改动 | 计算量 | 物理可信度 | 裁决难度 |
|---|---|---|---|---|
| 多时相训练 | 数十行 dataset + 条件维 | 与现有臂同量级 | 5/5（真值） | 中（须处理训练/评估相位错配） |
| 矢量 WSS 辅助监督 | 数十行（多输出头 + 损失） | 与现有臂同量级 | 5/5（真值） | 低 |
| 壁面压力辅助监督 | 数十行（已有 `target="pressure"` 通路可复用） | 与现有臂同量级 | 5/5（真值） | 低 |
| 路线 A GAN PoC | 新建 `training_wss_gan/`（原稿 §10 列 7 个子目录） | 6 臂 × ≥5 种子 × 对抗训练 | 2/5（原稿自评） | 高（mode collapse、critic 记忆、归因困难） |
| 路线 C 新几何 + CFD | 网格化工具链 + thread ID 重映射 + 门禁 | 每例一次 Fluent 求解 | 5/5 | 低（真值，无归因问题） |

> 原稿 §4 的评分表里没有"已有真实数据的未用部分"这一行，因此这个对比在原稿内部无法做出。这是原稿最关键的结构性缺口。

## 4. 重排后的建议阶梯

替换原稿 §12.1 的两阶段方案。每一级以"能否证伪一个明确假设"定义。

### 第 0 级：协议同质性审计（前置，~0.5 天，无实验风险）

不再是"提取 BC 特征"（§2.3 已证伪其价值），而是**确认标准化协议真的对全部 174 eligible 例成立**：

1. 对全部 eligible 例校验 `udf-inlet.c` 波形常数一致性（已验 347/347，需按 eligible 名单复核）、`2.jou` 时间步与迭代数一致性、Carreau 参数一致性；
2. 列出 `Q_peak` 偏离中位 >1% 的例（约 8%）与 4 个 `vf-in` 解析失败的例，判定是求解异常还是解析问题；
3. 列出 `peak_step` 索引偏离 21 的 7 例，核查是否为收敛/波形异常。

产出是一份"协议同质性白名单"。**这批异常例若混在 train/test 中，本身就是当前指标噪声的一个候选来源**，且与后续所有实验正交。

### 第 1 级：用尽已有真实监督（最高优先级）

三个独立单变量臂，互不叠加，便于归因；均为真值监督、零物理风险：

- **1a 多时相训练**：每 epoch 从 81 相采样，条件化 `Q(s)/Q_peak` 与相位（跨例含义一致，见 §2.2），仍在 peak 相评估。硬护栏：p99 幅值比、top10 IoU 不得退化——这直接检验 §2.2 自我攻击第 1 条的风险。
- **1b 矢量 WSS 辅助头**：预测三分量 `τ_w`，主指标仍按模长评估。假设：方向监督约束近壁流结构，利于热点定位。
- **1c 壁面压力辅助监督**：多任务共享骨干，`p` 作辅助输出（`wall_pressure` 已在库，`target="pressure"` 通路已存在）。

判读沿用项目现有配对协议，但按 §3.4 提高种子数并预注册最小可检测效应。

### 第 2 级：损失函数创新（GAN 在此，且不享有特权）

只在第 1 级完成后进入。问题被收窄为"如何让损失对尾部与空间结构敏感"，候选并列：

- 分位数 / 期望分位数回归；
- **tail-weighted loss（必须有 tail-only 臂，补上原稿 §7 的缺口）**；
- 空间梯度 / 谱损失；
- CRPS 或混合密度输出；
- **conditional WGAN-gp critic 作为其中一个候选**，与手写损失同台竞争，共享同一套种子数、护栏与阴性对照（§3.6）。

若手写损失达到同等效果，GAN 的额外复杂度与训练不稳定性就没有理由。原稿 §14 最后一条"GAN 相对普通监督模型、分位数回归、混合密度网络或扩散模型是否有独立收益"应从附带问题上升为**路线 A 的准入门槛**。

### 第 3 级：物理闭环扩增（原稿路线 C，成本下调、优先级上调）

基于 §1.4：求解侧脚本链齐备，且**新几何不需要新 BC**。建议把讨论从"要不要做"改为"网格化怎么做"，并优先评估**保拓扑网格形变**路径（继承边界命名、边界层与 thread ID）。

这条路线是唯一能真正增加**病例级解剖多样性**的手段——而 §2.1 的清点表明，那正是唯一真正稀缺的一维。考虑到成本评分从 5/5 降到 3/5，它与第 2 级的相对次序值得与导师重新讨论；我倾向于**第 1 级完成后即并行启动路线 C 的网格化可行性试点（先做 1–2 例形变闭环打通）**，而不是等到 GAN 有正信号才启动。

原稿 §6 的全部泄漏合同与血缘 manifest 在这条路线上**必须**执行。

## 6. 与导师讨论时建议替换的问题清单

原稿 §11 的第 2、3 问已被 §1 核查回答。建议替换为：

1. **每例 81 个心动时相全部在库，当前只用 peak 一相。** 是否有物理或临床理由只关心 peak？若没有，多时相条件训练是否应优先于任何生成模型？
2. **WSS 矢量三分量在库但未用。** 建模目标是 `|τ_w|` 还是 `τ_w`？临床终点（瘤体增长、破裂）与哪一个更相关？
3. **入口 BC 全库统一（同一条硬编码 UDF 波形），出口量是求解器监视输出。** 这确认了任务是"标准化协议下的几何→WSS 映射"。这个定位是否与课题的科学问题一致？若希望做患者特异血流动力学，需要的是**新的逐例 BC 数据采集**，这是数据采集问题而非建模问题。
4. **新几何的网格化**：能否通过对已有 `.cas` 网格做保拓扑形变绕开重新网格化？这是路线 C 唯一的实质瓶颈，且路线 C 是唯一能增加解剖多样性的手段。
5. **能否获得未参与历史筛选的新病例作为最终确认集？**（保留原稿第 4 问，无可替代。）
6. **目标是论文创新还是现有精度？**（保留原稿第 1 问。）若为前者，"不可微 CFD 引导的血管几何生成"（路线 C + 论文思想）比"生成 WSS"（路线 A）更贴合参考论文，也更有新意。

## 7. 最终判断

> **原稿的方法学纪律（泄漏合同、血缘、护栏、拒绝虚假趋势）可靠，应当继承；但它的优先级排序建立在两个未经核查的前提上，核查后两个都不成立。**
>
> 前提一"真实数据已用尽，只能靠生成"——**为假**。每例 81 相用了 1 相，三分量 WSS 用了模长，壁面压力与内部速度场全量丢弃。
>
> 前提二"CFD 闭环成本极高，路线 C 只能长期考虑"——**大幅高估**。求解侧脚本链齐备，且因入口 BC 与流变全库统一，**新几何不需要新 BC**；真正瓶颈只剩网格化。
>
> 同时，我自己提出的"缺逐例 BC 导致任务欠定"这一根因假设，**被全库核查证伪**：347/347 例共享同一条入口波形，出口量是求解输出（用作输入即泄漏）。这反而确认了几何在标准化协议下（近乎）充分决定 WSS——因此尾部失败是真实的表征/损失问题，没有捷径，这一点**削弱了我对路线 A 的一条主要反对意见**。
>
> **建议顺序：第 0 级协议同质性审计 → 第 1 级用尽真值监督（多时相 / 矢量 / 压力）→ 第 2 级损失函数创新（GAN 与手写损失同台竞争，不享有特权，且需 tail-only 臂与阴性对照）→ 第 3 级物理闭环扩增（成本 5/5 → 3/5，建议在第 1 级后即并行启动网格化试点）。**
>
> 路线 A 不是"不能做"，而是"排序靠后"，理由从"前提不成立"修正为**成本与归因难度**：在效应量已小于种子噪声的区间里，用一个物理可信度自评 2/5、归因困难、方差更大的手段，去竞争三个物理可信度 5/5、成本低一到两个数量级的手段尚未占据的位置。
