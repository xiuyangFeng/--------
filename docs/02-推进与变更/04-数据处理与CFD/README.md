- **唯一数据版本是 v5.2d（2026-10-01 起）。**
  - 332 个单元：273 个真实单元（AG 85、AAA 67、ILO 121）+ 59 个形变合成单元（合成单元不进主线）。
  - 视图 `data_wss_v5/views_v5_2d_20261001`，快照 `data_wss_v5/anatomy_pointcloud_v5_2d_20261001`。
  - v5.2d 重训已完成（10-02）：CV5 折外三 seed 均值 0.7761、集成 0.7926，与 v5.2 持平；结果在 01 块 §41。
  - 体场训练用的数据根 `views_v5_2d_20261001/wss_min_volview_v1/`（10-02 建，273 个真实单元；已有体场视图与快照重建逐数组一致，12 个新建；主视图根未补 `volume.npz`），见[跟踪 §1](./数据处理与CFD_跟踪.md)。
- **已知限制：** 150 个单元每步迭代提前退出，标签误差约 4 %，用户决定先不动；另有 4 个单元的出口命名待人看图。完整清单见[跟踪 §1、§8](./数据处理与CFD_跟踪.md)。
- **同一病人的单元：** 共 4 组，含 10-02 新发现的 SUN_DONG_XIN / WANG_LI_MIN。标签都是各自正确、互不重合的独立求解，按用户规则无需处理。
- **合成几何数据扩充已暂停（10-02）：** 不能提高真实病人上的整体精度；cfd_auto 转为给新的真实病人算标签。
- **cfd_auto 全流程抽样验证完成（10-02）：**
  - AG / AAA / ILO 各随机 5 例，只给 STL，走新病例默认，15 / 15 全自动走通，人工修复 0 次；7 例需要确认出口命名，自动提议全部正确。
  - 与库内原解比较：十门全过 8 / 15，峰值 WSS R² 中位 0.974。
  - 不过关的 7 例都来自协议对新病例的默认做法与库内不同（斜切口延伸方向、AAA 一律 P 族、P 族四面体对库内 poly-hexcore），各额外跑一次后 6 / 7 转为全过。
  - 怎么改待用户定（[跟踪 §8](./数据处理与CFD_跟踪.md) 第 9–13 项）。详见[验证报告](./cfd_auto全流程抽样验证_2026-10-02.md)。
