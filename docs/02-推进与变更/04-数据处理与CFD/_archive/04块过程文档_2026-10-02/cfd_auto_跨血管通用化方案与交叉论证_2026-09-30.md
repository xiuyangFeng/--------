## 1. 建议与待决策事项

建议沿用已有编排和几何处理基础，将系统组织为 **通用计算流程、血管床协议、病例输入、执行环境** 四个部分。新血管床先建立并验证协议，同床后续病例通过输入数据和配置进入相同流程。

当前最需要解决的三件事是：

1. **协议真正贯穿执行与验收。** 部分 JSON 参数目前未进入实际公式，求解安排可以变化，但算后检查仍依赖原四出口和固定步数。
2. **解除出口数量和历史模板依赖。** 动态管理入口/出口，独立生成边界条件及 Fluent 求解设置，使没有参考 `.cas` 的病例也能接入。
3. **建立适应局部血管几何的精度控制。** 以局部管径、狭窄、分叉及目标输出决定网格，并用代表病例验证网格和时间精度。

建议第一个跨血管对象采用单入口、双出口的颈动脉分叉。它能以相对可控的复杂度暴露四出口假设。脑血管多入口及环路网络放在随后验证，最终应按实际数据来源和近期科研需求决定顺序。

**第一个交付标准：没有库内参考 `.cas`、开口数量也不同的新病例，仅凭几何与病例配置，即可完成网格、求解、结果导出和质量报告；当前主动脉协议的既有回归仍通过。**

交叉论证时，优先决定：初期覆盖范围、首个新血管床、边界条件数据来源、独立设置生成的实现方式，以及目标指标与允许误差。本文列出的新阈值和策略应经过验证后冻结，不能直接视为生产默认值。

## 2. “通用”的具体含义和证据边界

### 2.1 目标范围

统一操作流程可以是：

```mermaid
flowchart LR
    A[几何与病例输入] --> B[协议及能力检查]
    B --> C[开口确认与几何处理]
    C --> D[局部网格与质量检查]
    D --> E[生成边界条件和求解设置]
    E --> F[求解与数值验收]
    F --> G[结果包与质量报告]
```

建议第一阶段覆盖三维、刚性壁、不可压血流的不同管径和分支结构，先验证单入口 N 出口，再扩展多入口和带环路网络。静脉瓣、流固耦合、冠脉心肌外压等需要独立物理能力与验证，不应由更换血管名称隐式启用。

STL 提供形状，不能唯一确定真实入流、下游阻抗、压力参考和心动周期。病例可以使用测量输入，也可以使用经论证的标准协议，但必须记录来源。没有测量支撑的结果应解释为“指定协议下的模拟”，不能自动等同于患者真实血流。

## 4. 建议架构：明确四类信息的职责

| 部分 | 负责内容 | 应避免的依赖 |
| --- | --- | --- |
| 病例输入 | 几何、单位、坐标变换、开口角色、测量波形、患者参数及来源 | 从目录名推断所有生理设置；最大口必然为入口 |
| 血管床协议 | 支持的拓扑与物理模型、边界条件生成策略、网格规则、时间安排、验收标准 | 将主动脉左右分流等规则放进通用核心 |
| 通用计算流程 | 阶段执行、边界映射、求解设置生成、检查、缓存、状态和输出契约 | 直接读取某位历史患者的 case 作为所有病例的必需输入 |
| 执行环境 | Fluent 版本与接口、Slurm、资源、许可证、环境路径 | 把集群路径、节点排除项和生理协议混在一起 |

四部分合并后形成一次运行的**有效配置快照**，供生成器、预检、求解、后处理和结果清单共同使用。参数覆盖需记录最终值与来源；无法支持的模型、未知字段及不合法单位应在提交作业前报出。

### 4.1 动态边界描述

每个开口至少记录稳定 ID、物理角色、可选解剖名、面积、法向、几何位置和确认来源。求解时将稳定 ID 映射到最终网格 zone/thread，并验证一一对应和边界条件类型。

开口 ID 不应只依赖 STL 顶点或边界环枚举顺序。几何改变后重新匹配，并检查旧确认是否仍有效；将元数据更名和物理角色修改区分，后者必须使相关设置失效。

### 4.2 兼容策略

将 `aortoiliac_rcr4_v1` 保留为冻结兼容预设，记录现有模板和 UDF 的内容身份。新生成器先并行提供，再用当前病例比较有效设置、边界挂接和 CFD 目标量；经过回归后再决定迁移默认入口。

历史标签的复现标准与新协议的数值验收分别版本化。新网格或新波形导致的物理结果变化应形成明确数据版本，避免与已有训练标签混用。

## 5. 几何与网格：从局部特征建立默认策略

### 5.1 几何输入与修复

建议增加以下检查和记录：

- 显式单位转换、坐标方向和变换矩阵；尺寸范围由血管床协议提供。
- 连通分量、非流形、自交、缺陷孔洞与生理截断口的区分；无法可靠分类时输出定位图供确认。
- 切口平面度相对局部直径的误差、切口与局部轴线关系；闭合分割表面的裁切作为独立可选阶段。
- 修复和重网格的表面偏差、局部截面积变化、总体积变化；保留原始几何及变换关系。
- 延伸长度、方向、碰撞处理及解剖区/人工延伸区标识。延伸策略改变后，用敏感性分析检查关注区域是否受边界位置影响。

修复容差同时考虑绝对位移与局部直径比例。比例值需要用代表病例确认；不能简单把 0.5 mm 换成另一组未经验证的常数。几何闭合和无碰撞属于必要条件，仍需检查是否保留了关注的狭窄和分支形态。

### 5.2 网格尺度与边界层

建议尺寸场同时受以下因素约束：局部管径解析需求、表面曲率、狭窄喉部、分叉、近邻壁面间隙及目标输出。允许较简单区域使用较粗网格，避免因最小分支而把整个模型均匀细化。

边界层应控制首层高度、增长率、总厚度及局部覆盖，保留现有棱柱完整性门。狭窄区和细分支需局部检查，防止整体覆盖率掩盖关键区域缺层。首层设置应由流动模型和 WSS 精度决定；不能将湍流模型的某一 y+ 目标当作所有层流血管的统一标准。

当前 tet/prism 与 poly-hexcore 两条路线都可作为候选。选择依据应是几何保真、质量、目标量收敛与总成本；默认采用哪种单元类型需要同条件比较。

### 5.3 精度档位及计算预算

建议建立“探索、标准、精细”候选档位，并为每个血管床用代表病例标定。档位需对应明确的网格规则、时间精度和可报告的验证范围，而非仅对应单元数量。

代表病例至少做三个有序网格级别，并检查时间步加密；依据所关注的压降、分流、TAWSS、OSI、局部 WSS 等量判断变化。不同网格比较需统一解剖区域和映射方法，并估计插值误差；近零量采用有物理意义的绝对误差或归一化尺度。

单元数和内存预算属于资源约束。如果关键局部精度与预算冲突，应报告约束冲突，不能自动粗化后仍标记为同精度达标。

## 6. 物理协议与数值验收

### 6.1 边界条件与设置生成

入口应明确采用质量流量、体积流量或速度，以及空间分布、波形周期和实际周期积分。出口模型可逐步提供指定压力、阻力和 N 出口 RCR，按血管床及输入数据选择。

RCR 的流量基准和参数单位必须一致；现有公式包含按质量流量使用的阻抗约定，迁移为体积流量接口时要同步转换阻抗与顺应性。压力须说明绝对/表压、参考压力和远端压力。几何分流规则可以作为特定协议的建模假设，不能由出口直径单独推导出普适的真实灌注分配。

材料、黏度模型、壁面模型、离散方法、初始化、边界挂接、监控和导出应能够由配置独立生成。继续使用经过验证的 Fluent 2023R1 后端是可行起点；TUI journal 与可用 API 的取舍见 §8，暂不同时扩展多个求解器。

预检增加参数维度、范围、波形积分、开口完整覆盖和模型能力检查。配置生效测试应改变均压、Murray 指数、周期等参数，核查实际生成公式、设置和验收预期是否同步变化。

### 6.2 将验收分成不同目的

| 验收类别 | 检查内容 | 不应代替的判断 |
| --- | --- | --- |
| 几何与网格 | 保真、有效区域、质量、边界层与关键局部解析度 | 网格数目接近历史病例不等于独立性通过 |
| 数值与产物 | 边界实际通量守恒、迭代充分性、周期波形稳定、字段/单位/帧完整性 | 作业 COMPLETED 或没有发散不等于结果达标 |
| 物理适用性 | 输入来源、边界模型和材料/壁面假设的适用范围、必要敏感性 | 数值收敛不等于患者真实血流已验证 |
| 历史回归 | 与冻结旧协议、旧结果的可比性 | 旧队列的经验分布不能成为所有血管的通用真值 |

刚性壁、不可压模型的质量守恒应使用所有入口和出口的实际有符号质量通量，统一法向约定，同时检查逐相位与周期积分误差。低流量/反向流相位需用协议定义的稳定归一化尺度，不能以接近零的瞬时入口流量作唯一分母。扩展到移动壁面时须纳入域内储存变化。

收敛判据按协议声明的稳态、周期态或统计态目标选择。以下周期判据仅用于目标为周期稳态且适用该假设的任务；非周期任务需另行定义并验证统计稳定性，不能因真实非周期波动而无限延长预热或直接判作数值失败。

周期验收比较相同物理相位上的完整压力、流量波形，并按用途抽查 WSS 等目标量；只比较均值可能遗漏幅值和相位差。时间轴记录物理时间、周期序号及相位，旧步号作为兼容输出。

时间步选择也要分别满足稳定性与目标量精度。减步长后不再发散只证明稳定性改善；需在空间误差受控、周期状态可比较时检验步长细化对幅值、相位和周期指标的影响。采用变步长还须确认 UDF/RCR 递推读取实际步长、时间层状态和输出相位一致，避免把迭代不足误认为时间离散误差。

可探索最少/最多周期与连续多周期达标停止，但应先确认 RCR 充盈过程、慢衰减状态和目标指标都被覆盖。达到最大周期仍未达标时，输出未通过原因。步长细化、增加迭代、重新网格和改变物理模型是不同操作，需要分类诊断；数值重试不应静默改变物理协议。

所有声明为必需的检查必须参与最终状态，缺失证据标记为未验证或失败。参考性库对比单独展示；如果用户或协议将其列为必需条件，比较失败不能仍进入可供下游自动使用的 `checked` 集合。

## 7. 运行效率、缓存和可追溯性

### 7.1 阶段缓存与有效配置快照

建议建立阶段依赖：几何规范化 → 开口/修复 → 网格 → 物理设置 → 求解 → 后处理。缓存签名至少包括该阶段的输入内容、有效参数、上游产物、算法版本；运行清单还应包含外部模板、UDF、相关依赖及执行环境版本。

预期行为示例：

- 同一路径 STL 内容变化：几何及受影响下游失效，旧命名确认需复核。
- 只改变入口波形：几何及网格可复用，设置与求解失效；若网格策略依赖流动尺度，则相关网格也需重新评估。
- 只改变后处理统计：已有原始场满足数据需求时复用；新增尚未保存的场或相位则不能假装仅后处理即可完成。
- 阈值变化：重新验收；若触发新的精度要求，再按依赖决定是否重算。

现有 fingerprint 和 MANIFEST 是起点。应扩展为合并后的有效配置及输入身份快照，避免只保存协议名称。缓存产物需要完成标记、内容验证和原子发布，防止中断留下半成品。

### 7.2 作业管理与断点恢复

每个子作业登记到病例和阶段下；取消、超时、恢复接管覆盖 driver 与 Fluent/网格标定子任务。资源限额应包括总核数、内存、许可证与并发任务，最终脚本应反映实际配置。

流场断点恢复作为后续优化，须同时保存流场、物理时间、RCR 历史状态、必要 UDF 状态以及输出进度。当前 YU_TIAN_HAI 模板使用 `C_UDSI` 和上一时间层 `C_UDSI_M1` 保存/读取压力、流量历史，不能未经验证断言 case/data 必然丢失或必然完整恢复这些状态。应在非周期边界时刻中断，核查当前及历史时间层、时间/步长、波形相位和后续完整周期；通过“连续运行 vs 中断恢复”的等价性验证后才能替代当前干净重跑。缺失状态或快照损坏时明确回退。

结果包应包含可读取的网格与字段、原始解剖区/延伸区标识、边界映射、单位、物理时间/相位、有效配置和质量报告。保留当前 ASCII 输出兼容入口；是否引入二进制场格式，应根据体场 I/O 成本及后续 GNN、可视化工具的读取需求决定。

性能评估分别报告排队时间、几何/网格准备、求解、后处理、总核时、峰值内存、存储量、重试次数和人工干预次数。比较在相同精度与物理设置下进行。暂不承诺加速倍数或固定开发天数。

### 12.1 结论

1. **方向同意。** 四部分职责划分、P0 → P1 的先后、冻结兼容预设加并行新生成器的迁移方式都成立。§3.2 的 E01–E10 逐条复核属实（补充见 12.4）。
2. **原稿把“通用”主要当成软件解耦问题，少了物理尺度这一层。** 协议里现在写的是绝对数（0.005 s、0.5 mm、7 mm²、8 个周期、各队列的经验门限）。换血管床时，这些数应由几条尺度关系推出来，再用少量算例确认；否则每个新床都要重新凑一遍经验值，而新床恰恰没有库可供标定。
3. **日志回放得到四个原稿没有的事实，其中两个会改变实施内容**（12.3）：库内 UDF 实际执行的出口模型是两元件而不是源码写的三元件；八个周期里大部分是在给出口模型充压，这个过程可以解析地预先消掉。
4. **一个看似合理的简化被数据否定**：不能用“固定分流比例的出流边界”替代 RCR（12.3 的 F4）。原稿保留压力型出口是对的。

### 12.2 从控制方程看：一次刚性壁、不可压计算由七样东西唯一决定

| 决定量 | 现在写死在哪 | 换血管床时应由什么给出 |
| --- | --- | --- |
| 流体域（几何、单位） | STL 默认 mm；尺寸范围 50–1500 mm；五个开口 | 病例输入显式声明；协议给尺寸范围 |
| 流体（密度、黏度模型） | 模板 `.cas` 与 UDF 里的 Carreau 常数 | 协议字段，生成器写入 |
| 入口流量波形与剖面 | UDF 里的 Fourier 系数、`T`、入口面积除数 | 波形作为数据（周期、谐波或采样表），均值只由波形积分得出 |
| 各出口的压力—流量关系 | UDF 四段重复代码与 `protocol_rcr()` 常数 | 每个出口一条记录：模型类型、参数、初始状态 |
| 离散（网格尺度、时间步、每步迭代） | 模板尺寸 + 参考库密度；0.005 s × 20 次 | 由局部半径、Stokes 层厚度、峰值流速推出的规则 |
| 初始状态 | 全场从静止、出口模型从 0 压力起算 | 协议声明；出口模型可预充到周期态 |
| 输出（哪些帧、哪些量） | 1120–1280 每 2 步、峰值 1162 | 按物理时间与相位声明，步号只作兼容标签 |

**三维求解器本身不关心“树”还是“环”。** 方程只看到若干入口和若干出口；环路只会难住中心线、自动命名和 `preflight.anatomy_split`（它把中心线当单根树递归）。所以核心数据模型应是“M 个入口 + N 个出口”的平铺列表，树结构只是某些协议可选用的启发式。§2.1 把“多入口和环路”排在后面，对几何工具是合理的，对求解核心没有必要，P1 就应一次做成 M 入口 N 出口。

换床时应让协议携带的尺度（ν 按 3.3×10⁻⁶ m²/s、周期 0.8 s 估算）：

| 量 | 含义 | 腹主动脉 R≈10 mm | 髂 / 颈动脉 R≈3–4 mm | 脑动脉 R≈1–2 mm |
| --- | --- | --- | --- | --- |
| Womersley 数 α = R·√(ω/ν) | 脉动惯性对黏性 | 约 15 | 约 5–6 | 约 1.5–3 |
| Stokes 层厚 δ = √(2ν/ω) | 基频下近壁剪切层厚度，与管径无关 | 0.92 mm（δ/R ≈ 0.09） | δ/R ≈ 0.25–0.3 | δ/R ≈ 0.5–0.9 |
| 壁面剪切对半径的敏感度 | τ ∝ Q/R³，故 δτ/τ ≈ 3·δR/R | 0.5 mm 位移最坏对应 15 % | 约 40–50 % | 100 % 量级 |
| 出口平均流速 U = 分流 × Q / A | 流量设定是否合乎生理；也是单位错误探测器 | — | — | — |

由此得到三条可以直接写进协议的规则（**估算**，数值待直管算例确认）：

- **网格**：大血管的近壁层由 δ 决定（第 8 次谐波对应 0.32 mm，棱柱层总厚应覆盖基频的 δ）；小血管 δ 与 R 同量级，整个截面都是剪切层，决定精度的是“直径方向有几个单元”。规则写成：棱柱总厚 = min(c₁·δ, c₂·R 局部)，面网格尺寸 ≤ R 局部 / k。
- **修复容差**：`REPAIR_MAX_MOVE_MM = 0.5` 应改成相对量。要把局部 WSS 改变控制在 ε 以内，位移上限约为 ε·R/3（ε = 5 % 时，R = 10 mm 对应 0.17 mm，R = 1.5 mm 对应 0.025 mm）。这是最坏情形的上界（整圈一起动），局部自交修复的实际影响更小，但量级说明 0.5 mm 对小血管不可用。回答 Q08。
- **时间步**：取三者最小——波形最高谐波周期的 1/20 左右（现波形第 8 次谐波 0.121 s，0.005 s 对应 24 步，合格）；峰值流速下的 CFL（h = 0.5 mm、U = 0.5 m/s 时 CFL ≈ 5，狭窄射流 2 m/s 时 ≈ 20；小血管 h 缩到 0.15 mm 后同一时间步 CFL 翻三倍）；出口耦合的稳定限（见 F1）。

### 12.3 日志回放得到的事实

**F1（已核实）库内 UDF 实际执行的是两元件模型，R1 没有动态作用。**

源码按三元件后向欧拉写：`Pn = ((R1+R2+R1β)·Qn + β·Pn_1 − R1·β·Qn_1)/(1+β)`，其中 `Pn_1`、`Qn_1` 取 `C_UDSI_M1`。但剖面函数被调用时，`C_UDSI` 与 `C_UDSI_M1` 存的是同一个值（上一步末写入、随后被时间推进复制），带 R1 的两项相消，实际递推是

`P[n+1] = ((R1+R2)·Q[n] + β·P[n]) / (1+β)`，β = R2·C/Δt

即总阻力 Rt = R1+R2、时间常数 τ = R2·C 的两元件模型，压力比流量滞后一步。用各例 UDF 常数和日志里逐步打印的 `P_ave`、`Q_ave` 检验下一步压力：

| 病例 | 两元件递推的残差（Pa，四出口最大） | 按源码三元件的残差（Pa，四出口最小） |
| --- | --- | --- |
| AAA YU_TIAN_HAI | 0.56 | 122 |
| AAA SHI_YUN_XI | 0.77 | 113 |
| ILO XUE_YOU_TANG-0/before | 0.62 | 190 |
| ILO GUO_YU_SHU-0/before | 2.6 | 151 |
| AG QIN_SI_FU | 4.2 | 148 |

出口压力在 11–15 kPa，两元件递推复现到千分之一以内。含义：

- **兼容预设必须复现“实际递推”，不是教科书公式。** P1 重写 N 出口 UDF 时若顺手“改对”成三元件，库内标签就复现不了。
- **E01 要补一句**：`R1_coeff`、`R1_diameter_exp` 即使接进公式，也只通过 τ = 1.79·(1 − R1/Rt) 和 `R2 > 0` 这道门起作用，不改变高频阻抗。
- **`R2 ≤ 0` 的物理含义**：R1/Rt = ρ·c·U/P（c 为协议的波速公式，U 为该出口平均流速）。R2 ≤ 0 等价于 U 超过 P/(ρc) ≈ 1.4 m/s，也就是协议给这个出口派的流量高得不合生理（同侧 50/50 把一半流量压给近闭塞的一侧）。通用预检应直接查各出口平均流速是否落在协议声明的范围内，这比面积阈值 7 mm² 更本质，还能顺带抓出单位错误。
- **新协议如果要真三元件**（**估算**）：显式滞后一步时，扰动放大因子约为 1 − c·Δt/L，L 为该支的惯性长度，要求 c·Δt/L < 2。c ≈ 7–10 m/s、Δt = 0.005 s 时 c·Δt ≈ 35–50 mm，细短出口（延伸段 10 倍直径、直径 2–3 mm）正好落在临界附近。届时要么在迭代内更新压力，要么按这个条件缩步长。现行两元件没有这个问题。
- **断点恢复比 §7.2 担心的简单**：递推的全部状态就是每个出口上一步的 (P, Q) 两个数，存在出口相邻单元的 UDS 当前层里，随 data 文件保存。仍需做“连续算对中断恢复”的等价性验证，但不存在更深的历史层。

**F2（已核实）出口压力可以不靠三维计算、由协议本身预测到 1–4 %。**

只用“设计分流 × 入口波形”驱动两元件递推、从静止起算 1280 步，与三维结果末周期的出口压力比较：均值偏差 −2.4 % 到 +2.7 %，逐步均方根 0.4–3.8 %（YU_TIAN_HAI 最好，四出口都在 0.8 % 内；GUO_YU_SHU 最差，它的实际分流偏离设计 0.8 个百分点）。

含义：`sanity_gates_by_cohort` 现在是用 322 份日志的分位数标出来的，新血管床没有这样的库。**门限应改成“协议的零维解 ± 数值容差”**，对任何出口数都适用；偏差本身有物理解释（三维通路阻力改变了分流）。现行 `outlet_p_rel_mean` 的 +3 % 到 +9 % 也可以这样拆开：波形截断使实际均值流量为 0.0355 kg/s，协议按 0.033 kg/s 设计，周期态应为 +7.6 %；八个周期没充满再减约 1.5–2 %，得到观测的 +5.5 % 到 +6.3 %。它是协议常数，不是数值误差。

**F3（已核实现象，提速幅度待验证）八个周期主要花在给出口模型充压，流量波形早已接近周期态。**

| 周期 | 出口压力均值相对第 8 周期（五例范围） | 流量波形与第 8 周期的均方根差（四例，不含 QIN_SI_FU） |
| --- | --- | --- |
| 1 | −69 % 到 −72 % | 4–13 % |
| 3 | −20 % 到 −24 % | 0.7–3.0 % |
| 5 | −5 % 到 −7 % | 0.2–0.8 % |
| 7 | −0.9 % 到 −1.4 % | 0.04–0.35 % |

压力按 e^(−t/τ) 上升（τ = R2·C ≈ 1.2–1.6 s，每周期残差乘 0.55–0.6）；第 7 到第 8 周期还在变 0.9–1.4 %，按这个速率外推，第 8 周期离周期态仍差约 1.5–2 %。流量残差以同样的速率衰减，且各出口 τ 差别最大的 GUO_YU_SHU（1.17–1.57 s）收敛最慢——各出口充压快慢不同，充压期间出口间压差在变，分流跟着漂。

含义：**把各出口的初始压力预置为零维周期解的起点值，充压瞬态就从源头消失**，剩下的只是三维流场自身建立所需的 2–3 个周期。这比 §7 列的缓存、断点恢复都更直接地减少求解量，§7 和 Q06、Q09 应补上这一项。它会改变结果（去掉标签里那 1–2 % 的未充满偏差），所以只用于新协议版本，库内协议保持不动。**待验证**：取一例库内病例预充后算 4 个周期，与 8 周期标签比较壁面剪切。

**F4（已核实）瞬时分流在一个周期内大幅变化，固定比例出流不等价。**

周期平均分流与设计值吻合到 0.1–0.8 个百分点，但瞬时分流不是常数：YU_TIAN_HAI 的一个出口在一个周期内从 0.1 % 变到 45 %，另外四例都出现过单支瞬时回流（瞬时份额为负）。高频下各支流量由惯性（长度/面积）分配，平均值才由阻力分配。所以“既然 RCR 基本把分流定死了，不如直接指定出流比例”这个简化不成立，N 出口压力型出口模型必须保留。

**F5（已核实）入口—出口逐步闭合和波形周期性现在就能检查，而且有区分力。**

用 UDF 里的入口波形和日志里的出口流量，逐步比较 Σ出口 与 入口设定：

| 病例 | 末周期逐步最大不闭合 / 平均流量 | 末两周期流量波形差是否持续衰减 |
| --- | --- | --- |
| AAA、ILO 共 4 例 | 1.3×10⁻⁴ 到 6.5×10⁻⁴ | 是 |
| AG QIN_SI_FU | 2.3×10⁻² | 否，第 4–7 周期停在 1.5–2 % |

QIN_SI_FU 是 AG 队列的设置模板。它的周期均值闭合到 0.06 %，现行按均值的门看不出异常；逐步口径下它比其余四例差 35 倍以上，且周期间差异不衰减。原因未查（每步 20 次迭代未收敛、或流动本身不严格周期，两者都可能）。这印证了 E07 和 §6.2 的判断，也说明这两项检查不需要改 UDF 就能对库内全部日志离线回放，可以在 P0 先做。

**F6（已核实）入口波形的两处协议内不一致，新协议不应继承。**

Fourier 基频 w = 6.491 对应周期 0.968 s，UDF 却按 T = 0.8 s 取模：周期接缝处流量跳 0.53 ml/s（很小），但 0.8 s 内的均值是 a0 的 1.1028 倍；同时 RCR 按 0.033 kg/s 设计，既不等于 a0（0.0322 kg/s）也不等于实际均值（0.0355 kg/s）。`flow_ratio ≈ 1.103` 这道门检查的是“入口面积除数填对了没有”，不是守恒。新协议里均值流量只应有一个来源（波形积分），验收分成两件事：入口实际流量对设定波形（抓除数和单位错误）、入口对出口（抓收敛问题）。

**F7（已核实）执行环境。** 集群除 `fluent/231` 外还装有 `fluent/2024r1` 和 `openfoam/7`；GNN 环境里没有 PyFluent，在 2023R1、2024R1 两个安装目录下按包路径搜索也没找到。§8 “Fluent 接口”一行应把这当作已知条件。

### 12.8 需要拍板的三件事

1. **第一个真实新血管床按什么数据来源定**（Q02）。合成直管和 Y 管不受影响，可以先做。
2. **新协议的出口模型**：沿用现行两元件（稳定、与库内同一物理），还是改成真三元件（出口压力波形更接近生理，但要处理显式耦合稳定性，且与库内不可比）。只看 WSS 时建议沿用两元件。
3. **是否花一例 CFD 验证预充**（F3）。成立的话，新协议每例求解量大约减半。
