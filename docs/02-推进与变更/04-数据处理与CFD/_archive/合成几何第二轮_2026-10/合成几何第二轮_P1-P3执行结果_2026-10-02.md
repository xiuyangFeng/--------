## 〇、先看结论

1. **子例几何现在是从子例表面实测的（R1 缺陷已修）。**
   - 同心狭窄设计 −50 %，实测直径狭窄 DS 为 0.46–0.60。
   - 偏心狭窄实测 DS 为 0.26–0.33，与对母例同截面直径比约 0.77 一致。
   - 口径族对母例同站位直径比为 0.75。
   - 唯一明显偏离设计的是 QIN ecc3：病变放在母例局部偏宽处，相对参考段 DS 只有 0.05，而相对母例同截面最小直径比为 0.77。
2. **20 个弯折候选里，只有 3 个真正改变了瘤颈–瘤囊角 β（变化 ≥ 3°）。**
   - 这 3 个是 HAN neck+15（+11.1°）、HAN neck−10（−6.7°）和 CHEN neck+15（+12.5°）。
   - ZHANG 的两个瘤颈候选放在瘤颈上游，β 只变了 0.0° 和 −0.6°，归为“上游弯折”。WANG_LI_MIN 的两个没有瘤囊，β 不适用。
   - 其余 13 个是段内弯折：枢轴处弦角确实改变约 15°，但队列里的分支起始角不变。
   - **据此，S5 的 P1 分支规则触发：** AAA 的 3 个瘤颈候选中只有 1 个达标（多数不达）。P5 角度族改以能实施目标 β 的母例为主，AAA 记为覆盖缺口，不放宽质量门。
   - 角度 CFD 测试的 6 个子例中，只有 2 个是 β 剂量（HAN neck+15、CHEN neck+15），其余 4 个是段内弯折。
3. **按面积 / 体积加权、加上绝对单位之后，AG 母例 HAN 的瘤颈转角响应仍然清楚。**
   - 瘤囊峰值 WSS 的 RMS 只有 0.14 Pa（母例瘤囊均值 0.5 Pa），但 61 % 的瘤囊面积变化超过 10 %，OSI 的 RMS 为 0.13。
   - cfd_auto 锚点与库内标签在该区几乎为 0，所以这个响应可以归因。
   - AAA 两个母例的锚点与库内差在分支、髂总和瘤囊都和形变响应同量级（ZHANG 瘤囊 46 % 面积 > 10 %，形变响应 42 %），**在 P4 之前不能归因**。
4. **整体刚体变换：网络本身不变，但部署前端在两处依赖世界坐标轴。**
   - 输入、中心线和坐标架一起精确旋转时，X5D_v51、M1 三头、PF6_VF6 的输出变化小于 1e-6。
   - 第一处依赖：中心线 RMF 标架的初始方向取世界 x 轴，所以除绕 x 轴外的旋转都会改变角向特征 θ。转 180°（相当于 LPS↔RAS 坐标约定互换），X5D 峰值 WSS 的 |Δln| 中位为 0.096、p99 为 0.55；体场压力 p99 为 1.4 个标准差。
   - 第二处依赖：X5Dcap 的虚拟端盖离散也用世界轴，带来额外的 p99 0.01–0.07。
   - 中心线重提本身（同一 STL 重跑）是确定性的。旋转后重提带来的抖动为 p99 约 0.05–0.07。
5. **局部形变里，坐标架能解释未动区一部分“假响应”，但解释不了模型和 CFD 的不一致。**
   - 瘤颈 / 主干弯折会让分叉原点移动 6.7–27.7 mm、z 轴转 2.8–9.2°。在未动区，坐标架部分的 RMS 是预测总变化 RMS 的 19–86 %。
   - 把坐标架固定为母例的之后，未动区与 CFD 的 R² 有所改善（HAN neck+15 X5D −4.99 → −2.16），但仍为负；运动区与 CFD 的一致性基本不变。
   - 口径族不动坐标架，却让全模型未动区变化 0.08–0.17（|Δln WSS| 的 RMS）。这来自分流先验特征，与 CFD 协议（出口面积决定 RCR）方向一致，但幅度未验证。
6. **P3：全库同人筛查（37,128 对真实单元两两配准）复现了 3 组已知同人，并新发现 1 对。**
   - 新发现：ILO 的 SUN_DONG_XIN-0/before 与 WANG_LI_MIN-0/before 配准中位距离 0.46 mm，下一对跨组最近的是 1.58 mm。
   - 按人合并后，210 个患者组变成 208 个人；CV5 有 8 个测试单元（2 个人）在训练折里有同人单元，原先只算到 4 个。
   - **WANG_LI_MIN 是试点母例。** 它在 P2 里所用的 fold3 模型，训练集里有同一人（SUN_DONG_XIN），所以那一行不算留出。

## 一、P1　现有材料复核

### 1.1 实测几何的做法（`synth_geom/geomeasure.py`）

- **截面：** 每 1 mm 沿中心线切平面截面，量面积、等效直径 d_eq = 2√(A/π)、腔心偏移和 Feret 最小 / 最大宽度。
- **判为无效的站位：**
  - 离分叉 < 1.5 r；
  - 闭合环既不包含中心线点，腔心也不在 0.6 r 以内（偏心喉部允许中心线落在腔外）；
  - 截面里同时含有另一非相邻段的中心线（并腔 / 贴合的两支）；
  - Feret 比 < 0.55（不是管状截面）。
- **队列量：** 用实测半径替换图谱半径后，沿用 `cohort.measure_segments`（瘤颈 / 瘤囊、最大 / 近端直径比、狭窄指数）。母例、子例和 273 个真实单元全部用同一种方法测。
- **病变描述（`lesion`）：** 参考直径取病变两侧各 15 mm 窗的中位；报直径狭窄、面积狭窄、半高长度、偏心（腔心偏移 / 参考半径）、Feret 比。另报对母例同截面的直径比和面积比，这一项不依赖参考窗。
- **分析管上的验证（18 项测试全过）：**
  - 恒等形变测得原半径；
  - 同心 −50 % 测得 DS 0.50 / AS 0.75；
  - 偏心测得面积狭窄与解析值一致，且腔心偏移 > 0.1；
  - 口径 −25 % 测得直径比 0.75；
  - 用实测半径算队列狭窄指数，能看到病变（旧的继承半径缺陷看不到）。
- **全库覆盖：** 273 / 273 真实单元可测。其中 27 个（主要是 ILO 术后）表面有 1–6 条非流形边，只用于截面测量，不形变、不进 CFD。有效站位比例中位 0.75（p5 0.61）。
- **图谱半径与实测半径不是同一定义：**
  - 两者的秩相关：AG / AAA / ILO 的主干直径比为 0.92 / 0.93 / 0.86；髂内外狭窄指数 0.77–0.90；髂总段 0.56–0.76（最低）。
  - AAA 的 β 实测中位 38.4°，高于图谱半径给出的 33.1°，因为瘤囊起点随半径定义改变。
  - 两套数分开登记，不混用。

### 1.4 联合形态异常标记

- **方法：**
  - 本队列 11 个实测特征，稳健标准化（中位 / IQR），用 Ledoit-Wolf 协方差算马氏距离。
  - 最近邻排除同患者组。
  - 子例与母例都表示为“留一真实单元分布中的分位”，> 95 才标记。
  - 背景是全队列，只作描述。训练用的参照统计属于 P3 冻结项。
- **结果（`p1_tables.md` §3）：**
  - 只有 HAN cia1+15（马氏 p94、最近邻 p95）和 HAN combo（p94 / p98）被标记。
  - HAN 母例本身已在 p92 / p91，所以标记主要反映母例本身就偏离队列中心，形变把它往外推了 2–7 个分位点。
  - 其余子例与母例的分位差都在 ±25 以内。
  - 这些特征对瘤颈转角几乎不敏感（β 不在特征里，因为不是每例都有瘤囊）。这一项只能用来排查异常，不能证明形态真实。
- **尝试 / 通过 / 跳过分母**见 §4 表：
  - 不含对照，共 40 个尝试：35 个通过，1 个检查不过（WANG_LI_MIN br3+15），4 个跳过（快速门在全部候选位置都没过：CHEN cia1+15、AN sten2、WANG sten2、WANG cia1+15）。
  - 覆盖缺口：AAA 未破裂亚组（33 例）一个都没尝试；ILO 同心狭窄在两个母例上都跳过。

| 直接 | 全部 0 | < 1e-6 | X5D、M1、PF6 < 1e-6；**X5Dcap 中位 0.001、p99 0.07** | 0 |
| RMF 重载 | 全部 0 | 同直接 | X5D 0.045 / 0.27；M1 TAWSS 0.068 / 0.39；PF6 压力 0.13 / 0.98 sd，速度 0.086 / 0.57 U | X5D 0.096 / 0.55；M1 峰值 0.12 / 0.84；PF6 压力 0.29 / 1.4 sd，速度 0.18 / 1.0 U |
| 前端重提 | 全部 0（确定性） | X5D 0.002 / 0.056；M1 0.005 / 0.061；PF6 速度 0.005 / 0.073 U | 同 RMF 重载 | 同 RMF 重载 |

解读：

- **网络和特征程序：** 在“所有几何输入一起精确旋转”时不变。
- **RMF 的世界轴依赖：**
  - 起因：`wss_features/atlas.py` 里，根段 RMF 的初始法向固定取世界 x 轴，再投影到切平面。
  - 后果：角向坐标 θ（以及 flowref 里依赖 θ 的弯曲 / 分叉平面 / 先验分箱特征）跟随 STL 的世界朝向。
  - 只有绕 x 轴的旋转能保住它（T1 为 0）。
  - 训练数据都在同一套 CT 朝向里，所以这在训练集内是自洽的；但**部署前端没有在特征之前统一朝向**。
  - 用户上传的 STL 若用了另一套坐标约定（如 RAS 对 LPS，正好是 T3），WSS 预测的中位变化约 10 %，体场更大。
  - 这一项不属于合成几何，单列为待决事项（第四节 D-a）。
- **X5Dcap 的额外依赖：**
  - 起因：`wss_features/cloud.py` 里，虚拟端盖的平面基按世界轴选取，端盖离散随朝向改变，影响端盖面积派生的分流先验。
  - 幅度：小于 RMF 那一项（p99 0.01–0.07）。
- **前端重提抖动：** VMTK 中心线在旋转后重提有抖动（p99 约 0.05–0.07），这是比较母例和子例时，前端自带的一层非形变差。

### 2.3 局部形变：坐标架与网络贡献分离（`synth_geom/p2_local.py`）

- **做法：** 同一子例几何、同一采样（STL 顶点），算三次预测：
  - P：母例，标准前端；
  - C_std：子例，标准前端，即用子例自己的解剖坐标架和尺度，这就是部署时的做法；
  - C_pin：子例，但坐标架和尺度固定为母例的。
- **分解：**
  - 总变化 = C_std − P；
  - 仅几何 = C_pin − P；
  - 坐标架部分 = C_std − C_pin。
- **坐标架定义：** 原点在主动脉分叉，+Z 是主干弦，+X 是左右髂总均值差。

| 子例 | 分叉原点移动 | z 轴 / x 轴转角 | 未动区 X5D 总变化 / 其中坐标架 | 未动区 PF6 速度 总 / 坐标架（U） |
|---|---|---|---|---|
| HAN neck+15 | 16.2 mm | 4.9° / 4.5° | 0.027 / 0.019 | 0.050 / 0.034（CFD 0.007） |
| HAN neck−10 | 10.2 mm | 3.1° / 2.4° | 0.029 / 0.012 | — |
| CHEN neck+15 | 11.5 mm | 4.0° / 3.2° | 0.060 / 0.032 | 0.096 / 0.047（CFD 0.072） |
| ZHANG neck+15 | 27.7 mm | 9.2° / 9.0° | 0.035 / 0.030 | — |
| WANG neck+15 | 10.2 mm | 4.2° / 3.1° | 0.080 / 0.026 | — |
| 髂总 / 分支弯折 | 0 | x 轴 0–2.0° | 0.002–0.070 / ≤ 0.014 | 0.048–0.105 / ≤ 0.037 |
| 口径族 | 0 | 0 | 0.08–0.17 / 0 | — |

- **CFD 对照（面积加权 R²，标准 / 固定坐标架）：**
  - HAN neck+15 未动区：X5D −4.99 / −2.16，M1 OSI −8.20 / −3.75。固定坐标架后改善，但仍为负。
  - 瘤囊、刚体段、过渡段：两种做法几乎一样，例如 HAN neck+15 过渡段 X5D 0.40 / 0.38。
  - **结论：** 坐标架是未动区假响应的一个来源，但不是模型抓不住真实响应的原因。
- **固定坐标架后未动区仍有的剩余变化，来源包括：**
  - 前端重提抖动（2.2）；
  - 网络的全局感受野（运动区改变了全局上下文）；
  - 分流先验特征（口径族最明显）。
- **本轮没有把这三项再分开。** 口径族的未动区变化方向，与 CFD 协议（RCR 按出口面积）引起的全局分流变化一致，幅度要等口径族的 CFD 才能核对。
