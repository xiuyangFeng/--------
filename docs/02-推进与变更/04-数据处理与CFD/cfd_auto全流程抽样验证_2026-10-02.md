## 二、怎么测的

### 2.1 测试口径：盲测“新病例”路径

- 每例**只给 STL**：标准清单里该单元的原始 data_new STL，复制到批次目录 `inputs/`（sha256 与原文件一致），单元号改成 `<队列>/val/…`，因此对 cfd_auto 来说就是一个库外新病例。
- 模板、网格族、表面密度目标、出口命名（部署端命名 + 置信度门）、延伸方向与长度、RCR 全部按协议 `aortoiliac_rcr4_v1` 的新病例默认值，**不使用该例库内的设置、网格或命名**。
- 全程由编排器完成：`python -m cfd_auto.orchestrate run batch.json`（准备 → CFD → 发散自动降级 → 后处理 → 物理自检 → 与库内原解比对）。
- 对照对象：该单元的库内原始 CFD（`data_new/<单元>` 的壁面 / 体场导出、Fluent 日志、.cas）。

### 2.3 判据（开跑前写定，`COMPARISON_CRITERIA.md`）

- **自动化**：A0 零介入到达结果；A1 只经过设计内的出口命名确认；A2 需要人工修复；A3 未走通。编排器自己的发散降级（库内步长 → 首周期半步长 → 全程半步长）和网格修复阶梯是设计内的自动恢复，不算介入。
- **与库内一致**：compare v2 十门，与 09-27/28 回归同一套。
  - P1 峰值帧 WSS R² ≥ 0.95；P2 相对 L2 ≤ 0.15；
  - P3 均值 / 中位 / p99 差 ≤ 5 % / 5 % / 10 %；P4 前 10 % 热点 IoU ≥ 0.80；
  - P5 壁面压力去均值 R² ≥ 0.99、均值差 ≤ 2 %；
  - P6 出口流量份额差 ≤ 0.02、峰值帧出口压力差 ≤ 3 %。
  - TAWSS、OSI、体场、分支段、插值地板只报告，不设门。
- **物理自检**：协议按队列分两级的算后门（入流比、左右分流、侧内份额、出口压力、周期性）。
- **用户规则**：不过关的单元只允许额外跑一次；空闲 CPU 全部可用（每例 92 核，CFD 最多 15 个并行）。

### 2.4 网格质量怎么量

- 库内网格和新网格用同一套代码，只算解剖区，因为延伸段两边长度和方向都不同。
- 单元级正交质量按 Fluent 的定义：几何正交度与 1 − 偏斜度（四面体等体积偏斜，其余单元等角偏斜）取小。
  - 30 套网格上，Python 实现的全域最小值与 Fluent `/mesh/quality` 逐例一致到 3–4 位有效数字，库内的多面体网格也一样。
  - 起初漏掉了偏斜度项，算出的最小值偏高；用 LOU_YANG 的最差单元核对后补上。
- 库内 .cas 只复制到批次 `libmesh/` 后读取，不在库目录里读。

## 八、局限

- 15 例样本小。抽样排除了库内标签本身有问题的单元，所以这里的一致率反映的是“库内标签可信时”的复现能力。
- 库内 AG 全部是每步迭代提前退出的单元（标签对充分收敛约 4 % L2）；cfd_auto 继承模板设置，同样提前退出，所以 AG 的比较是同口径的。
- 只比较了峰值帧、末周期 81 帧、TAWSS / OSI 和峰值帧体场，没有比较前 7 个周期。
- LIU_XING_GUO 的新解右髂内流量在周期之间不完全重复（§五），说明这一例在更密的网格下存在周期间变化，标签本身对网格敏感。
- LOU_YANG 的发散原因没有查实。
- 归因运行每例只有一次，只能检验一个假设，没有对每个因素做完整的析因。
