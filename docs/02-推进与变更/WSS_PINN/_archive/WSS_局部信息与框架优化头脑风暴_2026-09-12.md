## 1. 从血流物理反推：WSS 的"局部"是哪三件事

WSS = μ ∂u_t/∂n，由近壁速度剖面决定；峰值帧的近壁剖面由五类机制决定：

| 机制 | 几何决定因素 | 壁面表现 |
| --- | --- | --- |
| 截面尺度 | Q/R³（Poiseuille），Q 为协议常量 | 沿程均值 |
| 弯曲二次流（Dean 流） | 曲率大小 **和方向**，且滞后上游 2–5 个管径 | 弯曲外侧/内侧壁不对称（充分发展流外侧高；入口段可反号） |
| 分叉 | 分流嵴（carina）位置、分叉角、子支半径比 | 分流嵴高 WSS；髂总外侧"髋部"低/振荡 WSS |
| 扩张（瘤腔） | 面积比 A/A_neck、扩张率 dA/ds | 逆压梯度→分离→低 WSS 区 + 再附着脊 |
| 收缩/狭窄 | 最小面积、收缩率 | 2–3 mm 宽的喉部射流热点 + 下游分离 |

由此，对 WSS 有意义的"局部信息"有三个属性，**当前输入与结构都还没有覆盖**：

- **各向异性**：轴向与周向相关长度不同。E2 在 support 分辨率（5000 点）做了切平面分额；但 C1 的全分辨率 query patch（`next_geometry.build_query_patch` → `LocalPatchFiLMRefinement.forward_patch`）仍用 **atlas 全局坐标**的相对偏移，并对 16 个邻居做 **mean 池化**，既无局部坐标架也无注意力。
- **相位参考**：周向角只有相对"弯曲方向"或"分叉平面"才有跨病例意义。核对 `wss_v5/centerline_features.py`：θ 用旋转最小化坐标架（`_rmf`），起始参考为父段末端法向或解剖 +X，沿中心线平行输运——**它不跟踪弯曲方向、也不跟踪分叉平面**。这解释了为什么 ρ/sinθ/cosθ 消融只有 −0.005（§5.1b）：模型拿到的是一个跨病例无物理对应的角度。
- **上游条件化**：s 处是否分离、在哪再附着，取决于上游几个管径内的几何。现在唯一的非局部上下文是每例一个全局向量（C1 的 FiLM context = query 自身特征 ⊕ 逐例池化的粗层向量，见 `baseline_models.py` 的 `patch_context`），既不沿流向、也不分支路。

另外两个硬事实：入口波形 172 例逐位相同 → WSS 的病例间差异**纯由几何决定**，唯一的非几何未知量是髂内/外分流（出口面积只能解释 28–78%）；母库里已有 **81 帧 WSS 向量标签**（`wall_wss_vec`）与壁面压力（`wall_pressure`），至今只用了标量峰值帧。

## 2. 几何特征候选（部署合法：只需壁面点云 + 中心线）

每条给出物理依据、算法、预期与"跑 GPU 之前的预登记检查"（沿用 §11.2 的做法：先用 C1 的残差算上限，再决定投入）。

**F1 弯曲参考周向角（bend-side indicator）**
- 物理：Dean 流的外侧/内侧壁不对称是曲率**向量**的函数，不是曲率标量的函数。
- 算法：中心线单位曲率向量 κ̂ = d t̂/ds / |d t̂/ds|；壁面点径向单位向量 r̂（现有 `radial_vec`）；特征 cosφ_bend = r̂·κ̂，以及带幅值的 κ·cosφ_bend；补挠率 τ(s)。再加**滞后版本** κ̂(s−2D)、κ̂(s−5D) 在当前截面的投影，表达"上游弯曲在这里留下的二次流"。直段 |κ|R < 0.05 时置 0 并加有效 mask。
- 预登记检查：在 C1 test34 残差上，按 |κ|R>0.05 的弯曲段分箱，看残差对 cosφ_bend 的相关；若残差里有可解释的周向一阶模态，这个特征就是补它的最便宜方式。
- 预期：物理 +0.01～+0.03；最直接受益的是 AG 与 ILO 的髂动脉弯曲段。

**F2 分叉参考角（flow-divider indicator）**
- 物理：分流嵴侧高 WSS、髋部侧低 WSS 是分叉的确定性模式；`dist_to_junction_mm` 是各向同性的，分不清"离分叉 5 mm 的嵴侧"和"离分叉 5 mm 的髋部侧"。
- 算法：分叉平面法向 n_b = t̂_child1 × t̂_child2；子支内到分叉 3D 以内的点：cosψ = r̂ · (指向兄弟支的平面内方向)（嵴侧 +1、髋部 −1）；父支近端点：r̂ 与分叉平面的夹角；再加分叉角、子支半径比。§18 已确认的分叉快速定位器（516 处，506 有候选）直接给出分叉位置。
- 预登记检查：C1 残差在分叉 3D 内对 cosψ 分箱。
- 预期：主要作用在 top10 IoU（热点定位），物理 +0.01～+0.02。

**F3 上游历史与流动发展**
- 物理：入口段长度 L_e/D ≈ 0.06 Re（层流）量级，主动脉段基本都在发展段；分离与否取决于上游扩张历史。
- 算法：s/D 自入口；上游窗口（2D、5D）内的最小/最大面积比、自上次收缩/扩张以来的距离；Dean 数代理 De = Re·√(R/R_c)，Re ∝ Q/R（Q 常量 → 由 R、κ 决定）。G6 已经覆盖"上下游 10 mm 最小面积比"，这里把窗口按管径而非固定毫米取，并加曲率历史。
- 预期：+0.01 量级，与 S3 结构性方案重叠，二选一。

**F4 内蕴/测地描述子**
- 物理/几何：欧氏球邻域在分叉隔膜两侧和贴近的髂内/外之间会"穿壁"；测地量不会。
- 算法：用点云鲁棒 Laplacian（Sharp & Crane 2020，`robust_laplacian` 包，支持点云）算：到分流嵴、到入口/出口边缘、到瘤颈的**测地**距离；多扩散时间的热核签名 HKS（[GReAT](https://arxiv.org/abs/2508.19030) 用 HKS 做 8449 例血管几何的自监督预训练，再迁移到 49 例冠脉 WSS）。
- 预期：替换 `dist_to_junction/endpoint` 的欧氏版本，单独增益可能小；主要价值是给 S6/P2 铺路。

**F5 截面形状（G2/G4/G5 已在待验收清单）**
- 支持按原计划做，补两项：局部扩张比 A(s)/min_{上游 5D} A（分离判据）与到最大面积截面（瘤腔中心）的沿程距离。

**F6 Murray 法则分支流量先验（不是 RCR 输入）**
- 物理：协议给定 Q_in 与左右 50/50（出口阻力主导）；髂内/外分配未知，但 Murray 法则 Q_i ∝ R_i³（或指数 2.33）给出**只由几何决定**的估计。逐点 Poiseuille 尺度 τ₀ = 4μQ_branch/(πR³)。
- 用法两种：(a) ln τ₀ 作输入（与 ln R 的差别只在 ln Q_branch，即 7 个分支常数 + 病例依赖的髂内/外比）；(b) **残差参数化**：目标改为 ln(τ/τ₀)，去掉 R⁻³ 主趋势与分支尺度，让局部模型只学"形状"。A3 病例幅值头塌成常数说明全局池化拿不到逐例尺度，这条是用物理先验直接给。
- 预登记检查：逐例、逐分支残差均值对 ln τ₀ 的相关；若 ILO 域的逐支偏置能被解释掉一半，就值得。
- 预期：主要作用在 ILO 与逐例均值 R²，物理 +0.01～+0.03。

**F7 预测壁面压力的切向梯度（物理级联，投机）**
- 物理：τ ≈ (R/2)·dp/ds（Poiseuille）；壁面压力场光滑、长波占比高，现有压力模型 R² 0.75。
- 用法：冻结压力模型 → 壁面预测压力 → 切平面梯度 → 作 WSS 输入特征。风险与 VELWSS1 同类（误差放大），但压力比速度平滑得多。只在 F1–F6 之后考虑。

## 3. 结构与注意力候选（"局部注意力"该长什么样）

**S1 局部坐标架 query patch + patch 内注意力（E2 与 E3 在全分辨率上融合）** ★首选
- 改动：E3 的 patch 相对偏移改为 (轴向, 周向, 法向) 局部坐标 + 邻居法向在该坐标架下的差分；mean 池化改为 query 条件的注意力池化（logits 含相对坐标与特征相似度）；K 16→32 并按四个象限配额（复用 `geometry_neighborhood` 的分额逻辑）；两环半径（2.5 / 6 mm）在全壁面点云上取。
- 这就是规范等变 / 局部参考系卷积在点云上的实现（[GEM-CNN](https://arxiv.org/abs/2003.05425)；Suk 等 [SE(3) 等变网格网络做壁面血流估计](https://www.sciencedirect.com/science/article/pii/S0010482524004128)；2026 年 [1078 支冠脉的 GEM-GCN WSS](https://www.sciencedirect.com/science/article/pii/S0010482526001460)），也是 DoMINO / [GeoTransolver](https://arxiv.org/abs/2512.20399) "多尺度球查询几何嵌入"的做法。
- 预期：+0.01～+0.02 物理；是 C1 最自然的下一步，且零初始化可保持逐位兼容。

**S2 全分辨率窗口注意力（PTv3 / Erwin 式）**
- 做法：按 (分支, s, θ) 序列化壁面点 → 32–64 点的窗口（≈5–10 mm）做 shifted-window 自注意力 2 层；或用球树层级（[Erwin](https://arxiv.org/abs/2502.17019)，[Erwin-NSA](https://arxiv.org/abs/2508.10758)）。在 5000 support 上或直接在全壁面点上跑（后者才是 2–10 mm 尺度的真正"局部注意力"）。[PTv3](https://arxiv.org/abs/2312.10035) 的序列化窗口在管状几何上有天然的序：分支内的 (s, θ)。
- 预期：中；比 S1 贵，若 S1 有效再上。

**S3 中心线序列上下文（各向异性的非局部）**
- 做法：沿每条分支每 ~2 mm 切片，把片内壁面点池化成"截面 token"（截面统计 + 中心线特征 + F1/F5 特征），在血管树上做双向 Transformer 或状态空间模型（分叉处加连接 token），输出逐截面上下文，**替换 C1 里逐例全局向量**作为 FiLM 条件。这样上下文是"沿流向、分支路、有上游记忆"的。
- 文献：2026 年 [从中心线到血流：各向异性 RBF 解码器](https://arxiv.org/abs/2605.27578)（中心线 + 入口流量的 Transformer 编码，沿血管形态对齐的各向异性 RBF 解码到壁面，多支冠脉数据上比最好的神经算子基线相对 ℓ₂ 降 52%）；CenterlinePointNet++（MICCAI 2023）。
- 预登记检查：把 log WSS 分解为"截面均值 log τ̄(s)"与"截面内模式 log g(s,θ)"两部分，算 C1 残差各占多少：截面均值残差多 → S3；截面内残差多 → S1/S4。
- 预期：对 ILO 逐支尺度、瘤腔分离/再附着位置有针对性，物理 +0.01～+0.03。

**S4 管道展开 (s, θ) 二维图像分支（框架级）**
- 做法：每条分支展开成 (s, θ) 图（θ 周期填充，θ 参考取 F1/F2 的物理参考），WSS 场成为二维纹理，用 2D U-Net 预测后重采样回点；分叉区三张图重叠混合；与点云编码器并联。二维卷积对"条纹/斑块"这类局部纹理的归纳偏置最强，也是临床 unfolded WSS map 的表达方式。
- 风险：分叉与端帽的图缝合、非圆截面的畸变、θ 参考不连续。
- 预期：不确定，但上限可能最高；先在 AG 队列（拓扑简单）验证。

**S5 物理/距离感知注意力与 regime 路由**
- [Transolver](https://arxiv.org/abs/2402.02366) 的 physics-attention 把点软分配到"物理状态切片"（射流/分离/发展流），[Transolver-3](https://arxiv.org/abs/2602.04940) 与 GeoTransolver 是其工业尺度版本；2026-09 的 [距离感知注意力 + 壁距专家路由](https://arxiv.org/abs/2609.07222) 显示专家会**无监督地自组织成近壁/过渡/自由流三档**。对壁面场，可做"按局部 regime 特征（扩张率、曲率、到分叉距离）路由的混合专家头"，替代单一 MLP 头。
- 预期：小到中；实现便宜（只改 head）。

**S6 内蕴扩散算子分支（DiffusionNet 式）**
- [DiffusionNet](https://arxiv.org/abs/2012.00888)：可学习扩散时间的 Laplacian 扩散 + 切平面梯度内积特征，在点云 Laplacian 上直接可用；多尺度、测地一致、对采样密度鲁棒（正合部署点云密度未知的需求）。作为与 SA 主干并联的第三条通路。
- 预期：中；是 F4 的结构化版本。

## 4. 目标、损失与解码

**T1 切平面 WSS 向量目标** ★便宜且信息量大
- 标签已有（`wall_wss_vec`，81 帧）。把 WSS 向量投影到 (轴向, 周向) 得 (τ_a, τ_c)，多任务或直接替代标量：|τ| 由范数得到；τ_a 的符号标记逆流（分离区）；τ_c 标记二次流。方向是"局部流动拓扑"的直接监督，对热点定位与分离区应有帮助；也为将来 OSI 铺路。
- 预登记检查：训练集上 τ_a<0 的点占比与其 WSS 分布；C1 在这些点上的残差是否系统偏高。

**T2 壁面压力辅助头**：标签已有；与 WSS 共享表示。§17 联合模型未双赢，预期小，放后。

**T3 热点级联细化（coarse-to-fine）**：第一阶段（C1）预测 → 取预测 top 20% 区域 → 第二阶段在全分辨率局部 patch 上学 log 残差。Pa 空间 R² 被尾部主导，把容量按损失贡献分配是最直接的办法。训练时以真值热点 + 随机区域混合采样。

**T4 局部结构损失**：E6（物理毫米范围内近邻差分）单独对尾部病例有效但 C2 = E2+E6 反而弱于 E2；改为切平面坐标架下的**各向异性**差分（轴向/周向分别）与两尺度 Laplacian 金字塔，并只叠在 S1 上重测。

**T5 分解目标**：log τ = log τ̄(s) + log g(s,θ)，前者交 S3（或 F6 先验），后者交局部模型；与 §4.2c 的"逐例尺度 + 形态误差"分解一致，但把"尺度"从逐例细到逐截面。先做 §3 S3 的方差分解检查。

## 5. 训练框架层

**P1 全帧预训练 → 峰值帧微调** ★
- §10 的 T4 掉 0.11 是监督稀释 + 统计错配，不是"多帧信息无用"（归一化只掉 0.02）。改成两阶段：81 帧带相位条件预训练（80 倍局部流动模式监督：同一几何在不同流量下的分离/再附着如何移动），再在峰值帧用峰值统计微调。零数据成本。
- 预期：+0.01～+0.02，且对最难病例更稳。

**P2 几何自监督预训练**：GReAT 的路线（HKS 自监督，8449 例几何 → 49 例 WSS）。我们只有 172 例，可用公开血管几何（如 Vascular Model Repository、公开 AAA 表面）或大量合成管状几何做 Point-MAE / HKS 回归预训练，再微调。中等投入。

**P3 合成理想几何 CFD 预训练**：参数化弯管/狭窄/分叉/瘤腔，粗网格 CFD 数千例，先学"局部几何→局部流动"的物理先验。投入大，但 2026 年 [中心线→血流](https://arxiv.org/abs/2605.27578) 与 [PI-GNN 狭窄冠脉 WSS](https://pmc.ncbi.nlm.nih.gov/articles/PMC13212768/)（40 例临床几何经统计形状模型扩到 1000 例）都是这样解决小样本的。

**P4 训练卫生（做任何比较之前）**：EMA/SWA 权重平均、三 seed 或配对初始化（仓库已有 `paired_initialization.py`）、确定性算子。目的不是提升，而是把可读效应从 0.03 压到 0.01，否则 §2–§4 里一半的候选根本判不出来。

**P5 检索/atlas 先验**：在 (分支, s/L, φ_bend) 坐标下，对每个 query 点检索训练集同位置的 WSS 分布（中位/分位）作输入或作 kNN 基线（S1 计划里"解析先验与 kNN 检索基线"）。小样本下的非参数先验，也是"典型模式 + 病例偏差"的可解释分解。

## 6. 优先级建议（供拍板）

| 层级 | 候选 | 理由 | 成本 |
| --- | --- | --- | --- |
| 先做 | P4 训练卫生（EMA + 3 seed） | 否则以下一切不可读 | 低 |
| 第一批 | F1 + F2（物理参考角）、S1（局部坐标架 patch 注意力）、T1（向量目标） | 直接补 §1 的三个缺口，改动小、零初始化可兼容，预登记检查一天内可做 | 低 |
| 第二批 | S3（中心线序列上下文）、F6（Murray 先验 / 残差参数化）、P1（全帧预训练→峰值微调）、T3（热点级联） | 针对逐支尺度与尾部，投入中等 | 中 |
| 框架级押注 | S4（(s,θ) 展开图 U-Net）、S6（DiffusionNet 分支）、S2（全分辨率窗口注意力）、P2/P3（预训练数据） | 上限高、不确定性高，先在 AG 队列验证 | 高 |

预登记检查清单（只用 C1 已有预测，不占 GPU）：
1. 残差对 cosφ_bend（弯曲段）与 cosψ（分叉 3D 内）的分箱相关 → F1/F2 上限。
2. 残差的截面均值 / 截面内分解 → S3 与 S1/S4 的分工。
3. 残差在切平面内的轴向/周向相关长度 → S1 的 K 与半径设定。
4. 逐支残差均值对 ln τ₀（Murray）的相关 → F6 上限。
5. τ_a<0 区域的残差 → T1 的期望。
