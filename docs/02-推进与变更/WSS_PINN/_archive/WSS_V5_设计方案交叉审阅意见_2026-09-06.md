## 0. 一页结论

**总评。** 方案在方法学纪律上很扎实：数据合同、泄漏边界、指标命名、部署不变量、失败处置都写清楚了，§1.2 引用的历史数字我逐条核对无误。它的问题不在"写错"，而在两点：**没有把这套数据最重要的结构性事实用起来**；**目标值与已有证据脱节**。下面五条按重要性排序。

1. **边界条件协议的结构没有被利用（§2）。** 我用拓扑审计的 5 个解剖切面面积和 172 例 UDF 重新核算：总外周阻力 R_total、左右侧分配 50/50、R2·C 时间常数都是**协议常量**；唯一逐例变化的是每侧髂内/髂外分配，而它只有 28%–78% 能被出口面积解释。于是：主动脉、瘤腔、髂总段的流量在协议下**完全由几何决定**，绝对 Pa 的 Q-WSS 原则上可达；髂内/髂外段带有约 20%–45% 的**不可约幅值不确定性**，换任何架构都消不掉。V5 应把这个结构写进输入（协议流量分数场）、参考场（Poiseuille/Womersley 先验）和验收（按血管段分级），而不是指望网络从 5000 个点里重新发现 R⁻³ 和分流。
2. **没有正面回应几何单输入的历史天花板。** 第五轮 F0 结案（2026-07-12）：拟合足、预算非限、learning curve 约 40 例后平台、标签噪声小（R²_cap 0.92–0.96），几何-only 上限 dev1 field≈0.31 / casemean≈0.21；RCR oracle 再加 +0.08。V5 §1.2 没有引用这组证据，也没有说明 V5 靠哪几个新杠杆突破它。我的判断是：真实 mm 尺度、干净标签、局部表示、物理参考场、显式分流代理这五项各有正证据或机理依据，值得一试，但目标必须按此校准。
3. **§13.2 的目标与证据差 2–3 倍。** 面积相对 L2 median ≤0.25 相当于病例 R² ≈0.88–0.91（换算见 §5.2），历史最好逐病例 R² 均值 0.26；速度目标 0.20 对应的历史读数是 0.96。建议改成"相对解析基线 + 相对 oracle 差距 + 按段分级"的两级门槛。
4. **缺少零参数解析基线。** 共享入口波形 + 已知 Carreau–Yasuda 黏度 + 中心线半径，意味着每个壁面点都有一个可精确计算的非牛顿 Poiseuille/Womersley 参考 WSS，每个体域点都有一个轴向速度参考剖面。它应是每张结果表的第一行；模型达不到它就是负收益。目前 S0/S1 只有 P2V 小基线。
5. **时间建模没有利用"全库共享波形"。** 81 帧逐帧按 t 查询是最贵也最弱的形式。建议时间特征用 (t/T, Q(t), dQ/dt)，输出用训练折 POD 得到的周期时间基系数（预计 4–8 个模态），一次前向出全周期，TAWSS 与峰时解析可得。

其余意见见 §3–§5：输入坐标系、幅值分解的更简形式、体场在局部标架输出、压力 gauge 取入口面、部署离散鲁棒性提前、4 例入口面积偏差的处理等。§6 是 D-01～D-12 的建议填写，§7 是首两周行动清单。

### 2.3 对 V5 的含义

**按血管段，而不是按模型，定义能力级别：**

| 段 | 协议下的流量 | 几何单输入可辨识性 | 建议产品级别 |
| --- | --- | --- | --- |
| 主动脉、瘤腔（分叉上游） | Q_in(t)，固定 | 完全由几何决定 | Q-WSS 候选 |
| 髂总 | 0.5·Q_in(t)（狭窄阻力略作调整） | 由几何决定 | Q-WSS 候选 |
| 髂外、髂内 | 0.5·Q_in(t)·f，f 只部分几何可解释 | 幅值不可约不确定性 20%–45%（τ∝Q^β，β≥1 时更大） | 默认 R-WSS；Q-WSS 必须带区间 |

这与 RCR oracle 完全一致：oracle 的增益就是髂内/外分配信息。AG 增益最大（+0.110）而 AG 的分配恰恰最能被面积解释，说明旧 6D 输入根本没有出口面积信息——**显式的"协议流量分数场"是最便宜的杠杆**。

**导师约束下的处理：** RCR 不进输入。进输入的是几何 + 协议常量：分支身份、Q_in(t)、左右 0.5、面积代理 f_area = A_ext/(A_ext+A_int)。RCR 只用于 (a) 分层评价，(b) oracle 天花板，(c) 未来"同几何多分配"增量 CFD 的设计变量。§13.3 的 Q/R 分级应改为"按段预注册"：主动脉、瘤腔、髂总争取 Q-WSS，髂内/外默认 R-WSS。

产品定义也应随之明确：V5 输出的是**协议条件下的 WSS**（训练 CFD 设置下新几何的预期响应），协议常量写入 model card。

## 3. 建模审查与建议

### 3.1 输入表示：给网络一个"管道坐标系"

第五轮 B-REP 显示原始坐标下的局部映射跨病例不可迁移（其他病例 15NN casemean −4.10），而 LocalGeoPE 的相对编码有正收益（R²_cb 0.20→0.29）。两者合起来说明：局部几何有用，但必须在**病例无关的坐标系**里表达。

- **典范管道坐标**：每个 support/query 点带 (s, ρ=r/R(s), θ)。s 为所属分支弧长，ρ 为到中心线距离除以局部半径，θ 为相对局部曲率法向的方位角。不同患者的场在这个坐标系里长得像，这是 138 例能学到东西的前提。瘤腔和分叉处该坐标定义不良，作为**带有效性标志的特征**保留，笛卡尔局部坐标同时保留。
- **局部标架**：切线 t̂、法向 n̂、副法向 b̂ 来自 atlas。体场速度在 (t̂, n̂, b̂) 中预测再旋回，天然旋转等变，不再需要旋转增强（第一轮 rotaug 是全场最差臂）。
- **逐点特征清单**（全部几何/协议可导出）：R(s)、dR/ds（扩张→逆压梯度→分离→低 WSS）、κ(s)（Dean 数→WSS 偏向外侧壁）、到最近分叉的距离、分支 ID、距入口弧长 s_in、表面局部曲率（由法向差分得到）、协议流量分数 f(x)、参考场 τ_ref(x,t)（§3.2）。
- **s_in 是一阶特征**：入口是 plug 剖面，稳态入口长度 L_e≈0.06·Re·D，按 Re≈560（均值流量、μ∞）、D≈22.7 mm 约 0.7 m，远大于域长，主动脉段全程处于发展流，壁面剪切随 √s 衰减。这是协议产物，但网络必须知道它。**需核查各例流量延长段长度是否恒定**：若不恒定，它是另一个影响入口段 WSS 的隐藏协议变量，应写入 M6/M7。
- 邻域用**半径 ∝ 局部 R 的 ball query** 而不是 kNN：kNN 依赖点密度，换成部署形态的点云（不同来源、不同密度）后会漂（第五轮 A1 密度迁移敏感）；ball query 是尺度感知且离散鲁棒的。邻域限制在同分支或以分支 ID 加权，避免分叉处欧氏近邻混支、瘤腔对侧壁污染。

### 3.2 物理参考场 + 残差学习：把 A4 从"创新储备"提到首轮

方案把"中心线简化流动基场 + 三维局部残差"列为 A4 储备。我认为它应是首轮结构，理由是它同时解决幅值尺度、样本效率和可解释性三件事，而代价只是一个预处理。

**WSS 参考场。** 对每个壁面点，用 R(s) 与 Q_branch(t)=f(x)·Q_in(t) 计算充分发展圆管的壁面剪切。必须用 Carreau–Yasuda（μ∞=0.0035、μ0=0.16、λ=8.2、a=0.64、n=0.2128）解 1D 管流，而不是牛顿 Poiseuille：n=0.21 的强剪切变稀使瘤腔低剪切区（γ̇≈1–10 s⁻¹）的表观黏度比 μ∞ 高一个数量级以上，牛顿先验会系统低估低 WSS 区。1D 非牛顿管流按半径网格离线解一次即可。

**瞬态参考场。** Womersley 数 α=R√(ω/ν) 在本队列约 4–25（R 从 P5 2.6 mm 到 P95 16 mm，ω=2π/0.8）。主动脉与瘤腔是强非定常区：壁面剪切相位领先流量可达约 45°，幅值高于准稳态。因此 §6.1 的"入口峰值帧"WSS 本来就不等于 Poiseuille 峰值。由于波形全库共享，可以对半径网格**离线预计算 Womersley 剪切时序 τ_W(R,t)**（牛顿 μ∞ 近似或 1D 非牛顿脉动解），作为查表参考。这是共享波形协议带来的免费结构。

**模型形式。** 建议 log 加性分解替代 §5.2 的参考集归一化：

log τ̂(x,t) = log τ_ref(x,t) + a_θ(𝒢,t) + r_θ(x,t)

a_θ 是来自全局 latent 的病例级标量头（吸收整体尺度），r_θ 是局部残差头，对残差在参考集上的均值加弱惩罚使尺度归 a_θ。优点：不需要每步在参考集上前向计算 Z，chunk 不变量自动成立，秩相关与 top-k 对 a_θ 不变，"幅值 vs 形状"的诊断拆解仍然直接。§5.2 的面积均值归一形状 S 可在推理后于固定参考集上算出，用作 R-WSS 产品；§5.2 的参考集归一化架构降为对照臂。

**速度参考场。** 体域点的轴向速度参考 u_ref = (Q_branch(t)/A(s))·φ(ρ; α) · t̂，φ 取 Womersley 剖面（或 plug→抛物线的入口段插值）。网络在局部标架里学残差（二次流、偏斜、射流、回流）。**预测：** 仅这个零参数先验在管状段就能达到 E_u≈0.4–0.6，瘤腔内失效。它是体场任务的真实基线；旧 V4 的 0.96 与它相比是负收益。

**压力参考场。** 沿中心线的 1D Poiseuille 压降 + Bernoulli 项给出 p_ref(s) − p_inlet，作为 §3.7 gauge 下的先验。

### 3.3 骨干与候选顺序

- **WSS 头的最强现成锚点不是 D2 c125-k128，而是 PointNeXt-R + LocalGeoPE 线**（S3 三 seed 0.29；+L-SA2+log-radius 0.35）。D2 c125-k128 是体域 PINN 线的 provenance。建议 S1-W 用 PointNeXt-R + LocalGeoPE（ball query 半径 ∝R）+ atlas 特征 + τ_ref + log 残差头；S1-V 用 D2 层级编码 + 各尺度局部特征到 query + 局部标架输出。A0 P2V 仍作欠拟合诊断锚。
- **A3 建议具体化为"中心线 transformer + 局部点解码器"**：7 段 ≈1400 个中心线样本做一维 tree attention（长程结构：上游瘤腔→下游射流、上游狭窄→下游流量）；每个 query 交叉注意最近的 k 个中心线样本，再融合表面局部邻域特征。中心线是一维的，全局注意力几乎免费。这是 1D 血流动力学 + 3D 局部修正的自然神经版本，放第二轮。
- **自监督几何预训练是一个低成本杠杆**：所有可用几何（含被排除单元、ILO 另一相，约 250 个几何，剔除 test34）做掩码点建模或 atlas 特征回归预训练编码器，不涉及 CFD 标签，无泄漏。138 例监督下编码器欠训练是很可能的瓶颈。

### 3.4 时间：用共享波形换掉逐帧查询

- 时间特征改为 (t/T, Q_in(t)/Q_peak, (dQ/dt)·T/Q_peak, 少量谐波)。波形全库共享，所以 t 与 (Q, dQ/dt) 信息等价，但后者是物理坐标（准稳态项 + 非定常惯性项），映射更平滑，跨相位泛化更好。UDF 的 mod-T 重置直接体现在 Q(t) 里，不必人为平滑。
- **周期时间基**：在训练折上对 log τ(x,·)（体场对各分量）做 POD，网络对每点输出 K 个系数，一次前向出 81 帧。TAWSS、峰时、相位滞后从系数解析得到；推理成本降 81 倍；时间平滑性自动满足。**先在 S0 验证**：K=4/6/8 在留出折上的重建相对 L2，我的预期是 K≈6 时 ≤0.05；不达标再回退到逐帧查询。
- 峰值快照用**入口峰流帧的固定索引**（全库相同），不用逐例 WSS 峰帧，方案 §6.1 已这样写，同意。

### 3.5 体场：为什么以前是 0.96，V5 怎么避免

旧 V4 用单一全局 latent + 归一化盒坐标去定位 400k 个 cell 中的一个点，这是定位失败而不是流体学失败：网络退化成预测均值（斜率≈0）。V5 的三件事直接对症：各尺度局部特征到 query（方案 §4.3）、典范管道坐标（§3.1）、轴向参考剖面（§3.2）。此外 batch 内按 (病例, 相位) 组织、体积权与近壁分带配额，方案已写。补一条：训练侧 query 从 CFD cell 坐标抽样会让网络学到网格密度捷径（近壁加密），评估时务必用几何均匀采样的 query 复核（方案 §16.2 最后两行已有意识）。

### 3.6 压力 gauge：入口面均压优于体积均值

§6.3 选逐帧空间中心化是对的方向，但参考量建议改为**入口切面面积均压** p̄_inlet(t)，而不是全体体积均值：

- 体积均值被瘤腔体积主导，gauge 随瘤体大小变，给共享表示添了一个无意义的几何依赖。
- 临床量是压差：ILO 的跨病变压降、AAA 的瘤腔压 ≈ 入口压。以入口为零点，Δp(入口→各出口, t) 直接是主指标，和 FFR 类指标同构。
- 入口面是几何上良定的平面，训练与部署用同一几何程序取面，方案 §6.3 "固定几何参考集"的要求同样满足。

已知压力脉动幅值 ±30% 由 RCR 顺应性决定、几何不可解释，因此只有空间压差是可学目标，方案的判断正确。

### 3.7 物理约束、多任务：同意降级，补两点边界

- 对 138 例的条件均值预测器，只有**线性**约束（连续性、no-slip、切面通量守恒）是合法的；强式动量在条件均值上不成立（方案 §7.4 已写出 E[u·∇u]≠E[u]·∇E[u]）。首轮完全不做强式动量，S5 只试弱式通量平衡。
- 多任务：同意"不是默认获益"。WSS 与速度的物理耦合是局部的（τ=μ∂u_t/∂n），近壁法线剖面监督是唯一可靠的粘合剂；Profile oracle 0.63–0.70 是它的上限参考。压力独立支路。

## 4. 数据与合同意见

### 4.1 D-01 现在就能定：B-Full

95 GiB 原始时序在集群上不是决策问题。建议直接冻结 B-Full：Zarr（每例一组，chunk = 1 帧 × 64k 实体 × 全通道，zstd 低压缩级，速度场压缩比不会超过 1.5×，容量按不压缩预算）；静态几何只存一次；15k/5k 缓存是索引。pilot 只比格式与读取模式，不再比 Full/Compact。把 §8–§9 省下的设计精力挪到 §3.4 的几何单输入 query 生成程序——那才是部署侧的真实风险。

### 4.2 A_udf≠A_mesh：现存 4 例、全在 train、影响为二阶项

| `AAA/unruputer/CHEN_SHU_LIN` | 0.888 | −11.2% | −11%～−16% |
| `AAA/ruputer/LIU_YONG_LAN` | 0.911 | −8.9% | −9%～−13% |

### 5.2 目标换算与建议门槛

面积相对 L2 与病例 R² 的关系是 E_τ² = (1 − R²_c)·CoV²/(1+CoV²)，CoV 为该例 WSS 的面积加权变异系数：

| 病例 CoV | E_τ=0.25 ↔ R²_c | 0.35 ↔ | 0.50 ↔ | 历史逐病例 R² 0.26 ↔ E_τ |
| --- | --- | --- | --- | --- |
| 1.0 | 0.875 | 0.755 | 0.50 | 0.61 |
| 1.5 | 0.91 | 0.82 | 0.64 | 0.72 |

§13.2 的 WSS median ≤0.25 与速度 median ≤0.20，相对历史最好读数分别是约 2.5 倍和 4–5 倍的误差能量缩减，且高于第五轮估计的几何-only 天花板。建议改成两级：

- **Gate-1（相对，S1 起用）**：E_τ 比 S0-PRIOR 低 ≥25%，比 kNN 检索基线低 ≥15%；病例配对 95% 区间不跨零；速度同理。
- **Gate-2（绝对，按段，S0 后登记）**：主动脉/瘤腔/髂总：E_τ median ≤0.40、A^full 相对偏差 median ≤0.15、Spearman median ≥0.75 → Q-WSS；髂外/髂内：Spearman ≥0.75 且 top10/bottom10 IoU ≥0.35 → R-WSS，幅值只报区间。这些数字是起点，S0-PRIOR/S0-CEIL 之后修订一次即冻结，不看 test 调整。

### 5.3 CV 与统计

3-fold 患者分组 + 队列分层可行；`HOU_SHEN_QIAN=KANG_XI_MING` 同几何须同组。§11.4 的配对 bootstrap、Holm 校正、seed 作为算法重复而非样本，全部同意。补一条：每张表按 §2.3 的血管段分层，用 atlas 分支 ID 划段，作为**头条表**而非附表。

### 5.4 部署鲁棒性提前

第五轮 A1 已证明密度迁移敏感（STL 映射 Gate 0/8）。不要等到 S7：S1 起每个 checkpoint 都用部署形态的壁面点云（两种密度重采样，可由分割表面采样得到，模型不读表面）作 support 复评一次，与 CFD 节点 support 的差异写进 Gate-1。ball query（§3.1）是让这个测试通过的结构性前提。

### 5.5 不确定性

S6 反正要训 3 seeds：用 seed 集成的幅值头离散度作为逐例幅值不确定性标记，在内部 CV 上验证它与真实幅值误差的相关性。通过则 Q/R 的逐例选择有了只依赖部署可得信息的依据（方案 §13.3 要求的那条规则），成本为零。
