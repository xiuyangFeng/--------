# WSS V5 体场（压力 / 速度）全周期时间实验矩阵（2026-09-19）

**起因**：WSS 线的融入 t 实验（[WSS_V5_偏心与全周期时间实验矩阵_2026-09-18.md](./WSS_V5_偏心与全周期时间实验矩阵_2026-09-18.md)）跑完后，导师要求把同一套「融入 t」也在**压力**和**速度**上各做一遍。用户 2026-09-19 拍板：每个臂只做 **一个 seed（1234）**，用显卡并行。

**底座裁定**：用户初始指定 X5D_v51，实测其 27D 输入含 `curv_k1/k2/gauss/curvedness`、`tn_dot` 等壁面专属 sidecar，内部单元上没有定义，`config.validate_features` 也拦着。改用体场原生的 **PF6 / VF6** 配方（18D 体场特征 + Murray `log_q_branch_murray`/`log_tau0_murray`），把老 v5 的配方原样搬到 v5.1 数据与 `cv3_v51` 三折，作为本批的峰值帧折底座。

**读数规则**：每臂只在自己的留出折（46 例）上读数，门控用三折均值 + 三折符号一致性；`test34` 本轮**未用**。峰值帧（步 1162）全云评估；周期指标在每例固定子采样上算（压力 20000 内部单元 + 4000 壁面节点，速度 20000 内部单元，seed 20260919 按 unit_id 派生），离线上限 / T-null 与每个臂共用同一套子采样行。

合计 24 次训练、42 次评估（折底座只评 best，时间臂 best+last）。

**与 WSS 线的口径差异**：WSS 是对数空间（log-z、TAWSS），体场是**线性** z——压力用 `p_rel(x,t) = p(x,t) − p_volume_mean(t)`（逐帧相对压力），速度逐分量。A0 实测周期内 `p_volume_mean` 的 DC 摆幅 2290 Pa，远大于峰值帧空间信号（`p_rel` 空间标准差中位 359 Pa），所以逐帧去 DC 是必须的，不能沿用单一全局参考。

## 6. 判读

**压力时间基头 PTB8 / PTB16：No-Go。** 全周期确实比 T-null 高 0.10、谷底 0.58 远好于 T-null 的 0.31，但峰值帧相对同折底座掉 0.051–0.063 且**三折全掉**。和 WSS 线一样，系数头把容量花在低流量帧上，峰值帧被牺牲。TB16 相对 TB8 无增益（全周期差 0.0003、谷底差 0.0005），2K\* 这一档可以不再扩。

**压力相位查询 PT0：有条件过门，但不足以改部署。** `last` 同时过两道门（峰值 +0.037、全周期 +0.096 且三折同向），是本批唯一过门的臂。三点保留意见：

1. **过门依赖 checkpoint，而且根子是单折失稳（逐帧图见 §9）。** `best`（EMA(train_loss) 选模）全周期只有 0.4771、fold0 的 0.401 低于该折 T-null 的 0.4194，掉到 2/3。把 best/last 逐折拆开看，fold1（0.453 vs 0.452）和 fold2（0.577 vs 0.583）两个 checkpoint 逐帧几乎重合，**整个 0.056 的差全部来自 fold0**（0.401 vs 0.565）：fold0 的 EMA 选点在谷底附近塌掉，最差帧 −0.936@49、81 帧里 10 帧为负，而 `last` 只有 3 帧为负、最差 −0.107。所以不是「last 的选模规则更好」，而是 **PT0 在 fold0 上训练末段不稳定，EMA 恰好选中了坏的那个点**。
2. **峰值帧的「提升」主要来自一个弱底座。** 逐折 Δ 是 −0.0087 / +0.0689 / +0.0275，增益几乎全在 fold1，而 fold1 的底座本身就异常低（0.6479，另两折 0.79）。更像是相位条件带来的额外样本多样性救了那个折，而不是 T0 普遍强于峰值帧训练。
3. **最差帧仍是负的**（best −0.32、last −0.089，都出现在 48/49 帧附近，即谷底前后）。全周期均值是 81 帧等权，低流量帧仍然没学好。

**速度全线 No-Go。** VT0 和 T-null 打平（+0.002 / +0.004，折符号 1/3 与 2/3），VTB4/VTB8 比 T-null 还差 0.04–0.05，且三个时间臂峰值帧全部低于折底座。结合 A3 的 `peak_freeze` ≈ T-null，结论是：**速度场在一个周期里近乎自相似**，全周期 R²_cb 上「不训练的峰值场 × 波形」已经接近这个指标的天花板，本批的时间头没有拿到任何超出缩放的信息。速度要谈全周期，得先换一个能区分时间结构的指标（例如逐帧去掉共同缩放后的残差、或相位/加速度相关量），而不是继续加 K。

**部署口径不变。** 压力 / 速度的部署仍用峰值帧 PF6 / VF6；需要周期量时用峰值预测 × 训练折时间形状（T-null），不要用本批的 TB 头。

新增结论（不改 §6 的 Go/No-Go，只把原因落实到帧上）：

1. **fig5 把压力与速度的差别一图说清**：共同时间缩放 r(t)（= `T-null − peak_freeze`）对压力在减速段与谷底最多买到 **+1.9** R²，对速度**全程贴 0、谷底还为负**。速度场在一个周期里近乎自相似，峰值帧冻住不动就有 0.553，T-null 只多 0.004 —— 这就是速度三个时间臂拿不到任何增量的根因，可学的东西不在这个指标里。
2. **压力的时间臂确实在离峰段赢了，只是不够买回峰值**。PTB8 的全周期 0.539 比 PT0 的 0.477 还高、谷底 0.583 也更好——时间基头在「把整个周期学像」上是有效的，它输在峰值帧（相对自己的折底座 −0.051）。当前部署要的恰好是峰值帧，所以仍是 No-Go，但这说明 TB 的失败是**任务取舍**而非学不动。
3. **速度在最深谷底（步 1216 附近）模型相对 T-null 有 +0.4 的尖峰**，谷底 20 帧均值 0.280 vs 0.118 是真实增益；但峰值窗 0.764 vs 0.972、减速段 0.604 vs 0.729 把它吃光，全周期净值 0.559 vs 0.557。
4. **PT0 的 best/last 差是单折失稳**（fig6）：fold1/fold2 两个 checkpoint 逐帧几乎重合，0.056 的周期差全部来自 fold0（0.401 vs 0.565），fold0 的 EMA 选点在谷底塌掉（最差帧 −0.936@49，10 帧为负；`last` 只有 3 帧为负、最差 −0.107）。修正 §6 的措辞：不是「EMA 选模在体场不可靠」这么一般的结论，而是「PT0 在 fold0 上训练末段不稳定，EMA 恰好选中坏点」。下一步应先查这个不稳定。
