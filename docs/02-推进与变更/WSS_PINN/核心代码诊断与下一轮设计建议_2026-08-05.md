## 0. 执行结论

### 0.1 一句话结论

**V3 已经排除了“明显的求导代码错误”，但尚不能把六臂结果的主因确定为“单一全局 latent”。当前更确定的问题是：物理方程与瞬态 peak 标签不完全匹配；出口压力的“真 BC”身份、空间位置和可部署性尚未闭环；入口/壁面交线上存在不相容边界迹；validation 聚合存在固定病例双倍权重；而 `u,v,w,p` 的监督、采样、共享表示和选模口径还没有与四通道场重建目标对齐。**

### 0.2 当前范围锁定

本轮唯一主任务是提高患者级峰值体域 `u,v,w,p` 重建质量。具体含义是：

- 训练主输出固定为 `u,v,w,p`，不恢复直接 WSS 输出分支；Stage 4 若测试一阶混合形式，梯度/应力只能是服务方程闭合的辅助变量；
- 不新增 WSS loss、WSS 辅助监督或以 WSS 反选 checkpoint/架构；
- 不继续调 `wss_mri_calculator` 的 velocity→WSS 算法；Profile-Secant V3 按当前冻结版本使用；
- WSS 只在基于 `u,v,w,p` validation 指标选定最终 checkpoint 后运行一次，作为下游 sanity check，不进入开发闭环。

冻结的 Profile-Secant V3 在 CFD 真速度输入下，test35 全壁面病例 overall R² 均值约
`0.9604`、pooled high-WSS R² 约 `0.9440`。这足以把当前主要优化瓶颈前移到上游场重建；
但逐病例 high-WSS R² 均值约 `0.7735`、平均峰值仍低估 `15.81%`，所以它是高质量
后处理器，不是无误差真值算子。尤其不能用其输出反向掩盖预测速度的空间平滑、近壁偏差
或压力误差。

### 0.3 本轮后可以保留的结论

1. V3 query 路径对 query coordinate 没有 3NN/IDW 和 query 邻域离散切换；给定 support 时，是光滑的坐标函数。
2. V3 六臂在训练病例上继续改善、在 val15 上 93–204 epoch 后恶化，**泛化过拟合是事实**；但“过拟合由全局 latent 引起”仍是假设。
3. `xyz+geom` 对当前六臂的 speed MAE/RMSE 有最稳定的正增量；BC 对总体速度近中性；当前准稳态 PDE 对 speed MAE 的配对增量为负。
4. 当前 near-wall speed R² 全负，说明速度场在边界层附近仍存在严重区域性失真；这是 `u,v,w` 重建本身的 P0 问题，不需要借助 WSS 目标才能成立。
5. V1/V2 的 3NN-IDW 在 support 重合点附近和 kNN 切换面上会产生强导数伪影，因此 SAME 点 strong-form residual 不能代表独立连续场的 PDE 满足度。
6. B 级六例探针提示：当前 V3 与病例盲群体场高度相关，患者特异条件不足应成为优先假设；但该结论尚未扩展到 test35 × 六臂 × `u/v/w/p`，不能写成已确认根因。
7. B 级目标病例自身 k-NN 平滑探针说明 bulk 真值并不需要极高空间频率才能达到较高 R²，因此 PE/Fourier 对 bulk 的先验优先级下降；该 oracle 使用了目标病例真值，不能证明 PE 无效，也不能外推到 near-wall。
8. B 级六例探针只排除了“当前 V3 global max-pool checkpoint 的 support 重采样方差是主要误差源”；不能外推到未来 FPS/局部核架构。
9. B 级梯度余弦显示训练后 `data` 与总 PDE 强反向，而 continuity 与 data 轻微同向；这支持 continuity-first，但在直接测量 `cos(grad data, grad momentum)` 前，不能写成冲突只来自 momentum。

### 0.4 必须撤回或降级的原结论

| 原表述 | 修订后判断 |
| --- | --- |
| “物理公式正确，所以 physics 没问题” | 代码算子可以正确实现**准稳态方程**，但瞬态 peak 标签的适用方程还包含 `rho·du/dt`；实现正确不等于模型设定正确。 |
| “全局 latent 是主因” | 局部条件缺失是合理候选机制，但缺少局部/position encoding/BC/support 稳定性的受控消融，不能称为已确定根因。 |
| “validation data loss=1 恰好等于全局均值预测” | 零输出等于训练集标准化均值预测；只在与 train 统计完全同分布、同聚合口径下期望 MSE 才接近 1，对 val15 不是精确恒等式。 |
| “V1/V2 二阶导数根本不存在” | 固定邻居集内二阶导数可以存在；问题是它在支撑点夹紧区和邻居切换面上有强偏差/不连续，不具备稳定收敛的 strong-form 含义。 |
| “`momentum_z` 大就是分量失衡” | 当前 `mean(mx²+my²+mz²)` 与坐标正交旋转无关；z 大本身不是 bug。按轴强行等平会破坏旋转不变性。 |
| “入口/壁面交线上 wall 目标一定正确” | 连续体上 plug inlet 与 no-slip wall 在交线处存在不相容边界迹；节点后处理为 0 不能决定 PDE 边界的唯一“真值”。正确工程处理是不在交线节点同时施加两个 Dirichlet 目标。 |
| “CFD 散点 residual 可以定义训练地板” | 撤回。三例、k 敏感的局部二次导估计不能生成全库、逐点、同方差的 loss floor。 |
| “Fourier 编码是必然解” | 位置编码是待测候选。高频特征会同时放大一/二阶导数噪声，必须与局部条件做正交消融。 |
| “把实测压力 monitor 作为输入，收益约 1.6%” | `7.7%×21%` 不是合法的因果方差分解；更重要的是该 monitor 可能是求解后响应量，未证明可部署前不得作为输入。 |

## 1. 先把科学问题定义正确

### 1.1 这不是单纯的 `geometry -> uvwp`

对不可压缩、脉动、出口 RCR/Windkessel 边界的血流，前向映射更接近：

\[
(\Omega,\;Q_{in}(t),\;R_1,R_2,C,\;\text{history/state},\;t)
\longrightarrow (\mathbf u(\mathbf x,t),p(\mathbf x,t)).
\]

当前 V3 网络实际只读取几何 support，流量、出口 RCR 参数、心动时相和前一时刻状态都没有作为输入。因此，即使网络容量充足，任务也可能因缺少条件而是多解映射。

Fluent UDF 代码还显示：

- 入口速度是随时间变化的 uniform profile；
- 四出口压力由 `R1/R2/C`、当前/前一时刻的出口流量与压力状态递推得到；
- `p-out*-rfile.out` 是 report/monitor 时序，不能在未闭环前直接等同于“推理前可知的边界输入”。

### 1.2 必须区分“输入”、“监督”和“求解响应”

| 量 | 当前来源 | 科学角色 | 下一轮要求 |
| --- | --- | --- | --- |
| 血管几何/局部几何 | support point cloud | 可部署输入 | 保留，增加局部条件的受控消融 |
| 入口流量或波形 | `vf-in-rfile.out` / UDF | 可能是可测或可指定输入 | 明确部署场景；至少输入 phase + `Q(t)` 或完整波形摘要 |
| RCR `R1/R2/C` | UDF 常数 | CFD 求解前边界参数 | 若未来可获得，应优先于求解后压力 monitor 作为条件 |
| `p-out*` monitor | Fluent report | 求解中/后响应或边界附近观测 | 未证明可用时，不得当作可部署输入 |
| 实际 pressure-outlet face 上的 profile 值 | RCR UDF/Fluent 边界状态 | 可作边界监督 | 需从真实 face/profile 链恢复，不能用内部 monitor 粘贴代替 |
| 内部 `u,v,w,p` | CFD cell-center | 监督标签 | 保留，但需补充标签不确定性与网格体积口径 |
| 壁面 WSS | CFD wall export | 冻结下游验证量 | 不进入训练或选模；只在最终 `u,v,w,p` checkpoint 上做 sanity check |

### 1.3 `u,v,w,p` 目标决定了不能只看 speed R²

四通道场重建不是一个单标量回归任务。至少存在四类彼此不可替代的误差：

- `u/v/w` 分量误差：决定速度方向、回流和局部输运是否正确；
- speed 误差：反映幅值，但会掩盖方向错误；
- `p` 误差：受病例 gauge 选择影响，绝对点值、压力梯度和入口—出口压降必须分开；
- 区域误差：near-wall、core、分叉、入口和各出口的样本规模与工程重要性不同。

因此，下一轮主指标固定为：

- `u/v/w` 的 case-balanced 与 pooled MAE、RMSE、R²；
- 速度向量 L2 误差、speed 指标，以及排除极低速点后的方向余弦；
- near-wall/core/分叉和 AG/AAA/ILO 分层结果；
- 截面总流量、分支流量分配与全域质量守恒误差；
- 病例定 gauge 后的 `p` 点值误差、压力梯度误差和入口—出口压降误差。

四通道监督建议显式写成

\[
L_{field}=\sum_{j\in\{u,v,w,p\}}\beta_j\,
\mathbb E\left[\left(\frac{\hat y_j-y_j}{s_j}\right)^2\right],
\]

其中 `s_j` 是只用训练集冻结的尺度或标签不确定性，`beta_j` 是预注册的任务权重。
这样才能区分“单位/方差造成的数值尺度”与“研究上希望强调哪个通道”，避免由标准化
方式偷偷决定速度和压力的优先级。

`p` 不应因为数值尺度不同而被共享 loss 自动降级。建议至少比较“共享 trunk + 四个 head”
与“共享几何 encoder + velocity decoder / pressure decoder 分离”，并记录各任务对共享层的
梯度范数和余弦相似度。若 `p` 的绝对 gauge 不稳定，应优先优化病例中心化压力、压力差或
梯度，而不是通过增大统一 MSE 权重强迫网络记忆任意参考零点。

### 1.4 冻结 WSS 验证器的正确使用边界

`wss_mri_calculator` 的高精度是在 CFD 真速度分量及其原始空间采样分布上验证的。预测场
可能具有不同的频谱、偏置、方差压缩和近壁误差结构，因此“CFD 真速度上 WSS 算得准”不
自动推出“任意神经网络速度上 WSS 也算得准”。正确使用方式是：

1. 先完全基于 validation 的 `u,v,w,p` 指标选模型；
2. 冻结 checkpoint、WSS 算法、参数和评估点；
3. 只做一次 downstream WSS 审计，检查误差是否被梯度算子异常放大；
4. 若 WSS 变差，回到 `u,v,w` 的近壁剖面、方向和空间频谱诊断，不直接调 WSS 算法或加入 WSS loss。

## 2. 证据分级与已验证事实

### 2.1 证据等级

| 级别 | 定义 | 可以怎么写 |
| --- | --- | --- |
| A | 代码/配置/机器可读输出已入库，可直接复现 | “已确认” |
| B | 有只读数值复核，但探针脚本或逐例产物未入库 | “强证据，待工程化复现” |
| C | 机制合理，但没有受控消融或外部确认 | “假设/候选方向” |

### 2.2 物理算子：实现一致性与模型适定性分开

原始审计用制造解 `u=(aY²,bZ²,cX²)`、`p=dXY` 逐项比对了无量纲换算、速度雅可比、应变率、Carreau–Yasuda 黏度和完整 `div(2μD)`，报告最大误差为 `1e-17–1e-15` 量级。代码阅读与此一致：`physics/residuals.py` 没有把变黏度项简化为 `mu·laplacian(u)`。

**证据等级：B。** 制造解探针没有入库，所以它应当被迁移成正式单元测试后再升为 A。

这个结论只证明“代码正确计算了所写下的准稳态残差”，不证明该残差应该在瞬态 peak 标签上被压到 0。

### 2.3 V3 query 路径是光滑的

`ConditionalSmoothPointNetField.decode_query` 只接收 query xyz 和 broadcast case latent，然后通过 Linear+tanh 网络输出 `u,v,w,p`。V3 的 `physics_coords` 与 support/query 排除后独立采样。

**证据等级：A。** 这排除了 V2 的 SAME-IDW 重合点伪影，但不保证网络所学函数的空间带宽、局部信息或导数精度足够。

### 2.4 latent 没有完全塌缩，但不等于信息充分

原审计在 10 个 test 病例上观察到 latent 范围约 `-0.616…0.717`，244/256 通道的病例间 std `>0.01`。这可以排除“所有病例 latent 几乎相同”的极端故障。

**证据等级：B。** 通道有方差不等于 latent 包含了恢复局部血流所需的充分统计量，也不等于 latent 对 5000 support 的重采样稳定。

### 2.5 过拟合已确认，但根因未确认

| xyz / DATA | 0.2534 | 0.6418 | 103 | 1.0479 | 0.7881 |
| xyz / DATA+BC | 0.2637 | 0.6598 | 106 | 0.9939 | 0.7235 |

**证据等级：A。** 但下列机制都能导致该现象：

- 单一全局 max-pool latent 缺少局部条件；
- 缺少入口波形/RCR/时相等条件，映射本身多解；
- 123 个独立训练病例对 20 万参数网络的病例级覆盖有限；
- 对当前 V3 的 B 级六例重采样探针未发现有意义的 support-sampling variance；该机制从当前 V3 根因列表降级，但未来局部/FPS 架构仍需重新检查；
- AG/AAA/ILO 解剖和边界分布异质，单一分享场函数可能负迁移；
- 训练目标以全体 cell-center 回归为主，与近壁梯度目标不同。

因此只能写“过拟合已确认”，不能写“全局 latent 根因已确认”。

## 3. 对抗性问题清单

### P0-1 选模与确认集口径已不足以支撑新一轮“确认性”结论

#### validation 的固定双倍权重

`train.py` 的 validation 先在每个 batch 内求 MSE，再把 validation batch 等权平均。val15 与 `batch_cases=2` 产生 7 个双病例 batch + 1 个单病例 batch，最后的 `ILO/ZHANG_YAN_SHAN-0/before` 每个 epoch 都被固定赋予其他病例 2 倍权重。

后果：`best_validation_data` 不是严格的病例等权或点等权目标。它仍然是一个未使用 test 的有效开发 checkpoint，但不应被过度解读为精确病例均衡选模。

修复要求：

- 若目标是点等权，聚合 `sum_squared_error / number_of_points`；
- 若目标是病例等权，先求每例 loss，再对 15 例等权平均；
- checkpoint 选择、评估和论文主指标必须使用同一种聚合原则。

#### test35 已经成为 development-exposed screen

V3 训练期间没有用 test35 选 checkpoint，这一点仍然正确。但 V1/V2/V3 结果、near-wall 失败、逐病例异常和本设计文档已经反复读取 test35，并用它决定下一轮架构、采样和 loss。

因此：

- test35 可继续作为历史统一 screen；
- 下一轮在 test35 上的改善只能称为 exploratory development result；
- 最终确认需要新的 lockbox/外部队列，或在原 train138 内做嵌套/重复病例级划分。

### P0-2 准稳态 momentum 不是瞬态 peak 的完整生成方程

完整动量方程为

\[
\rho\frac{\partial\mathbf u}{\partial t}
+\rho(\mathbf u\cdot\nabla)\mathbf u
+\nabla p
-\nabla\cdot(2\mu\mathbf D)=0.
\]

当前 residual 有意省略 `du/dt`。既有三例局部导数审计中，k=96 加入时间项后 residual 均值约从 `1737` 降到 `1494 Pa/m`，说明时间项非零；其他未解释部分同时受局部拟合器误差、网格离散、边界状态和可能的数值求解误差影响。

结论：

- continuity 对瞬态不可压缩流仍应为 0，可以独立保留研究；
- 当前 quasi-steady momentum 更适合称为“有偏正则”，不应称为真实标签必须精确满足的约束；
- 在方程未修正前讨论 `lambda_pde` 的最优值，只是在调整模型偏差的强度。

### P0-3 出口压力链不能再简化为“exact peak BC”

当前资产链是：

`bc_metadata BC_O1..O4` → 减病例 pressure gauge → 广播到 pressure-outlet boundary node coordinates。

对抗性核对确认了三层不同的含义：

1. `BC_O1..O4` 来自 `p-out*-rfile.out` report 时序；
2. `.cas.gz` 中 report 面可指向 `outlet-*1` interior surface，而代码贴目标的坐标来自 `outlet-*` pressure-outlet zone；
3. UDF 在真正 pressure-outlet 上使用 RCR 状态和流量递推 profile 压力。

原审计报告了 monitor target 与边界附近 cell-center 压力的大幅差异（随机 40 例/160 出口：中位 gap 约 `+210.5 Pa`，p95 绝对 gap 约 `706 Pa`）。第二轮 B 级核对进一步发现，Fluent 主日志中的 UDF `P_ave_out*` 确实直接对 pressure-outlet face 的 `F_P` 做面积平均；代表病例中该值与 CFD 出口面静压相差约 `2–8 Pa`，而 V3 使用的 monitor 高约 `348–1066 Pa`。

因此，**monitor 与真实 outlet face 不是同一压力量的机制已有强证据，且无需重跑 Fluent 即存在恢复路径**。但全 173 例覆盖、时间步去重、gauge 转换和双路径误差分布尚未形成入库脚本，证据等级仍为 B；冻结合同不能把单例核对升级成全库 A 级结论。

下一轮处理顺序：

1. 工程化解析 `Fluent_*.out` 的 `P_ave_out* / Q_ave_out*`，绑定 case、timestep、zone 和日志 SHA256；
2. 对有双路径的训练病例比较 UDF face-average 与 CFD 出口面静压，Gate 阈值只能由 train-only 误差分布冻结，不使用 val/test 调阈值；
3. 对日志缺失病例使用已验证的 CFD 出口面静压回退，并在 manifest 中标记 provenance；
4. 当前 monitor 仅保留历史监督对照，不得继续称为 exact boundary pressure 或可部署输入；
5. `R1/R2/C` 可作为待验证的可部署条件，求解后 outlet pressure monitor 不可作为普通前向输入。

### P0-4 入口/壁面不应使用共享顶点同时施加两个 Dirichlet 目标

当前 `inlet_coords` 与 `wall_coords` 都由 face zone 的唯一顶点生成。入口圆盘边缘顶点同时属于 velocity-inlet face 和 wall face，因而同一坐标收到：

- inlet plug velocity；
- wall no-slip velocity。

原审计在 25 例上观察到重叠约占入口顶点 `7.16%`。这一 bookkeeping 冲突确实存在，但不应用“Fluent 节点真值为 0，所以 wall 唯一正确”来解释。边界条件施加在 face 上，交线是测度为 0 且边界迹可不连续的部位。

推荐修复：

- 在 inlet face **内部面积采样**，而不是在共享顶点采样；
- 在 wall face 内部做面积均匀采样；
- 对入口边缘留出一个网格容差级 buffer，不在同一点同时计算 inlet 和 wall loss；
- 保留 UDF 真实规定的 plug profile，不用内部速度标签悄悄替换边界定义。

### P0-5 当前 no-slip 的 wall zone 范围需要反向审计

`build_qs_smooth_v3.py` 把所有 Fluent `zone_type==wall` 的顶点并集写入 V3 `wall_coords`。当前 Gate 检查的是“冻结 sidecar wall 是否能在全部 Fluent wall 中找到”，但没有反向确认“所有被加 no-slip 的 wall 是否都属于目标流体域/评估表面”。

这不能直接判定为错误：额外 wall 可能是六个 fluid subdomain 中真实的物理壁面。但在每个 zone 的拓扑、与 strict interior 的邻接关系和与冻结 lumen 的归属没有入库前，“all wall no-slip”仍是一个未闭环合同。

### P1-1 BC 归一化不一致是事实，但“统一到 field std”不是唯一科学答案

当前：

- data loss 在标准化 `u,v,w,p` 上计算；
- wall/inlet 用 `U0=1 m/s`；
- outlet 用 `rho·U0²=1060 Pa`；
- 三个 BC 子项再等权平均。

这使权重同时混入了物理单位、标签分布尺度和任务优先级。原审计计算的“一个全库标准差误差”对比说明了这种隐式权重存在，但把 BC 全部改用 field std 只是一种回归标准化方案，不自动代表 no-slip 等物理约束得到了正确权重。

建议明确拆成：

\[
L_{BC}=\sum_k \alpha_k\;\mathbb E
\left[\left(\frac{e_k}{s_k}\right)^2\right],
\]

其中 `s_k` 是入库的尺度/观测不确定性，`α_k` 是显式任务权重。不再让单位换算偷偷决定任务优先级。

### P1-2 只看梯度范数不能证明 loss 竞争

原审计的单 batch 快照显示：初始时 PDE 梯度很小，训练后 PDE 梯度可大于 data。这说明固定 `lambda_pde=1` 可能产生明显的阶段性失配，但范数不包含方向信息：

- 大梯度可与 data 同向，不一定有害；
- 小梯度也可与 data 强反向；
- 真正需要记录的是 `cos(grad L_data, grad L_pde)`、不同层的范数和病例间分布。

第二轮 B 级探针测得训练后 `cos(grad L_data, grad L_PDE)≈-0.399`，而
`cos(grad L_data, grad L_continuity)≈+0.052`。这说明冲突并非仅是范数现象，并强烈
指向 momentum 组；但由于尚未直接测量 `cos(grad L_data, grad L_momentum)`，冻结版
只允许写“momentum 被高度怀疑”，不写“冲突只来自 momentum”。

因此，在新方程定义前不建议直接上 `loss_data/loss_phy`、GradNorm 或其他动态权重。先确保优化的 physics 本身是适定的，再处理数值平衡。

### P1-3 不应强制把 x/y/z momentum 调成相同 RMS

当前 momentum 三分量组合为平均平方误差，本质上是残差向量的欧氏范数平方，对正交坐标旋转不变。注册坐标的 z 轴若更接近主流向，`momentum_z` 更大并不意味着 loss 写错。

不推荐“每个轴除以自己 EMA RMS 后等权”，因为这会让物理约束依赖人为坐标轴。如需局部方向分析，应使用局部切向/法向或流线坐标，且只作诊断，不修改原方程的向量范数。

### P1-4 撤回当前“残差地板”方案

不建议使用

`mean(relu(abs(r)-r_floor)^2)`

并把三例 k=96 的聚合 residual 换成逐点 floor。原因：

1. 只有 3 例、每例 256 个 core 点；
2. k=48/96 对二阶导数和 residual 影响很大；
3. 误差在空间上明显异方差，近壁、分叉和 core 不同；
4. quasi-steady 残差包含真实的时间项缺失，不是纯测量噪声；
5. 用 RMS 作绝对值门限会把少数大误差点与大多数点混在一起。

更合理的方向是：恢复瞬态项、使用弱形式 residual，或用网格连通性构建误差可估计的离散残差。

### P1-5 近壁短板是“数据分辨率 + 表示 + 目标”三者共同问题

已有数据表明，2 mm 近壁带并不稀疏，真正稀疏的是最靠壁的第一网格层。但不能由此直接得出“tanh 注定表达不了 0.5 mm 边界层”。tanh MLP 理论上可以表示高频，问题更可能是频谱偏置、优化难度、缺少局部条件和监督不对齐。

同样，Fourier 特征也不是无风险修复。B 级目标病例自身平滑 oracle 表明 bulk 真值在数毫米尺度仍可保持明显高于当前模型的 R²，这降低了“高频表达不足是 bulk 主瓶颈”的先验概率；但该 oracle 使用目标病例真值，只能给出目标平滑性的下界，不能替代模型消融，也不能判断 near-wall。若保留 PE，必须使用带限频率，并把独立 query 上的场值、导数和守恒指标加入 Gate。

### P1-6 分层采样必须先定义“想无偏估计的目标分布”

当前从 cell-center 记录均匀抽样，并不严格等于对物理体积均匀。如果没有 cell volume，`n_b/N` 代表的是“记录数比例”，不是真实体积比例。

重要性权重的正确形式是：

\[
w_b=\frac{P_{target}(b)}{P_{sample}(b)},
\]

但 `P_target` 必须先明确是：

- cell-record 等权；
- 物理体积等权；
- 病例等权后再体积等权；
- 或者显式近壁重加权目标。

建议把“对目标总体的无偏风险估计”和“显式提高困难区域权重”拆成两项 loss。near-wall、core、分叉和边界区的配额以及 `lambda_region` 都只能是待测起点，必须由预注册的目标分布和多 seed 结果决定，不能把任意采样比例写成物理真理。

壁面采样应优先使用 face area/barycentric sampling。若只有节点，节点的代表面积应与局部面积或间距平方成正比，不是反比。

### P1-7 近壁 profile 监督需要拓扑 Gate

沿壁面法向构造速度剖面可以直接审计边界层速度恢复，但在弯曲、薄壁、近邻分支和分叉处可能：

- 穿出 lumen；
- 进入相邻分支；
- 使用错误法向方向；
- 用插值器的平滑偏差伪造更好剖面。

所以必须保存 wall-face ID/分支归属，对 ray 全程做 inside-domain 和 nearest-wall identity 检查，并把插值 CFD 标签的误差与模型误差分开。

## 4. 对历史 3NN-IDW 与新局部解码器的修订判断

### 4.1 V1/V2 strong-form residual 为什么不可靠

`1/d²` 3NN 插值有三个独立问题：

1. 精确重合点受 `clamp_min(epsilon)` 和极大最近权重支配，latent 坐标导数被强烈压低；
2. 靠近 support 时 Shepard 权重产生人工驻点倾向；
3. kNN 邻居集切换使插值只是分片光滑，一/二阶导数在切换面上不连续。

因此，V1/V2 的 SAME 点 residual 已确认虚低；独立 query 上的 residual 则会受邻居切换和高曲率强烈影响。这不影响其场值回归指标，但使 strong-form momentum 结论失去可信度。

### 4.2 PointNet++ + 光滑核是合理候选，不是已确定最优解

SA encoder 中 FPS/ball query/kNN 可以是离散的，因为 PDE 对 support coordinate 不求导。给定 support 后，query decoder 必须对 query coordinate 一/二阶稳定可导。

全质心 Gaussian softmax 核是一个候选：

```python
d2 = torch.cdist(query_pos, centroid_pos).square()
logits = -d2 / (2 * positive_bandwidth.square())
w = torch.softmax(masked_logits, dim=1)
local_feature = w @ centroid_feature
```

它避免了 top-k 切换，对固定质心是光滑的。但仍有风险：

- 带宽太小时退化成尖锐近邻，导数可爆增；
- 带宽太大时退化成另一种全局 latent；
- 全质心参与可能引入跨分支非局部泄漏；
- 每 epoch 重采样 support 会让 FPS 质心和局部特征抖动；
- 当前实验没有分开“局部条件”与“高频坐标编码”的贡献。

因此不建议一次性上线 PointNet++ + Gaussian + FiLM + Fourier。正确的因果设计见第 5 节的 2×2 矩阵。

### 4.3 新架构的导数 Gate 必须是尺度无关的

不建议使用“穿过任意质心时导数不得为 0”或“二阶导跳变必须 `<1e-3>`”这类绝对门限。真实函数在某些点的导数本来就可以为 0，且绝对数值依赖坐标/特征尺度。

应使用：

1. 已知一/二阶导数的制造场；
2. 相对 L2/Linf 导数误差；
3. 探针加密收敛率；
4. 对 support 重采样的导数和场值稳定性；
5. 固定物理长度尺度下的频率/带宽检查。

## 5. 修订后的下一轮实施路线

### Stage 0：零训练证据和数据合同 Gate

Stage 0 分成阻塞 Gate 与后续资产，避免让完整多面体拓扑恢复拖住低成本、可归因的
Stage 1。**0A 阻塞 Stage 1；0B 阻塞 Stage 2 和任何 BC loss；0C 阻塞 Stage 3；0D 不阻塞主路线。**

#### 0A. 选模、零训练基线与可复现证据（阻塞 Stage 1）

- 修复 val15 单病例 batch 双倍权重，validation 必须先逐病例计算，再对病例等权平均；
- validation 病例、每例 query 点和随机 seed 固定且跨臂完全一致；开发阶段可用固定 5k/例，
  晋级报告再做 full-volume，不允许不同架构因评估采样不同获得虚假增量；
- 冻结唯一 checkpoint 标量：

\[
S_{field}^{cb}=\frac{1}{N_{val}}\sum_c\frac14
\sum_{j\in\{u,v,w,p\}}
\operatorname{MSE}_{i\in c}\left(\frac{\hat y_{ij}-y_{ij}}{s_j}\right),
\]

  其中 `s_j` 只来自 train split。主 checkpoint、early stopping 和 seed 内排序只最小化
  `S_field^cb`；`best_total`、pooled 指标、physics residual 和 WSS 全部是副指标；
- 建立 train-only 病例盲群体场/atlas 基线；其带宽或 K 只能在训练内部选择并冻结，
  不得用 val/test 真值拟合仿射校准；
- 将制造解、IDW/局部核导数、latent、support 重采样、BC overlap、outlet gap 和分组
  梯度探针工程化为 JSON/CSV/测试，并绑定 checkpoint SHA256、split SHA256、case list 和代码状态；
- 报告 case-balanced + pooled + cohort-specific 指标；配对增量报告病例 bootstrap CI、
  改善病例数和最差亚组；
- test35 永久标注为 development-exposed。正式确认优先使用新 lockbox/外部队列；若无，
  使用预注册的 nested patient-level outer split，不能把普通重复 split 写成未触碰确认。

#### 0B. 最小边界数据合同（阻塞 Stage 2/BC，不阻塞纯监督 Stage 1）

- 解析 `Fluent_*.out` 的 `P_ave_out* / Q_ave_out*`，与 CFD 出口面压力做 train-only
  双路径 Gate；日志缺失病例保存明确回退 provenance；
- 入口/壁面使用 face interior 或至少剔除共享交线坐标，禁止同一点两个 Dirichlet 目标；
- 逐 wall zone 反向审计其是否邻接目标 strict fluid domain；
- manifest 明确区分“可部署 input”、“训练 supervision”和“CFD 求解后 monitor”；
- 恢复 `R1/R2/C`、入口流量/面积和 phase 的来源、单位、时相与缺失状态；
- 若 outlet face pressure 仍不能可靠恢复，则新路线不使用 outlet BC loss，不得回退 monitor。

#### 0C. 区域和工程积分资产（阻塞 Stage 3，不阻塞 Stage 1）

- `interior_dist_to_wall`、最近壁层真实物理距离、分叉/主干区域标签；
- inlet/outlet 与关键分支截面的面积、法向和流量积分权重；
- 病例 pressure gauge、压力梯度与入口—出口压降的统一定义；
- `u/v/w/speed/p` 的病例、点、区域和队列分层评估脚本。

#### 0D. 高成本拓扑资产（非阻塞，按收益决定）

- 完整 cell volume、face connectivity、wall face area/normal/branch identity；
- Stage 1 前先用 train-only 局部点密度量化“记录等权 vs 近似体积等权”的差异；
- 只有该差异足以改变模型排序或 Stage 3 的重要性权重时，才投入完整 `.cas.gz` 多面体拓扑恢复。

### Stage 1：先做无 PDE 的 2×2 可归因表征实验

在其他配置不变、参数量尽量匹配的前提下，只拆两个因素：

| 臂 | 病例/局部条件 | query coordinate |
| --- | --- | --- |
| B0 | train-only 病例盲群体场/atlas | 固定零训练基线 |
| G-Raw | 当前 global latent | raw xyz |
| G-PE | 当前 global latent | 带限 positional/Fourier encoding |
| L-Raw | 光滑局部多尺度条件 | raw xyz |
| L-PE | 光滑局部多尺度条件 | 带限 positional/Fourier encoding |

共同要求：

- 默认使用 `xyz+geom`，因为它是当前最稳定正增量；
- Stage 1 四个训练臂统一**不输入病例 BC**，只比较表示因素；可部署 BC 的增量严格留到 Stage 2；
- 因此 Stage 1 只能裁决“同等缺失条件下哪种表示更好”，不能把其绝对性能解释为完整 patient-specific surrogate 上限；
- 不加 outlet proxy loss，B0 也不读取目标病例的 `u,v,w,p`；
- 当前架构的过拟合最佳点约在 100–200 epoch，因此可以用 400–600 epoch + 预注册 patience 做开发筛选，不再默认跑 2500；
- 执行顺序固定为 B0 → G-Raw/L-Raw → 通过导数 Gate 后的 G-PE/L-PE；PE 轴优先级低于局部条件轴，但保留用于检验交互；
- 先用单 seed 筛四臂，再按 `S_field^cb` 对前两臂做至少 3 seeds；
- 选模不读 test35。

这个矩阵能回答：

- 改善主要来自局部条件，还是坐标高频表示；
- 两者是独立增益，还是只有交互时有效；
- 高频编码是改善四通道场，还是只改善点指标却伤害导数、流量或压力梯度；
- 模型相对 B0 的增量来自更好的群体解剖对齐，还是患者特异信息。

主排序仍使用 `S_field^cb`。相对 B0 的逐病例 ΔR²、残差相关或偏相关只作机制诊断，
必须病例级汇总；任何仿射校准都需 train-only/cross-fitted，禁止在 eval truth 上拟合后再
宣称患者特异增量。

### Stage 2：单独验证可部署边界条件

固定 Stage 1 胜出表征，严格比较“无 BC input / 有 BC input”；边界条件应作为单独因素，
不得和新架构或新 loss 同时上线。

优先候选输入：

- `Q_in(t)`/峰值流量及 phase；
- 真实入口面积或平均入口速度；
- 每个出口的 `R1/R2/C`；
- 若只预测单时刻，还需能表示 RCR 历史的状态或波形摘要。

不允许直接输入求解后实现的出口压力 monitor，除非研究问题明确是“已知这些测量时的场同化”，且论文把它标为 oracle/non-deployable。

只有每个几何一个 BC 组合时，网络很难区分“几何效应”和“BC 效应”。最有力的确认是对少量同一几何生成多 BC 的 CFD counterfactual 数据。

因此 Stage 2 有两层结论：现有数据可回答“这些可部署条件是否增加预测信息”；只有同几何
多 BC 反事实才能支持“模型会因果响应 BC”的 conditional surrogate 声明。后者是正式
机理确认，不阻塞前者的开发实验。

### Stage 3：优化 `u,v,w,p` 的多任务结构、采样与 loss

在 Stage 2 最佳监督场上每次只加一个因素；若 Stage 2 的可部署 BC No-Go，则回到
Stage 1 最佳监督场：

1. 基线：当前 strict-volume record-uniform 采样；
2. 分层采样 + 明确目标分布的重要性权重；
3. 分层采样 + 显式 near-wall / 分叉困难区域监督；
4. `u/v/w` 与 `p` 分头 decoder，并对共享 encoder 记录梯度冲突；
5. 逐项加入速度向量、截面流量、压力梯度或入口—出口压降辅助目标。

所有辅助目标必须来自当前可部署输入或 CFD 监督的确定性派生量。每轮只增加一个因素，
并保持参数量、病例、采样预算、seed 和 early-stop 规则可比。禁止用冻结 WSS 后处理结果
选 checkpoint、调 loss 或裁决架构。

主指标：

- `u/v/w/speed/p` 的 case-balanced 与 pooled MAE/RMSE/R²；
- 速度向量误差与方向误差；
- near-wall/core/分叉区域误差和逐病例失败率；
- 截面流量、分支流量分配和全域质量守恒；
- pressure gauge、压力梯度与入口—出口压降；
- AG/AAA/ILO 分层结果；
- 任一新增 loss 不得以另一个关键通道或某个队列超过预注册等效界值的退化为代价。

冻结的 WSS 只作为 Stage 3 完成后的附录型 downstream audit，不参与主表排序。

### Stage 4：只在最佳监督设计上重新引入 physics

建议按以下优先级，不再直接恢复当前 `BC+quasi-steady PDE, lambda=1`：

1. **DATA + continuity**：先回答不可压缩约束是否能在不伤害 `u,v,w,p` 的情况下带来增益；
2. **瞬态动量分两条互斥路线，不得混写**：
   - 2A：从相邻 CFD 时相预计算 `du/dt` 作为已知源项；这是标签依赖的 physics-informed supervision，便宜但不属于部署时自洽 physics；
   - 2B：建立 phase/time-conditioned 稀疏多时相模型，由 autograd 得到 `du/dt`；这是新的时序路线，需单独数据合同、route ID 和预注册，不与单时相 Stage 1–3 混训；
3. **弱形式/VPINN**：在 2A 或 2B 的瞬态定义闭环后，把空间导数转移到测试函数；弱形式只能缓解空间二阶导数问题，不能自动补回缺失的时间项；
4. **一阶混合形式**：额外预测应力/梯度辅助量，用一阶关系替代直接对 `u` 做二阶 strong-form 求导。

动态权重只能在以上方程定义合格后使用，并且必须记录：

- data/continuity/momentum/BC 的梯度范数；
- `cos(data, continuity)`、`cos(data, momentum)` 和 `cos(data, BC)` 的直接测量，不再由总 PDE 反推 momentum；
- 动态权重的时序和夹紧比例；
- `u,v,w,p` 场值、工程积分量和 independent-collocation physics 的 Pareto 变化。

## 6. 最小实验矩阵与 Go/No-Go

### 6.1 开发矩阵

| 阶段 | 实验 | 目的 | 是否使用 PDE |
| --- | --- | --- | --- |
| S0-a | case-balanced 选模标量 / B0 atlas / 探针入库 | 修复选模并建立零训练下界 | 否 |
| S0-b | outlet 双路径 / inlet-wall / wall-zone Gate | 闭环可部署边界合同 | 否 |
| S1 | B0 + G-Raw / G-PE / L-Raw / L-PE | 分离患者条件、局部性与 PE | 否 |
| S2 | 最佳表征 × 无/有可部署 BC input | 验证条件可辨识性 | 否 |
| S3 | 基线/分层/分头 decoder/流量与压降辅助 | 优化 `u,v,w,p` 多任务重建 | 否 |
| S4 | DATA / +continuity / +source-term transient 或 time-conditioned transient | 验证物理增量 | 是 |

### 6.2 进入正式确认的必要条件

1. 数据合同无边界重叠、无未分类 wall zone、无 monitor/boundary 混写。
2. 新 query decoder 通过制造场的场值、一阶和二阶导数收敛测试。
3. checkpoint、early stopping 和 seed 内排序只使用冻结的 `S_field^cb`；不得用 pooled R²、test35、physics residual 或 WSS 反选。
4. 开发增量在病例配对 CI、多 seed 和队列分层上同时可接受；不得只报 pooled R²；B0 atlas 必须作为永久零训练对照。
5. 使用的 BC input 在真实部署时可获得；否则只能标记 oracle。
6. 任一通道或工程积分量的改善不能以其他关键通道、困难区域或某个队列明显恶化为代价。
7. physics 增量必须在 independent collocation 上改善物理指标，同时通过预注册的 `u,v,w,p` 等效或优越 Gate。
8. 正式确认不再依赖已用于开发的 test35；无外部 lockbox 时使用 nested outer split。
9. WSS 不参与训练、early stopping、checkpoint 选择或架构排序；只允许对冻结主模型做一次下游审计。WSS audit 失败可以阻止下游可靠性声明，但不能触发 WSS 算法调参或在同一轮重选 checkpoint。

### 6.3 建议的停止条件

- 局部条件和 PE 在多 seed 下都无增量：停止继续加解码器复杂度，转向缺失 BC/标签分辨率。
- overall speed 改善但 `u/v/w` 方向、near-wall、流量或 `p` 压降稳定恶化：判为不通过，不用单一聚合指标覆盖结构性失败。
- 加入瞬态/弱形式 physics 后 residual 降低但 `u,v,w,p` 稳定恶化：将 physics 降级为诊断指标，不再作主训练目标。
- 相同几何的多 BC CFD 反事实实验显示网络不响应 BC：不得宣称是 patient-specific conditional surrogate。

## 7. 优先级结论

| 优先级 | 动作 | 原因 |
| --- | --- | --- |
| **P0-1** | 实现 `S_field^cb`、修 validation 聚合、加入 B0 atlas、锁死 test35 exposure | 没有唯一选模标量和零训练基线，任何新架构增益都不可解释 |
| **P0-2** | 工程化 outlet UDF/CFD 双路径与 inlet-wall/wall-zone Gate | 使 Stage 2 的 BC 输入和监督有真实来源链 |
| **P0-3** | 把制造解、导数、atlas、latent、gap、support 和梯度探针入库 | 将新增 B 级测量变成可复现证据 |
| **P0-4** | 按 B0 → G/L-Raw → G/L-PE 执行无 PDE 表征实验 | 优先验证患者特异/局部条件，再低优先级检查 PE 与交互 |
| **P1-1** | 输入可部署 `Q(t)/phase/RCR`，并做同几何多 BC 验证 | 解决映射不适定和因果可辨识性 |
| **P1-2** | 分层采样 + `u/v/w` 与 `p` 分头解码 + 流量/压降辅助 | 解决四通道尺度、区域难度和共享表示冲突 |
| **P2** | 在最佳监督场上先测 continuity，再分开 source-term transient 与 time-conditioned transient | 先闭环时间项定义，再考虑 weak form 和动态权重 |
| **P3** | 外部 lockbox/新队列确认 | 使新结果恢复确认性证据等级 |

**不建议的顺序**：直接实现“PointNet++ 多尺度 Gaussian + FiLM + Fourier + 分层采样 + 动态 PDE + residual floor”并一次训练。这会把至少六个机制混在一起，无论成功或失败都无法形成可发表的科学归因。

## 9. 最终裁决

1. **当前 V3 可作为历史基线，不应续训到 5000 epoch。**
2. **下一轮第一件事是 Stage 0-a：实现病例等权 `S_field^cb`、修 validation 聚合、工程化 B0 atlas 与诊断证据；不是换更大模型。**
3. **B0 病例盲群体场必须永久进入主表。局部条件是高优先级轴；PE/Fourier 因 bulk B 级证据降为低优先级，但仍通过带限 2×2 检查交互，不允许先验宣判无效。**
4. **出口 monitor 已有强 B 级证据表明不同于真实 pressure-outlet face；它不得再称为 exact BC 或可部署输入。真实 face pressure 的恢复路径可执行，但必须先工程化全库 Gate。**
5. **当前 quasi-steady momentum 的负增量不证明“物理无用”，只证明当前方程、权重、目标和数据组合 No-Go。**
6. **当前唯一优化主线是 `u,v,w,p`；不能再用 full-volume speed R² 代表全部场质量，必须同时约束分量、区域、流量、pressure gauge/梯度和压降。**
7. **Profile-Secant V3 冻结为下游验证器：不再调算法，不加入 WSS loss，不用 WSS 反选模型；仅在 `u,v,w,p` 主 checkpoint 冻结后做 sanity check。**
8. **本文科学设计冻结为 v1.0。后续只允许因 Stage 0 Gate 不可实现或新增入库反证而修改；普通训练结果不得事后改指标、阶段顺序或 Go/No-Go。**

### 10.3 两版都缺失的零训练测量

#### 10.3.1 bulk 真值平滑性 —— 高频表达不是首要假设的 B 级证据

对 CFD 真值做 k-NN 局部平均（一个**已知空间分辨率**的预测器），6 个 test 病例 case-balanced：

| k | 有效半径 (mm) | speed R² | u R² | v R² | w R² | 预测/真值方差比 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 8 | 0.61 | 0.9116 | 0.9496 | 0.9455 | 0.9262 | 0.839 |
| 32 | 0.98 | 0.8831 | 0.9334 | 0.9296 | 0.8975 | 0.793 |
| 128 | 1.59 | 0.8041 | 0.8892 | 0.8783 | 0.8298 | 0.712 |
| 512 | 2.70 | 0.6891 | 0.8234 | 0.8048 | 0.7218 | 0.632 |
| 2048 | **4.81** | **0.5806** | 0.7498 | 0.7310 | 0.6119 | **0.575** |
| — | 实测 E5 | **0.2336** | — | — | — | **0.19–0.38**（README） |

**结论**：一个空间上粗到 4.81 mm 的预测器就能达到 speed R² 0.58，而训练模型只有 0.23，
且其方差保留率（0.19–0.38）**低于** 4.81 mm 平滑器（0.575）。
若瓶颈是空间带宽，模型应落在这条曲线上；它落在曲线**下方很远**。

因此：positional/Fourier 编码在 bulk 的先验优先级应下降。但该预测器读取了目标病例
自身 CFD 真值邻域，只证明真值可被平滑，不证明网络能从现有输入恢复该场，也不能排除
PE 对优化、局部条件交互或 near-wall 的作用。冻结路线保留带限 PE 消融，不将其当首发变量。

> **限制**：k-NN 平均在壁面处按构造违反 no-slip（把核心区速度拉进近壁），
> 因此它对 **near-wall** 是偏悲观的代理，不能用来论证“near-wall R² 本质病态”。
> 该表的 bulk 结论不受影响（近壁点仅占 3.5%–5.6%）。

#### 10.3.2 跨病例群体场基线 —— 建议作为下一轮的第一号对照

用 40 个 **train** 病例的注册坐标点云做 k-NN 平均，预测 test 病例的速度
（除坐标外**不使用目标病例的任何信息**）：

| K | speed R²_cb | 方差比 |
| ---: | ---: | ---: |
| 16 | −0.1588 | 0.406 |
| 64 | −0.0788 | 0.341 |
| 256 | −0.0206 | 0.270 |

原始 R² 受幅值影响，用相关与偏相关分离“结构”和“幅值”（6 个 test 病例，speed）：

| 量 | 值 |
| --- | ---: |
| `corr(truth, 模型 E5)` | +0.4623 → 允许仿射缩放的 R² **0.2488** |
| `corr(truth, 群体场 K=256)` | +0.4264 → 允许仿射缩放的 R² **0.2115** |
| **`corr(模型, 群体场)`** | **+0.7566** |
| 偏相关 `corr(truth, 模型 \| 群体场)` | **+0.2373** |
| 偏相关 `corr(truth, 群体场 \| 模型)` | +0.0917 |

**读法**：V3 最佳臂的输出与一个**完全病例盲**的注册解剖平均场相关 0.757；
在允许最优仿射缩放的口径下，它比该基线只高 **0.037**。
模型确实学到了病例特异结构（偏相关 0.237，且群体场对模型残差只剩 0.092），
但其表观技能的**主体是群体解剖先验，而非患者特异血流动力学**。

推论（供交叉论证）：

1. 这个基线**必须永久进入指标表**。否则 0.23 → 0.30 的改善无法与“更好的解剖先验”区分。
2. 修订版 Stage 1 必须同时报告相对群体场的逐病例增量；但 checkpoint 主读数仍是预注册
   `S_field^cb`。偏相关/增量 R² 是机制诊断，不得用 eval truth 拟合仿射缩放后参与选模。
3. 六臂中最稳健的 geom 增量（+0.19 R²_cb）**可能主要是解剖先验分量**。这可直接检验：
   geom 提高的是偏相关（病例特异部分）还是群体对齐部分。
4. 这与修订版 §1.1“缺少条件导致多解映射”的判断一致，并给出了量化幅度。

> **限制**：6 test 病例、40 train 病例、K=256、单臂（E5）、仅 speed。
> 建议工程化为全 test35 × 六臂 × `u/v/w/p` 的标准基线后再作正式结论。

#### 10.3.3 当前 V3 checkpoint 的 support 重采样稳定性

同一 checkpoint、5 组独立 5000 support、同一批 6000 query（6 个 test 病例）：

| 量 | 值 |
| --- | ---: |
| 跨 seed 预测 std / 预测自身空间 std | **0.017** |
| 跨 seed 预测 std / 真值 std | **0.007** |
| 单 seed speed R² → 5 seed 平均后 | +0.1765 → +0.1766（增益 **+0.0001**） |

**对当前 V3 global max-pool checkpoint，support-sampling variance 不是主要贡献因素。**
该结论不能外推到未来 FPS、局部核或多尺度 encoder；新局部架构仍需保留重采样 Gate。

#### 10.3.4 梯度余弦 —— 竞争是真的，momentum 被高度怀疑

修订版 §P1-2 正确指出范数不含方向。实测（`xyz+geom/DATA+BC+PDE`，3 个不同 epoch 的 batch）：

| | `cos(∇data, ∇PDE)` | `cos(∇data, ∇continuity)` | `cos(∇data, ∇BC)` |
| --- | ---: | ---: | ---: |
| 随机初始化 | +0.0928 | +0.0520 | −0.0205 |
| `best_validation_data` | **−0.3991**（逐 batch −0.392 / −0.360 / −0.445） | **+0.0523** | −0.0591 |

**结论**：
1. 训练后 PDE 梯度与 data 梯度**强反向**，跨 batch 一致 → “竞争”不是范数假象；
2. 但 **continuity 单独始终为正（+0.05）**，两个阶段都不与 data 冲突；
3. 因此 PDE 组的反向高度指向 momentum，但在直接测量
   `cos(grad data, grad momentum)` 前不能写成“只来自 momentum”。这仍足以支持 Stage 4
   先 `DATA + continuity`、再处理动量的排序。

#### 10.3.5 IDW 二阶导数：修正措辞，保留结论

沿一条 3NN 邻居集只切换 1 次的探测线（长度 0.1，401 个探针）：

| | d²/ds² 取值范围 | 相邻探针最大跳变 |
| --- | --- | ---: |
| 固定邻居集区间内（372/401 点） | [−3.094, 27.664] | 0.1279 |
| 整条线（含 1 次切换） | [−5.174, 27.664] | 0.1279 |
| 解析真值 | [−0.507, 0.270] | — |

**修订版正确**：固定邻居集内二阶导数存在、有界、无不连续。
**但结论不变**：即便在这段最干净的区间里，其量级也偏离真值约 **73×**。
正确表述是“IDW 二阶导数存在但有巨大系统性偏差”，不是“不存在”。

### 10.4 出口压力链：强 B 级证据与可执行恢复路径

修订版 §P0-3 把“gap 由面位置差引起”列为待确认。现有资产表明该 Gate 很可能可从已导出
日志和 CFD 场直接完成，不需要重跑 Fluent；但在全库解析脚本和逐例报告入库前仍不是 A 级。

关键发现：Fluent 主日志 `Global_conditions/Fluent_*.out` 中含 UDF
`DEFINE_EXECUTE_AT_END` 的 `Message()` 输出，逐时间步记录了**真正
pressure-outlet 面**上的 `P_ave_out*`（面积平均静压）与 `Q_ave_out*`。
`DING_JUN_FENG` 共 81,984 行（1281 时间步 × 并行分区），去重后 1281 步。

`DING_JUN_FENG` @ `step 1162`（peak）四个出口：

| 出口 | ① UDF `P_ave`（边界面积平均静压） | ② CFD 场出口面静压 | ①−② | ③ 重建的 RCR profile `P_n` | ④ **V3 实际使用的 monitor** | ④−① |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| out-le | 12848.20 | 12856.37 | **−8.17** | 13000.19 | 13914.03 | **+1065.83** |
| out-li | 13609.80 | 13614.77 | **−4.97** | 13409.70 | 14131.88 | **+522.08** |
| out-re | 12333.72 | 12336.07 | **−2.35** | 12321.19 | 12682.07 | **+348.35** |
| out-ri | 12497.61 | 12500.67 | **−3.07** | 12488.31 | 12846.31 | **+348.70** |

（③ 由 `P_n = ((R1+R2+R1β)Q_n + βP_{n−1} − R1βQ_{n−1})/(1+β)`、`β = R2·C/Δt` 重建，
RCR 常数取自该例 UDF；流量自洽性校验：`Q_out-le = 0.04831 kg/s → 4.56e−5 m³/s`，
入口峰值 `10.73e−5 m³/s`，占比 42%，与几何/速度估计一致。）

**结论**：

1. 代表病例中两条独立路径互证：UDF 记录的边界面积平均静压与 CFD 场在出口平面的静压
   吻合到 **2–8 Pa（0.02%–0.07%）**。这证明“从标签场恢复 outlet face pressure”
   在该例可行；是否全库等价必须由 Stage 0-b 逐例 Gate 决定。
2. 代表病例中 V3 使用的 monitor 与 pressure-outlet face 明显不是同一压力量，前者高
   348–1066 Pa，四个出口方向一致；这为机制提供强证据，但全库结案仍需工程化 Gate。
3. 全库可行性普查（173 例）：**171 例**有 >1 MB 的 Fluent 主日志，**168 例**日志含
   `P_ave_out*` 打印，**173/173** 的 UDF 含 4 组完整 `R1/R2/C`。
   5 个例外：`AG/fast/WANG_YONG_FAN`、`AG/fast/ZHANG_XIU_ZHEN`（无大日志），
   `AG/slow/LI_BING_YI`、`ILO/LIU_YUE_DONG-0/before`、`ILO/LI_SHENG_WEN-0/before`（日志无 `P_ave`）。
   这 5 例可用标签场路径覆盖；168 例可做双路径一致性。`≤20 Pa` 只保留为探针阶段建议，
   不进入冻结 Gate；正式阈值由 train-only 分布确定。

冻结路线据此把“恢复真实出口 pressure”定义为可执行的 Stage 0-b 解析任务，并把双路径
一致性写入 boundary Gate；阈值由 train-only 分布冻结，不沿用代表病例直接定常数。
`R1/R2/C` 是当前明确可在 CFD 求解前获得的优先出口条件候选；monitor 压力不是。

### 10.5 已合并到主路线的三项冻结修正

#### 修正 1：Stage 0 按依赖分层，成本跨度约两个数量级

Stage 0 内部混杂了 5 行改动与需要重建整套网格拓扑资产的任务。建议显式分层：

| 层 | 内容 | 量级 | 是否阻塞 |
| --- | --- | --- | --- |
| S0-a | 修 validation 聚合；把一次性探针写成测试；加群体场基线到指标表 | 低 | 阻塞 Stage 1 |
| S0-b | 出口双路径重建 + 一致性 Gate（§10.4）；入口/壁面交线与 wall-zone 审计 | 单个解析脚本 | 阻塞 Stage 2/BC，不阻塞 Stage 1 |
| S0-c | `interior_dist_to_wall`、区域标签和工程积分资产 | 中等 | 阻塞 Stage 3 |
| S0-d | cell volume / face connectivity / 分支归属全套恢复 | 大，需解析 `.cas.gz` 多面体拓扑 | **否**，不应阻塞 Stage 1 |

S0-d 的 cell volume 有低成本替代：用局部点密度（k-NN 半径立方的倒数）构造每条记录的
等效体积权重，先把“记录等权 vs 体积等权”的差异**量化**，再决定是否值得做完整拓扑恢复。

#### 修正 2：PE 轴降权，并增加 B0 群体场基线

修订版 Stage 1 用 `{全局/局部条件} × {raw/PE}`。按 §10.3.1，bulk 真值平滑性使 PE
作为首要修复的先验价值下降，但没有证明 PE 无效。冻结设计为：

- **保留 2×2**（PE 与局部性可能有交互，值得一测），但
- **必须增加第 5 行：跨病例群体场基线**（零训练，几分钟），并且
- checkpoint 主读数固定为 `S_field^cb`；同时报告相对群体场的逐病例增量和病例级机制诊断。

否则四个臂即使全部“改善”，也无法排除“只是更好的解剖先验”。

#### 修正 3：Stage 4.2 显式拆分标签源项与时相条件模型

“使用相邻时相构建 `du/dt`”在当前架构下不可直接实现：网络只预测单个时相，
`∂u/∂t` **无法由 autograd 得到**。两条路必须显式选择：

- **(i) 把 `du/dt` 作为 CFD 派生的已知源项**：残差变成标签依赖项，
  按修订版 §1.2 的分类它属于 **supervision**，不是部署时可施加的 physics。可行、便宜，但必须声明。
- **(ii) 把网络改为时相条件化**，监督多个时相 → `∂u/∂t` 由 autograd 得到，残差自洽，
  并且**同时补上 §1.1 指出的时相/条件缺失**。科学上更强。

(ii) 的数据成本（实测）：每例 81 个时间步；单例 `ascii_in` 目录 **5.6 GB**；
`data_new` 总量 **4.3 TB**。因此稠密全时相不可行，但**稀疏时相子集**
（例如每例 5–9 个时相 × 降采样点）是可审计候选；正式启动前仍需单独核算 I/O、
派生存储、时相覆盖和训练预算，不能仅凭单例目录大小宣称已可行。

### 10.7 本轮仍未回答的问题

1. 群体场基线的结论只在 speed、单臂、6 例上成立；必须先扩到完整 validation / nested outer split 的 `u/v/w/p` 主表；test35 只能保留 exploratory screen。
2. geom 的 +0.19 增量究竟落在“群体解剖先验”还是“病例特异分量”上，未分离。
3. k-NN 平均是读取目标病例真值的特定平滑 oracle，只能称为“可达到的平滑参考”，
   不是网络表示能力的理论天花板；它只支持降低 bulk PE 优先级。
4. 近壁的正确度量仍未确定。k-NN oracle 因违反 no-slip 而不能用于近壁定性；
   建议改用**壁法向切向速度剖面斜率**（这是 `u,v,w` 场的属性，不是 WSS，未越范围锁定）。
5. `cos(∇data, ∇momentum)` 未单独测量，动量归因是由 continuity 的 +0.05 反推的。
