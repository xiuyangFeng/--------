## 1. 科学问题

1. **TAWSS**：用部署配方（X5D_v51，27 维部署可得输入）直接回归周期平均 |τ|，在 log 空间能否至少达到峰值帧的水平，在 Pa 空间能否超过「峰值预测 × 波形」这个不训练就有的基线？
2. **OSI**：方向反转的周期积分量能否直接从几何回归到可交付（OSI > 0.1 / > 0.3 掩膜、低 TAWSS ∧ 高 OSI 滞留区）？必须超过「峰值预测的单调映射」这个自由基线，否则 OSI 只是 TAWSS 的换皮。
3. **单模型多头**：峰值 + TAWSS + OSI 一次输出，峰值帧是否不受损（≤ 0.02）？只在 1、2 过门后问。
4. **对照组合部署**：X5D 峰值 + T0 离峰帧拼出的周期曲线算 TAWSS，是否被直接回归超过？超过则组合路线关闭。

OSI 需要向量，但**本矩阵不做向量时间基头（原阶段 2b）**：OSI 本身是周期积分标量，直接回归比先重建 81 帧向量再积分少一层误差；2b 只在 OSI 直接回归失败时再议。

## 2. 冻结的数据与定义

| 项 | 合同 |
|---|---|
| 数据 | v5.1 视图 `data_wss_v5/views_v5_1/wss_min_view_v1/`，170 例，train136 / test34，筛选用 `cv3_v51/fold{0,1,2}.json`（患者分组，重复几何同折）；test34 只作锁定确认 |
| 标签源 | 视图 `bundle.npz` 的 `wall_wss_vec` (81, N, 3)（源 case.h5 `wall_temporal/`）。不新跑 CFD |
| 周期定义 | 帧 0…79（步 1120…1278）各权 1/80。帧 80（步 1280）= 帧 0 + T（T = 0.8 s，`q_norm[80] − q_norm[0] = 0`），81 帧等权会把相位 0 记两次；周期收敛时 1/80 等权与 [0, T] 梯形积分等价，未收敛时只用本周期不混入下一周期 |
| TAWSS | `(1/80) Σ_k ‖τ⃗_k‖`，Pa |
| OSI | `0.5 · (1 − ‖Σ_k τ⃗_k‖ / Σ_k ‖τ⃗_k‖)`，∈ [0, 0.5]，无量纲 |
| RRT | `1 / ((1 − 2·OSI) · TAWSS)`，只报不训 |
| rev_frac | 与峰值帧方向反向（τ⃗_k·τ⃗_peak < 0）的帧份额，诊断标签，不作目标不作输入 |
| 目标空间 | TAWSS：`ln(max(TAWSS, 0.05 Pa) + eps)` 再 z-score，统计量只用训练折（镜像 `wss_global_stats_*` 结构，新文件 `cycle_stats_{train136,fold0,fold1,fold2}.json`）。OSI 两种（阶段 1 单一变量对照）：`osi_linear` = 线性 z-score，输出裁到 [0, 0.5]；`osi_logit` = `logit(clip(2·OSI, 1e-3, 1−1e-3))` 再 z-score |
| 输入 | X5D_v51 的 27 维逐位不变；不加 RCR / 患者波形 / 任何真值派生量 |
| 统计 | 特征 z-score、目标统计量、ckpt 选择全部只用当前训练折 |
| 评估口径 | 病例等权 R²_cb 为主，归一化空间与物理空间并列（与工作簿一致）；新增阈值掩膜 IoU（§7） |
| 周期审计 | 每例记录 `mean|τ⃗_80 − τ⃗_0| / mean‖τ⃗‖`，> 5% 标记「周期未收敛」（5 例抽查 2 例 14–16%，3 例逐位相同）；**不剔除**，只做敏感性重算 |
| 工程 | 配置驱动、默认关闭、旧配置逐位不变；改完重评 `X5D_v51_s1234` best，metrics.json 逐字段 ≤ 1.5e-5；在新冻结副本执行，队列指纹预检 |

### 阶段 1 判据（预注册，三折折外均值 + 折间符号）

| 门 | 条件 |
|---|---|
| **G1.1** TAWSS 对峰值帧 | A1 归一化 R²_cb ≥ 同折 X5D_v51 峰值帧归一化 R²_cb **− 0.02**（时间均值不比峰值帧难学；c0 证据预期 ≥ +0.0） |
| **G1.2** TAWSS 对自由基线 | A1 物理 TAWSS R²_cb ≥ max(TAWSS-null, TAWSS-ratio) **+ 0.05**，3/3 折同向；低 TAWSS（< 0.4 Pa）掩膜 IoU 不劣于基线 |
| **G2.1** OSI 有效 | 线性 OSI R²_cb > 0 且逐例 R² 中位 > 0，3/3 折 |
| **G2.2** OSI 对自由基线 | OSI > 0.1 掩膜 IoU ≥ OSI-null **+ 0.05**，3/3 折同向；OSI > 0.3 IoU 与 Spearman 报出 |
| **G2.3** OSI 面积标定 | 逐例 |pred − true| 的 OSI > 0.1 面积份额中位 ≤ 5 个百分点（防止「全场抹平」骗 R²） |
| **G3** 滞留区 | A1 + 胜出 O 的滞留区（TAWSS < 0.4 ∧ OSI > 0.1）IoU ≥ 基线组合（TAWSS-null + OSI-null）**+ 0.05**，2/3 折同向 |
| **G4** 组合路线 | 若 B1 执行：A1 的 TAWSS ≥ B1 − 0.01 → 组合路线关闭；否则记录 B1 作为周期曲线备选 |

胜出规则：O1 默认胜出；O2 只有在 OSI > 0.1 IoU 与 R²_cb 同时 > +0.01 且 3/3 折同向才取代。敏感性：所有门在「剔除周期未收敛例」的子集上重算一次，只报不判。

## 7. 评估口径（冻结）

主指标病例等权；归一化与物理空间并列；分队列 AG / AAA / ILO。

| 目标 | 指标 |
|---|---|
| TAWSS | log-z 与 Pa 的 R²_cb、逐例均值 / 中位 / p10、负例数、MAE、Spearman、`r2_linear_fit` + 斜率（型态 vs 幅值分开看，§30.6 教训）、高 TAWSS top10 IoU（现有 hotspot 机制）、**低 TAWSS < 0.4 Pa 掩膜 IoU**（面积权） |
| OSI | 线性 OSI 的 R²_cb、逐例 R²、MAE、Spearman；**OSI > 0.1 / > 0.3 掩膜 IoU**（面积权）；逐例面积份额标定误差；`r2_linear_fit` + 斜率 |
| 组合 | 滞留区（TAWSS < 0.4 ∧ OSI > 0.1）IoU、面积份额误差；RRT R²（只报） |
| 诊断 | rev_frac 与预测 OSI 的 Spearman；周期未收敛例子集敏感性 |

不用：81 帧逐帧 R²、pooled R²、NMAE_range 单独作证据（§30.6：对型态不敏感）。

**2026-09-21 补充（用户裁定：TAWSS / OSI 加落地一致性指标，WSS 峰值帧线仍用 R² / NMAE 口径）**：`evaluate.py` 对 `target ∈ {tawss, osi}` 额外输出 `result["cycle_agreement"]`（`eval.cycle_agreement=True` 默认；`cycle_rel_tolerance=0.3`、`cycle_min_segment_points=200`、`cycle_osi_rel_floor=0.01`），字段：逐例 Lin CCC（TAWSS 在 ln(max(y,0.05)) 空间、OSI 线性）、逐点相对误差中位与 ≤ 30% 份额、top10% 热点 Dice、阈值掩膜 Dice + 真值/预测面积份额、按语义血管段（bundle `wall_semantic_id`，trunk / 左右 CIA / 四末支，≥ 200 点）的段均值相对误差（逐例中位与最差段）；病例级 Bland–Altman（病例均值取相对差、掩膜面积份额取绝对差：偏差、95% 一致性界、病例级 CCC）。逐例明细在 `per_case`。实现 `metrics.lin_ccc / dice_masks / cycle_agreement_case_metrics / cycle_agreement_aggregate`，`tests/test_cycle_targets.py` 11 项，全套测试通过；旧目标输出逐位不变。

### 12.2 判读

1. **周期平均 TAWSS 和峰值帧一样好学，且已经是一个可部署输出。** 归一化 R²_cb 0.858 对同折峰值 0.854、Pa 0.716 对峰值 0.713，三折都持平或略高；与 §30.8 的 c0 证据一致。对自由基线，A1 在每个折、每个指标上都赢（Pa +0.012/+0.025/+0.023，log +0.11/+0.10/+0.14，低 TAWSS IoU +0.11/+0.15/+0.17）。
2. **G1.2 之所以不过，是 Pa 口径被高值尾部主导。** TAWSS 真值最大 131 Pa；fold1 一例极端尾部把 Pa 拉到 0.654 而 log 仍 0.863。基线「峰值预测 × 波形」本来就带着峰值帧的尾部型态，所以在 Pa 上它已经不差（0.696），直接回归的增益全部在中低值区（log +0.118、低 TAWSS 掩膜 +0.094）。预注册时把 G1.2 定在 Pa，没有预见到这一点——按规则记 **FAIL**，不事后改门；但要说明「FAIL」的含义是「Pa 上没比 T-null 高出 0.05」，不是「TAWSS 学不好」。
3. **OSI 有超出单调映射的真实信号，但 0.1 掩膜不灵敏。** R²_cb +0.11、Spearman +0.08、OSI > 0.3 IoU 0.25 对 0（单调映射根本到不了 0.3），滞留区 IoU +0.10 三折同向。OSI > 0.1 IoU 只 +0.02 的原因：0.1 恰在 OSI 分布中位（训练折中位 0.095，> 0.1 面积 49%），真值与预测在阈值附近都很密，掩膜 IoU 对这一档几乎不区分模型。O1 高预测面积（0.552 对 0.493，G2.3 FAIL），O2 的 logit 目标空间把面积份额标定到 0.030（PASS），R² 低 0.026；按预注册胜出规则 O2 不能取代 O1（IoU/R² 都不 > +0.01），但 O1 又不过 G2.3——OSI 线没有胜出臂。
