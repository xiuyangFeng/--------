1. **物理关系**：WSS = μ ∂u_t/∂n，OSI 是壁面剪切向量方向随时间翻转的积分量，所以 OSI 由**近壁速度的方向历史**完全决定（CFD 速度 → WSS 0.965，§27）；压力只通过逆压梯度间接驱动近壁反向（Womersley，§30.10 图 C），壁面压力的空间型态本身对 OSI 信息很弱。12 例真值：Spearman(OSI, 周期均值壁压) 中位 **+0.45**（瘤腔滞止区压力高、流弱），但去掉 ln TAWSS 的三次式后残差与壁压相关 **−0.05**，即压力对 OSI 的信息完全被 TAWSS 覆盖；壁压脉动幅值与 OSI 相关 0.01。
2. **文献 OSI 口径与精度**（2026-09-23 核对）：Rygiel 2025 AAA（LaB-GATr，21 帧向量 WSS 派生）OSI **MAE 0.064 / approximation disparity 0.381**（交叉验证）、外部集 0.048 / 0.298，snapshot NMAE 0.18 / 0.14，并明说「OSI 量化方向变化、本质上捕捉湍动型态，比 TAWSS 难」；Graph transformer 颅内动脉瘤脉动流（arXiv 2601.19876，直接预测 WSS 不经速度）OSI 常规相对 L2 **68%**、修正 rL2* 5.3%、SSIM 0.74，「派生场比 CFD 更平滑」；In-PI-MGN（npj Digit Med 2026，体场滚动再派生）OSI 只报相关系数图与三档阈值分类，承认「低 TAWSS 区近壁方向的微小波动让 OSI 失准，训练目标偏向整体流场而非边界层」；Gharleghi 2022 冠脉分叉瞬态 WSS 归一化偏差 < 5%，无 OSI 数。**我们**：O1 单 seed test34 pooled approximation disparity **0.47–0.48**、MAE 0.064、NMAE(÷range) 0.13，三 seed 集成 R² 0.573 / CCC 0.73 / > 0.3 IoU 0.27——MAE 与 Rygiel 交叉验证持平，disparity 高 0.09（数据集不同：他们 100 例 CT AAA 无髂支细分，我们 170 例三队列含髂内外）；文献没有人报 OSI 掩膜 IoU，我们的 > 0.3 IoU 0.27 与 IA 论文「派生场更平滑」是同一现象。
3. **思路评估（体场辅助头 + 周期量）**：代码上 `velocity_pressure` 联合模式只覆盖体场（PointNet++ 3+1 头、query 并集 + 逐任务掩膜），壁面周期量走 `wss_cycle_multi` 三通道头，两者未打通；打通 = query 并集扩到「壁面 ∪ 内部」+ 五任务掩膜 + 多通道统计量，约 1–2 天代码（配置驱动可做），训练成本约 2 倍。机理上不看好：(a) 上面第 1 条，压力对 OSI 无独立信息；(b) 速度场周期内近乎自相似（§31 peak_freeze ≈ T-null），峰值速度头学不到谷底反向；(c) 预测速度 → WSS 0.547 远低于直接 0.717（§27），近壁速度正是预测最差的地方；(d) 文献里体场优先派生的路线（In-PI-MGN）OSI 反而更差，直接预测壁面量的路线更好；(e) 本项目里体场和壁面之间已验证的迁移只有「几何先验 → 体场」（F6 接体场 +0.045 / +0.027），没有反向证据。**建议先做零训练探针再决定**：用已有 cv3 折外 `PF6_v51 / VF6_v51` 预测（`runs/volume_time_20260919/*_f*/eval/ckpt_best/predictions/`，部署可得）取壁面预测压力与最近内部点预测速度，作为附加特征与 17 维几何 + Murray 先验一起喂给轻量点级回归器拟合 OSI（训练折拟合、留出折读），对比几何-only：若 OSI R² 增量 < +0.02 或 > 0.3 IoU 增量 < +0.03，则不开联合训练。
4. 更值得先做的仍是 §34.9 的 1–3 项（异构集成 + 阈值校准、rev_frac 辅助头 + 掩膜损失、分离相关几何特征）。
5. **Rygiel 2025 是向量口径（2026-09-23 核对）**：网络每个顶点输出 21 个时刻的 **3D WSS 向量**（τ ∈ ℝ^{T×|P|×3}），TAWSS = 时间平均 ‖τ‖、OSI = ½(1 − ‖Στ‖/(T·TAWSS)) 都从预测向量序列派生、无独立头；瞬态 WSS 的 MAE / NMAE / disparity 都按向量差的欧氏范数算（LaB-GATr 交叉验证 MAE 0.267 Pa、disparity 0.567、余弦 0.657；外部集 0.296 / 0.513 / 0.684）。我们直接回归标量 |τ|，峰值帧 pooled 标量 disparity 三折 0.444 / 0.536 / 0.453，T0 的 81 帧 pooled 标量 disparity 0.515（TB8 0.567）。**两者不可直接比**：向量误差 ≥ 幅值误差（‖a−b‖ ≥ |‖a‖−‖b‖|），且他们 21 帧全周期 pooled、我们峰值单帧或标量；标量数只是他们向量数的下界。TAWSS / OSI 两个标量派生量的 disparity 才是同口径可比的（我们 TAWSS 0.31–0.35 对 0.33–0.39、OSI 0.45–0.48 对 0.30–0.38）。若要同口径比瞬态 WSS，只有做 2b 向量头。
