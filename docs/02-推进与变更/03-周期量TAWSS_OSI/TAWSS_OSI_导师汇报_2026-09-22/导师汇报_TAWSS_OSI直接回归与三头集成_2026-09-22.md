## 1. 为什么要直接回归 TAWSS / OSI

**临床要的是周期量。** 落地报告要给 TAWSS（周期平均壁面切应力）、OSI（振荡剪切指数）和由它们定义的「滞留区」（低 TAWSS 且高 OSI），而不是单一峰值帧的 WSS。

**逐帧追全周期已被证明不可行。** 09-18 的全周期时间线（矩阵 [偏心与全周期](../../02-时间建模/_archive/阶段文档_2026-09-30/WSS_V5_偏心与全周期时间实验矩阵_2026-09-18.md)）里，时间条件模型只有峰值附近好学，减速期谷底 R² 掉到 0.17（图 1）。09-21 的逐帧指标套件把原因定位在惯性滞后与回流：谷底帧的真值与几何的相关本身就低，不是幅值或噪声问题。所以「先重建 81 帧再积分」这条路的误差会被谷底帧拖累。

**但周期均值反而稳定。** 同一批实验里，时间基臂的周期均值分量 c0 三折 R² 0.79 / 0.81 / 0.80，远高于峰值帧的 0.62 和谷底的 0.27。周期积分量是把 80 帧平均掉的量，逐帧的难点被平均掉了。这就是直接回归 TAWSS 的依据。

![图 1 动机](figures/fig01_motivation_frame_r2.png)

**图 1.** 上：入口流量波形；下：逐帧 WSS 时间条件模型 T0 的三折折外 R²_cb 随时间的变化。峰值帧 0.70，减速期谷底 0.17。绿色虚线是周期均值分量 c0 的 R²（0.80），直接回归 TAWSS 就是在赌这条线。

**OSI 为什么要设一个「自由基线」。** 170 例真值里，OSI 与 ln TAWSS 的逐例 Spearman 中位 −0.76：流弱的地方 OSI 高（图 2a）。所以一个只会「把峰值预测单调映射成 OSI」的东西就能拿到不错的分数。要证明 OSI 直接回归有价值，必须超过这个不用训练的基线（OSI-null，训练折上的等渗回归）。TAWSS 同理，设两个基线：TAWSS-null（峰值预测 × 训练折平均波形，再按 80 帧积分）和 TAWSS-ratio（峰值预测 × 常数 0.317）。

![图 2 标签结构](figures/fig02_label_structure.png)

**图 2.** (a) 170 例真值的 OSI 对 ln TAWSS 联合分布，橙线为分箱中位。(b) 临床关注区域在三队列的壁面面积份额：OSI > 0.1 占约一半壁面，OSI > 0.3 占 10–14%，滞留区在 AAA 占 29%、AG 只占 8%。

**标签怎么来。** 不新跑 CFD。从 v5.1 视图的 81 帧壁面剪切向量派生：帧 0–79 各权 1/80（帧 80 = 帧 0 + T，81 帧等权会把相位 0 记两次）。TAWSS = 周期平均 |τ|，OSI = 0.5·(1 − |Στ| / Σ|τ|) ∈ [0, 0.5]。41 例周期未完全收敛（帧 80 与帧 0 差 > 5%），只标记做敏感性，不剔除。

**输入合同不变。** 与已部署峰值模型 X5D_v51 完全相同的 27 维部署可得输入（壁面点云 + 中心线派生几何 + Murray 分流先验），不加 RCR、患者波形或任何真值派生量。

### 3.1 G1.2 为什么不过：Pa 口径被极端高值尾部主导

TAWSS 真值最大 131 Pa，fold1 一例极端尾部把 Pa R² 拉到 0.654 而 ln 空间仍 0.863。基线「峰值预测 × 波形」本身带着峰值帧的尾部型态，所以在 Pa 上它已经不差；直接回归的增益全在中低值区（ln +0.118、低 TAWSS 掩膜 +0.094）。预注册时把 G1.2 定在 Pa 空间，没有预见这一点。**按规则记 FAIL、不事后改门**，但它的含义是「Pa 上没比基线高 0.05」，不是「TAWSS 学不好」。test34 上的尾部分解（图 4a）证实了这个判断。

### 3.2 G2.2 为什么不过：0.1 恰好落在 OSI 分布中位

训练折 OSI 中位 0.095，OSI > 0.1 占 49% 壁面。真值和预测在阈值附近都很密，掩膜 IoU 对这一档几乎不区分模型。离线换阈值重算（图 5）：0.1 档增益只 +0.02；0.2 档 +0.077 已过 +0.05；0.25 以上单调映射的 IoU 为 0（映射根本到不了那个值域）而模型仍有 0.25–0.38。**这不改变 G2.2 的 FAIL 记录**，但说明 OSI 掩膜门若要有区分度应设在 0.2 或按分位。

### 3.3 O1 与 O2 没有胜出臂

O1（线性目标）R² 高 0.026 但系统性高估 OSI > 0.1 面积（+6 pp，G2.3 FAIL）；O2（logit 目标）面积标定好（3 pp）但 R² 低。两者 IoU 差在 seed 噪声内，按预注册胜出规则 O2 不能取代 O1，O1 又不过 G2.3。

### 3.4 按规则的处置与用户裁定

预注册规则：G1 与 G2 不同时通过 → M1 不开；A1 不过 G1 → B1 组合评估臂不执行；无胜出臂 → 阶段 3 不开。**所有后续都没有自动提交**，把四个选项（推进 A1 / 事后改门 / OSI 换阈值 / 全部收口）交用户拍板。09-21 用户裁定「GPU 空闲就做实验确定想法」，于是阶段 3 与 M1 在同一授权下开启，目的是**验证 §3.1–3.2 的判断而不是重新选模**。

**图 15.** 真实队列上 TAWSS 相对 L2 我们 0.31（test34）/ 0.35（折外）对 Rygiel 0.33–0.39，持平到略好；OSI 0.45 / 0.48 对 0.30–0.38，落后。MAE 受幅值影响不可直接比（我们均值 1.28 Pa，含髂动脉射流；Rygiel 只到髂动脉 5 cm）。

怎么说：
1. **TAWSS 是有竞争力的**：真实队列、不输入患者流量、部署只要壁面点云 + 中心线，相对 L2 好于最接近的真实 AAA 工作；分段误差中位 8.6% 与 Griffo 2026 在 1078 支真实冠脉上的血管均值误差 23.6% 相比也不差（粒度不同，只作参照）。
2. **OSI 是全网最难的周期量**（Rygiel：高流量时退化最大；Sheng：rL2 68%；Garnier：「精度更低」），我们也一样。不做逐点数值主张，主张的是掩膜级交付（> 0.3 区、滞留区 IoU 0.56）。
3. **两条没人做的证据**：直接回归周期量对「峰值 × 波形」自由基线的定量比较（文献只做重建 → 积分，从不跟这个基线比）；三头单模型不伤峰值的预注册门。
4. **短板**：test34 是开发期反复读过的集合（本轮只读一次，但历史上已用于选峰值模型）；缺同协议外部基线（LaB-GATr / GEM-GCN）与真实分割面验证；OSI 落后。
