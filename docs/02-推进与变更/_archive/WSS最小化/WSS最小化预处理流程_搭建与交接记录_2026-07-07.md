## 1. 目标（老师口径）
- 只做一个目标：几何 → **WSS**，网络输入默认 `x,y,z`、输出 `wss`，**单头**（不再多头）。
- 点数从原 13000 壁面 + 2000 近壁 大幅减少：壁面可配 **1500 / 2000 / 3000** 可扫。
- 严格顺序：**先解剖配准 / 正交化 / 标准化，最后才稀疏化**。
- **保留**全部几何特征，后续用 mask 决定是否喂进网络（不删数据）。
- 时间步**一次性全做**（81 步）；样本装配默认取**峰值收缩期**单样本，可切全相位（后续要每一相位都预测准）。
- 预留第二条路径：近壁点 → 预测速度 → 算子 → WSS（数据已备，改配置即可）。

## 2. 已确认决策
| 项 | 选择 |
|---|---|
| 解剖配准 | **v2 分叉原点版**：VTP 中心线 `DistToBifurcation≈0` 分叉区域→原点；入口端→分叉 trunk 主轴对齐 +Z；分叉后远端分支平面固定横轴；缺 VTP 拓扑时自动退回几何中心/曲率平面，`det(R)=+1` |
| 坐标标准化 | 逐病例 各向同性缩放到 [-1,1]（保形，视角一致） |
| WSS 标准化 | 全局 `log_z`（近似对数正态），覆盖全部时间步 |
| 数据范围 | `AG/fast`(25) + `AG/slow`(62) |
| 时间步 | 全做；样本默认峰值收缩期（由 `vf-in` 入口波形定位），可切 `all` |
| 单位 | 逐病例自动从中心线包围盒反推 mesh→mm 因子；异常标记待复核 |

## 3. 原始数据结构（核实）
每病例（如 `data_new/AG/fast/CHEN_SHI_MING/`）：
- `ascii/<case>-<t>`：壁面节点，含 `wall-shear`(+ 分量) —— WSS 来源
- `ascii_in/<case>-<t>`：内部 cell，含 velocity —— 第二条路径速度来源
- `centerline/centerline_points.csv`：单条有序中心线（abscissa 0→L，毫米）
- `Global_conditions/vf-in-rfile.out`：入口流量波形 → 峰值收缩期
- 坐标在 81 个时间步内**静态**（已核实），故几何/配准/掩码只算一次，场值按时间步堆叠。

## 4. 代码结构（pipeline_wss_min/）
- `config.py` —— 所有开关（**扫实验主要改 `SampleConfig`**）
- `raw_io.py` —— 读 ascii（**自动探测逗号/空白分隔符**）、centerline、波形；**文件名前缀回退匹配**
- `registration.py` —— 中心线主导刚性配准（正交基 + det=+1，矢量同步旋转）
- `preprocess.py` —— 每病例：校验 → 单位统一 → 配准 → 归一化 → 掩码 → 堆叠时间步 → `bundle.npz` + `report.json`
- `global_stats.py` —— 第二遍全局 WSS 统计
- `build_samples.py` —— **归一化后**稀疏化（FPS/random）+ 样本装配（配置驱动）
- `reporting.py` —— 日志 / 每病例报告 / 批量审计
- `run.py` —— CLI 编排；`README.md` —— 详细说明

## 10.6 解剖原点版配准 v2（2026-07-07 追加）

目标：进一步响应“同一坐标轴 / 同一视角 / 血管基本朝向一致”的导师口径，避免仅以壁面重心作为原点造成分叉区域在不同病例中上下漂移。

本次算法升级：

- **原点**：默认 `RegistrationConfig.center_on="bifurcation"`，从 `centerline/centerline.vtp` 读取 `DistToBifurcation`，取分叉附近中心线点均值作为解剖原点；若 VTP 或数组不可用，自动退回旧的几何中心策略。
- **主轴**：默认 `main_axis_mode="inlet_to_bifurcation"`，用中心线 abscissa 起始端到分叉点的 trunk 方向对齐 +Z；这样主干在 `z<0`，分叉/出口在 `z≈0~正值`。
- **横轴 / roll**：默认 `roll_source="branches"`，使用分叉后远端中心线点在垂直 trunk 平面内的主方向固定横轴；缺分支信息时退回曲率平面。
- **追踪字段**：每例 `bundle.npz` 与 `report.json` 新增 `transform_origin_kind` / `origin_kind`、`transform_main_axis_mode` / `main_axis_mode`、`transform_roll_source` / `roll_source`，批量审计 CSV 同步记录，便于发现 fallback 病例。

坐标 QA 产物：

- `outputs/wss_min/alignment_viz_anatomical_v2/01_before_after_overlay.png`
- `outputs/wss_min/alignment_viz_anatomical_v2/02_aligned_ortho_overlay.png`
- `outputs/wss_min/alignment_viz_anatomical_v2/03_aligned_small_multiples.png`
- `outputs/wss_min/coord_check_20260707_anatomical_v2/coord_check_summary.csv`
- `outputs/wss_min/coord_check_20260707_anatomical_v2/front_view_page*.png`
- `outputs/wss_min/coord_check_20260707_anatomical_v2/top_view_page*.png`

验证结果：

- `split_AG_wss_min_v1` included **81 例**全部处理完成。
- `origin_kind=bifurcation`、`main_axis_mode=inlet_to_bifurcation`、`roll_source=branches`，无 fallback。
- `unit_anomaly=0`；`rotation_det=1.000000`；最大正交误差约 `3e-16`。
- 新图中分叉原点位于红线交点附近，主干统一向下，分叉/出口统一向上，整体朝向比旧“壁面重心原点”更符合解剖坐标。

## 10.8 P0/P1：LR 复核口径统一 + 主轴壁面 PCA 兜底（2026-07-08 追加）

目标：继续收敛“同一原点、同一视角、基本朝向一致”的数据处理前置条件，优先修复会影响后续 `x,y,z -> wss` 的坐标问题，而不是进入训练侧调参。

本次核心修复：

- **LR 复核图口径统一**：`visualize_lr_check.py` 改为复用正式配准里的 `_select_wall_branch_side()`，对分叉两侧各自计算横断面双峰分离度，取更像双髂支的一侧。这样复核图与 preprocess 使用同一套逻辑，避免单侧取样造成“某例全蓝/全红”的假象。
- **QA 默认应用病例 override**：`visualize_lr_check.py`、`coord_check.py`、`visualize_alignment.py`、`visualize_stl_point_overlap.py` 均走 `registration_for_case()`；做旧口径对照时，显式传 `--roll-source/--roll-sign-mode`。
- **主轴壁面 PCA fallback**：默认仍用中心线入口端→分叉点 trunk 弦向；若该弦向无法清楚区分“单主干侧/双髂支侧”，则用壁面点云 PCA 长轴兜底，并让双髂支侧落在 +Z。该逻辑主要修复中心线端点缺主干或落在分支导致的主轴倾斜。
- **审计字段补充**：`bundle.npz`、`report.json`、批量审计新增 `main_axis_source`、`main_axis_wall_sep_delta`，用于识别 `centerline_chord` / `wall_pca_fallback` / `centerline_chord_ambiguous`。

## 10.11 P4：主干横向二次居中（2026-07-08 追加）
