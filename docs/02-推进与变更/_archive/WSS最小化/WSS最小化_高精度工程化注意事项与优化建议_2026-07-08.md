## 1. 核心判断

老师提出的“输入简化为 `x,y,z`，输出单一 `wss`，通过严格坐标规整和少量点提高精度”的方向是合理的，尤其适合当前 WSS 预测精度不足时作为独立主线推进。

这个方向合理的前提不是“点越少越好”，而是：

1. 多病例必须被放到同一个解剖坐标框架中。
2. WSS 目标必须用一致、可逆、train-only 的统计方式归一化。
3. 稀疏采样必须发生在完整几何完成配准和标准化之后。
4. 训练、验证、测试、反归一化、可视化必须共享同一套 manifest 和元数据。
5. 最终指标必须回到物理 WSS 单位后计算，而不是只看归一化空间 loss。

如果这些工程条件成立，`x,y,z -> wss` 可以先被视为“统一解剖坐标系下的壁面 WSS 标量场拟合”。这条路线的优势是目标清晰、训练稳定、可解释性强、后处理链路更容易闭环。

需要谨慎的是：如果模型取得很高 R2，不一定说明它学到了完整流体物理，也可能学到了统一坐标系下的平均 WSS 热力图。因此必须设置模板基线和局部区域评估，判断模型是否真正超越坐标模板。

## 3. 高精度工程化的成功标准

正式训练前建议明确以下验收标准：

1. **可复现**：给定 split、采样方式、点数和 seed，可以重建完全一致的训练样本。
2. **可逆**：任意预测点都能从归一化坐标回到原始 CFD / STL 表面位置。
3. **可评价**：所有主要指标都能在反归一化后的物理 WSS 单位上计算。
4. **可视化**：预测 WSS 可以回插到完整壁面或 STL 面片，生成 CFD / Pred / Error 热力图。
5. **可解释**：能区分整体区域、分叉区域、高曲率区域、高 WSS 区域、低 WSS 区域的误差。
6. **可对照**：至少有模板基线、MLP/PointNet/GNN 基线、不同采样点数、不同采样策略的对照。

如果只得到一个整体 R2，而没有反归一化、回插和区域评估，这个结果不适合作为工程化高精度结论。

## 4. 数据与预处理注意事项

### 4.1 必须先用完整原始 CFD 做规整

推荐顺序：

1. 读取完整壁面点云和中心线。
2. 校验原始坐标单位和 WSS 量级。
3. 使用完整几何做分叉原点、主轴、roll 的刚性配准。
4. 做坐标标准化。
5. 保存完整壁面点的 `wall_coords_norm`、原始坐标、刚性变换和 scale。
6. 在标准化后的完整壁面点上采样。

不要先采样再做配准。少量点不足以稳定估计解剖主轴、分叉平面、局部扩张和弯曲方向，容易让不同病例落入不一致坐标框架。

### 4.2 节点顺序必须显式校验

当前 `read_wall_fields`（`raw_io.py:91-99`）只按行序取 `wall-shear`，从不读 `nodenumber`；`preprocess.py:185-190` 把每个时间步的 WSS 直接按行堆叠成 `wss_ts`。源码注释虽写“坐标静态（已核实）”，但读取期**没有任何逐时间步的对齐守卫**——一旦某病例某步导出行序不同（Fluent 重排、部分节点缺失、分隔符切换导致的错行），错位不会报错，只会静默污染目标。正式工程化时建议：

- 保存参考时间步（如峰值步）的 `nodenumber` 数组到 bundle。
- 每个时间步读取后，先比对 `nodenumber` 与参考一致；不一致则按 `nodenumber` 重排后再取值。
- 若某病例时间步节点集合（长度或集合）不一致，直接报错或标记为异常并写入审计。
- 便宜的兜底自检：抽查同病例相邻时间步的坐标列是否逐行相等（坐标本应静态），不等即报警。

这是高精度任务中的 P0 风险。节点错位会把目标变成噪声，少点采样时单点权重更大、影响更甚。

### 4.3 单位异常和物理异常要固定剔除口径

需要固定一份 denylist / excluded list，不要随着实验临时变化。

`split_AG_wss_min_v1.json` 已固化如下清单，正式流程应直接引用它，不要在脚本里另写一份：

- excluded（6）：`fast/PENG_JI_MING`（单位和 CFD 物理量级异常）、`slow/LIU_XI_QUAN`、`slow/WEI_JUN_WEN`、`slow/TE_JIN_WANG`（缺 WSS 或 WSS 全零）、`slow/LIN_SHU_TIAN`（几何离群）、`slow/NIE_QUAN_ZHONG`（WSS-min 坐标/STL QA 异常）。
- pending（1）：`slow/ZHAO_XIU_XUAN`（未分配到 `split_AG_v1` 任一名单，暂不纳入，评估后再定）。

**当前口径**：`global_stats.compute_global_wss_stats` 默认读取 split 的 `train_cases` 白名单；`build_samples` 默认只装配 train/val/test included 病例。只有显式 `--all-raw` 才扫描原始 cohort 目录。旧 bundle 即使仍在磁盘上，也不会进入默认 WSS 统计或样本 manifest。

建议所有训练、统计、可视化和汇总都从同一份 split / manifest 读取病例清单，形成单一事实源。

### 4.4 每个样本应保存足够的反变换元数据

为了后续可视化和回插，样本或 manifest 中建议至少保存：

- `case`
- `cohort`
- `step`
- `sample_idx`：稀疏点对应完整壁面点索引
- `coords`：归一化坐标
- `coords_raw` 或可由 `sample_idx` 回查完整原始坐标
- `coord_scale`
- `unit_factor`
- `transform_centroid`
- `transform_rotation`
- `origin_kind`
- `main_axis_mode`
- `roll_source`
- `wss_norm_method`
- `wss_mean`
- `wss_std`
- `wss_eps`
- `split_version`
- `sampling_method`
- `n_points`
- `seed`

如果这些元数据缺失，训练可以跑，但预测结果很难工程化回到原始血管表面。

## 5. 归一化策略

### 5.1 坐标归一化

当前主线是逐病例各向同性 `max_abs` 缩放到大致 `[-1,1]`。

优点：

- 多病例几何落在统一数值范围。
- 模型训练稳定。
- 对只输入 `x,y,z` 的路线很友好。

风险：

- 绝对血管尺寸被弱化。
- 如果 WSS 与真实尺度、半径、入口流量相关，纯 `x,y,z` 可能碰到上限。
- 高 R2 可能部分来自“统一模板坐标”，不一定表示真实物理外推能力强。

建议正式对照：

1. `xyz`
2. `xyz + coord_scale`
3. `xyz + local_radius`
4. `xyz + abscissa_norm + local_radius`
5. `xyz + coord_scale + local_radius + abscissa_norm`

如果 `coord_scale` 或 `local_radius` 显著提升测试集 R2，说明纯坐标丢失了关键尺度信息，正式工程模型应纳入这些轻量特征。

### 5.2 WSS 目标归一化

建议主线继续使用全局 `log_z`，但必须改成 **train-only 统计**。

推荐公式：

```text
y = (log(wss + eps) - mean_train_log_wss) / std_train_log_wss
```

反归一化：

```text
log_wss_pred = y_pred * std_train_log_wss + mean_train_log_wss
wss_pred = exp(log_wss_pred) - eps
wss_pred = max(wss_pred, 0)
```

注意事项：

- `mean/std` 只能由训练集计算，且**要显式排除 excluded/pending 与单位异常病例**（否则如 §4.3 所述，异常量级会污染 `mean/std`）。当前 `global_stats.py` 未做这两层过滤，是首要改点。
- 统计应在“采样之前的完整壁面点”上累积，而不是在稀疏样本上算——否则不同点数/采样策略会各自得到一套统计，破坏可比性。当前 `global_stats` 在 `bundle.npz` 全量壁面点上累积，这点是对的，改 train-only 时保持该粒度。
- peak-only 实验最好使用 peak-only train 统计。
- all-phase 实验最好使用 all-phase train 统计。
- 不建议把 peak-only 和 all-phase 共用一套统计后直接比较。
- 不建议正式主线使用 per-case WSS 标准化，因为它会抹掉病例间绝对 WSS 量级，影响工程应用。
- 如果极端值影响过大，可测试 `log1p`、percentile clip 后 `log_z`、robust z-score，但必须在训练集上确定参数。

### 5.3 评估必须回到物理单位

训练 loss 可以在归一化空间中看，但主要汇报应使用反归一化后的物理 WSS：

- RMSE_WSS
- MAE_WSS
- R2_WSS
- MAPE 或相对误差，注意低 WSS 区域会不稳定
- 高 WSS 区域 top 5% / 10% 的 RMSE、MAE、R2
- 分病例 R2 / RMSE
- 分区域指标：主干、分叉、分支、高曲率、低半径区域

如果归一化空间 loss 下降，但物理单位误差没有改善，应以后者为准。

## 6. 采样方法建议

### 6.1 采样发生的位置

采样必须发生在：

```text
完整壁面点云 -> 单位统一 -> 解剖配准 -> 坐标标准化 -> 稀疏采样
```

不要在原始坐标或未配准坐标上采样后再训练。

### 6.2 候选采样方法

#### 1. 全局 FPS

当前默认方法，适合作为 clean baseline。

优点：

- 覆盖均匀。
- 可复现。
- 对点数扫描友好。

缺点：

- 不一定照顾高 WSS 区域、分叉区域和高曲率区域。
- 对局部峰值可能欠采样。

建议扫描点数：

- 1000
- 1500
- 2000
- 3000
- 5000

#### 2. Random

作为 baseline，不建议作为最终主线。

作用：

- 判断 FPS 的增益。
- 检查模型是否对采样扰动敏感。

#### 3. 分段 / 分支分层 FPS

按中心线 `abscissa_norm` 或分支区域分桶，每个区域内做 FPS。

优势：

- 防止大面积区域占据过多采样预算。
- 保证入口、主干、分叉、分支都有稳定覆盖。

建议方式：

```text
按 abscissa_norm 分成 K 段，每段至少采 n_min 点，剩余点按表面积或点数比例分配
```

如果能可靠区分主干和两条分支，优先使用分支分层。

#### 4. 面积加权采样

如果 STL 面片可用，建议按三角面片面积做 surface sampling，再映射到最近壁面节点。

优势：

- 减少原始 CFD 节点密度不均造成的偏差。
- 更符合真实表面面积分布。

注意：

- 需要保存面片到节点的映射关系。
- 需要确认 STL 与 CFD 壁面点一一或近似对应。

#### 5. 曲率 / 半径突变增强采样

对高曲率、半径快速变化、分叉附近区域提高采样比例。

优势：

- 更关注 WSS 梯度可能较大的区域。
- 对峰值 WSS 和局部误差更有帮助。

注意：

- 使用几何特征增强采样可以作为正式方法，因为不直接使用 WSS 标签。
- `curvature` 如果有端点尖峰，需要 clip 或使用 percentile 阈值。

#### 6. 混合采样

推荐作为工程候选：

```text
70% 全局 FPS
20% 分叉/高曲率/半径突变区域
10% random 或局部补点
```

这种策略比纯 FPS 更关注关键区域，又不会完全牺牲全局覆盖。

#### 7. WSS-aware 采样

使用真实 WSS 高值区域提高采样概率。

建议定位：

- 只作为 oracle / 上限实验。
- 不作为正式主线，避免被质疑使用标签信息造成采样泄漏。

如果最终工程部署时推理阶段没有真实 WSS，就不应依赖 WSS-aware 采样。

### 6.3 采样策略需要固定 metadata

每个 sample set 必须记录：

- 采样方法
- 点数
- seed
- 采样索引
- 是否分层
- 分层字段
- 是否使用几何增强
- 是否使用标签信息

否则不同实验难以复现和横向比较。

## 7. 正式训练注意事项

### 7.1 Split 和统计

正式训练必须满足：

- 病例级 split，不能点级随机拆分。
- train/val/test 不共享病例。
- WSS target 归一化统计只使用 train cases。
- 坐标配准和坐标 scale 是逐病例几何操作，可以对所有病例独立计算，但目标统计不能混入 val/test。
- excluded cases 和 pending cases 必须固定。

### 7.1.1 小样本统计的脆弱性（容易被忽视）

当前只有 test 16 例、val 8 例。这带来两个必须正视的问题：

- **单一划分的方差大**：per-case R2 中位数在 16 例上抖动明显，换个 seed / 换几例可能让结论翻转。正式对照（尤其是“深度模型是否超过模板基线”“点数拐点”这类结论）建议至少报告 **5-fold 或 repeated split 的均值 ± 标准差**，而不是单点数字；单一 split 仅用于快速迭代。
- **val 8 例做早停不稳**：8 例的验证 physical RMSE 容易被一两个难例主导，early-stop 可能选到偶然点。建议同时看 val 的 per-case 分布，必要时对多个 checkpoint 在 test 上复核趋势一致性（注意别把 test 用于选模，只做趋势健全性检查）。
- 报告结论时明确写清“基于单一 split_AG_wss_min_v1，n_test=16”，避免把小样本点估计当作稳定精度。

### 7.2 模型从简单开始

建议顺序：

1. 模板基线：训练集统一坐标下的 KNN / RBF / voxel 平均 WSS 场。
2. MLP：只输入 `x,y,z`，确认单点坐标函数上限。
3. PointNet / PointNeXt：学习点集上下文。
4. GraphSAGE / GNN：如果需要局部邻域结构，再加图。
5. 局部 patch 模型：如果高 WSS 区域仍差，再考虑 patch / local attention。

不要一开始直接上复杂模型。高精度问题首先要确认数据链路和采样是否干净。

### 7.3 必须设置模板基线

模板基线非常重要，用来回答：

> 只要把病例配准到统一坐标系，训练集平均 WSS 热力图本身能达到多少 R2？

建议模板基线：

- 在训练集归一化坐标中建立 KNN 插值器。
- 输入测试点 `x,y,z`，输出训练集中邻近点的平均 `log_wss`。
- 也可做 voxel grid / RBF / Gaussian kernel baseline。

如果深度模型只比模板基线略好，说明模型主要学习的是空间平均模板。

如果深度模型明显超过模板基线，才更能说明模型学到了更复杂的几何分布规律。

### 7.4 Loss 设计

主线建议：

- `MSE` 或 `SmoothL1` on normalized log-WSS。
- 指标汇报在 physical WSS。

可选增强：

- 高 WSS 区域加权 loss，但要谨慎，最好只用训练集标签定义。
- 分叉区域几何加权 loss，可作为工程优化。
- Huber / SmoothL1 减少极端值影响。
- 多尺度 loss：全局点 + 局部高曲率区域。

不建议过早使用复杂组合 loss。先得到 clean baseline 后再加权。

### 7.5 验证和早停

早停指标建议优先：

1. validation physical RMSE_WSS
2. validation physical R2_WSS
3. high-WSS region MAE / RMSE
4. normalized loss

如果只用 normalized loss 早停，可能选到物理空间表现不最优的 checkpoint。

## 8. 反归一化与可视化闭环

### 8.1 标量 WSS 反归一化

模型输出 `y_pred_norm` 后：

```text
log_wss_pred = y_pred_norm * std_log_train + mean_log_train
wss_pred = exp(log_wss_pred) - eps
wss_pred = clip(wss_pred, 0, +inf)
```

真值 `y_raw` 应该直接保存原始 WSS，用于检查反归一化是否正确。

建议写一个独立的 round-trip QA：

```text
y_raw -> normalize -> inverse_normalize -> y_raw_recovered
```

要求误差接近数值精度。

### 8.2 坐标反变换

如果需要把预测点从归一化坐标回到原始 CFD 坐标：

```text
aligned  = coords_norm * coord_scale
world_mm = aligned @ rotation.T + centroid     # 与 registration.TransformResult.inverse() 一致
native   = world_mm / unit_factor
```

这与前向 `coords_new = (pts - centroid) @ R`、`coords_norm = aligned_mm / scale`、`world_mm = native * unit_factor` 严格互逆（`registration.py:38-46`、`preprocess.py:154`）。**注意**：`rotation`、`centroid`、`unit_factor` 目前只在 `bundle.npz`，样本里只有 `coord_scale`（见 §0 核对表）——要么把这三项也写进样本/manifest，要么评估脚本按 `case` 回读 bundle，否则反变换会跨文件手工拼装、易错。

实际可视化更推荐保存 `sample_idx`，直接在完整壁面数组中回查原始点，绕过整条反变换链，误差最小。

### 8.3 稀疏点到完整壁面的回插

如果模型只预测 2000 个点，而后续可视化需要完整表面：

候选方法：

1. 最近邻回插：简单快速，但可能块状明显。
2. KNN 加权回插：推荐 baseline，使用归一化坐标或原始 mm 坐标。
3. 面片插值：如果 STL face 可用，更适合生成连续表面。
4. 图拉普拉斯平滑：用于减少插值噪声，但不能过度平滑高 WSS 峰值。
5. 直接全点推理：如果模型支持完整壁面输入，推理阶段可对所有 wall points 预测，避免回插误差。

工程上最推荐：

- 训练用稀疏点。
- 推理可对完整壁面点分批预测。
- 如果显存不够，再用 KNN 回插。

### 8.4 可视化必须固定色标

用于对比的图应包含：

- CFD WSS
- Pred WSS
- Absolute Error
- Relative Error

注意：

- CFD 和 Pred 必须使用同一色标。
- Error 使用单独色标。
- 每个病例最好保存同一视角的 PNG。
- 汇总图使用统一色标或按 percentile 色标，并在图注说明。

## 9. 评估指标建议

**先固定几条口径，避免同名指标算法不一致**：

- R2 一律在**物理 WSS 线性空间**报告主结论（`R2 = 1 - SS_res/SS_tot`）。如果额外看 log 空间 R2，必须注明空间，两者不可混比。
- 线性空间 R2 会被少数高 WSS 点主导（平方项放大），所以**必须搭配 log 空间指标和分区域指标**才完整——单看线性 R2 容易高估低 WSS 区表现。
- 聚合方式要写清是 **point-pooled（所有点拼一起）** 还是 **per-case 再平均**：point-pooled 会被点多的病例主导（§9 末已强调），主结论建议用 per-case 中位数/均值。
- MAPE / 相对误差在低 WSS 区分母趋零会爆，报告时设一个 WSS 下限阈值或改用 top-k 区域的相对误差。

整体指标：

- `R2_WSS`（物理线性空间）
- `RMSE_WSS`
- `MAE_WSS`
- `Pearson/Spearman`
- normalized loss（仅作训练监控，不作主结论）

分病例指标：

- 每病例 R2、RMSE、MAE。
- 箱线图或 violin plot。
- 标记最差病例。

分区域指标：

- 主干区域。
- 分叉区域。
- 分支区域。
- 高曲率区域。
- 小半径区域。
- 高 WSS top 5% / 10% 区域。
- 低 WSS 区域。

可视化指标：

- CFD / Pred / Error 三联图。
- 高误差区域定位。
- 分病例散点图。
- 误差 CDF。

最终主结论建议使用：

```text
test physical R2_WSS / RMSE_WSS / high-WSS top10% MAE / per-case median R2
```

不要只使用全局点级 R2，因为点数多的病例会主导结果。

## 10. 推荐实验矩阵

### 10.1 第一阶段：验证数据链路

目的：确认预处理、采样、归一化、反归一化、可视化闭环正确。

实验：

1. 单病例 overfit：2000 点，确认 loss 能接近 0。
2. 5 病例小训练：检查 split、loader、反归一化。
3. round-trip QA：WSS normalize/inverse normalize 误差。
4. sparse -> full surface 回插 QA。

通过标准：

- 单病例可过拟合。
- 反归一化无明显偏差。
- 可视化回插位置正确。

### 10.2 第二阶段：clean baseline

实验：

1. 模板 KNN baseline。
2. MLP `xyz -> wss`。
3. PointNet / PointNeXt `xyz -> wss`。
4. FPS 2000 点。
5. train-only peak `log_z`。

目的：

- 判断只靠坐标的真实上限。
- 判断深度模型是否超过模板基线。

### 10.3 第三阶段：点数扫描

固定模型和归一化，扫描：

- 1000
- 1500
- 2000
- 3000
- 5000

指标：

- test R2_WSS
- per-case median R2
- high-WSS top10% MAE
- 推理时间
- 可视化质量

目标：

- 找到精度和计算成本的拐点。

### 10.4 第四阶段：采样策略扫描

固定点数，例如 2000 或 3000，对比：

- random
- global FPS
- abscissa 分层 FPS
- branch 分层 FPS
- area-weighted
- geometry-boosted mixed sampling
- WSS-aware oracle

正式推荐只从非标签采样策略中选主线。

### 10.5 第五阶段：特征消融

对比：

- `xyz`
- `xyz + coord_scale`
- `xyz + local_radius`
- `xyz + abscissa_norm`
- `xyz + local_radius + abscissa_norm`
- `xyz + coord_scale + local_radius + abscissa_norm`

目的：

- 判断纯坐标是否足够。
- 判断是否需要保留最小几何特征来突破精度上限。

### 10.6 第六阶段：全相位

peak-only 做通后，再切到 all-phase。

需要注意：

- all-phase 应有自己的 train-only WSS 统计。
- 输入如果仍只有 `x,y,z`，不同时间步同一点会对应不同 WSS，模型无法区分相位。
- all-phase 若要预测每一相位，至少需要加入时间或入口流量特征。

建议 all-phase 输入：

```text
x, y, z, phase 或 inlet_flow
```

否则同一坐标多时间步多标签，会造成任务本身不可辨识。

## 11.5 数据泄漏与“虚高精度”自检清单

高精度主张最怕的不是模型不够强，而是精度虚高。汇报前逐条过一遍：

- [ ] WSS `mean/std` 只用 train_cases 算，且排除 excluded/pending/单位异常（当前 `global_stats` 未做，见 §0）。
- [ ] 坐标归一化逐病例独立，未跨病例共享统计（当前 OK）。
- [ ] 采样不使用真实 WSS 标签（WSS-aware 仅作 oracle 上限，不进主线，见 §6.2-7）。
- [ ] 早停/选模只用 val，不碰 test；test 仅在最终评估用一次。
- [ ] peak-only 与 all-phase 各用各的 train 统计，不交叉比较（见 §5.2）。
- [ ] R2 高时，与模板 KNN 基线对照，确认不是只学了统一坐标系下的平均热力图（见 §7.3）。
- [ ] 主结论用 per-case 聚合而非 point-pooled，避免点多病例主导（见 §9）。
- [ ] 结论标注单一 split、n_test=16 的小样本前提；关键结论给 k-fold 均值±方差（见 §7.1.1）。
- [ ] round-trip QA（normalize→inverse）误差接近数值精度（见 §8.1）。
- [ ] 反变换/回插用样本自带元数据或按 case 回读 bundle，无跨文件手工拼装错配（见 §8.2）。

## 13. 当前建议的主线决策

短期最推荐的主线（顺序即优先级，**P0 未清零之前不要开始正式训练/汇报精度**）：

**第一步——先修 §0 的四个 P0（阻塞项，训练前必须全部完成）**

1. `global_stats` 改 train-only：已接收 split 的 `train_cases` 白名单，同时排除 excluded 6 + pending 1 + 单位异常病例。
2. 样本 payload 存 `sample_idx`（稀疏点→完整壁面点索引）+ 反变换元数据（`transform_centroid/rotation`、`unit_factor`、`coord_scale`、WSS 统计、`split_version`、`seed`、`sampling_method`、`n_points`）。
3. 多时间步 WSS 读取按 `nodenumber` 校验/重排，堆叠前加坐标静态自检守卫。
4. 补 `inverse_normalize` 公共函数 + round-trip 单元测试（误差需接近数值精度）。

**第二步——P0 清零后再进入训练与对照**

5. 固定 `training/splits/split_AG_wss_min_v1.json`（train 56 / val 8 / test 16），只用 train_cases 算统计、只用 included cases 训练。
6. 使用 train-only peak `log_z`，采样先用 FPS 2000。
7. 建立模板 KNN baseline（回答“统一坐标平均热力图能到多少 R2”）。
8. 训练 MLP / PointNet clean baseline。
9. 反归一化到原始 WSS 后评估（物理线性空间 + per-case + 分区域），生成 CFD / Pred / Error 可视化。
10. 再扫点数和采样策略；最后做 `xyz` 与轻量几何特征消融，关键结论给 k-fold 均值±方差。

一句话结论：

> 这条路线要想做到工程化高精度，关键不是先换大模型，而是把完整几何规整、train-only 归一化、可逆元数据、合理采样、物理单位评估和表面回插可视化做成一条闭环。闭环稳定后，再讨论模型复杂度才有意义。
