## 3. 当前 VMTK 主线的主要薄弱点

### 3.1 表面版本选择和中心线提取是分离的

`pipeline/extract_features.py` 在提取阶段按文件名/首个候选寻找表面；`pipeline_wss_min` 后续又根据 CFD 壁面包围盒重新选择权威 STL。多 STL 病例可能出现：

1. VMTK 在 STL-A 上提取中心线；
2. bundle 根据 CFD 匹配选择 STL-B；
3. 后续把 STL-A 的中心线特征映射到 STL-B/CFD 壁面。

`YANG_YU_QING-1` 就是该故障模式。

### 3.2 单位推断依赖中心线长度，存在循环依赖

中心线覆盖不足、端点不贴开口或选择了错误 STL 时，会直接改变壁面单位因子；单位错误又会放大中心线—壁面距离。这会把“中心线问题”和“单位问题”互相污染。

### 3.3 入口按世界坐标 `max Z` 选择

`detect_all_openings()` 把开口中心 Z 最大者作为入口。只要原始病例方向不同或发生坐标轴交换，就可能把髂支当入口。入口选择应由开口面积、主干解剖结构和 CFD inlet zone 共同确定，不能依赖世界 Z。

### 3.4 小开口固定按点数过滤

当前开口环少于 10 个点就丢弃。这个阈值与网格分辨率绑定，不与实际开口面积或周长绑定，可能漏掉低分辨率小分支。

### 3.5 `LargestRegion` 清洗可能误删有效支路

`clean_centerline()` 剪裁后只保留最大连通域。如果某个有效 outlet path 因数值问题暂时断开，它会被静默删除，最终只留下主干和部分分支。

### 3.6 只运行一次 VMTK，没有失败重试策略

`XIE_JIN_QUAN` 的目标未到达是可识别错误，但当前流程没有针对单目标重新提取、种子内移、表面轻度修复或参数重试。

### 3.7 几何导数没有按拓扑路径计算

当前切线、曲率和扭率直接对 VTK 原始点数组做 `np.gradient`。VTK 点数组不是一条严格的有序序列，分叉处还同时包含多条路径，因此这些导数可能跨分支相减，产生虚假的大曲率/扭率。

### 3.8 `BranchId` 只有二值语义

当前 `BranchId={0,1}` 只能表达主干/下游分支，不能区分四个出口。工程模型若需要沿每条分支编码，必须提供稳定的 `OutletId` 或 `PathId`。

## 4. 建议的 VMTK Centerline V2 流程

### 阶段 A：先冻结权威表面和单位

1. 从同一病例顶层收集全部 STL；
2. 使用 Fluent 壁面与 STL 的包围盒中心、三轴跨度、最近邻距离联合选择权威版本；
3. 单位优先从 STL↔Fluent 匹配推断，不再从中心线长度推断；
4. 生成 `surface_selection.json`，记录候选、评分、单位、哈希；
5. 中心线提取只允许读取 manifest 中冻结的权威 STL。

这一步应在 VMTK 前完成，中心线不能参与权威表面和基础单位的决定。

### 阶段 B：表面拓扑预检

正式提取前强制检查：

- 表面连通域数为 1；
- 非流形边为 0；
- 开口环数量符合预期，本队列应为 5；
- 每个开口面积、等效半径和法向可计算；
- 不允许异常微小孔洞被当作 outlet；
- 必要时只做可追溯的 clean、triangle、轻度平滑或局部修孔。

预检失败时不能直接进入训练数据生产。

### 阶段 C：稳健入口/出口识别

入口推荐按以下优先级确定：

1. Fluent inlet zone 的几何中心；
2. 已冻结的边界标签；
3. 最大开口面积 + 主干长度/分叉结构联合判别；
4. 世界轴只作最后兜底，不能作为默认规则。

出口必须保留全部其余合法开口，并给出稳定 `OutletId`。种子点建议从开口中心沿内法向内移 `0.25–0.5 × 等效半径`，避免种子恰落在边界三角形或数值退化位置。

### 阶段 D：多级提取与定向重试

建议每例最多三轮：

1. 标准全目标 VMTK；
2. 若部分 target 未到达，对失败 outlet 单独运行 source→target，再与成功路径合并；
3. 若仍失败，对表面执行轻度 clean/remesh、调整种子内移距离后重试。

每轮必须保存：VMTK 日志、种子坐标、失败 target、参数、输出哈希。禁止失败后静默保留不完整中心线。

### 阶段 E：重建中心线图

VMTK 输出后先去除重复无向边，再建立显式图：

- 唯一入口根节点；
- 每个表面出口对应一个叶节点；
- 图应连通、无孤立点；
- 对主动脉—双侧髂动脉结构，期望 5 个端点和 3 个图分叉节点；
- 每条 root→outlet 路径分配稳定 `PathId`/`OutletId`。

不要再把 VTK 原始点数组直接当序列。

### 阶段 F：逐路径计算几何特征

对每条有序 root→leaf 路径按弧长重采样，再计算：

- abscissa；
- tangent；
- curvature；
- torsion；
- radius 与 `dR/ds`；
- 到最近分叉点的图距离。

共享主干点可保留公共值；分叉邻域的导数应按各路径单独计算，并显式标记 junction mask，避免跨支路差分。

## 5. 必须增加的自动 Gate

建议按“硬 Gate + 软 Gate”执行。

### 5.1 硬 Gate：不通过即重试或排除

- 权威 STL 哈希与提取输入 STL 哈希完全一致；
- 权威 STL 开口数与中心线端点数一致；
- 每个开口都能唯一匹配中心线端点；
- 图连通，无孤立点、无异常环；
- VMTK 日志不得出现未处理的 `Target not reached`；
- 中心线不得整体落在权威表面之外；
- 单位因子不能由待审计中心线单独决定。

### 5.2 软 Gate：进入人工复核队列

- 开口中心到端点距离大于开口等效半径的 0.5 倍；
- 壁面距离/局部半径 p95 大于 `2R`；
- 超过 `2R` 的壁面点比例大于 5%；
- 中心线端点离开口超过 10 mm；
- 分叉数、路径长度或局部半径出现队列极端离群。

阈值应先用 173 例分布校准，再冻结到配置和测试中，不能长期写死在绘图脚本。
