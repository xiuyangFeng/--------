## 2. 论文问题与可证伪假设

论文的中心问题是：**在给定仿真协议内，几何先验如何提高 WSS 的空间预测与采样鲁棒性，其失效边界在哪里？** 研究重点是可复验的表示与泛化问题，而非按 V1→V6 的实验顺序讲故事。

| 假设 | 现有支持 | 下一步关键区分实验 |
| --- | --- | --- |
| H1：分支尺度与局部壁面信息具有互补价值 | C1→X5 的开发结果支持；X5 使用几何派生的相对流量与尺度特征 | 修正标签下做同信息预算的受控消融，与解析尺度基线、现代点云和壁面模型比较 |
| H2：显式处理采样变化可提高部署输入的稳定性 | X5D 在粗采样条件下改善；全密度 Pa 单模型增益并非五 seed 一致 | 同患者、同 seed、同点参照扫描；独立验证非均匀采样、表面扰动和切口变化 |
| H3：总体拟合改善能传递到区域与病例级 WSS 描述量 | 已有热点、分域与病例误差分析 | 新标签下验证均值、p95、热点定位；区域面积统计须有面元权重 |
| H4：该表示具有跨输出任务价值 | PF6/VF6 独立三 seed 结果可作支持 | 在相同修正数据与选择协议下复验；速度向量、分支流量、压降另行核验 |

**关键解释边界**：X5 的 `log_q` 是几何分配的相对份额，`log_tau0 = log_q − 3 log(R_mm)` 是尺度代理，并非测得的患者绝对流量或真实 WSS。RCR 审计显示 CFD 的出口参数本身按面积/Murray 规则构建。因此，当前优势可解释为模型利用了已知协议结构；尚未证明它能从几何唯一恢复任意患者的真实生理条件。

当前模型属于**几何与物理启发先验增强的监督学习**。只有实际训练包含相应 PDE 残差并通过受控验证时，才能把该模型称为 PINN。也不应把离线 surrogate 直接表述为已完成动态更新与临床闭环的数字孪生系统。

## 4. 数据与评价合同

### 4.1 修复后数据必须重新形成可追溯版本

保存原数据/结果身份，新增修正版本与变更清单，至少记录：病例/患者映射、分区、原/新 UDF hash、网格与出口语义、CFD 收敛与周期检查、raw 导出 hash、母库/视图/sidecar/stats 版本、代码/config/checkpoint hash。

对 26 例核查最终导出完整性、物理时间与单位、质量守恒、分支流量及压力。中途分流恢复合理仅是检查点，不是最终收敛验收。另有 GUO_AI_JUN 协议偏差待定项，须记录处置依据；不能因某病例拖低分数而选择性排除。

由于 **22 个训练病例也改变了标签**，需要分别完成：

1. **固定旧模型的修复敏感性分析**：冻结 checkpoint，比较旧/新真值，定位标签变化的影响；标为诊断。
2. **修正数据上的论文确认训练**：刷新所有受影响视图、统计量、标签派生 sidecar 和预测缓存后，重训主模型、关键对照与必要消融；标为新实验。

几何本身未改变也须验证 row_index、采样点、坐标架与标签对应；不得把新 GT 与旧缓存中的 GT 混用。训练折的统计量、拟合规则和任何先验标签都只来自该训练折。

### 4.2 开发集与独立验证

- 现有 train138/test34 名称保留，避免路径漂移；论文将反复用于结构筛选、诊断和密度选择的 test34 明确描述为**开发暴露集**。
- 五 seed 测量训练随机性；不会使 test34 恢复独立，也不是五个独立患者队列。
- 优先增加未暴露的新时间段/外部病例作为最终确认集。样本量按主要效应、患者差异和区间精度预估，不预先承诺某个病例数足以投稿。
- 若短期没有新病例：冻结候选与规则，在现有患者内执行分组嵌套 CV，外折完整包含预处理拟合、特征统计、调参及二阶段 OOF 训练。它提供内部验证，但仍应披露方法已利用本队列开发，不能称全新盲测。
- 原有 X5 CV 不可代替 X5D CV；不能把 X5 的估计值外推成 X5D 新患者性能。AG/AAA/ILO 是数据分组，未经来源核实不得称为多中心外部验证。

### 4.3 主指标、尾部与统计单位

当前 WSS 主指标是 Pa 空间的病例等权场 R²_cb。每病例权重为 1，病例内点等权：

`R²_cb = 1 − mean_i[mean_j((pred_ij − true_ij)²)] / mean_i[mean_j((true_ij − μ)²)]`

其中 `μ = mean_i[mean_j(true_ij)]`。它**不是逐病例 R² 的均值**；现有 `legacy_vertex` 也不是面积加权指标。

| 层次 | 主报告 | 防止误读 |
| --- | --- | --- |
| WSS 整体 | Pa R²_cb、病例等权 MAE、逐病例 R² 分布 | pooled、case mean、log_z、拟合后 R² 分开命名 |
| 稳健性 | 逐病例配对差值、P10/低分病例比例、队列分层 | 数百万点不等于数百万独立样本；低方差病例的 R² 不稳定需同时看 MAE |
| 高值区域 | 各病例真值 p90 区域的误差、幅值比、热点 IoU | 固定区域定义；逐例 p90 与全点 pooled p90 不混用；top10 IoU 不是临床风险识别 |
| 区域与病例 | 预定义分支均值/p95、左右差、Bland–Altman | 临床阈值需独立依据；点比例不写成表面积比例 |
| 速度 / 压力 | 向量分量与速率分开；壁面/体内压力域分开；压降和流量单列 | 高速率 R² 不代表方向正确，高压力 R² 不代表压降准确 |
| 集成 | 单模型 mean±SD 与集成分别报告，写明 seed 数、Pa/log 平均方式 | 同一预测转换空间后再算指标；不拼接来自不同集成空间的数值 |

统计以患者为独立单位，主对比报告患者配对差和患者级 bootstrap 区间；同患者多侧/多帧采用分组重采样。另列 seed 间变异，不把患者×seed 当独立样本。预先指定一个主要对比，其余消融注明探索性质或处理多重比较。新阈值只在训练/验证阶段确定，不能用既有测试结果倒推 Go/No-Go 线。

## 7. 写作、图件与知识库维护

正文围绕“问题→方法→公平比较→采样与患者泛化→边界”组织。历史失败路线保留在补充材料的方法选择依据；影响主要结论的标签错误、测试暴露和不成功的关键对比必须在正文可见。

主图建议六张：①任务与方法；②修正数据上的主要比较；③先验与局部表示归因；④密度及几何泛化；⑤区域描述量/代表病例与失败边界；⑥效率及跨输出扩展。各 panel、现有资产和缺口见[论文规划](../../paper_idea/论文规划_几何驱动WSS与部署鲁棒性_2026-09-15.md)。

文档职责保持分工：本总纲管策略；[V5 跟踪](../00-V5设计与历史跟踪/WSS_V5_训练实验跟踪_历史卷_2026-09-06至09-20.md)与 `training_wss_min/experiments/<批次>/` 管原始事实和执行；[任务索引](../../01-任务/README.md)管 A–E 状态；[外部复现库](../../paper_reproduction/README.md)管论文方法适配；[论文规划](../../paper_idea/论文规划_几何驱动WSS与部署鲁棒性_2026-09-15.md)管主张、写作和图件。入口文件不再复制每一轮实验表。

每个正式结果应能回到 `数据版本 + split + seed + config + checkpoint选择规则 + eval路径 + 指标字段`。图件还需 `病例选择规则 + 原始/映射数据 + 单位/色标 + 脚本 + source data`。后续更新原责任文件，再在[总推进记录](../代码修改与实验推进记录.md)或 [WSS 专用记录](../WSS最小化_代码修改与实验推进记录.md)记录实质性变更。
