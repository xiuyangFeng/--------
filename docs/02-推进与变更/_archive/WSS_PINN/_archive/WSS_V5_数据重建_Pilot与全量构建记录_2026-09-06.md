## 1. 冻结的数据合同（schema `wss_v5.0`）

| 项 | 决定 |
| --- | --- |
| 母库范围 | B-Full：anatomy 池全部 cell 的 81 帧 `u,v,w,p` + 解剖壁面全部节点的 81 帧 WSS 标量/向量/壁面压力 + 静态几何 + 5 解剖切面 + 条件/协议元数据 + 拓扑 sidecar |
| 坐标 | Fluent 病例原始坐标系，真实 mm = Fluent m × 1000；不做刚性配准（正逆变换恒等，需要时由 atlas 派生） |
| 部署输入合同 | 壁面点云 + VMTK 中心线 atlas；法向由裸点云 PCA 估计并做 MST 一致定向；开口由中心线端点生成虚拟盖并吸附到点云边缘；内外判定 = 近邻投票 + 点云 winding number（面积以中心线内部点自校准） |
| 壁面实体 | 节点（172 例均为节点导出）；节点面积权 = 相邻解剖壁面 face 面积等分；未导出节点 `valid=False`，标签 NaN，不补零 |
| 体域实体 | cell 中心，按参考帧（step 1120）导出行序；`dist_to_wall_mm` 为到壁面三角形的精确距离 |
| 时间轴 | step 1120…1280 步长 2（81 帧），`time_s = step × 0.005`，`phase_s = time − 5.6` |
| 压力 | 只存原始 Pa；参考量 `p_volume_mean_pa[T]`（体积权）、`p_inlet_mean_pa[T]`（入口切面相邻 cell 面积权）、`p_case_cycle_mean_pa`（梯形时间均值）；不存中心化数组 |
| 条件/协议 | UDF 路径与 sha、Fourier 系数、Carreau–Yasuda 参数、A_udf / 速度入口面面积 / `inlet_area_ratio`、四出口 RCR、协议表（R_total、左右份额、髂内外份额、R2C、RC、协议 id 与例外原因）、solver tier、壁面审计状态、split 角色/折/患者组 —— 全部 `audit_only`，**不进模型输入** |
| 依赖标签 | 每个数据集带 `dependency` 属性：`model_feature` / `quadrature_only` / `audit_only` / `offline_reference_only` / `label`；loader 只能把 `model_feature` 拼成输入 |
| 存储 | 每例一个 `case.h5`，时序数组 chunk = 1 帧 × 65536 实体 × 全通道，lzf；`manifest.json` 含每个数据集的 shape/dtype/单位/标签与 sha256、raw 逐帧文件 sha256、gate 结果 |

HDF5 组：`geometry/`（atlas 表 + RMF 标架 + 虚拟盖）、`wall_static/`、`wall_temporal/`、`volume_static/`、`volume_temporal/`、`interfaces/<label>/`、`pressure_reference/`、`conditions/`、`topology/`、`query_geometry/`。逐点几何特征（壁面与体域同名）：`segment_id, semantic_id, s_local_mm, s_from_root_mm, radius_mm, curvature_per_mm, dr_ds, dist_to_junction_mm, dist_to_endpoint_mm, junction_mask, endpoint_mask, end_zone, r_mm, rho, theta_rad, axial_offset_mm, junction_ambiguous`；壁面另有 `normal_out_pca`（部署形态）与 `normal_out_mesh`（仅审计）。

## 3. Gate 定义（逐例，全部必须通过；已签收审计记录的例外可豁免）

source（.cas sha 与拓扑审计一致；81+81 帧齐全）｜identity（ASCII↔cell 双射且 anatomy 行数等于审计；壁面缺节点 ≤4；无壁面行落在解剖壁面之外）｜labels（有限、WSS≥0、壁面压力与相邻 cell 压力中位差 ≤1 Pa，HAN_JIAN_FU 按壁面审计豁免）｜integration（体积和、节点面积和与网格精确一致；5 个接口语义齐全）｜geometry（atlas 对齐中位 |r−R|/R ≤0.25；PCA 法向与网格法向中位 ≤10°、p95 ≤30°）｜domain（真实 anatomy cell 内判召回 ≥0.99；切面外 ≥2 mm 的延长段 cell 误判 ≤2%；壁外 1–3 mm 壳层误判 ≤2%）。阈值在 `contract.GATES`，报告中如实列出实际值。

## 4. Pilot v1（作业 13051，12 例，17 分钟）

病例：固定 10 例（CHEN_SHI_MING 正常 AG、HAN_JIAN_JUN 空格分隔导出、LI_LAO_PING 宽大瘤腔、WANG_JIN_MING-0 ILO/C 层、HAN_JIAN_FU 首帧重排+壁面压力偏移、LIU_FENG 缺 1 节点、ZHOU_KE_XUN 多面体+网格壁面重提、GUO_AI_JUN 协议例外、CHEN_SHU_LIN 入口面积比 0.888、WANG_SHU_SHENG-0 原节点值体域导出）+ train 内池最大 ILO/LIU_LIAN_YOU-0（704k cell）与最小 AG/YIN_YU_RONG（278k）。

结果：12/12 构建成功，**11/12 过 gate**。全部通过：身份双射、anatomy 行数与审计一致、体积/面积与网格精确一致、标签有限非负、atlas 对齐 0.04–0.15、PCA 法向中位 1.0°–1.8°/p95 ≤5.5°、协议字段、5 接口。唯一失败：LI_LAO_PING 域召回 0.979 < 0.99。

冒烟阶段发现并修复的两个几何程序问题（修复前后见 `audits/smoke*`，不在正式快照内）：

1. 裸点云名义面积 spacing² 比真实节点面积低约 19%，内部 winding number 中位仅 0.79 → 改为 kNN 密度面积并用中心线内部样本自校准（校准后中位 1.00，估计壁面总面积与网格差 0.4%）。
2. 近邻投票在开口附近天然偏"内"（延长段 cell 的近邻是壁面 rim 点）→ 开口附近与非置信点一律走 winding；虚拟盖平面吸附到点云边缘（原中心线端点偏内 0.3–0.8 mm）。

LI_LAO_PING 失败根因：瘤腔褶皱处"背离最近中心线点"的法向定向启发式翻错 1.5% 法向，winding 在该区域跌到 0.4；漏判 cell 全在 trunk 段、rho 1.2–3（瘤腔外侧叶）。修复：PCA 法向按 kNN 图最小生成树做一致性传播（Hoppe 1992），分量整体符号由中心线多数决定。修复后 LI_LAO_PING 召回 0.999（8000 抽样），法向与网格法向中位 1.1°、无翻转；CHEN_SHI_MING 不变。
