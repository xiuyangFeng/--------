> 更新：2026-09-30。本页合并历次问题讨论、文献依据和未执行方案；唯一的实验状态与完整成绩入口是[时间建模_实验跟踪](./时间建模_实验跟踪.md)，保留原 §30.x / §31.x 编号。本次只整合已有证据，不新增文献检索、训练、推理或选模。

## 1. 当前要解决的问题

目标是从血管几何与推理时可得边界条件，快速恢复同一个周期的**三分量速度、相对压力和标量 WSS**，重点提高谷底与减速段，同时报告峰值、各阶段和整周期精度。研究不要求三个量必须共享一个网络；现有证据更支持保留专用模型。

当前输入主要覆盖既定 CFD 协议及公共波形。患者独立的入口波形、心率、出口阻抗和参考压力需要相应数据，不能通过新增几个网络输入字段获得泛化证据。压力是逐帧减体域均值的 `p′`，不是绝对血压；标量 WSS 可计算 TAWSS，不能由此恢复方向反转或 OSI。WSS 向量扩展属于后续明确立项的任务。

目前保留 U0 作速度锚定对照，D1 作低成本方向监督候选，G11 作平均精度更高的结构候选；压力保留 P1，WSS 保留 W1。**速度第三轮八臂均未通过全部预注册主对照门，G11/D1 均不是已确认替代基线。** 当前没有临床误差容限、独立外部验证或端到端临床流程速度的达标结论。

## 2. 把时间建模和信息不足区分开

如果几何与边界条件 `G,B` 确定了已经收敛、可重复的周期响应，可以直接学习 `f(G,B;x,φ)`。真实流体有惯性和历史，并不意味着代理必须按时间递推；并行相位查询能避免真值初始场和逐步误差累积。C-FiLM 已经一次几何编码、多相位解码，不能把这一点再当新贡献。

反之，若同一 `G,B,φ` 对应不同未记录初态、未收敛状态或非相位锁定流动，直接网络与输入相同的 RNN 都不能凭空恢复缺失信息。先审计周期质量、边界参数和标签，再决定是否增加状态。旧记录中有 53/261 单元端点幅值差异的质量提示；只看 0–79 首尾差不等于 0/80 同相位闭合误差。

以下三类误差应分别定位：

1. **表示误差**：即使给定真值低秩系数或相位图，能否重建原场？真值图合成是 oracle 压缩诊断，不是部署成绩。
2. **条件预测误差**：几何/BC 能否预测这些系数、图或局部响应？重建很好不保证条件映射学得好，也不能据此宣布几何不可预测。
3. **空间和近壁误差**：体域平均速度准，不保证近壁导数与 WSS 准。历史预测速度→校准剪切算子的 WSS R² 约 0.549，真值速度进入同算子约 0.966；这提示要单独验收近壁链路，不能当本轮周期成绩。

因此当前优先研究**随相位变化的空间交互、幅值与方向的优化分配、近壁专用表示**。继续增加时间层数、采用自回归、改更大底座都只是候选；需有相应误差证据和配平控制。

旧体场 §31 的 A3 T-null 使用留出 CFD **真值峰值场**，只能作 oracle 诊断；`z_peak_freeze` 冻结的是标准化峰值图，反标准化仍随相位变化。VF6 原本输出三个速度分量，但旧周期主表先取速率模长。因而旧 No-Go 只能用于当时指定结构/峰值保护协议，不能解释成时间信息对速度方向无用。

### 4.1 本轮速度证据对假设的收缩

对 U0 既有预测的诊断显示，谷底方向耦合能量占误差 57.82%；0.10–0.30 m/s 的点占 13.08%，却贡献约 52.95% 误差。当前逐相位 z-MSE 对一些谷底物理误差已经具有约 60 倍峰值权重，不能直接推断“低流量训练关注不够”。

分解 `‖p−y‖²=(‖p‖−‖y‖)²+2‖p‖‖y‖(1−cosθ)` 中第二项仍受幅值影响，不是纯角度误差。D1 提高谷底/减速方向 cos，但总场改善较小；D2 降低幅值项，却增加更大的方向项。因此优先问题是**空间速度结构与监督取舍**，而非把所有低速点统一加权。

G11 相对 U0 谷底/减速 R² 增加 0.0157/0.0094，低于预定幅度；减速方向 cos 小幅下降，困难单元 P10 未改善。固定查询时间约为 U0 的 1.65 倍，也超过 1.5 倍成本偏好。G11 的早/晚谷底 R² 为 0.4796/0.2876；晚谷底及较高残留速率区域仍需重点解释。

这些数字说明候选有研究价值，但不支持“谷底已解决”“所有时间模型无用”“发现了血流惯性机制”。逆轴向速度只是相对几何切向的符号，不能直接称临床回流、闭合涡旋或湍流。

## 6. 增加训练轮次：先回答优化问题

**可能提高，但没有证据保证。** 训练 z-MSE 继续下降只说明训练目标仍可优化；若只有最后一个 checkpoint 的正式开发评价，就不能判断留出精度在第 100、150、300 轮如何变化。D1/D2 总 loss 不同，横向比较必须用共同 z-MSE；学习率已衰减时，机械续训和重新设定长周期日程也不是同一个实验。

对 121–140 轮与 141–150 轮共同训练 z-MSE 的复核，U0/D1/G10/G11 下降约 0.182%/0.436%/0.331%/0.294%，且末学习率已为 1e-5。它们在当前日程末段接近平台；这不证明更慢退火无效，也不支持把八个实验全部翻倍。P1 末段仍下降约 3.261%，可列后续压力候选，但不同任务不能按 loss 数值排名。

建议先保留 U0 与 G11 的结构配对，以同一个 seed 比较训练长度。对照必须同划分、采样/归一化、总目标及 checkpoint 规则，主看谷底/减速/周期以及方向和困难单元，不能只看训练 loss 或周期均值。

| 建议 ID | 固定设计 | 能回答的问题 |
|---|---|---|
| H-U0-300 / H-G11-300 | 各自从配对初始化训练 300 轮，cosine 总长 300，last300 / 15600 步，均 seed1234 | 更长预算＋较慢退火的整体策略；先各自对父150，再同预算比较 G11/U0 |
| H-U0-tail / H-G11-tail（后备） | 只读原 last150，恢复模型/AdamW/scaler/RNG/步数；151–300 轮固定 1e-5 | 前150轮轨迹不变的低学习率追加；它的失败不能否定从头慢退火 |

从头 300 轮的学习率自第 6 轮起就与旧方案不同；第150轮的状态不是原 last150，故不能把结果仅归因于“再多跑150轮”。现有 runner 硬锁150并禁止原地 resume，需新入口与输出，不能修改旧冻结代码或仅加载权重后悄悄重置优化器。所有额外训练节点预先固定，last300 为主终点，不按开发集回选最佳 epoch。

具体日志、恢复合同和评价安排统一见[结果主文档 §30.28](./时间建模_实验跟踪.md#s30-28)及[可复算轮次复核](../../../training_wss_min/experiments/velocity_phase_v52_20260930/analysis_20260930/training_horizon_review.md)。以上均为建议，本次未提交新训练，不覆盖 last150 正式成绩。

记忆模块的轻量形式可写为 `dm_k/dt=(q−m_k)/τ_k`，以已知完整波形计算周期初态，几何产生响应系数或 τ；不读取真历史、无 teacher forcing。若真实标签未充分周期收敛，不强制两端相等。它至多是物理启发的表达，不能等同已恢复 Navier–Stokes 惯性。

55 个开发留出单元已经参与多轮设计，只能用于开发筛选；当前按用户要求一实验一 seed。候选结构和合同冻结后，其他患者分组折可提供内部稳健性证据；若论文声称新 BC 泛化或临床可用，还需对应独立验证。

## 9. 论文主线及维护方式

现在最有依据的主线是：**完整周期平均分隐藏了减速/晚谷底的方向与残留空间流动误差；方向监督与幅值监督存在取舍，相位条件在体内图交互中呈现有条件的收益。** 当前只能称研究线索，不能预先写成机制已被证实。

论文需要三类相互衔接的证据：误差定位（幅值/方向分解及空间、阶段分布）；严格机制对照（A1−A0、G11−G10/G01、必要时 G-E、训练长度配对）；冻结后的泛化及完整流程成本。局部坐标、图、记忆、物理约束各有先例，创新不能只靠模块名称或“首次”表述。
