# 老师的 Time Transformer 想法：我们已经验证了什么（2026-09-24 梳理）

> 目的：把 09-08 以来所有「往模型里加时间」的实验收成一张图、一张表，回答三个问题：老师的草图在我们的数据上意味着什么；每一块已经验证到什么程度；还剩什么没验。数字全部来自 [偏心与全周期时间实验矩阵](WSS_V5_偏心与全周期时间实验矩阵_2026-09-18.md)（P0.7–P0.12）与 [时间建模_实验跟踪](../../时间建模_实验跟踪.md)（§30–§31），这里不产生新结果。口径除特别标明外都是 **v5.1 cv3 三折折外、seed 1234、物理 Pa R²_cb、病例等权**。

> **2026-09-27 证据复核**：修正 T0 的 TAWSS、注意力增量及“可预测性上限”的解释；完整分析与优化顺序见 [时间建模复核](../../../../../training_wss_min/experiments/wss_time_transformer_v51_20260924_r3/analysis_20260927/time_modeling_review.md)。本页部署和跨路线数字保留 09-24 历史语境，当前状态以所属路线跟踪为准；无新训练或评估。

## 0. 一句话结论

老师草图的**几何编码、时间条件与锚定解码骨架已有可用实现**：冻结峰值模型当锚、几何 × 相位学离峰修正、指定峰值帧逐点保持。四臂 Transformer 全周期 0.499–0.502；跨帧注意力的增量在 warm 组为 −0.0015、raw 组为 +0.0017，尚未显示稳定的 Pa 主指标优势。隐藏特征在两种注意力条件下均三折改善时间形态，不能笼统说没有价值。历史 T0（0.517）和 C-raw（0.511）读数稍高，但预算与选模不同，不能据此作纯结构归因或等效结论。**约 0.50 的平台与跨帧相关 0.96 都不能证明数据可预测性上限。** T0 的 TAWSS 为 **0.7164，高于 T-null 约 0.696**；P0.10–P0.12 新增锚定臂未超过该基线。标量 WSS(t) 不能唯一确定 OSI，周期量另有 03 块直接回归路线。

## 1. 老师的草图，以及它在我们数据上等价于什么

老师画的：

```text
   几何(t_i)  ...  几何(t_k)          ← 多个时刻的血管
        │              │
        ▼   3D encoder (trained)      ← 已训练好的峰值模型当编码器
   3D feat(t_i) ... 3D feat(t_k)
        +  time feat(t_i ... t_k)     ← 时间特征
        ▼   Time Transformer          ← 跨时刻做注意力
        ▼   4D decoder
          WSS(t)
```

在我们的数据协议下，这张图有两处要先说清，否则会高估它能学到的东西：

| 草图里的元素 | 我们的数据 | 后果 |
|---|---|---|
| 几何(t_i) … 几何(t_k) 是多个时刻的几何 | CFD 是**刚性壁面**，81 帧使用同一几何 | 3D encoder 只需跑一次，重复编码不增加动态观测；时间变化由相位条件与几何交互生成 |
| time feat | D0 对 v5.1 **170 例**审计波形逐位相同；172 是更早队列描述，RCR 按协议不作输入 | `φ(t) = (q_norm, dq_norm, sin, cos)` 是共同相位条件；可学习几何依赖的不同时间响应，但不能据此验证新入口波形/心率泛化 |
| Time Transformer 跨帧注意力 | 每一帧的 token = 同一病例几何摘要 + 该帧公共相位编码 | 没有新增病例动态观测，但 attention 仍可能改变归纳偏置和有限样本效率；P0.12 仅检验当前表示/预算下跨帧交互的增量 |

于是老师的草图在我们这里的可实现形式（P0.9 形式化，P0.10–P0.12 都用这一式）是：

```text
ln τ̂(x,t) = L0(x,t) + R(h(x), φ(t)) − R(h(x), φ(t_peak))

L0(x,t)   = T-null：冻结 X5D 的峰值 ln τ̂ 按训练折逐帧 μ(t)/σ(t) 缩放（不训练就有 0.46）
h(x)      = 几何表示：冻结 X5D 隐藏特征 query_x / patch_context，或原始 27 维几何
φ(t)      = 4 维相位编码
R         = 时间头（MLP，或 Time Transformer）
⇒ 峰值帧 ln τ̂(x,t_peak) ≡ 冻结 X5D 输出，逐点恒等（实测偏差 8.9e-16）
```

## 3. 模型框架图

### 3.1 公共骨架（所有时间臂共享）

```text
                     ┌────────────────────────────────────────────────┐
  壁面点云 + 中心线   │  X5D_v51 峰值模型（同折训练，冻结 = 「3D encoder」） │
  27 维逐点几何 ──►  │  stem → sa(编码,53 万参数) → fp + local_wall_branch  │
                     │  → KNN 到 query 点 = query_x(32 维)                │
                     │  → head MLP + query-patch FiLM = 峰值 ln τ̂_peak(x)  │
                     │  最粗层 max 池化 = patch_context(病例向量, 256 维)    │
                     └───────────┬──────────────────┬─────────────────┘
                                 │                  │
                    h(x) 几何表示 │                  │ ln τ̂_peak(x)
                    (query_x / patch_context /       │
                     或绕过编码器直接用 27 维原始几何)  ▼
                                 │        T-null 基底 L0(x,t)
                                 │        = μ(t) + σ(t)/σ(t_peak)·[ln τ̂_peak − μ(t_peak)]
                                 ▼                  │
        φ(t) 相位 ──►  ┌──────────────────┐         │
   (q_norm, dq_norm,   │  时间头 R(h, φ)   │         │
    sin, cos; 81 帧)   │  MLP 或 Transformer│         │
                       └────────┬─────────┘         │
                                │ R(x,t) − R(x,t_peak)  ← 锚定差分，末层零初始化
                                ▼                   ▼
                          ln τ̂(x,t) = L0(x,t) + [R(x,t) − R(x,t_peak)]
                                │
                                ▼
                     峰值帧 ≡ X5D（逐点恒等）；其余 80 帧由时间头修正
```

各臂只换图中两个模块：

| 臂 | h(x) 几何表示 | 编码器状态 | 时间头 R | 训练成本 / 折 |
|---|---|---|---|---|
| P-mlp（P0.10） | query_x ⊕ patch_context ⊕ 峰值标量 | 冻结，缓存一次 | 几何投影 + 独立时间 encoder → 加性融合 → 解码 MLP（128/64/128-128） | ~3 min |
| P-mlp-qx | query_x ⊕ 峰值标量 | 冻结 | 同上 | ~3 min |
| C-raw | 原始 27 维 ⊕ 峰值标量 | 不经过编码器 | 同上 | ~3 min |
| TL-warm（P0.11） | 第二条 X5D 支路的 query_x ⊕ 峰值标量 | stem/sa 冻结，fp + 局部分支解冻，从峰值权重起 | 同上 | 285 min |
| TL-random | 同上 | 同上，几何支路随机初始化 | 同上 | 285 min |
| TT-warm（P0.12） | query_x ⊕ 原始 27 维 ⊕ 峰值标量 = 60 维 | 冻结，缓存 | 见 3.2 | ~1 min（缓存后） |
| TT-raw | 同 60 维，query_x 置零 | 冻结 | 见 3.2 | ~1 min |
| TT-warm-noattn / TT-raw-noattn | 同上 | 冻结 | 同一 Transformer，注意力改成对角 mask（只看自己那一帧） | ~1 min |

不走这个骨架的两臂：**T0** 把 φ(t) 直接拼进 27 维输入、端到端重训整个网络（没有锚，所以峰值会掉）；**TB8/TB16** 不输入 t，网络直接输出 K+1 个时间基系数。

### 3.2 老师草图的 Transformer 版（P0.12 实际实现）

```text
  每例固定 1024 个 context 点的 60 维特征 ──逐点非线性投影到 64D 再 mean──► 病例几何 token g
                                                          │
  81 帧相位 φ(t₁) … φ(t₈₁) ──► 与 g 融合 ──► 81 个时间 token
                                                          │
                              Temporal Transformer：2 层、d=64、4 头、FFN 128
                              full 臂：81 帧互相注意力
                              noattn 臂：同参数、同初始化，注意力 mask 只留对角
                                                          │
                                              每帧上下文 c(t)（81 个）
                                                          │
  逐点 60 维特征 h(x) ──► 与 c(t) 拼接 ──► 解码 MLP ──► R(x,t) 标量残差
                                                          │
                                  接 3.1 的锚定差分与 T-null 基底 → ln τ̂(x,t)

  参数量 120 769（四臂相同，初始张量 hash 相同）；训练 1800 步、每步 4 例 × 1024 点 × 81 帧
```

要点：时间模块只看到**病例级的几何均值 token**，逐点几何是在解码器里才拼进去的。这是本轮的设计选择，所以「局部几何 × 跨帧」这种时空 token 没有测过（见 §5）。

### 3.3 对照：03 块的直接回归（周期量已走这条路）

```text
  27 维几何 ──► X5D 同配方网络 ──► 三个头：峰值 WSS ｜ TAWSS(log) ｜ OSI
                                     （M1，一次前向；标签由 wall_wss_vec 81 帧派生）
```

不经过 WSS(t)，所以不受谷底帧学不好的拖累；TAWSS 在 cv3 上 0.716，与 T0 积分出来的 0.716 一样，test34 集成归一化 0.881 与峰值帧集成持平。

### 3.4 训练时每一步到底看几帧（各臂不同，容易混）

| 臂 | 每步每例看几帧 | 帧怎么选 | 400/150 epoch 下每帧被看到的次数 | 为什么这样 |
|---|---|---|---|---|
| T1 / T4（§10）、**T0**（阶段 2） | **1 帧** | `sample_frame_index`：每例每 epoch 按 (seed, epoch, 病例) 抽 1 帧，均匀 81 帧，另以 1/9 概率保底抽峰值帧（`peak_frame_prob`） | 400 epoch → 每例总共看 400 帧，平均每帧约 5 次，峰值帧约 12% | 整个网络每帧都要重新前向，成本与单帧训练相同；每样本每步只见 1 帧是 T0 的固有劣势，设计时按记录、不补偿 |
| **TB8 / TB16**（阶段 2） | **全 81 帧（压缩成 K+1 个系数）** | 加载时把每点 81 帧 z 投影到时间基，目标 = 9 或 17 个系数；系数 MSE 按 Parseval 等于加权帧 MSE | 每步都监督整个周期 | 不输入 t，一次前向重建 81 帧 |
| **P-mlp / C-raw 等**（P0.10） | **全 81 帧** | 几何特征已缓存，时间头对每个采样点一次算出 81 帧输出，损失在 (点 × 81 帧) 上取均值 | 4000 步 × 8 例 × 2048 点，每点每次都是 81 帧 | 编码器冻结、头很小，81 帧几乎不增加成本 |
| **TL-warm / TL-random**（P0.11） | **全 81 帧** | 几何支路每步前向一次得到 query_x，时间头同上 81 帧一起算 | 150 epoch = 1800 步 × 8 例 × 2048 点 × 81 帧 | 同上，几何支路只跑一次就服务全部帧 |
| **TT-\***（P0.12） | **全 81 帧** | 81 个相位 token 一起进 Transformer，解码器对每点输出 81 帧残差 | 1800 步 × 4 例 × 1024 点 × 81 帧 | 同上 |

两点澄清：(1) 「9 帧」不存在。v1 的「9 相位区间均衡采样」在 81 个等距帧上与均匀采样等价，v2 已撤销；留下的只有 1/9 的峰值保底概率。(2) 当前 T0 在输入端加入相位，每帧需重新前向，所以选择随机帧以控制预算。这是当前实现的成本选择，并非端到端训练只能看一帧：把几何编码与时间解码分开，即使几何支路可训练，也能一次几何前向服务 81 帧（TL 即如此）。81 帧监督增加时间覆盖，不增加独立病例数。评估侧各臂均覆盖留出折全部 81 帧。

## 4. 逐条判定：老师的想法哪里对、哪里在我们的数据上不成立

| 草图里的断言 | 验证它的实验 | 证据 | 判定 |
|---|---|---|---|
| 用训练好的 3D encoder 当几何特征提取器（冻结） | P0.10 P-mlp / P-mlp-qx 对 C-raw | 冻结隐藏特征 0.433（含病例向量）/ 0.483（去掉）都低于原始几何 0.511；含病例向量时训练 loss 最低、留出最差 | **当前探针未胜出**；符合过拟合/表示迁移风险，未隔离样本内外特征偏移机制 |
| 预训练权重比从头训好 | P0.11 TL-warm 对 TL-random | +0.031 / +0.028 / +0.033 三折同向 | **该部分冻结日程下成立**；random 的 stem/sa 随机且冻结，不能替代充分训练的从零端到端基线 |
| 跨帧注意力提高预测 | P0.12 full 对 diagonal | warm 组 −0.0015、raw 组 +0.0017；TAWSS raw 组 +0.008 三折同正但 ln / 时序相关三折下降 | **未见稳定 Pa 主指标优势**；小幅信号与指标取舍并存，不构成对其他时空表示的理论否定 |
| 4D decoder 输出 WSS(t) 且不牺牲指定峰值帧 | P0.10–P0.12 的锚定写法 | 正式 r3 峰值帧对冻结 X5D 偏差 ≤8.9e-16 ln Pa，四臂峰值恒为 0.713 | **成立**；工程恒等保护峰值，也锁定供体峰值误差，不保证每点真实峰时正确 |
| 把整周期 WSS 都训练好 | 当前时间臂与真值诊断 | 较好臂全周期约 0.50、谷底约 0.30；K=8 真值投影谷底 0.974；T0 拟合 r² 与 c_peak 跨帧秩相关 0.96 | **尚未达到稳定高精度**；表示压缩上限与预测能力不同，相关性不证明数据上限；RCR 多由几何按协议生成，仍需审计未提供条件与表示不足各自的贡献 |
| 有效提高 TAWSS | 所有时间臂的 TAWSS 列 | TT 0.685–0.693、TL-warm 0.692、C-raw 0.696、T0 0.716；T-null 0.696；直接头 A1 约 0.716 | **T0 高于 T-null，新增锚定臂未超过**；尚无证据表明先预测全周期比直接回归更有优势 |

| 几何(t_i) … 几何(t_k) 多时刻几何 | 无 | 刚性壁面 CFD，几何不随时间变 | **不适用于现有数据**。若将来有动壁面 / 4D 几何，这一项才有内容 |

## 5. 还没验证的（老师的想法可能仍然成立的地方）

1. **多 seed 与 v5.2 数据量。** P0.10–P0.12 全是 seed1234，当前配置的随机性尚未估计。v5.2 有 261 个病例单元（202 患者组），其峰值收益不能直接外推到时间任务；应同折、同预算配对重建基线。
2. **局部时空 token。** 当前时间模块只看非线性点特征的病例级均值；局部几何仍在解码器。局部 patch 的时间条件建模值得作为待验证候选，并需同局部表示的对角注意力对照，分离空间表示与跨帧交互收益。
3. **完整向量时间输出（阶段 2b）。** 从 WSS 序列派生 OSI 需要方向；不能将平均向量/反向辅助头等同完整向量时间模型。03 块后续 V1/V2 已有未过门记录，应先读最新结果再定候选，不能保证向量输出提高精度。
4. **输入与标签合同。** 优先审计几何是否涵盖协议出口条件、周期首尾与积分定义；不默认加入部署不可得的 RCR、压力或真实速度历史。
5. **速度时间响应。** §31 当前速度臂没有推进依据，但体场 T-null 使用真值峰值场，是 oracle 参照，不能据此宣布任何速度预测模型的绝对天花板。

## 6. 给老师的汇报口径与建议的下一步

- **可以直接说的**：几何—相位建模能改善不训练的时间基线；峰值锚定能保护指定帧。当前病例级时间 token 的跨帧注意力没有稳定提高 Pa 主指标，隐藏特征有小幅时间形态收益。实验限制了这版实现的推进依据，尚未证明数据上限或否定其他时空建模。
- **周期量的交付**可继续走直接回归。T0 的 TAWSS 确实超过 T-null，但没有超过直接头的现有证据；OSI 需要单独目标或方向信息。03 块在 09-24 后已有数据扩充与辅助目标结果，以[所属跟踪](../../../03-周期量TAWSS_OSI/TAWSS_OSI_实验跟踪.md)为准。
- **时间线若继续**：先确认帧级交付需要，核对周期标签与指标合同；在稳定数据版本上配平锚定 MLP/对角/全注意力对照，再根据误差定位检验局部空间—时间表示。优先多 seed 的可归因比较，不优先增加 Transformer 层数。详见 09-27 复核报告，未启动新实验。
