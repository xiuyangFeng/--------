> 起因：老师要求项目能展示**一个完整心动周期**里 WSS / 体场怎么变化，只看峰值帧不行；幅值不准可以接受，重点看趋势。此前时间线只用逐帧 Pa R² 评判，没有回答「现有模型的趋势到底行不行」。本次**不训练、不改任何权重**：在 v5.1 cv3 三折留出 136 例上重建已有时间臂的 81 帧预测，先复现已存主指标对账，再按「趋势」口径重算，并出 5 个病例的「CFD vs 预测」并排动画。
>
> 证据目录：`training_wss_min/experiments/wss_time_trend_20260927/`（脚本、逐例结果、自动汇总 [trend_report.md](../../../../../training_wss_min/experiments/wss_time_trend_20260927/trend_report.md)、图、动画）。跟踪条目：[时间建模_实验跟踪 §30.15](../../时间建模_实验跟踪.md)。

## 0. 结论先读

1. **在老师的「趋势」口径下，已有的学习时间头明显好于「峰值 × 波形」（T-null），而且改进比 Pa R² 上看到的大得多、稳得多。** 逐帧空间 Spearman（每帧「哪里高哪里低」对不对，与幅值无关）从 T-null 的 0.619 升到 0.73–0.75（配对 +0.11 至 +0.13，136 例里 99 % 变好，三折同向）；谷底段 0.405 → 0.58–0.61；每帧最低 20 % 区的位置 Dice 0.448 → 0.62–0.64；不跟随全壁脉动的区域（回流 / 相位滞后，占壁面 10 %）逐点时序相关 0.21 → 0.39–0.45。同一批模型在 Pa R² 上只比 T-null 高约 +0.04，这个口径低估了时间头的价值。
2. **「整体一起升降」T-null 已经够好，学习头没有再改进。** 全壁面积加权平均 WSS 曲线的相关 T-null 0.996，学习头 0.994–0.995；低 WSS（< 0.4 Pa）面积占比曲线 MAE 0.060 对 0.062–0.066。如果老师只看全壁汇总曲线，不训练的 T-null 就能用；要看「低剪切区在哪里、怎么移动」，必须用学习时间头。
3. **T-null 做成动画时空间格局是冻结的。** 它每一帧的空间排序与峰值预测完全相同（构造性质，见 §1），按百分位看是一张不动的图，只能整体明暗脉动。动画里舒张期瘤腔 / 分叉处的高低翻转，T-null 一概显示不出来。
4. **老师草图里的跨帧注意力，在趋势口径下同样没有贡献。** 全注意力对同参数、同初始化的对角注意力：TT-warm −0.003、TT-raw −0.002（空间 Spearman，三折不同向）。TT 系列比 C-raw 好一点（空间 Spearman +0.014 至 +0.020，约 70–80 % 病例变好），来自逐点投影 + 病例级上下文 + 解码器这套结构和 X5D 隐藏特征，不来自跨帧注意力。它们与 C-raw 的训练预算也不同，这个差只作参考。
5. **峰值帧误差基本不决定趋势好坏。** 跨病例看，该例峰值帧 R² 与全周期空间 Spearman 的秩相关只有 0.09（T-null）/ 0.16（C-raw）；峰值窗格局准的病例，谷底格局也只是中等程度地准（秩相关约 0.5）。趋势的短板在减速—谷底段的格局变化，这是时间头要解决的，不是提高峰值帧精度能解决的。
6. **还差在哪里。** 谷底段空间 Spearman 最好也只有约 0.60；非同步区时序相关最好约 0.45（AAA 瘤腔这类区域占壁面 15 %，最难）；瘤腔内涡旋冲击留下的碎斑、主动脉上成串的环状涡带，所有模型都画不出来，预测偏平滑、舒张期对比度偏低。
7. **端到端不锚定的 T0 与最好的锚定头打平，没有明显优势。** T0 空间 Spearman 0.752、谷底 0.613，对 TT-warm-noattn 配对 +0.003 [−0.001, +0.008]（58 % 病例）、谷底 +0.008；但峰值窗 −0.006（不锚定，峰值帧偏离 X5D）、非同步区 −0.015。它的推理要对 81 帧各做一次完整前向，峰值帧也和部署报告不一致，所以不作展示候选。T0 不参与选例，本页动画不受影响。

## 1. 为什么换口径：老师要的「趋势」在指标上是什么

老师的要求是能展示一个完整周期里 WSS / 体场怎么变，幅值不准可以接受，重点看趋势。此前时间线的主指标是**逐帧物理 Pa R²_cb 的周期均值**，它主要由高值区与幅值决定，恰好是老师说可以放宽的部分。所以这次先不训练，把「趋势」拆成几类可计算的量，在已有模型上重算一遍，看现有模型在这个口径下到底行不行、哪一类最好、差在哪里。

| 展示时看的是 | 指标（本次新增或沿用） | 与幅值有关吗 | 定义要点 |
|---|---|---|---|
| 每一帧「哪里高、哪里低」对不对 | **逐帧空间 Spearman**（新增） | 无关 | 每帧在全部壁面点上算真值与预测的秩相关，帧 0–79 平均；另按峰值窗 / 减速段 / 谷底 20 帧 / 舒张平台分段 |
| 低剪切区的位置随时间怎么移动 | **最低 20 % 区位置 Dice**（新增） | 无关 | 每帧各自取最低 20 % 点，面积加权 Dice |
| 高剪切热点的位置 | 最高 10 % 区位置 Dice（新增） | 无关 | 同上，取最高 10 % |
| 临床阈值下的低 WSS 区 | 低 WSS（< 0.4 Pa）区 Dice、面积占比曲线 MAE / 相关（新增） | **有关**（绝对阈值） | 阈值与部署页、周期量合同一致 |
| 整体一起升降（全壁平均） | 全壁面积加权平均 WSS 曲线的相关、峰谷幅度比、归一化形状误差（新增） | 形状无关、幅度比有关 | 曲线先除以自身均值再比形状 |
| 每个点自己的波形 | 逐点时序相关（ln，沿用 P0.10 口径；Pa 版新增）、逐点归一化波形误差（新增） | 无关 | 归一化波形 = 该点 τ(t) / 该点周期均值 |
| 什么时候到峰、什么时候到谷 | 峰时误差 P90（沿用）、谷时误差（新增） | 无关 | 按周期环绕计帧差；舒张平台很平，谷时 P90 不稳定，只看中位 |
| 流动不跟着全壁脉动的地方 | **按真值同步性分层的逐点时序相关**（新增） | 无关 | 分层只用真值：r = 该点 ln 波形与本例全壁平均 ln 波形的相关；r ≥ 0.9 同步区、0.5–0.9 过渡区、< 0.5 非同步区（回流 / 相位滞后） |

更正上一轮对话里的一个说法：P0.10 报告里已经有 T-null 的 ln 时序相关（0.808）和峰时误差，不是「从没算过趋势指标」。本次真正新增的是**逐帧空间格局、低 / 高剪切区位置、面积占比曲线、全壁曲线和按同步性分层**这几类。

有一条构造性质要先说明：T-null 的 ln τ̂(x,t) = μ(t) + σ(t)·z(x)，σ(t) > 0，所以**每一帧的空间排序与峰值帧预测完全相同**。T-null 做成动画时，按百分位看是一张不动的图，按 Pa 看只是整体一起明暗脉动。它在空间 Spearman 上随时间的起落，只来自真值自身格局的变化。

## 2. 做了什么

| 臂 | 是什么 | 峰值帧 | 本次来源 |
|---|---|---|---|
| T-null | 同折 X5D 峰值预测 × 训练折逐帧 log 统计，不训练 | = 同折 X5D | 缓存重算 |
| C-raw | 锚定时间头（原始 27 维几何 + 峰值 ln → MLP），P0.10 | = 同折 X5D（逐点恒等） | `head_last.pt` 重推理 |
| TT-raw / TT-warm | 老师草图的 Transformer 版（P0.12 r3），raw 屏蔽 X5D 隐藏特征、warm 使用 | = 同折 X5D | `ckpt_last.pt` 重推理 |
| TT-raw-noattn / TT-warm-noattn | 同上，注意力改对角（无跨帧交互），同参数同初始化 | = 同折 X5D | 同上 |
| T0 | 端到端相位查询（阶段 2），不锚定 | 不等于 X5D（fold2 −0.033） | `ckpt_best.pt` 逐帧重推理 |

- 数据与协议：v5.1 cv3 三折留出 136 例（AAA 44 / AG 60 / ILO 32），seed 1234；趋势指标用帧 0–79（一个 0.8 s 周期，帧 80 = 帧 0 + T），每折病例均值再三折算术平均；配对差在 136 例上算，95 % CI 为病例自助法。
- **对账**：七个臂复现已存的全周期 / 谷底 / 峰值 / TAWSS Pa R²_cb、ln 时序相关、峰时误差，与已存值最大绝对差 T-null 4e-14、C-raw 5e-8、T0 2e-8、TT 系列 ≤ 1.1e-5（CPU 重推理对 GPU 原评估）。说明预测重建与原评估是同一个东西，新指标是在同一批预测上算的。
- 执行：node04（Slurm 之外，ssh + nohup），T-null / C-raw / TT 用 CPU（每臂每折约 1–4 min）；T0 用两张 A100 分 12 片逐帧前向，与用户训练队列共享 GPU，每片 2.0–2.5 h（约每例 10 min）；动画在 master CPU 渲染。没有训练，没有改 `training_wss_min/*.py`。

### 3.4 臂间比较

- **TT 对 C-raw**（正 = TT 更好）：TT-warm 空间 Spearman +0.017 [+0.013, +0.022]（79 % 例，3/3 折）、谷底 +0.024、非同步区 +0.054；TT-raw +0.014 / +0.022 / +0.034。TT 在 Pa R² 上反而略低于 C-raw（0.499 / 0.502 对 0.511），两个口径给出相反的排序。C-raw 训练预算约为 TT 的 8.9 倍，这里只能说在各自已有配置下 TT 的趋势略好。
- **跨帧注意力**（全注意力 − 对角，同参数同初始化）：TT-warm 空间 Spearman −0.003 [−0.005, −0.002]、谷底 −0.005、非同步区 −0.001；TT-raw −0.002 / −0.003 / −0.004，均不胜。**老师草图的核心模块在趋势口径下也没有贡献**；TT 相对 C-raw 的小优势由非注意力部分带来。
- X5D 隐藏特征（warm 对 raw）：空间 Spearman +0.003、非同步区 +0.02，方向与 r3 报告的「隐藏特征改善时间形态」一致，幅度小。
- **端到端 T0**：对 C-raw 空间 Spearman +0.023 [+0.018, +0.029]（79 % 病例、3/3 折）、谷底 +0.038、非同步区 +0.041；对 TT-warm-noattn 只有 +0.003 [−0.001, +0.008]（58 %）、谷底 +0.008 [0.000, +0.017]，而峰值窗 −0.006（21 %，0/3，不锚定的代价）、非同步区 −0.015、逐点归一化波形误差差 0.010。结论：去掉峰值锚、端到端训练整个网络，趋势上与最好的锚定头打平，换来的是峰值帧偏离 X5D，以及推理时 81 次完整前向。

### 3.5 峰值帧误差会不会传到趋势（残差分析）

![峰值误差与趋势](../../../../../training_wss_min/experiments/wss_time_trend_20260927/figs/fig3_peak_vs_trend.png)

- 跨 136 例，该例峰值帧 Pa R² 与全周期空间 Spearman 的秩相关：T-null 0.09、C-raw 0.16、T0 0.18；与 ln 时序相关：0.10 / 0.20 / 0.08。
- 峰值窗空间 Spearman 与谷底空间 Spearman 的秩相关：0.50–0.58（各臂，T0 0.53）。
- 读法：峰值帧预测差的病例，趋势并不系统地更差；趋势好坏主要由减速—谷底段的格局变化决定。对「要不要继续追峰值帧精度」这个问题，这是反方向的证据：峰值帧精度影响的是幅值（Pa），不是趋势。

## 5. 对后续工作的含义

**展示（部署侧）**

- 全周期动画值得用学习时间头，不要只用 T-null。T-null 只适合「全壁汇总曲线」这类整体升降展示，空间格局会冻结。
- 首版候选有两个，都是锚定写法，峰值帧逐点等于报告里现在的峰值图，动画与静态图不会打架：
  - **C-raw**：输入只有原始 27 维几何 + 峰值 ln，最简单，每折训练约 3 min；
  - **TT-warm-noattn**：趋势指标最好（空间 Spearman +0.02），但要取 X5D 的隐藏特征，部署侧需要在 X5D 推理时挂钩子（缓存工具已经这样做过）。
- 现有权重都是 v5.1 cv3 的折模型，部署前要在全量训练集上重训一个头，成本是分钟级。这一步和前一条的选择需要你拍板。
- 不推荐 T0 做展示：趋势只和锚定头打平，峰值帧与报告不一致，每例要 81 次完整前向（本次共享 A100 上约 10 min / 例）。
- 展示时要写明：幅值仅供参考（谷底偏平滑、对比度偏低）；只有一条协议入口波形，不能换患者心率；中段接缝是已知伪影。

**训练（研究侧）**

- 时间线的主指标建议从「全周期 Pa R²」换成本页的趋势指标：分相位空间 Spearman、最低 20 % 区 Dice、非同步区时序相关，Pa R² 与峰值保持降为护栏。开跑前写死门槛。
- 不扩大 Transformer：跨帧注意力在两种口径下都没贡献。可做的方向是让时间上下文变成**局部 / 分区的**（瘤腔、分叉、射流区各有自己的时间响应），对照要带同结构的对角版本；以及改用逐点归一化波形作训练目标、把幅值交给峰值头和 TAWSS 头。
- 峰值帧：趋势的短板不在峰值帧（§3.5），不需要为了全周期展示单独再做峰值帧方法实验；峰值精度随数据量（v5.2、合成数据）提升，通过锚自动传到幅值。

## 6. 局限

1. **单 seed、v5.1、cv3。** 所有臂都是已有的 seed 1234 模型。cv3 这 136 例已被时间线多轮使用，不是未触碰集。结论用于定方向，不用于报最终精度。
2. **趋势指标是本次新定义的，没有预注册门槛。** 这里的比较都是描述性的，不作 Go / No-Go 判定。下一轮训练如果改用这些指标当主指标，要在开跑前写死阈值。
3. **臂间不是同预算对照。** C-raw 训练点序列预算约为 TT 的 8.9 倍，T0 是端到端 400 epoch + EMA 选模，TT 是冻结缓存 1800 步选 last。TT 对 C-raw 的差异可能部分来自这里（与 09-27 复核的提醒相同）。
4. **低 WSS（< 0.4 Pa）指标依赖幅值。** 它和临床阈值一致，但会被幅值偏差带偏，与「只看趋势」的口径不完全一致，所以同时报了与幅值无关的最低 20 % 区 Dice。
5. **谷时误差在舒张平台上定义不稳。** 平台段 Q 近乎常数，逐点最小值帧接近随机，P90 约 36 帧（≈ 半个周期），只作参考。
6. **只覆盖壁面 WSS 的标量模长。** 方向 / 反流（需要向量）和体场全周期都不在本次范围；TL-warm / TL-random 需要重跑 X5D 支路，本次未纳入。
7. **执行环境。** 推理在 node04（Slurm 之外，ssh + nohup），与用户同时运行的 `wss_v52_synn_20260927` 训练队列共享两张 A100。本次只新增 `experiments/wss_time_trend_20260927/` 下的文件，没有改 `training_wss_min/*.py`，不影响该队列的代码指纹。
