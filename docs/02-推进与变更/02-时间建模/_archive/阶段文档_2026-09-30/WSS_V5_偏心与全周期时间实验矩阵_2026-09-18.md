## 1. 科学问题（重述）

1. **偏心**：不再问"作为输入有没有独立信息"（已答：没有），改问 (a) 截面偏心是否**稳定标记模型薄弱的病例**（n=136 折外复核）；(b) 模型是否**系统性抹平流动不对称**（输出端，可量化）。
2. **时间**：在**不损失峰值帧精度**（≤ 0.02）的前提下，能否恢复 81 帧周期与 TAWSS；通过后再问 OSI（阶段 2b）。
3. **交互**：偏心几何是否解释**周期内（减速/谷底相位）**的不对称 WSS——先在 CFD 真值与折外残差上只读检验（D5），过门才开卡（I1）。

老师关心的"血流是否对称、会导致什么问题"在物理上的正确表达是 **OSI（时间不对称）与 m=1 模态（空间不对称）**，两者都是输出端量，本矩阵把它们做成可交付的指标，而不是再加一个几何标量输入。

### P0.9.1 先把思路写完整：这个候选到底在断言什么

**设定。** 记几何为 Ω（点云 + 中心线派生的 27 维逐点特征），相位为 t（81 帧等距；入口波形 261 例逐位相同；RCR 按协议由出口面积 Murray 分配、不作输入）。目标是 ln τ(x,t)。因为波形共享、RCR 不进模型，t 对模型只是一个标量索引：**模型能学到的全部时间依赖 = 几何 × 相位**，等价于 81 个共享同一几何编码器的相关回归任务。

**导师草图的形式化。**

```text
L₀(x,t) = μ_train(t) + [σ_train(t)/σ_train(t_peak)]·[L_peak(x)−μ_train(t_peak)]
ln τ̂(x,t) = L₀(x,t) + R(h(x),φ(t)) − R(h(x),φ(t_peak))
⇒ ln τ̂(x,t_peak) = L_peak(x)；R 初值为零时，整周期退化为同折 T-null(B_scale)
```

- `L_peak(x)`：同折冻结的 X5D 峰值路径（FP 解码 → head MLP，加 query patch FiLM 残差项）的**物理 ln Pa 输出**；它只与所选折 checkpoint 保持逐点一致，不能等同当前默认部署的 v5.1 五 seed 集成；
- `h(x)`：X5D 在 FP 解码并加上局部壁面分支之后，经 KNN 映射到 query 点的 `query_x`（X5D 配方 width 32 → 32 维），可并接最粗层 max 池化的 `patch_context`；不能仅用峰值标量。`query_patch` 还会在原模型的输出端加入独立局部修正，**不包含在 `query_x` 中**；冻结探针若只读 `query_x`，检验的是选定切点而非整套 X5D 几何信息。
- `φ(t)`：与 T0 同一协议的 4 维相位编码（`q_norm`、`dq_norm`（周期中心差分版）、`t_sin`、`t_cos`），逐点广播；
- 训练顺序：第一步冻结整个几何网络，只训时间头；第二步若有必要，为时间分支复制同构几何支路并小学习率解冻后段，**独立的峰值参考路径仍完全冻结**。这样解冻不会悄悄改变锚；代价是额外前向/缓存，须重新估算。

**它包含三个可以分开证伪的子假设：**

| 子假设 | 内容 | 证伪它需要什么 |
|---|---|---|
| **H1 峰值保持** | 训练时间修正时不损失所选折峰值 checkpoint 的输出 | 采用上面的锚定写法后，带锚臂在 t_peak 与**同折冻结峰值模型**逐点恒等；它是工程验收 D8，不是精度增益，也不保证等于当前默认部署集成 |
| **H2 迁移收益** | 峰值预训练得到的**几何支路权重**使时间模型在相同标签、架构、锚、训练预算下更易学习或更稳健 | 同折同 seed 比较几何支路从峰值 checkpoint 初始化的 `TL-warm` 与随机初始化的 `TL-random`；两臂时间头都随机初始化，T0-v52 是性能参照，不单独证明迁移因果 |
| **H3 冻结切点的可用性** | 选定的峰值 `query_x` / context 足以支持有用的离峰修正 | D7 的受限线性/MLP 探针给出可用性证据；失败可能来自探针容量、训练或切点选择，不能单次否定所有峰值表示 |

**当前判断。** 这个候选不引入新观测量，而是改变初始化、归纳偏置和监督分配；**不能由此推出有限模型的性能上限等于“理想 T0”**。H1 可由构造保证并作工程验收；H2 应分开报告最终精度、达到给定精度所需计算量及跨 seed 稳定性；H3 先用低成本探针缩小风险，不能把探针当作表示的理论上限。

### P0.9.2 对抗性论点（第一性原理）

**A. 相同观测信息，不同模型与训练路径。** T0 与 TL 都只用几何和协议相位；TL 改变初始权重、冻结范围、融合位置及每步监督的帧数。有限容量与有限训练下，不能拿“通用逼近器”直接推断谁的可达精度更高。与 T0-v52 的比较回答实用性能；只有保持结构、锚、损失和预算一致、只改时间分支初始化的配对实验，才支持迁移收益归因。不能与 v5.1 的 T0 数字直接相减。

**B. 峰值特征可能不足以描述谷底（H3 的风险）。** 峰值监督不要求网络保留全部离峰相关几何信息。D2 变体 C（真值峰值场 + 时间形状）谷底 R² **−1.05**（折外）/ −1.22（test34），§30.6 的 T0 谷底 Spearman 约 0.61、r² 约 0.37，说明只缩放峰值场不够；**这些证据不证明峰值隐藏特征已丢失所需信息**。D7 检验选定特征与有限头是否足够；若不过，可检查局部 patch 特征、更深/更浅切点或有限解冻，不能宣称整个峰值表示的上限就在 T-null。

**C. 谷底残差未必是小量。** 锚定写法保证峰值恒等，但 D2 变体 C 的负 R² 只能说明该固定缩放预测误差很大，**不能推出真值残差的方差或所需网络容量**。谷底修正是否易学要看逐帧残差的空间结构与实测学习曲线；不能因为采用残差形式就假定训练更容易。

**D. 归因混淆：四个变量同时变。** 导师草图相对 T0 同时改变 (i) 几何支路初始化，(ii) 冻结范围，(iii) 融合位置，(iv) 每步监督帧数。T0 每步每例抽 1 帧；冻结特征可复用一次几何前向服务多个相位，但 81 帧头损失仍有显存、I/O 与训练开销，不能预先写成“几乎零成本”。`TL-warm` 与 `TL-random` 必须共享**同一个冻结峰值参考场**；时间几何支路同构、训练时均可更新，时间头均随机初始化且用相同损失、帧暴露量、优化器和预算，**只有几何支路的初始权重不同**。若随机臂改为锚定自己的峰值头并增加峰值损失，便不再是单变量预训练对照。由于两臂都用了预训练峰值锚，这个配对识别的是**额外迁移几何权重到时间支路**在所选日程下的增量，而非“有无任何峰值预训练”的总效应；也不能证明所有从头训练方案都更差。T0-v52 仍作为已有路线性能参照；若要归因于多帧监督，可另加同结构的单帧采样臂，不能凭 T0 差值下结论。

**E. 效应量对噪声。** 同配置抖动单 seed ±0.04 物理（§20.1 X0 对 C1）；v5.1 三折 T0 全周期 0.545 / 0.459 / 0.546，折间极差 0.09。旧方案设想的全周期 +0.03、谷底 +0.05 在随机性附近；v5.2 应使用五折同 seed 配对差、患者组不确定区间，并补 seed 检查稳定性。不能把 v5.1 的三折符号规则或绝对阈值直接搬到 v5.2；新阈值在观察首个 TL 折外结果前冻结。

**F. 先界定帧级交付物。** 目前已有 M1 三头发布包（峰值 + TAWSS + OSI，`wall_cycle_multi_v1`），但默认发布包仍是 X5D_v51；两者不能混称为“当前默认部署”。同一 cv3_v51 三折上，T0 派生 TAWSS 0.7164、直接 A1 头 0.7162、T-null 0.696，说明**旧协议下未见明显 TAWSS 优势**，不等于未来 TL 不可能改善 TAWSS。标量 |WSS| 周期模型可给相位图、低 WSS 区、逐点峰时与滞后；**不能给 WSS 方向、回流区或 OSI**，这些需要向量目标。复议时先写清目标是逐帧标量场、局部峰时还是向量/OSI，再与同协议直接头比较增量价值；没有明确帧级用途时按研究线安排预算。

**G. 区分观测边界与可学习性。** 协议入口波形共享；RCR 等患者特异条件不作输入。当前材料不足以把谷底误差定量归因于“缺失边界条件”或“峰值表示不足”中的任一项，更不能断言前者已可忽略。v5.1 学习曲线提示增加病例可能有益，但它测的是峰值任务，不能把每翻倍斜率直接外推到时间任务；v5.2 的收益需另测。

**H. 波形通用性。** 输出只在协议波形下有定义；部署只能说「协议波形下的 WSS(t)」，不能说患者自身的周期。库内没有第二种波形，`q_norm` / `dq_norm` 对所有病例是相同相位的确定函数，不能据此声称模型学到了跨波形泛化。

**I. 旧先例只能提醒谨慎。** X13a / X13b（全帧预训练 → 峰值微调）+0.026 / +0.006 在 ±0.04 带内，说明暖启动不自动带来可复现增益；本候选方向相反、目标也不同，不能用旧结果直接判成败。迁移可能改变样本效率、正则化和有限预算下的可达解，但不能创造输入里没有的观测信息。

### P0.9.4 注意要点（工程陷阱清单，实施前逐条核）

1. **冻结 = eval 模式。** 冻结参考路径必须关 drop_path（X5D 配方 0.1）、固定 BN 运行统计；时间分支若解冻则按自己的 train/eval 状态管理。断言冻结参考路径同一输入两次前向逐位相同，且不受时间分支更新影响。
2. **特征统计与帧统计只用折训练集。** 编码器沿用该折 X5D 的 `feature_stats.json`（冻结模式），μ(t) / σ(t) 用新的 cv5 逐折文件；留出折病例（含派生病例与重复几何组）不进任何拟合。
3. **锚定在物理 ln τ 空间。** X5D 的 `global_stats` z 输出先反变换为 ln Pa，再用逐折 `μ(t),σ(t)` 构造 T-null(B_scale) 基底和带锚残差，最后转成当前帧的 frame_stats z 算损失。峰值参考场可按固定 support / 全云 query 缓存；训练点必须按稳定 node ID 和密度档一一对应，失配即报错。若训练时随机 support，则冻结参考场本身会变化，须明确选择同 support 在线重算或固定 support 训练，不能把两种协议混用。
4. **锚定的恒等式要真的成立。** `R(h,φ(t_peak))` 的相位编码必须逐位等于帧 21（步 1162）的编码；T-null 基底在该帧也必须逐点还原冻结峰值 ln Pa。D8 分别核这两项和最终输出。
5. **query patch FiLM 项属于峰值路径。** 它加在输出上，是冻结峰值标量的一部分；时间头另取 `query_x` ⊕ `patch_context`，不要重新实现或重复加。
6. **X5D 的峰值输出带 q90 pinball 偏置（λ 0.2）。** 锚继承这个偏置；时间头只用 MSE，不再叠 pinball；尾部指标照常报，判读时注明。
7. **0.05 Pa 地板是标签裁剪。** v5.1 全周期约 2.9% 点低于地板（谷底约 1–4%）；拟议主口径沿用带地板的 MSE，另报掩膜敏感性，v5.2 比例要重新核实。
8. **密度增广分阶段。** D7 先在原密度上判表示是否有信号；若进入阶段 B，时间分支训练可沿用折内密度增广，但必须核实参考场和时间特征使用同一重采样点集。0.5 mm 部署云最终单独验收。
9. **多帧监督仍有随机性。** 可用相位分块/梯度累积处理 81 帧，先测显存与吞吐；support/query 重采样、密度增广会让逐轮损失波动。`train_loss`、EMA 或固定 epoch 的选择规则要预先绑定实际训练/验证信号，不能因“全帧”推断无需 EMA。
10. **配置驱动、旧配置逐位不变。** 新字段名与实现待复议，不把本草案当代码合同；峰值权重加载可参考现有 `train.init_checkpoint_path`，但新双路径模型需显式记录峰值锚和时间几何支路两份权重来源。若改代码，旧 X5D 重评及相关回归测试须通过，容差按既有 GPU 归约噪声与正式评估合同确定。
11. **不动当前 §35 队列的冻结代码。** 当前 CV5 作业为 15636；即使作业结束，本候选仍须用户复议后才能实现，并使用新冻结副本与矩阵指纹预检。
12. **分清 IND 与未见患者泛化。** IND test91 可在折内方案确定后作为新单元分布转移补充，但它与 train170 有患者组重叠，不能充当无患者重叠的最终确认集；不能用它筛选。test34 已参与开发，不作新确认集。
13. **相位编码容量。** D1 的 K=8 是线性时间基表示的上限，与相位 MLP 的输入维数没有一一对应。`phase4+harm4` 可在需要时作为预先登记的容量敏感性臂，须与主臂同数据同预算比较，不能用 D1 数字证明 phase4 理论上足够。
14. **随机初始化臂共享外部峰值锚。** `TL-random` 只随机化时间几何支路，不随机化共同的峰值参考路径；两臂时间头以相同方法随机初始化。否则不能将差异归因于峰值几何预训练。
15. **预算基于预检而非旧墙钟外推。** 一折一例/一轮测双几何路径、缓存、相位分块、全帧评估、五折病例数（留出 55/57/50/50/49）后再定卡时和墙钟；目前不承诺 10–15 分钟的 TL 评估。

## P0.12 老师 Temporal Transformer 矩阵（V5.1、单 seed；2026-09-24）

> 用户授权：使用 V5.1，在 node04 单张 GPU 上执行老师的时间 Transformer 实验矩阵，配置驱动、前后兼容，每个实验先一个 seed。2026-09-24 后续明确允许共享 A100 剩余显存，不必等整卡空闲，并要求冻结副本。正式实现合同为 `time_transformer_v51_v2`，实验目录为 `wss_time_transformer_v51_20260924_r3`。这次是开发性筛选；此前留出折已经参与多轮方案选择。

### P0.12.1 问题与结构

老师草图的本轮可实现版本为：同折预训练 X5D 编码静态几何 → 固定几何特征与 81 帧相位 token → 时间 Transformer → 逐点、逐帧 WSS 解码。当前输入没有逐帧流速、压力或动态壁面，因此本轮测试的是几何条件下的跨帧注意力，不能把输出解释成新观测到的病例动力学。

**共享流量波形的适用范围（2026-09-24，按用户补充澄清）**：可提供的时间输入是所有病例共享的流量波形，推理时不提供逐帧速度或压力。当前实现已将 `q_norm`、`dq_norm` 与周期 sin/cos 一起输入，不仅使用位置编码。

在固定波形协议下，Q(t) 及其变化率由相位确定，不增加独立的病例信息，但显式提供这些量可作为学习加速/减速和峰谷关系的先验。病例几何仍不同，几何与相位的非线性交互可预测不同病例的幅值、相位滞后和波形形状；共享入口驱动不意味着必须输出共享 WSS 波形。在相关边界条件、材料/流体参数及周期状态固定或已知的适用范围内，没有速度/压力输入并不妨碍监督模型学习几何依赖的时间响应。

模型不能从共同 Q(t) 中识别未提供的病例专属出口阻力、入口幅值等差异，也不能由这轮单波形训练验证对新心率/新入口波形的泛化。若“共享”仅指归一化形状相同而实际流量幅值不同，后续应将可获得的实际幅值单独输入并核对单位，不能用归一化波形抹去该信息。本轮仍保持已冻结矩阵，检验固定共同驱动下跨帧 attention 的预测增量；胜出本身不证明识别了真实流动状态或物理记忆。

- 复用 P0.10 同折缓存的 32D `query_x`、27D `raw`、`peak_ln`，3D 编码器保持冻结，不重复 81 次前向；保留原始几何旁路。
- 所有臂都使用相同的 60D 输入张量与投影；raw 臂在同一标准化后将前 32D `query_x` 置零。该对照检验隐藏表示的额外输入价值，不是“有无任何预训练”的对照，因为峰值锚共同来自 X5D。
- 每例独立、固定抽取 1024 个 context 点（基于病例 ID、seed 与 context 流的 SHA256），训练和全云评估都复用该组点的特征均值形成病例级 token；query 抽样不改变 context。
- 几何 token 与 4D 相位特征（q_norm、dq_norm、sin、cos）融合后成为 81 个时间 token。Temporal Transformer 为 2 层、d=64、4 heads、FFN=128、dropout=0。解码器将局部点特征与每帧上下文拼接输出标量残差。
- 输出采用同一 T-null 基底加 `R(x,t) − R(x,t_peak)`。评估基底与缓存峰值以 FP64 计算，对所有留出点实测最大锚偏差；不能只用公式恒等代替工程验收。
- 无跨帧对照使用**同一个 Transformer、相同参数与初始化，只加严格对角 attention mask**。配置值 `frame_mlp` 是实验入口的历史名称，v2 中明确表示这个对角 mask 对照，不能描述成参数更少的普通 MLP。

### P0.12.6 正式 r3 结果与分析（2026-09-24）

仅使用验收通过的12个r3 run，V5.1 cv3、seed1234、last。下表为三折均值；全周期和谷底Pa R²先计算逐帧病例等权场R²，再作帧平均，不是病例R²均值。

| 臂 | 全周期 Pa R² | 谷底 Pa R² | TAWSS Pa R² | 全周期 ln R² |
|---|---:|---:|---:|---:|
| TT-warm | 0.4989 | 0.2857 | 0.6873 | 0.6517 |
| TT-warm-noattn | 0.5005 | 0.2877 | 0.6852 | 0.6555 |
| TT-raw | 0.5016 | 0.2923 | 0.6930 | 0.6491 |
| TT-raw-noattn | 0.4999 | 0.2914 | 0.6851 | 0.6512 |

**跨帧attention贡献小且依输入/指标变化。** warm组full−diagonal全周期差为−0.0047 / +0.0021 / −0.0020，均值−0.0015，谷底−0.0020；raw组为+0.0008 / +0.0038 / +0.0005，均值+0.0017，TAWSS+0.0080且三折同正，但ln R²、时序相关三折下降，ln幅值误差三折上升。不能说attention完全无用，也没有证据称其全面优于同预算对角对照。raw的Pa增益更多集中于峰前，而非解决流量谷底。

**隐藏特征的价值更多体现在时间形态。** 两种attention条件下，warm−raw的峰时误差median/P90、时序相关、ln幅值误差均三折同向改善。全attention下，峰时P90病例均值8.947→8.754帧，ln幅值误差0.5861→0.5460，相关0.8496→0.8533；但全周期Pa均值−0.0027、谷底−0.0066。P90是病例内点级P90再对病例、折平均，不是总体点级P90。raw仍有X5D峰值锚，故这不是有/无预训练对照；四臂峰值R²恒为0.7130是锚定约束，不是新模块的学习收益。

**历史参照只支持实用位置判断。** 原始Pa口径T-null全周期0.4616，学习残差后本轮约+0.037–0.040，同期对角对照也做到；增益不能归功于attention。旧C-raw为0.5109、T0为0.5166、解冻TL-warm为0.4987，本轮尚未取得超过前两者的读数。C-raw训练点序列采样预算约为r3的8.9倍；T0端到端训练并选EMA-best，r3冻结缓存并选last，因此不能从历史差距作纯结构归因。TAWSS也未超过T-null的0.6961。

**解释与建议。** 共同Q(t)由相位确定，attention没有引入新的病例观测，几何—相位逐帧映射已可能表达大部分固定协议响应；这与小增量相容，但未证明原因。时间模块只看到病例级几何均值token，局部几何通过解码器进入，不能据此否定其他局部空间/时间表示。训练loss在标准化ln空间，Pa主指标与其目标不同；warm训练loss更低但Pa未改善，不足以单独判断过拟合。无逐epoch验证曲线，也不能断言充分收敛。单seed、开发暴露三折、缺少病例级/逐点预测，使结论限于当前表示和预算；ln改善不能直接称为局部低WSS区域改善。

当前保留峰值锚定及几何—相位建模思路，将本轮作为低成本对照收口；不以此替换T0/C-raw参照方案，不优先扩大Transformer规模。若继续，先明确Pa精度、时间形态或TAWSS的目标，再做病例/相位误差诊断。本次没有新增训练、推理或效果门槛。
