**30.6 逐帧 R² 的相关 / 幅值 / 偏置分解（2026-09-20，只读已有 metrics.json）**

用户问：含 t 的结果里 R² 随入口波形起伏很大，而 NMAE 基本不动，是不是幅值把 R² 拉下去了、有没有去掉幅值的相关性指标。用 Gupta 等（2009）的分解 `R² = 2αr − α² − β_n²`（r = Pearson 相关，α = σ_pred/σ_true，β_n = (μ_pred − μ_true)/σ_true），从各臂逐帧已存字段直接还原：`r2_linear_fit` = r²，`linear_fit_slope`（pred = a·true + b 的 a）= r·α → α = a/r，β_n² 由恒等式反解；另取逐例 Spearman 均值与 Lin 一致性相关 CCC = 2rα/(1 + α² + β_n²)。脚本与产物在 `experiments/wss_time_ecc_20260918/analysis_20260919/`：`decompose_frame_r2.py`、`frame_r2_decomposition_{best,last}.{csv,txt}`、`fig5_r2_decomposition.png`（T0 三折均值逐帧）。best 与 last 各项差 ≤ 0.003。

判读：
1. **R² 的下降主要是相关本身在降，不是幅值。** 完全无尺度的 Spearman 峰值窗 0.90 → 谷底 0.61，Pearson r² 0.70 → 0.37；幅值/偏置项造成的 R² − r² 差距峰值窗只有 0.013、谷底 0.05。谷底帧模型只解释不到四成的空间方差，与 §10.6 「谷底场与峰值场相关只有 0.1、是另一种流动状态」一致。
2. **幅值收缩在谷底确实更重（α 0.85 → 0.43，top10 比 0.76 → 0.47），但 MSE 下最优 α 就是 r**，r 掉到 0.6 时 α 本来就该收到 0.6 附近；把 α 拉回 1 反而会让 R² 更低（2r − 1 − β_n² ≈ 0.18）。所以幅值不是可以「去掉」的误差来源，它是低相关的必然后果。
3. **NMAE_range 平不能作为「预测仍可以」的证据。** 它除以真值 max − min，分母被少数热点撑大，对空间型态是否对上几乎不敏感（峰值 0.006、谷底 0.005）；换成逐例均值就从 0.025 翻到 0.049，NRMSE_mean 全程 ≈ 1（误差量级与均值同阶，谷底 1.22 更差）。
4. **汇报建议**：逐帧 R²_cb 旁边并列 r²（`r2_linear_fit`）与 α（`slope/r`）或直接给 Spearman / CCC，让读者分清「型态对了幅值没对」与「型态本身没对」；不要用 NMAE_range 单独说明低流量帧。
5. 体场线（§31）目前存的周期字段只有 `frame_r2cb` 与 `frame_nmae_range`（`volume_time.VolumeTimeMetrics`），不能离线做这套分解；若要，需给累计器加逐帧 Σx、Σy、Σxy、Σx²、Σy² 五个和再重评（配置驱动、旧字段不变）。

推荐（按优先级；「状态」指现有代码 / 产物）：

1. **Pearson r 或 r²（= `r2_linear_fit`）**：对预测的任意仿射变换不变；R² = 2αr − α² − β_n²，r² 就是「幅值与偏置按最优重标定后 R² 的上限」。答「型态对不对」最直接。状态：WSS 时间线逐帧已存（§30.6 表）；体场线 `VolumeTimeMetrics` 只存 `frame_r2cb` / `frame_nmae_range`，要加逐帧 Σx、Σy、Σxy、Σx²、Σy² 才能算。
2. **Spearman ρ（逐帧、逐例取均值）**：对任意单调变换不变，log / Pa 口径一致，重尾热点不主导；答「排序对不对」。状态：`_spearman` 已有，逐例 field 指标已报；逐帧值在 `frame_r2_decomposition_*.csv`。
3. **按帧自身分位数取掩膜的 Dice / IoU**（如 top 10%、bottom 30%）：完全不含幅值，直接对应临床「低 WSS 区在哪」；4D flow 验证文献的「低 / 中 / 高分档重叠」就是这个。状态：`dice_masks` / `threshold_mask_metrics` 已有，但逐帧分位需要逐帧点级预测或两遍扫描，目前只在峰值帧与 TAWSS/OSI 上算。**建议先补这一项**：谷底场平且噪，逐点 r 可能被小尺度噪声拉低，而低 WSS 区定位未必同样差——这是尚未验证的假设。
4. **Lin CCC**：= r × C_b，一个数同时报相关与幅值 / 偏置，且可拆；适合门控用「一个数」的场合。状态：`lin_ccc` 已有，A1 TAWSS 0.907。
5. **approximation disparity（相对 L2）+ 余弦相似度**：为了和 Suk / Rygiel 同口径可比。注意相对 L2 的分母是 Σy²（未去均值），对恒正的 WSS 幅值比 R² 宽松，不能替代 r；余弦只对向量输出有意义（OSI 线 / 速度向量），标量幅值场的整场余弦被均值撑高，不要报。
6. **逐点时序相关 + 到峰时刻误差 + SAWSS(t) / 空间均值曲线**：答「趋势随时间对不对」，每点的 81 帧波形 Pearson 与幅值无关；需要逐点全帧预测落盘（真值 `wall_wss_vec` 已在 bundle）。
7. **展示**：逐帧 Taylor 图（r、α、去均值 NRMSE 一图）或现有 fig5 的 Gupta 分解条，比任何单一数字都清楚。

不推荐单独用：NMAE_range / NMAE(÷全局 max)（§30.6 第 3 条，对型态不敏感）；log 空间 R² 当替代（仍罚幅值）；整场未去均值余弦（被均值撑高）。

判读（按证据强弱）：
1. **不是幅值小、也不是地板噪声。** 地板以下份额全周期 ≤ 4%，与技巧相关 −0.08；低 WSS 份额剔峰后相关 −0.23；σ_ln 相关 0.47。§30.6 已证明幅值项只贡献 0.05。
2. **是这一帧的场「还剩多少由几何决定」在变。** 模型逐帧 r² 与 c_peak 的秩相关 0.96、与 c_murray 0.94，Spearman 与 c_murray 的线性相关 0.99：**模型能学到的就是几何 / 分流先验能解释的那部分**，峰值窗 0.77、减速 0.56、谷底 0.41，模型的 r² 跟着走。T-null 只是峰值场，它的曲线与 c_peak 重合（0.98）。
3. **减速期差是滞后（惯性）效应，不是流量低。** 同为 0.16 Q_max，加速帧型态与峰值场相关 0.82、减速帧 0.36；减速帧 56% 壁面 WSS 方向已相对峰值反向。主动脉—髂动脉 Womersley 数约 6–13（r 4–10 mm，T 0.8 s，ν 3.5e-6），近壁 Stokes 层对逆压梯度的响应快于核心流，减速一开始近壁先反向、核心仍前进，WSS 场由「流量 × 几何」变成「压力梯度历史 × 几何」；单例在 Q 仍为 0.43 Q_max 的减速帧已有 41% 壁面反向。
4. **谷底是另一种流动状态**：入口净流量 0.017 Q_max ≈ 0，壁面剪切来自残余涡、二次流和出口间的再分配（RCR 电容放电，内/外髂参数逐例不同且不在输入里），40% 壁面反向、场型态与峰值相关只剩 0.42（逐例 0.22–0.63）；ln|τ| 的空间方差里小尺度份额从 0.24 升到 0.37（单例 0.17 → 0.35），反向边界处 |τ| → 0 在 ln 空间形成随时间移动的「沟」，点几何回归器放不准位置。谷底帧型态变化速度也快 5 倍（1 − c_adj 0.01 → 0.05），与 §30.7「谷底不是稳定状态」一致。
5. **误差不集中在反向区本身**（单例反向区 SSE 份额 ≈ 点份额，区内相关不更差）——难的不是「反向区里预测不准」，而是整张图的型态在低流量时不再由几何决定；反向份额只是这个状态的标志。
6. **模型侧已排除**：帧条件归一化的 T0、有充足容量的 TB8/TB16、无训练的 T-null 三者的逐帧曲线同形态（相关 0.95+），谷底 Spearman 都停在 0.61 左右；D1 显示时间结构本身低秩（K=8 基对真值谷底 R² 0.97），所以难点不在时间维，而在**非峰值时间模态的空间系数图从几何预测不出来**。共享协议入口波形使得 4 个时间特征对所有病例相同，模型只能学「几何条件下的群体平均形变」，逐例的流动历史差异（RCR 参数、压力史）不在输入里，也不在部署可得性内。

- **自相似性诊断（fig5，体场特有）**：共同时间缩放 r(t) = `T-null − peak_freeze`，对压力在减速段/谷底最多买到 **+1.9** R²，对速度**全程贴 0、谷底为负**。速度场周期内近乎自相似（冻住峰值帧就有 0.553，T-null 只多 0.004），这是速度三臂拿不到增量的根因。
- **压力时间臂赢在离峰、输在峰值**：PTB8 全周期 0.539 > PT0 0.477、谷底 0.583 也更好；时间基头「把整个周期学像」是有效的，失败是**任务取舍**（峰值帧 −0.051）而非学不动。
- **速度只在最深谷底（步 1216 附近）相对 T-null 有 +0.4 尖峰**，谷底 20 帧 0.280 vs 0.118 是真实增益，但峰值窗 0.764 vs 0.972、减速段 0.604 vs 0.729 抵消掉，全周期净值 0.559 vs 0.557。
- **PT0 的 best/last 差是 fold0 单折失稳**（fig6），修正 §31.3 措辞：不是「EMA 选模在体场普遍不可靠」，而是 PT0 在 fold0 训练末段不稳定、EMA 恰好选中坏点。下一步先查这个不稳定，再谈换选模。
