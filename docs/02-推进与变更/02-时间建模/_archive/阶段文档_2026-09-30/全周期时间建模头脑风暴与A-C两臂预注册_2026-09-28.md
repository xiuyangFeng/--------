## 0. 结论先读

1. **当前损失已经被小流量帧主导**：舒张平台 + 谷底 47/80 帧，占训练损失约 72 %，峰值 + 加速只占约 8 %。原因不是幅值（每帧 ln 标准差 0.78–1.43，已按帧归一），而是帧数多（波形舒张期 0.5 s）和难度高（谷底每帧 z-MSE 是峰值的 3.5 倍）。改成 Pa MSE 则反过来，峰值 + 减速占 89 %。**所以「时间怎么归一」决定相位权重差十几倍，必须先定目标。**
2. **小流量帧的标签不是噪声**：帧 0 与帧 80（同相位、隔一个周期）真值 ln R² 中位 0.999，舒张期格局可重复，学不好是模型问题，不能简单降权。**真正的浪费是重复**：27 帧舒张平台几乎是同一个流动状态，一张平均图就能解释这一段 ln R² 0.86。
3. **峰值图是谷底的错误基底**：只用峰值图（T-null 与所有锚定臂的底子）谷底 ln R² 上限 0.20；5 张相位窗平均图、系数只随相位变且所有病例共用，全周期 Pa R²_cb 上限 **0.856**、谷底 **0.734**、峰值帧 0.993（现有最好时间臂分别 0.50–0.52 / 0.29–0.32）。这是「不再冻结峰值特征」的直接依据。
4. **文献里没有人修好舒张期**：唯一在「共用入口波形」设定下比较时间范式的工作（Sheng 2026，未经同行评审）结论是「逐帧 + 每层注入波形特征」最好，并明确说舒张末期误差最大、没有对策；逐帧归一化 / 按相位加权在核实过的血流文献里没人用过。
5. **用户 09-28 裁定**：谷底要求趋势正确、偏差不能太大，幅值能兼顾更好；只看整周期；暂不做向量输出（TAWSS / OSI 直接头精度够用）；A、C 各先训一臂。
6. **只看整周期时，峰值不需要单独一个头**（§4.1）：峰值帧按相位段等权进损失即可，峰值帧 R² 只作监控、不设门。
7. **A、C 两臂已实现、冒烟通过、作业 15918 已提交**（排在 master 当前队列之后）。两臂共用编码器、热启动、预算与数据管线，只在头 / 目标 / 损失上不同，可以直接配对比较（§6）。
8. **结果（09-28，§7）**：两臂都没过 G1。**C-FiLM 是所有时间臂里最好的**（全周期 Pa 0.536、谷底 Pa 0.344、谷底空间 Spearman 0.621，全部第一），但对前最好臂只高 +0.01～+0.02、单 seed。**A-WM5 的诊断最有价值**：谷底窗图本身 R² 只有 0.40（峰值窗图 0.72），而用真值图合成可达 0.734 → 瓶颈是舒张期空间格局的几何表示，不是时间建模。

### 1.4 基底上限：峰值图还是相位窗平均图

逐帧 ln τ(x,t) ≈ a_t + Σ_k b_kt·M_k(x)，M_k 为真值图；「共享系数」= 系数只随相位变、训练折池化拟合、留出折评估（接近可部署结构）。ln R²（病例中位，段内平均）：

| 用哪几张真值图 | 舒张平台 | 加速 | 峰值 | 减速 | 谷底 |
|---|---:|---:|---:|---:|---:|
| 只用峰值图 | 0.39 | 0.75 | 0.91 | 0.44 | **0.20** |
| TAWSS 图 | 0.61 | 0.72 | 0.82 | 0.68 | 0.37 |
| 峰值 + TAWSS | 0.65 | 0.78 | 0.93 | 0.73 | 0.45 |
| 峰值 + 减速 + 平台 + 谷底平均 | 0.87 | 0.78 | 0.93 | 0.87 | **0.70** |

真值图两两相关（逐例 ln Pearson 中位）：峰值–谷底 0.58、峰值–平台 0.69、峰值–TAWSS 0.91、减速–TAWSS 0.94。

臂 A 采用的 **5 张图（每段一张，M_k = ln(段内平均 τ)）**、非中心化共享系数：**全周期 Pa R²_cb 0.856、谷底 0.734、峰值帧 0.993**；ln R² 段均：平台 0.865、加速 0.963、峰值 0.959、减速 0.875、谷底 0.692。另一种定义（段内平均 ln τ）全周期 0.820 / 谷底 0.609，较差。

结论：全周期近似「约 5 张有物理意义的图 × 相位权重」。难点从「怎么建模时间」变成「这些图（尤其谷底、平台图）能否从几何直接回归」。TAWSS 也是时间平均图，已知可回归（cv3 约 0.72），这是 A 的依据。

### 1.5 时间方向是否被抹平（5 例导出，示意）

逐点 80 帧 ln τ 的 DFT：真值能量 75–80 % 在第 1–2 阶谐波，第 5 阶以上约 7–8 %。预测在第 5–8 阶只有真值能量的 30–58 %，第 9–20 阶 17–32 %；前两阶误差仍是绝对误差的大头。**时间方向确实偏平滑，但不是主要误差来源**，时间导数 / 谐波损失优先级低。

### 2.2 通用时空代理与损失

- **局部 token 而非一个病例均值**：AROMA（Serrano 2024，[2406.02176](https://arxiv.org/abs/2406.02176)）、Transolver / ++（[2402.02366](https://arxiv.org/abs/2402.02366) / [2502.02414](https://arxiv.org/abs/2502.02414)）、EAGLE 网格簇 token（[2302.10803](https://arxiv.org/abs/2302.10803)）、UPT（[2402.12365](https://arxiv.org/abs/2402.12365)）。「Read, Write, Relax」（2026 预印本 [2608.21677](https://arxiv.org/abs/2608.21677)）：纯 latent token 注意力相当于空间低通 → 解码端必须保留点级局部通路（可解释我们预测偏平滑）。
- **时空注意力**：TimeSformer / ViViT 的「先时间、再空间」divided attention；MPP（[2310.02994](https://arxiv.org/abs/2310.02994)）物理场上用 axial 注意力 + RevIN 实例归一；Earthformer 局部时空块 + 少量全局 token。
- **时间条件**：Poseidon（[2405.19101](https://arxiv.org/abs/2405.19101)）时间条件 LayerNorm；FiLM（[1709.07871](https://arxiv.org/abs/1709.07871)）；VCNF（[2406.03919](https://arxiv.org/abs/2406.03919)）多时间查询并行 + 空间注意力。FNO 原文：小数据下「2D + 时间递推」反而比 3D 一次输出好。
- **跨时间损失平衡**：Kendall 不确定性加权（[1705.07115](https://arxiv.org/abs/1705.07115)）逐帧用时平衡点等价于最小化 Σ log MSE_t，**会压低最难的谷底帧**，与目标相反；GradNorm / PCGrad 81 个任务成本高，且 Kurin 2022（[2201.04122](https://arxiv.org/abs/2201.04122)）、Xin 2022（[2209.11379](https://arxiv.org/abs/2209.11379)）显示常不胜调好的等权和；β-NLL（[2203.09168](https://arxiv.org/abs/2203.09168)）柔性降权不丢弃；按「病例 × 帧」标准化后的 MSE 恒等于 2(1 − Pearson)，即形态损失；FreDF（[2402.02399](https://arxiv.org/abs/2402.02399)）/ DILATE（[1909.09020](https://arxiv.org/abs/1909.09020)）/ PDE-Refiner（[2308.05732](https://arxiv.org/abs/2308.05732)，MSE 忽视低幅值成分）支持频域 / 形状项。The Well（[2412.00568](https://arxiv.org/abs/2412.00568)）用方差缩放 VRMSE，与我们逐帧 z-score 同理——**问题不在归一本身，在相位配比**。
- **生成式**：失真与真实感不可兼得（Blau & Michaeli 2018）；CorrDiff 式「均值模型 + 残差扩散」能补细尺度但逐点 R² 必降。现阶段不做。

| 编号 | 方案 | 回答的问题 | 成本 | 状态 |
|---|---|---|---|---|
| **A** | **相位窗图头**：一次前向输出 5 张相位窗平均图，训练折共享相位系数合成全周期（以后可加小残差） | 谷底 / 平台图能否从几何回归（上限 0.734） | 最低，与 X5D 同价 | **本轮一臂** |
| **C** | **相位 FiLM 进头的每一层**：编码器跑一次，81 帧一起解码；相位段等权损失 | 端到端 + 相位调制 + 时间归一化损失能否修好 T0 / 锚定臂的问题 | 低 | **本轮一臂** |
| B | 局部 token × 相位的因子化时空 Transformer（沿中心线 / 扇区 token，帧内跨 token 空间注意力 + token 内跨帧注意力，点级直连通路），必须配同 token 对角注意力对照 | 局部时空交互是否才是瓶颈 | 中 | 待 A / C 结果 |
| D | LSTM / GRU：只当 B 里时间混合器的消融（双向、周期边界），不做自回归 | 迟滞归纳偏置 | 低 | 只作消融 |
| E | 时间谐波输出头 | 文献空白，TB 头失败过 | — | 只作消融 |

RNN / LSTM / Transformer 的共同前提：波形共用、刚性壁，任何时间结构拿到的信息都是「几何 × 相位」，结构只改变归纳偏置，不增加信息（见 [09-27 复核](../../../../../training_wss_min/experiments/wss_time_transformer_v51_20260924_r3/analysis_20260927/time_modeling_review.md)）。所以本轮先动表示与损失，不先堆时间结构。

### 3.2 损失：时间怎么归一

| 编号 | 做法 | 作用 | 状态 |
|---|---|---|---|
| **L1** | **相位段等权**（5 段各 1/5）或按流动状态去重 | 小流量份额 72 % → 40 %，峰值 + 加速 8 % → 40 % | **C 已用** |
| L2 | 幅值 / 形态分解：每帧 Pearson 形态项 + 单独幅值项 | 与趋势指标对齐；须和 L1 一起用；防幅值头塌成常数 | 待 |
| L3 | 方向项 1 − cos | 谷底 40 % 反向点、OSI 前提 | 用户裁定暂不做（无向量输出） |
| L4 | β-NLL 异方差头 | 不可预测碎涡柔性降权 | 待 |
| L5 | ln 空间 Huber / Charbonnier，或 ln(τ + τ0)，τ0 < 0.4 Pa | 减少近零值在 log 里放大 | 待 |
| L6 | 小权重时间导数 / 按谐波归一的 DFT 项 | 高阶谐波缺失（只占约 8 % 方差） | 低优先 |

不推荐：逐帧 Kendall 加权、GradNorm / PCGrad。

### 4.1 只看整周期时，峰值还要不要单独一个头？

不需要。「峰值单独一个头」原本是保护措施：保证部署报告里的峰值与 X5D 一致、峰值帧不掉分。只看整周期时：

- 峰值帧只是 81 帧中的 10 帧（峰值窗），按相位段等权损失自然拿到 1/5 权重，不需要额外保护。
- 在 A 里，峰值窗图是 5 张基底图之一，是**基底**而不是保护头，这一张必须有（收缩期格局要靠它）。
- 峰值帧 R² 仍然**报告、不设门**，用来看取舍。
- 两个注意点，留到部署时再定：(1) 展示一致性——若全周期动画来自新模型、峰值页来自 X5D，两者会有差；可改为峰值页也取自全周期模型，或峰值页保留 X5D 并注明；(2) 新模型没有 X5D 的尾部项（pinball），最高 10 % 点的峰值幅值可能偏低，若以后要报峰值 Pa，需对比尾部指标。

## 5. 如果整体框架可以改：我的思考

从数据出发，而不是从「给峰值模型加时间」出发：

1. **骨架换成「空间基 × 时间系数 + 小残差」**。§1.4 说明真值是约 5 张物理图的低秩结构。框架可写成 ln τ̂(x,t) = Σ_k w_k(t)·M̂_k(x) + R(x,t)：共享几何编码器直接监督 K 张相位窗图（臂 A），w_k(t) 由训练折给出或弱病例调制，R 是相位 FiLM 头学的小残差（臂 C 的结构）。这是 DeepONet 式分支 / 主干分解，但分支输出有直接的物理监督（与失败的 TB 头不同：TB 学的是带符号、无物理含义的 PCA 系数）。每张图各算一次损失，天然完成「时间归一化」。
2. **一个模型出所有量**：峰值、TAWSS、OSI、相位窗图、全周期动画出自同一次前向，展示口径天然一致；TAWSS 可由图合成，也可保留直接头作一致性约束。
3. **空间表示要看得到上游**。谷底 / 减速格局由射流、分离、回流决定，取决于上游几何（瘤颈射入角、扩张比、分叉角）。当前 27 维逐点特征 + 局部 patch 看不到上游。建议引入沿中心线的环 / 扇区 token（呼应[局部形态线](../../../01-X5D主线与新数据/_archive/WSS_V5_局部形态实验矩阵_2026-09-17.md)唯一存活的 B2 扇区 token），沿血流方向做 1D 注意力（上游 → 下游），点级解码交叉注意相邻 token 并保留点级直连通路（RWR 的低通警告）。时间只以 FiLM 调制 token，跨帧注意力放最后、带对角对照。
4. **物理先验逐帧化**：直管 Womersley 解按 Murray 分支流量给每段 τ_W(s,t)，天然含相位滞后与近壁反流，可作输入通道或基底候选。§36 的一维先验在峰值上没过门，但时间维没测过；瘤腔里直管近似会失效，需分区看。
5. **数据是最大杠杆**（学习曲线每翻倍 +0.03）：Sheng 2026 的稳态增广在小数据下收益很大。cfd_auto 流水线（09-27）已能一条命令出 Fluent 解，可对已有几何跑少量**稳态**工况（如平台 / 平均 / 峰值三档流量）作多保真监督，教编码器「流量变了格局怎么变」（低 Re 下分离、回流的出现）；合成几何同理。只用于训练，不影响部署合同。
6. **指标与损失合同**：主指标 = 分相位空间 Spearman（全周期 / 谷底）+ 最低 20 % 区 Dice + Pa R²_cb（全周期 / 谷底）；损失按相位段等权；幅值与形态分开监督。开跑前写死门槛。
7. **不做**：自回归 rollout、加大 Transformer、现阶段的扩散模型。

推进顺序：看 A / C 结果 → 若 A 的谷底 / 平台图可学，骨架定为「多图 + 残差」，把 C 的 FiLM 头作为残差并入；若 C 明显更好，骨架定为端到端 FiLM，再用 C-帧等权对照拆开「损失」与「结构」的贡献；两者都不过 → 瓶颈在空间表示或数据，优先第 3、5 条。所有确认都在 v5.2 CV5 多 seed 上做。

### 8.2 实验协议：调参用 IND × 2 seed，确认用 CV5 × 3 seed

用户问：五折任务太多、不方便调优，该怎么做？结论：**不建议为调参新开 cv3，调参 / 筛选用 IND 划分 × 2 seed，只有最后的候选上 CV5 × 3 seed。** 理由：

- IND 划分和 CV5 是项目已定的两级协议（[消融待办表 §0](../../../../04-论文创新与框架/消融实验待办汇总_2026-09-27.md)：IND 筛选、CV5 确认）；X5Dcap_asym2 在两者上**都已有训好的同 seed 底座**，热启动不用重训。v5.2 上开 cv3 要重新划分并重训 X5Dcap_asym2 底座（每个约 5–6 h），且结果与已有协议不可比。
- 成本：IND × 2 seed = 每个配置 2 个训练（约 1–1.5 h，可并行）；cv3 × 2 seed = 6 个；CV5 × 3 seed = 15 个。
- 2 seed 而不是 1 seed：单 seed 间差异（±0.02 量级）与我们要看的效应同量级；两个 seed 同底座、同划分配对，至少能看方向是否一致。IND 测试集 91 例也比单个 cv3 折（约 45 例）大。
- 局限：IND 的 91 例入库时读过预测并修过数据（[没有未触碰确认集](../../../../实验设计总纲.md)），只作筛选；粗扫可以先 1 seed、入围再补到 2 seed。
