## 1. 建议与当前证据

**值得继续研究，而且现有数据已表明学习型时间场能够提高周期预测精度。下一轮最值得做的是恢复并改造局部空间解码，再比较几何条件算子；没有证据支持继续优先扩大普通跨帧 Transformer。**

近期要回答的可检验问题是：在相同患者划分、点×相位曝光和计算预算下，恢复完整壁面局部 patch，或者让局部聚合随相位变化，能否超过现在的 C-FiLM，并改善谷底格局和幅值？更长期的问题是：在不同入口波形、心率与出口阻抗下，模型能否快速生成完整速度/压力周期？这两个问题需要不同的数据合同。

### 1.3 一个有源码依据的新假设

正式时间源码在[冻结副本 cycle_field.py](../../../../../../GNN_cycle_frozen_20260929/training_wss_min/cycle_field.py:217)，主仓当前没有同名文件。实际过程是：

`X5D encode_support → query 插值特征32维 → 拼接27维单点几何 → 相位FiLM头 → 81帧标量WSS`

该路径保留了 support 分支的局部特征，但禁用了完整壁面查询 patch：`query_patch_nsample=0`，且没有调用原 `decode_query`。原底座的 full-wall query patch 是另一条局部精修支路，不能把它与 support 局部分支混为一谈。

**由此提出的假设是：当前时间模型可能缺少原底座的查询点附近精细几何表达。** 这不等于代码错误，也不证明它导致谷底误差；但恢复该支路并做配平消融，比再试一个普通时序模块更有针对性。

另外，当前 C-FiLM 已经每病例编码一次、在 query chunk 内同时输出所有相位。新方案不能再将“一次编码整个周期”写为相对它的新增贡献。

## 3. 推荐框架：先改哪里，何时换底座

### 3.1 首选：保留 X5D 编码器，恢复局部解码，并让邻域选择随相位变化

概念结构：

```text
壁面几何 ── X5D support编码 ───────────────┐
完整壁面局部patch ── 共享局部编码 ────────┼─ query特征 ─ 相位条件解码 ─ |WSS|(x,t)
相位/已知入口波形 ── 时间条件编码 ────────┘
```

近期沿用公共协议相位特征 `q_norm, dq_norm, sinφ, cosφ`；这是条件表征，不是新增患者测量。先恢复静态 patch，再验证相位相关的邻域聚合，两步拆开。

静态 patch 使用现有完整壁面邻域：每 query 16 个邻点、27 维几何及毫米相对坐标，输出局部 embedding，融合到新时间头。原模块约 4.5 万参数，可用于容量配平。**不直接把峰值头原有的标量残差广播到每个相位**：峰值全局 log-z 与时间逐帧 z 的标度不同，应采用新融合投影、零初始化并验证初始前向等价。

相位相关聚合可写为：

`α_ij(t) = softmax_j a(h_i,h_j,Δs_ij,Δr_ij,n_i·n_j,e(t))`

`h_patch(i,t) = Σ_j α_ij(t) V(h_j)`

相位进入邻居权重或池化前的非线性，使减速/谷底可以采用不同局部信息；只在均值池化后施加线性 FiLM，不足以声称学到了“随相位改变邻域选择”。法向、支路/测地约束避免近距离但隔腔的点被当作局部壁面邻居；粗尺度全局路径仍保留，以免阻断真实上下游联系。

这是当前最有依据、改动规模也最可控的研究方向。全周期训练仍端到端，不重新冻结峰值编码器，不新增单独峰值输出头。

### 3.2 第二选择：时空分离的局部 token / 图算子

如果第一批证实局部表达能改善，再检验更长程空间传播。不要直接对 N 个壁面点×80 个相位做全注意力：N=5000 时已有40万个 token，全局二次注意力不适合作为起点。

候选采用 128–256 个几何隐 token、64–128 维通道作为初始工程范围：

1. 按表面 patch 或中心线×周向扇区聚合，保留细粒度点分支。
2. 空间图传播/注意力处理分支拓扑、上下游和瘤腔关联。
3. 在每个 token 上做轻量圆周 TCN 或相位注意力。
4. query 通过连续局部插值/交叉注意力读取隐场，再由 full-wall patch 补局部细节。

与已有 WM-sec 的区别必须明确：它不再只是段内均值、无相位 token、同格硬查表。对照必须包含同样 token 的无跨时间交互版本、同样容量的池化版本；否则无法知道收益来自新空间表达还是注意力。

空间/时间分离的注意力成本约为 `O(T M² + M T²)`，另加编码和 query 解码；不是免费，也不能只报告注意力核时延。完整周期及已知完整入口波形的任务允许双向交互，无须人为改成预测未知未来的因果任务。

### 3.3 替代底座：几何条件神经算子

用两支输入编码：`G=血管几何`，`B={Q(t),T,出口RCR,血液参数}`；输出为 `fθ(G,B;x,t)`。当前先固定 B，做同输入的几何→标量 WSS 公平比较；只有新 BC 数据齐备后才打开波形分支。

候选优先级：

- **图/点云算子 + 局部 query 解码**：适应不规则几何，保留近壁分辨率，是首个替代底座。
- **DeepONet 式可学习低秩解码 + 非分离残差**：`f(x,t)=Σ a_k(G,B,x)b_k(B,t)+r(G,B,x,t)`。真正的新变量应是可学习空间模式、BC条件或残差；不要把已失败的 TB8/TB16 或固定 WM5 改名重跑。
- **等变图网络**：优先用于后续速度/WSS向量阶段；标量阶段可以比较，但收益不可从向量任务文献直接推定。

不优先直接将整个血管体素化后套标准 FNO：狭窄分支和近壁梯度可能受栅格分辨率限制，还增加几何预处理成本。若尝试，必须与不规则几何版本比较，并报告近壁/分支误差及内存。

### 3.4 多保真先验：放在可区分的信息实验里

R6展示了稳态先验→脉动场的可行性，但本项目要将纯几何、部署可得的1D/低保真先验、可部署稳态CFD先验分开比较。若稳态CFD只用几何和推理时可得BC计算，它是昂贵但可部署的输入；只有使用未知真值BC、目标后验信息等才标为oracle。R6的稳态求解在其配置下约5–30 min，本项目需要另外实测，且必须计入总流程。

稳态场不能直接提供脉动回流的相位记忆。1D/Womersley 等近似也不等于非牛顿 3D 真值。增加不同流量的稳态数据可以测试迁移，不能无依据地对已有 WSS 标签做流量比例缩放或时间拉伸后当成真实新 CFD。

### 3.5 为什么暂不以 LSTM、Mamba 或自回归为主线

当前输出是一段周期稳态响应，入口整个周期通常已知；现有模型已可并行解码，只有80个独立相位，长序列记忆不是已确认瓶颈。LSTM/GRU、TCN、状态空间模型可作为轻量时间机制对照，不宜每种都开一轮大矩阵。

自回归图模型适合未知未来、多周期扰动等任务，但需解决初始流场来源、累积误差、稳定化和推理步数。临床推理不能从真值 CFD 初始场起步却只计算 rollout 时间。若采用该路线，要比较预测/低保真初始化、整周期 rollout 与周期稳定误差，且把热身计算计时。

## 4. 分层实验矩阵

以下是**建议的下一轮设计**，并非对新训练的执行指令。顺序按可区分性和信息量排序；每一层收口后才扩展下一层。

### 4.1 P0：先冻结比较合同

不训练的新协议工作：归档当前42项结果/配置指纹；把旧81帧主表与新80相位主表分开；明确患者簇、目标尺度、指标面积权重；确认当前底座供体和实际解码路径。需要重新读取全量预测或新增推理时另列计算任务，本轮仅完成设计。

保留原 C-FiLM 作为当前默认参照；不要根据新指标重新挑它的 checkpoint。现有 WM-up 的第三 seed 是旧预注册补完项，不与本矩阵的新增机制混算。

### 4.2 P1：最小归因矩阵——首批建议5臂×2 seed

开发筛选暂沿用已暴露 IND（170/91）以衔接当前路线；解释仅限工程筛选，不能称独立确认。后续若持续多轮搜索，应改用训练侧固定患者分组验证或内层 CV。

| ID | 模型与唯一主要改变 | 比较对象 | 回答的问题 | 优先级 |
|---|---|---|---|---|
| E0 | 当前 C-FiLM 同期控制 | 已存控制复现 | 新数据管线/协议是否引入漂移 | 必须 |
| E1 | 相位直接拼接 MLP，参数与 E0 配平；无乘性FiLM | E0 | FiLM本身有无增量 | 高 |
| E2 | E0 + 无邻域信息的点式支路，约增加静态patch同等参数 | E0 | 增大容量本身是否足够 | 必须的容量控制 |
| E3 | E0 + full-wall patch静态可学习聚合 | E2/E0 | 恢复查询点局部几何表达是否有效 | **最高** |
| E4 | 同E3参数/模块，但局部聚合接收真实相位 | E3使用固定相位的同模块控制 | 相位相关邻域聚合是否有效 | **最高** |

执行细节：E3/E4 的共享聚合模块中，E3用固定相位向量，E4用真实相位；相位之后须有影响邻居选择的非线性/softmax。E3恢复的是完整壁面局部信息路径，不声称逐位恢复原mean-patch解码器。E2/E3/E4新增分支共同采用随机初始化和零输出融合，不让E3额外独享供体patch预训练；若要复用已训patch中间权重，另做初始化消融。资源最紧时先做 E0/E2/E3/E4 四臂，8 次训练，再补E1。

首轮E3/E4沿用相同K=16邻域和相同mask，几何筛选不得只给E4；新的测地/隔腔mask另作空间消融。E3下游时间头仍接真实相位，仅局部聚合条件固定。固定相位与真实相位虽然同名义参数量，有效自由度与算量不同，应另报。E1改变调制形式，不能要求与E0初始函数逐位相同；相同初始输出核验适用于E2–E4新增零残差路径。

共同固定：同供体/同 seed 热启动，编码器可更新；support/query随机流、每例空间点对应、归一化、损失、150 epoch和点×相位曝光一致；不同时打开新数据增强、尾部损失或学习率配方。使用当前 phase-FiLM 损失合同作为桥接，段等权与帧等权不再额外扩大搜索。所有候选采用同一 checkpoint 规则（当前 last），不能看 IND/CV 结果再改 best/last。

参数配平容差建议±10%；同时报告激活参数、FLOPs/运行时间与峰值显存，因为被绕开的供体参数不应计作有效容量。新增分支用零初始化融合做前向等价核验，检查目标梯度确实流经 patch；容量配平不等于计算量配平。

所有归一化统计、时间基/POD、相位窗系数、阈值校准只由相应训练/开发分区拟合；不得使用留出标签。供体也必须来自同一患者分组划分，不能使用已见过外层留出病例的供体。固定候选进入CV5后停止依该结果调参。

### 4.3 P2：只给少数框架替代方案预算

| ID | 候选 | 关键对照/边界 | 进入条件 |
|---|---|---|---|
| F0 / F0-control | E3+小型圆周TCN / E3+逐时间点独立支路 | 两臂都含相同patch、同参数和预算，只差跨时间混合；不能用无patch的E2代替控制 | 需诊断局部时间邻接是否有额外价值时；额外2臂×2seed |
| F1 | 同局部query头的几何图/点云算子 | 与P1胜出臂同输入、同输出；预算配平 | P1已有结论，仍有明显空间残差 |
| F2 | 局部空间token + 分离时空注意力 | 同token、同容量的无跨token/无跨时间混合对照 | 能明确区别已失败WM-sec和全局时间Transformer |
| F3 | 可学习低秩模式 + 相位残差 | 纯低秩、纯残差与组合；训练折拟合基底 | 需要压缩/时延收益，或窗口图已有足够精度 |
| F4 | 低保真先验条件化 | 几何-only / 1D先验 / 可部署稳态CFD分开；oracle另表 | 额外先验在部署端可获取且总时间可接受 |

不同时把 F1–F4 全开。建议第一批仅 F1 与 P1 胜出臂比较；F2需有独立空间/时间混合对照，F3/F4按误差诊断或预算决定。若P1没有改善，不自动升级为更大的Transformer：先检查空间标签质量、信息缺口、输入覆盖和模型实际可见邻域。

F0若实施，作用于E3每个query的`[P,80,H]`相位隐藏特征，不额外引入新空间token；初始候选为核宽3、三层膨胀率1/2/4的圆周卷积，H沿用控制。F0-control采用不跨相位的1×1/逐点MLP支路调整宽度配平；固定padding、采样和曝光，不能把时间打乱当作无时间混合对照。

### 4.4 P3：完整周期血流——另立输出合同

| 阶段 | 输出 | 训练方式 | 验证目标 |
|---|---|---|---|
| U1 | 体域速度向量 u(x,t)、相对压力 p′(x,t) | 首先数据监督，时空查询并行 | 减速/回流、方向、截面通量及压差 |
| U2 | U1 + 弱质量/边界约束 | 单独增加一类物理项，使用原CFD黏度合同 | 是否改善守恒而不牺牲局部精度 |
| W1 | 壁面向量 τ(x,t) | 与体域分别解码，可共享几何隐场 | 近壁切向方向与幅值、积分TAWSS/OSI |
| W2 | W1 + 直接周期头及积分一致性 | 真值监督保留；分别比较派生值与直接值 | 不能仅靠两个错误输出互相一致过门 |

近期暂不做WSS向量并不妨碍P1/P2推进。真正的“血流动画/回流/涡结构”至少需U1速度向量；标量WSS动画只能表达壁面剪切强弱。瞬时流线与粒子路径线也应分别标注。

## 5. 指标、数据与 Go/No-Go 合同

### 5.1 先处理81/80相位与周期收敛

- CFD时间步0.005 s，每2步保存，标签间隔0.01 s；81帧包含80个独立相位及重复端点，T=0.8 s。
- 新主表建议用0–79帧、等时间权；积分量同正式 `wall_cycle_v1`。旧81帧等权结果保留桥接，**所有候选和所有控制一起统一**，不能只改候选分母。
- 现有时间表名为TAWSS的0.7770由81帧均值计算，与M1的80帧正式标签不同，本页不据此声称时间积分优于M1。
- v5.2有53/261单元端点模长相对差>5%；这是幅值端点审计，不是完整向量流场收敛判据。保留全部病例并分层，不按模型表现删难例。
- 强制周期闭合/圆周卷积/谐波表示要做该53例子组敏感性。可以在80相位周期表示上建模，但不能把帧0与80两个有差异真值当成无冲突硬约束。
- 更密时间查询不等于获得更高时间分辨率真值；80帧插到320帧只能验证插值行为。真正高频精度需要更密CFD或测量对照。

### 5.2 标量时间场的主次指标

**主要目标：谷底空间格局 + 全周期物理误差；两者共同看。**

| 层次 | 指标 | 用途 |
|---|---|---|
| 主形态 | 谷底逐帧空间Spearman、减速期Spearman、低剪切区Dice | 是否找对位置 |
| 主幅值 | 全周期/谷底Pa MAE、NRMSE、R²_cb | 防止只有排序变好而数值不可用 |
| 局部时间 | 非同步区逐点相关、峰时误差、振幅比 | 防止仅拟合公共入口波形 |
| 周期量 | 正式80相位TAWSS误差；OSI仍保留直接头 | 对齐02/03路线 |
| 尾部 | 病例p10/p90、最差组、AAA/AG/ILO、端点审计组 | 防止均值掩盖失败 |
| 工程 | 完整周期时延、显存、不同点数/重采样鲁棒性 | 评估实际可用性 |

聚合说明必须固定：空间点/面积权重→相位权重→病例/患者权重。现有M1区域IoU为顶点计数；时间趋势脚本的Dice已有面积权重，但其“最低20%”阈值按点百分位。新表保留旧口径并增加一致的面积加权版本/面积分位定义，不把所有旧指标一律改称面积。

重复患者按簇bootstrap，保留术前术后/多状态关联；seed SD与患者不确定性分开。5折×3seed不等于15次独立临床验证。确认集CI反映固定候选的不确定性，不补救反复在同一开发集挑选结构的偏差。

### 5.3 建议的新筛选门，尚未执行

以下阈值是研究资源分配建议，不是临床可接受误差，也不改旧实验门：

1. **趋势通过条件**：谷底空间Spearman平均提升≥0.02，至少两个开发seed同向；患者簇配对CI下限>0。预先指定机制主比较：E1−E0、E2−E0、E3−E2、E4−E3、F0−F0-control；候选最终还须相对E0达到该趋势门并通过幅值护栏。CI仅用于开发筛选描述，不宣称确认性显著。
2. **幅值护栏**：全周期Pa R²_cb下降不超过0.01，谷底Pa MAE相对恶化不超过5%；同时报告NRMSE与校准，防止只换尺度获利。
3. **工程护栏**：整周期端到端时延/显存需符合预先给定预算。候选若仅小幅精度改善却翻倍总延迟，进入Pareto表，不自动胜出。
4. **边缘信号**：平均提升0.01–0.02且同向，仅补第三seed；反向或小于0.01停止该实现。若幅值明显改善而趋势无改善，只登记幅值收益，不事后改主目标。
5. **确认**：冻结不超过两条候选，再做患者分组CV5×3seed，与同协议控制配对。最后独立新中心/新采集病例仅一次验收；当前IND/CV5都不能代替它。

只有趋势门与幅值护栏共同满足，才进入确认；只过趋势门则登记精度取舍并检查校准/尺度，不直接推进。主趋势指标固定为谷底Spearman，其余趋势指标用于解释，不按其中最有利者替换主门。

近期峰值仍只报告，不恢复旧硬门，也不新增峰值头。若用户以后需要同时替代峰值部署，再单独给峰值任务设非劣效合同。

配对CI实现：先在每个患者簇内保留其全部单元和相位，同一重采样中保留所有seed的配对预测差；对病例/seed的汇总顺序预注册，不把seed×单元展平为独立样本。R²类非线性指标在每次重采样内重算；另表报告各seed方向及SD。

## 6. 从固定波形走向患者条件化：必须增加的数据轴

目前输入是几何与公共协议，队列间存在不同RCR总阻力设置，但没有形成可覆盖患者任意生理条件的训练分布。在这种数据上加波形编码器，主要只是重编码相位；**没有跨波形标签，就无法验证跨波形泛化。**

建议先做一批可负担的BC覆盖试验，再决定大规模CFD预算。例如12个来自训练/开发侧的代表几何×6组条件，共72个几何—条件组合，其中默认条件已有结果可复用。这个规模只用于检验条件化响应和数据需求，不足以确立跨患者临床泛化。

| 数据轴 | 首轮取样原则 | 必须避免 |
|---|---|---|
| 几何 | 按训练侧几何形态覆盖瘤径、偏心、分叉和狭窄；选择规则不看测试误差 | 把同患者重建当新增独立患者 |
| 入口平均/峰值流量 | 在可测或已有生理分布内设低/中/高代表条件 | 无依据地统一乘0.5/2后称生理合理 |
| 波形形状 | 收缩时长、减速形状、舒张回流；有临床/文献来源 | 只变幅值却宣称波形泛化 |
| 心率/周期T | 真实范围内变化，模型输入物理T | 只改变播放速度当新物理解 |
| 出口阻抗 | R_total、C及分配比例，优先生理可标定变化 | 把目标CFD反推量作为部署输入 |
| 几何壁/流变 | 先保持原刚壁Carreau合同；以后单独研究壁顺应性/FSI | 同时改变所有物理假设，无法归因 |

条件组合采用小型正交/空间填充设计，不做巨大笛卡尔积；周期收敛、网格/时间步质量先验收。RCR输入逐项标注“测量”“估计”“协议默认”“oracle”，若实际部署只能估计，就需要输入误差敏感性实验。

验证矩阵应包括：已见几何/新BC（机制诊断）、新几何/已见BC（病例泛化）、新几何/新BC（组合泛化）。主病例泛化中，同几何全部时间片、网格、BC和增强样本必须同组；不能随机划分快照。确认集还应独立于用于选择BC范围与模型的病例。

## 7. 物理一致性与临床验证的具体边界

正式定义：

`TAWSS = (1/T) ∫ ||τ(x,t)|| dt`

`OSI = 0.5 × [1 − ||∫ τ(x,t)dt|| / ∫ ||τ(x,t)||dt]`

因此只有标量序列时无法恢复方向相消，不能由其求OSI。向量阶段需统一坐标架、切平面投影及法向；低幅值处方向角病态，应以训练尺度预定义可靠幅值mask，同时报告低幅区绝对向量误差。

本项目原CFD使用Carreau非牛顿流变。若连接速度梯度与WSS，应使用切向牵引形式：

`τ = (I − nnᵀ) [2 μ(γdot) D(u)] n`，其中 `D(u)=(∇u+∇uᵀ)/2`。

符号按原CFD壁面牵引约定核对；黏度、单位、法向、坐标缩放一致。完整连续性/动量约束只能在速度/压力域上建立，不能对独立标量WSS头声称完成Navier–Stokes约束。

当前压力标签是逐帧减体域均压的相对压力p′；可以评价压差，不能由它宣称患者绝对血压波形。若以后需要绝对压力，应增加参考压力/可测边界并重定义标签，不能仅调整输出层。

临床验证建议逐级增加：

1. 同协议新几何CFD对照：分割/重采样稳健性、不同中心几何、盲测误差与时延。
2. 有可得入口流量、血压/阻抗估计的患者条件化对照：输入不确定性与输出误差一并报告。
3. Doppler、PC-MRI/4D-flow等实测速度/流量对照；必要时以体外流动实验验证近壁和压差。不能把MRI近壁差分直接当无误差WSS真值。
4. 若目标是风险判断，再研究临床结局、区域阈值与校准。TAWSS<0.4 Pa或OSI>0.1/0.3目前只是研究阈值，不自动构成诊断标准。

## 8. 算力、时延与执行顺序

### 8.1 预算怎么控制

9月29日IND单run记录约151–197 min，即约2.5–3.3小时/进程，包含训练、评估和I/O，且同卡两个进程共享。它不是GPU占用小时。10次P1训练可粗估25–33进程小时；四臂版本约20–26进程小时，仅用于当前实现量级参考。新patch/注意力须先测吞吐、显存与独占/共享卡时间，再给GPU小时和墙钟预算，不能简单按进程耗时求和冒充GPU小时。

后续每个候选CV5×3seed有15次训练；进入确认前先限为最多两条候选，同期控制是否可复用由代码、采样与指标合同决定。换骨干采用两种报告：固定点×相位曝光的机制比较，以及相同GPU小时预算下的精度—速度比较，避免对大模型不公平或隐藏成本。

### 8.2 速度目标怎样验收

当前C-FiLM已编码复用；待测的是完整管线，而非声称从81次编码降到1次的新收益。计时拆为几何预处理、编码、80相位解码、积分/导出和显示，注明点数、GPU/CPU、单模型/集成、冷/热启动；报告median/p95及模型失败率。

可以把“完整工作流≤1 min或≤2 min”作为临床工作流讨论的候选目标，但本页不把它当已确认要求或已达到结果。稳态CFD先验、网格生成和初始场热身都要计入。另报相对于**同几何、同物理精度CFD流程**的加速倍数。

### 8.3 推荐顺序

1. 完成P0合同与现有结果归档；保持当前C-FiLM为全周期研究基线。
2. 优先E0/E2/E3/E4，检验完整壁面patch和相位相关局部聚合；有预算再补FiLM直接拼接及TCN归因。
3. 冻结胜出者，在CV5×3seed确认；若无稳定增益，停止该局部实现，不继续盲增层数。
4. 一个强替代底座F1进入同协议比较，同时以独立数据预算设计BC变化小试验。
5. 当目标转向完整血流时再实施U1→U2→W1，分别验收速度、压力和向量WSS；之后进入独立临床/实测验证。

拟研究贡献应表述为“哪些空间表示、时间条件和输入信息能可靠改善周期血流预测，以及在何种条件下足够快”，而非把使用Transformer、DeepONet或某种注意力本身当作创新。
