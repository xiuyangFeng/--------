## 0. 现状快照

v0.7 已经具备：冻结特征库、模型族适配器、SSE 实时状态、任务删除与审阅锁定、分析层（沿程曲线 / 发现列表 / 可信区域）、两个阅片式报告页（折叠菜单、标准视角、视图状态、离散色带、区域统计、探针）、一页纸、并排比较页、参考侧车（几何范围 + 136 例折外人群）。

日常使用中最常碰到的空缺（来自 09-20 验收与讨论）：同一病例的 WSS 与体场分在两个任务里；同一 STL 重复上传会整套重算；任务只对当前浏览器会话可见；删除不可恢复；批量算完没有提醒；上传设置每次重选；没有测量与标注；出图是带中文界面的屏幕截图；多病例数字要手抄；发现列表只读；术语无解释。

## 2. 迭代一详细规格

约定：所有新接口沿用现有安全约束（会话、CSRF、owner 隔离、白名单文件、路径包含检查）；所有新文件名进 `OUTPUT_FILES` 或专用白名单；任何写入任务目录的操作走 `atomic_json`；不改预测数值，黄金回归必须 5/5。

### C1 病例卡归组

**需求**：列表可切换"按任务 / 按病例"。一个病例卡 = 同一输入几何（`input_sha256`）下的全部运行，按发布包分列，一键打开某个报告、一键并排打开 WSS 与体场、一键补跑缺少的发布包。

**设计**：
- 后端 `wss_deploy/cases.py`：`group_cases(jobs) -> list[case]`，按 `job["a"]["input_sha256"]` 分组（stage A 未完成的任务按 `job["input_sha256"]`，上传时即计算，见 C2）；组内按 `model_release.id` 与 `family` 归类，`latest` 取每个发布包最新的 done 任务。
- 接口 `GET /api/cases?q=&patient_id=&tag=&page=&page_size=`：

```json
{"cases": [{"input_sha256": "…", "case_ids": ["LIU_YU_MING"], "patient_id": "P-001", "scan_label": "基线",
   "latest_at": "…", "runs": [{"job_id": "…", "release_id": "X5D_v51_5seed_20260916", "family": "wall",
   "status": "done", "review": "reviewed", "created_at": "…"}], "missing_releases": ["PF6_VF6_peak_3seed_20260920"],
   "pending_review": 1}], "total": 12, "page": 1, "page_size": 20}
```

- 前端：列表头部切换按钮；病例卡显示病例号、患者、扫描标签、每个发布包一个芯片（状态与审阅徽标），按钮「打开」「并排打开」（跳 `/compare?left=<wall job>&right=<volume job>`）「补跑 <发布包>」（调用现有 `rerun` 接口，源任务取该几何最新 done 任务）。
- 病例卡只展示，不改变任务模型；`family` 字段由后端从 `model_release.contract.protocol` 推出（D 上一轮已在轻量快照里加了 `family`）。

**验收**：同一 STL 的 WSS 与体场两个任务合成一张卡；并排链接打开后两侧相机联动；补跑按钮创建的新任务复用中心线与映射（不跑 A 段）。测试：`tests/test_cases.py`（分组、缺失发布包、分页、owner 隔离）。

### C2 上传查重与几何复用

**需求**：上传时发现同几何已算过，提示"打开已有 / 只跑新发布包（复用中心线与出口确认）/ 强制重算"。

**设计**：
- `JobManager.create` 在保存前计算 `input_sha256` 并写进任务记录顶层（现在只在 stage A 之后才有）；查重 `find_by_input(owner, sha)` 返回同几何任务（按创建时间倒序，含状态、发布包、映射是否已确认）。
- 上传接口新增表单字段 `on_duplicate = ask | reuse | force`（默认 `ask`）。`ask` 且存在同几何任务时返回 `409` 与 `{"duplicate": true, "existing": [...], "reusable": <可复用几何的任务 id 或 null>}`，不创建任务；`reuse` 时走 `rerun(源任务, release_id)` 逻辑创建新任务（只跑 B 段，映射沿用），响应体注明 `reused_from`；`force` 照常创建。
- 批量上传每个文件独立判定，逐项结果里带 `duplicate` 信息。
- 复用条件：源任务 stage A 成功且出口已确认；否则只能 `force`。

**验收**：同一 STL 第二次上传弹出选择；选"只跑新发布包"后新任务 `timing_s` 无 `centerline` 项且 `mapping` 与源任务一致；黄金回归不受影响。测试：`tests/test_duplicates.py`。

### C3 用户名登录

**需求**：同一个人在任何浏览器登录后看到同一份任务列表；共享模式下用用户名口令替代单一令牌；本机模式保持免登录。

**设计**：
- `wss_deploy/users.py`：`users.json`（jobs 根下，0600）：`{"<username>": {"password": "scrypt$<salt>$<hash>", "role": "user|admin", "created_at": "…", "display_name": "…"}}`；CLI `python -m wss_deploy.cli user add|passwd|disable <name> [--admin]`（口令从终端读，不进命令行参数）。
- 登录：`POST /api/session` body `{username, password}`；旧 `{token}` 在存在 `users.json` 前继续有效（迁移期），并可用于创建首个管理员。会话行 `owner = username`，`role`。
- 迁移：现有任务的 `owner` 是随机会话串。CLI `python -m wss_deploy.cli jobs claim --owner <旧 owner> --user <name>` 与页面上"认领本会话任务"按钮（把当前会话 owner 名下任务改为登录用户）。
- 管理员：`GET /api/jobs?all=1` 看全部；普通用户仍隔离。口令错误限速（每用户每分钟 5 次）。
- 前端：登录框改为用户名 + 口令，右上显示用户名与「退出」；`改口令`在个人菜单。

**验收**：两个浏览器同一用户看到同列表；认领后旧任务归属用户；错误口令 5 次后 429。测试：`tests/test_users.py`（哈希、限速、认领、admin 全览、旧令牌迁移期）。

### C4 回收站

**需求**：删除先进回收站，30 天内可恢复，到期自动清除；恢复后任务 id 不变、报告可开。

**设计**：
- 目录 `outputs/wss_deploy_jobs/.trash/<job_id>/`（整个任务目录原子重命名进来）加 `trash.json`：`{deleted_at, expires_at, deleted_by, job_snapshot}`。现有 `delete` 改为入回收站；`deleted_jobs.jsonl` 改在**彻底清除**时写入。
- 接口：`GET /api/trash`（owner 隔离，含剩余天数）、`POST /api/trash/<id>/restore`、`POST /api/trash/<id>/purge`；启动与每日一次扫描过期项清除。
- 恢复：重命名回 jobs 根，重新加载记录，状态保持删除前；若 id 已被占用（不会，id 含时间戳）报错。
- 前端：列表旁「回收站」面板：项目、删除时间、剩余天数、恢复 / 彻底删除；删除确认文案改为"进入回收站，30 天内可恢复"。

**验收**：删除→恢复→报告打开；过期清除测试用可注入时钟；锁定任务仍不可删（沿用审阅锁）。测试：`tests/test_trash.py`。

### C5 完成通知与未读标记

**需求**：任务结束（done / failed / interrupted / awaiting_confirmation）时浏览器通知，列表里未读任务有标记与计数。

**设计**：
- 后端 `GET /api/events`：owner 级 SSE，推送该用户所有任务的状态跃迁（复用 `_publish`，增加 owner 级订阅表）。
- 前端：首次使用请求 `Notification` 权限；收到终态事件弹通知（点击跳转任务）；未读集合存 localStorage（`job_id:version`），打开任务即清除；列表标题旁计数徽标；标签页标题加"(3)"。
- 页面隐藏时仍接收（SSE 不受 `document.hidden` 影响）。

**验收**：DOM 桩测试未读逻辑；HTTP 测试 owner 级事件流只含本人任务。

### C6 记住习惯

**需求**：上传表单（单位、发布包、设备、模型数、线程、标签、患者字段的"沿用上次"）、报告默认口径（色标、分段、单位、阈值、透明度）按用户记住。

**设计**：
- 服务端偏好 `GET/PUT /api/preferences`（JSON ≤ 16 KB，存 `preferences/<username>.json`；未登录时前端退回 localStorage）。
- 报告页离线打开时读 localStorage 的 `wss-report-defaults`；在线打开（同源）时先 `fetch('/api/preferences')` 覆盖；`#view=` 链接优先级最高。
- 上传表单加"沿用上次的患者与标签"开关。

**验收**：改口径后新开报告默认生效；导出的视图状态不受默认值影响（状态里显式记录）。

### C7 测量工具

**需求**：两点直线距离；两点沿中心线弧长距离（两点投影到同一分支时）；局部管径与到分叉距离（点一点）；分段长度（分支上两点）。

**设计**（两个报告共用，放进共享脚本 `static/report_common.js`，见 §3）：
- 核心函数（node 可测）：`projectToCenterline(groups, p) -> {segment, s, radius, row}`、`arcDistance(groups, a, b)`（同分支返回 |s_a − s_b|，跨分支沿树走到公共祖先求和，返回路径）、`localDiameter(groups, p)`。
- 交互：菜单「测量」：模式按钮（距离 / 管径 / 分段），点击壁面取点；三维里画线段、端点球、标签（数值与单位）；测量列表可删除、复制；写入视图状态 `measurements: [{kind, points, value_mm, branch}]`，随导图与六视角截图输出。
- 精度提示：管径来自中心线内切半径 ×2，不是该点截面的最大直径；标签注明。

**验收**：node 测试直管弧长、分叉两侧弧长等于经分叉之和、管径等于 2×半径；DOM 桩下模式切换。

### C8 标注

**需求**：在壁面钉文字标签，可编辑与删除，随视图状态、导图、一页纸输出。

**设计**：
- 报告：菜单「标注」；点选后弹输入框；三维里 sprite 标签加连线；视图状态 `annotations: [{xyz, text, color, created_at}]`。
- 服务端存储：`PUT /api/jobs/<id>/annotations`（JSON ≤ 64 KB，审阅锁定后拒绝）写 `annotations.json`；报告在线打开时拉取，离线（单文件）时用内嵌副本；`rebuild_report` 把 `annotations.json` 内嵌进 meta。
- 一页纸：附「标注」表（编号、分支、弧长、文字）。

**验收**：标注 → 刷新 → 仍在；重建报告后离线文件含标注；锁定后 PUT 返回 409。

### C9 快捷预设

**需求**：内置三五个一键视图；用户可把当前视图存为预设并命名。

**设计**：
- 内置（按族）：壁面「瘤囊低 WSS 区」（低阈值高亮 + 主动脉分支 + 前视）、「髂分叉热点」（发现列表第一条高 WSS 簇飞到）、「主动脉沿程」（沿程菜单展开、s 带高亮）；体场「沿程压降」（沿程菜单压力曲线）、「流线全貌」（流线模式、透明度 0.08、前视）、「瘤囊截面系列」（主动脉自动截面 40/60/80%）。内置预设是**视图状态生成函数**，打开时按病例的分支名与发现计算。
- 用户预设：视图状态加 `preset_name`，存 C6 偏好（服务端）或 localStorage；菜单「预设」列出内置与用户预设，支持删除、重命名、导出。

**验收**：每个内置预设在两份真实报告上可应用且不报错（DOM 桩）；用户预设保存后在另一份同族报告可应用。

### C10 分支显隐

**设计**：显示菜单加分支勾选框（名称来自 `branch_names`，缺失时按 segment id）；壁面报告按顶点分支数组过滤三角面（面三顶点全隐才隐）与点云；体场按内部点分支过滤；隐藏的分支在沿程曲线里变灰；状态 `branches_hidden: [segment_id]` 进视图状态。

**验收**：隐藏后统计面板不变（只是显示），提示"统计不受显隐影响"。

### C11 探针记录

**设计**：探针卡片加「记录」按钮；记录表（编号、xyz、分支、s、半径、数值们）在菜单「测量」下方；「复制 TSV」「导出 CSV」；进视图状态 `probe_log`。

### C12 出版级导图

**需求**：导出 PNG：分辨率 1×/2×/4×，背景白 / 透明 / 当前，隐藏界面元素，色标可选叠加或单独导出 SVG，标签语言中 / 英。

**设计**：
- 渲染：临时 `renderer.setSize(w×k, h×k, false)` 与 `setPixelRatio(1)` 离屏渲染一帧，`toDataURL`，再恢复；透明背景用 `alpha: true` 的第二个渲染器或临时 `setClearColor(0,0)`。
- 色标 SVG：由当前色标、范围、分段、单位、标题生成矢量文件（`<svg>` 字符串下载）。
- 英文字典：图例标题、单位、分支名（Aorta, Left/Right CIA, Left/Right EIA, Left/Right IIA）、测量与标注默认词；语言存视图状态 `lang`。
- 文件名 `<case>_<view>_<field>_<k>x.png`。六视角导出复用同一路径。

**验收**：node 测试色标 SVG 生成与英文映射；DOM 桩下导出流程不抛错；真实浏览器由用户验收分辨率。

### C13 跨病例批量出图

**需求**：工作台多选任务 → 选择一份视图状态（当前报告导出的 JSON 或内置预设）→ 批量导出每例的 PNG，打包 zip。

**设计**：
- 报告页新增 message 协议（补进 `ANALYSIS_CONTRACT.md` §6）：父页发 `{type:"wss-view:apply-state", state}` 与 `{type:"wss-view:export", options}`，报告回 `{type:"wss-view:exported", png_base64, filename}` 或 `{type:"wss-view:error", message}`。
- 工作台 `static/batch_export.js`：隐藏 iframe 逐个加载 `/api/jobs/<id>/report`，等待 `wss-view:ready`（报告加载完成后发出），应用状态、导出、收集；用 store 方式的最小 zip 写入器（无外部库，约 80 行）打包下载；进度条与失败列表。
- 内置预设按族匹配：壁面状态只应用于壁面任务，混选时提示。

**验收**：node 测试 zip 写入器（Python `zipfile` 能解压、CRC 正确）；DOM 桩测试协议往返；真实浏览器由用户验收。

### C14 多病例汇总表导出

**设计**：
- `GET /api/jobs/export?ids=a,b,c&format=csv|xlsx`（xlsx 用 openpyxl，环境已有 3.1.5）。固定列：任务 id、病例号、患者、扫描标签、扫描日期、标签、发布包、族、状态、审阅状态、审阅人、创建时间、输入 SHA256 前 12 位、run_identity 前 12 位、计算总时长；壁面族：p99、最大值、均值、低 / 高 / 极高面积占比与面积 mm²、七条分支 p99、人群分位、质量等级；体场族：速度 p99、速度最大、压力 min / max、六条分支 ΔP、低速区数；发现条数（attention / note）。缺失填空，不猜。
- 前端：多选模式加「导出汇总表」；单病例卡也可导出该病例全部运行。

**验收**：xlsx 打开列名正确；混合族导出不报错；owner 隔离。

### C15 打包下载

**设计**：`GET /api/jobs/<id>/bundle.zip`：流式 `zipfile`（`ZIP_STORED` 对已压缩文件、`ZIP_DEFLATED` 对文本），内含白名单文件、按需生成的 `onepage.html`、`annotations.json`（若有）、`README.txt`（口径与版本说明）。多选时 `POST /api/jobs/bundle` `{ids}` 返回 zip 的 zip。审阅锁定不影响下载。

### C16 发现列表可编辑

**需求**：审阅人对每条自动发现标「确认 / 驳回」并写备注；可手动新增发现；一页纸只列确认与未判定项，驳回项归附录。

**设计**：
- `PUT /api/jobs/<id>/findings_review` body `{version, items: {"F1": {"decision": "confirmed|rejected|null", "note": "…"}}, added: [{"xyz_mm", "branch", "text", "kind": "manual"}]}`，写 `findings_review.json`，并合并进 `summary.findings.review`；审阅锁定后拒绝。
- 报告：发现列表每条加三态按钮与备注；离线文件用内嵌副本；在线时保存到服务端。
- 一页纸：确认项打勾、未判定项空框、驳回项附录；手动发现标「人工」。

**验收**：驳回项不出现在一页纸正文；锁定后 PUT 409；重建报告后决定保留。

### C17 术语说明

**设计**：`wss_deploy/glossary.py` 单一来源：`{key: {"zh": 名称, "zh_desc": 一句解释, "en": name, "en_desc": …}}`，覆盖 p99、最大值、面积占比估计、面积加权 p99、相对压、ΔP、可信位五种、置信度代理、人群分位、离散度质量等级、发布包、特征合同哈希、run_identity、标准视角来源。生成 `static/glossary.json` 供两个报告（问号图标弹出）与工作台使用；一页纸末尾附术语表。

**验收**：术语 key 与报告中使用处一一对应的测试（缺失即失败）。

### C18 审阅提醒

**设计**：列表顶部"待审阅 N"分区（done 且 unreviewed），默认展开；已审阅默认折叠；病例卡上显示 `pending_review` 计数；筛选器加「待审阅」。

## 5. 后续迭代规格（保留）

### N1 取消即时生效与时间语义

现状：`centerline.run_vessel_geom` 用 `subprocess.run` 同步等待，取消只在段边界生效；`compute_seconds` 累加所有尝试。设计：`Popen(start_new_session=True)`，取消时向进程组发 `SIGTERM`、2 s 后 `SIGKILL`；B 段耗时函数内加检查点；时间拆为本次尝试 / 累计 / 墙钟，页面默认显示本次尝试；中断写事件 `attempt_aborted`。验收：取消后 3 s 内进入 `cancelled` 且无残留进程；重试后计时从 0 起。

### N2 大几何提速（暂缓）

LIU 例：中心线 65 s、重采样 36 s、体场特征 76 s、推理 2 s。方案：VMTK 前抽稀到约 1 mm（改中心线 → 改预测，须新程序版本 + 34 例复核）；重采样过采样自适应与校准减轮（同上）；体场内判与壁面距离分块并行（不改数值，进黄金回归）；推理 kNN 图复用（触碰训练库，需逐位验证）。目标总时长 ≤ 90 s。

### N3 患者方向侧车

`orientation.json`：`{"schema_version": "wss-deploy.orientation/v1", "source": "dicom_affine|segmentation_export|manual", "patient_convention": "LPS|RAS", "stl_to_patient": [[4x4]], "note": "…"}`。`ingest` 校验正交与行列式 +1；`propose_outlets` 用患者左向量判左右并标来源；`frame_transform.direction_source` 写来源；报告标准视角改称解剖视角。验收：34 例仿射构造侧车后左右 34/34；无侧车时逐位不变。

### N4 出口命名标注飞轮

`export_labels.py` 导出 `mapping_history` 与验收记录为标注集（按输入哈希去重）；≥ 50 例独立集后 `build_confidence_profile.py` 生成门控所需 profile（`id / version / status / release / validation_set / sample_count / joint_lower_bound（Wilson 下界）/ allowed_orientation_sources / calibration`），写入 `reference.json` 的 `confidence_profile`；放行后结果页保留人工复核入口，报告标明校准编号；被改动病例回流训练侧 atlas 核对。现状：工作台仅 4 行标注。

### N5 无头浏览器验证与一页纸配图

独立环境装 Playwright chromium（swiftshader）；截图回归四张图感知哈希比较 + 控制台零错误；`POST /api/jobs/<id>/snapshots`（PNG 白名单 ≤ 8 张）供一页纸配图；记录首屏时间与内存作为 N9 基线。

### N6 类型化运行记录与迁移

`record.py` 的 `RunRecord` 与派生视图（summary / 报告 meta / job.summary / manifest），`run.json` schema v2，`migrate_v1_to_v2()`；黄金回归对派生 summary 逐键相等。

### N7 SQLite、分进程、流式上传

`jobs.sqlite`（WAL）；`api` + `geometry-worker ×2` + `model-worker ×1`；队列表与乐观锁；流式落盘与幂等键；FastAPI 迁移需独立 `GNN_deploy` 环境，不动共享训练环境。

### N8 常驻 VMTK 与环境合并

`vessel_geom serve` 行协议常驻子进程；conda-forge vmtk + pip torch 合并后重跑 50 项测试与 34 例回归；`conda-lock` 入库。

### N9 查看器合并与报告瘦身

`static/viewer/` 模块库，三个入口只做数据装配；坐标 float16、索引分块、`seed_pred` 不内嵌；LIU 例 10.9 MB → ≤ 5 MB。前提：N5 截图回归。

### N10 结构化报告与机构预设

`site_settings.json`（阈值、单位、色标、术语、模板、机构名），`GET /api/settings`；报告与一页纸按预设渲染并记录预设哈希；旧报告保持原口径并标注。

### N11 纵向对比的分支级配准

## 6. 风险

- C3 迁移期同时支持旧令牌与用户名口令，要有明确关闭旧令牌的开关，避免长期双轨。
- C2 的复用路径依赖源任务的出口确认；若源任务被回收或锁定，回退到强制重算并提示。
- C12 / C13 的真实分辨率与透明背景只能在用户浏览器验收；离屏渲染在集成显卡上可能失败，需要降级到 1×。
- C16 与审阅锁定的交互：锁定后发现决定不可改，重新打开后可改；一页纸必须读最终版本。
- 报告共享库让两个报告的内联 JS 再增大，N9 瘦身前报告体积会略涨（估计 +150 KB）。
