## 1. 审计方法

- 以前每轮界面改动都靠用户截图验收（框架文档多次记「真实浏览器验收待用户」）。本轮先解决这个问题：集群上的系统 Firefox 120 + Mesa llvmpipe 软件 WebGL 可以离屏渲染 three.js 报告，写了 `wss_deploy/devshot.py`（Marionette 协议直连，无需 selenium / geckodriver；自动收集页面 JS 错误）。
- 在草稿目录复制 4 个正式任务（M1 三头 LV_GUO_YOU、PF6/VF6 体场、X5D、LIU 体场）起回环沙箱服务，另上传 1 例停在「待确认出口」，逐页截图：工作台首页 / 详情 / 确认出口 / 上传框 / 按病例 / 队列总览 / 1024 与手机宽度、壁面报告、体场报告、一页纸、并排比较。
- 代码核查：TAWSS/OSI 在各模块的流向、`quality` 是否属于黄金比对键、任务记录摘要、报告相机初始化、服务启停方式。基线：360 项测试通过。

### 暂不做（及原因）

- 大几何提速 N2、方向侧车 N3：用户 09-21 裁定提速暂缓；方向侧车跨 ingest/centerline 需串行。
- 掩膜 / 封闭面上传：切口位置直接影响预测（训练协议 ±5 mm），需要单独验证，不能一夜上线。
- 临床阈值（如 AAA 修复直径）：属于临床决策支持，需导师 / 医生确认来源后再做成可配置项。
- 分享链接：安全面需要单独评审；当前单文件报告与打包 zip 已可离线转交。
- TAWSS / OSI 人群分位：M1 没有 CV3 折外预测，不能伪造；侧车只给几何范围。

### 5.2 明天验收怎么做

1. **切换正式服务（需要你执行；本会话的重启命令被自动模式拦截，没有动正式服务）**。队列为空时：

   ```bash
   cd /public/newhome/cy/Digital_twin/GNN
   PYTHONPATH=. ~/.conda/envs/GNN/bin/python -m wss_deploy.cli service status     # 只读：确认计算中 / 排队 / 待确认都是 0
   PYTHONPATH=. ~/.conda/envs/GNN/bin/python -m wss_deploy.cli service upgrade    # 约 10 s；令牌与已登录的浏览器会话不变
   PYTHONPATH=. ~/.conda/envs/GNN/bin/python -m wss_deploy.cli doctor             # 应只剩「只用令牌登录」一条 ⚠
   ```

   `upgrade` 会把当前手工进程的参数写进 `outputs/wss_deploy_jobs/service.json`、令牌迁入 `.service_token`；M1 例 `20260922_173705_27065942b465` 自动完整重建（只重算发现 / 沿程 / 结论，预测数值不变）；7 份报告刷新为新模板。之后日志在 `outputs/wss_deploy_jobs/server.log`。若想把推理固定到较空的显卡：`service upgrade --env CUDA_VISIBLE_DEVICES=3`。
2. **浏览器里看**（刷新页面即可）：首页「今日概览」→ 点 LV_GUO_YOU 的 M1 任务（周期量卡片、重点发现含滞留区）→「打开三维报告」（默认前视撑满、上方「峰值 WSS / TAWSS / OSI」、显示菜单勾「滞留区」、按 `?` 看快捷键）→「一页纸」（一页 + 附录、M1 三张卡）→ 体场任务报告（壁面压力页签可用、色标不再是 1.77e-3）→ 上传一例看确认出口页是否一屏。
3. **随访时间线**要真实数据：给同一患者的两次扫描填相同的匿名患者编号和扫描日期（详情页「编辑信息」）。
4. **机构模板**（可选）：工作台「设置 → 报告模板」或 `cli template set --institution … --department …`。
