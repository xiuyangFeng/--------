## 1. 判定口径与方法

判定复用 `pipeline_wss_min.raw_io` 按 pipeline 真实读取路径执行（`_read_ascii` / `list_timesteps` / `peak_systole_step` / `read_wall_fields`），未走 vtk/vtp、未做配准、未落盘。硬判据镜像 `qa_gate.LIMITS` 中**不依赖配准**的项：

| 判据 | 阈值 | 来源 |
| --- | --- | --- |
| 壁面 ascii 存在且有时间步文件 | 必须 | 结构完整性 |
| `centerline/centerline_points.csv` 存在且列名匹配 | 必须（几何特征/配准依赖） | 结构完整性 |
| WSS / 坐标全有限 | 无 NaN/Inf | `qa_gate` nonfinite |
| peak 步 WSS `p90 > 0` | `>0` | `qa_gate.peak_p90` |
| peak / 抽样步 零值率 | `≤0.01` | `qa_gate.peak_zero_frac / all_zero_frac` |
| `n_wall ≤ 50000` | **本次不作达标硬判**（见 §2） | `qa_gate.n_wall`（AG 专用上限） |

## 4. 给后续训练/split 的注意事项

1. **解剖不同，慎与 AG 混池。** AAA 是腹主动脉瘤、ILO 含介入前后，与 AG 的主动脉-髂动脉分叉不是同一形态；直接混池等于假设「几何→WSS」映射跨解剖可迁移，未必成立。建议各建独立队列/split，或作为跨解剖泛化对照。
2. **ILO before/after 同一病人配对，split 必须按病人分组**，否则 before 进 train、after 进 val 会标签泄漏。
3. **可用样本大幅扩容**（AG 53 训练例 → AAA 65 + ILO 106），正好支撑第四轮建议的**病例数 learning curve**：固定最优配方分档喂 13/26/40/53… 例，判断当前「效果差」是数据量受限还是协议/表示受限。
4. **配准适配是独立后续任务**（本轮未做）。若这些队列要进入 AG 现有训练口径，需单独验证 `flow_divider` 三臂聚类与 `wall_branches` 左右轴在瘤体/介入解剖上的成功率；预期需要按队列调参或改用队列专属配准。

## 6.4 可视化 QA 结果（2026-07-10 追加）

> 对 159 个可配准单元生成对齐后逐病例 X-Z 投影（颜色=z 高度）+ 三视图叠加，逐张目视 + 数值复核。脚本/图：[`assets_新队列审计/viz_new_cohorts.py`](assets_新队列审计/viz_new_cohorts.py) / [`alignment_viz/*.png`](assets_新队列审计/alignment_viz/)；数值异常：[`viz_numeric_flags.py`](assets_新队列审计/viz_numeric_flags.py) / [`viz_numeric_flags.csv`](assets_新队列审计/viz_numeric_flags.csv)。

**总体：朝向高度一致，AG 配准框架目视可用。** 4 张小图（AAA_ruputer/unruputer、ILO_before/after）中约 **150/159** 呈稳定一致的 Y 形——单一主干在下（低 z）、双髂支分叉在上（高 z），跨病例朝向统一；AAA 多数可见中段瘤体膨大（符合腹主动脉瘤）。这直接支撑 §6.1「框架可迁移」的结论。

**目视 + 数值定位到两类真实缺陷（与 §6.2 探针 FAIL 高度重合，且给出了机制）：**

1. **原点错位导致归一化塌缩（6 单元，致命但可修）**：`ILO/WANG_LI_MIN-0/before+after`、`ILO/ZHANG_MAO_JIN-0/before+after`、`AAA/ruputer/ZHOU_KE_XUN`、`AAA/unruputer/LIU_WEN_QI`（实为 3 个病人 + 2 个 AAA）。小图上表现为「底部一个小点/短条」。

   **专项诊断已确诊为「centerline 相对壁面的纯平移偏移」，非坏几何**（脚本 [`assets_新队列审计/diag_origin_offset.py`](assets_新队列审计/diag_origin_offset.py)，图 [`alignment_viz/origin_offset_check.png`](assets_新队列审计/alignment_viz/origin_offset_check.png)）：
   - **壁面与 centerline 的 bbox 对角线逐例完全相等**（如 WANG_LI_MIN/before 均 304.2mm、ZHOU_KE_XUN 均 261.2mm）→ 同尺度、同大小；
   - 质心偏移 **509–1920mm、方向以 Z 为主**（壁面 Z 心在 +385~+1452，centerline Z 心在 −580~+48）——像是壁面/CFD 网格保留了扫描床高位坐标、而 centerline 在 VMTK 局部系导出；
   - **把 centerline 按质心平移回壁面后，其每点到壁面最近距离中位数仅 6–16mm（≈血管半径）**，叠加图上绿色中心线精准穿过管腔含双髂支 → 形状完全吻合，只差一个平移。
   - 对照正常例 `AN_GUANG_JIE/after` 偏移仅 49mm、原点落在壁面内。

   机制：`flow_divider` 原点取自 centerline，被平移带偏 → `wall - origin` 落到千 mm 外 → `max|coord|` 归一化把真实解剖压成一点；`wall_branches` 左右轴也因原点错位失败（故探针报 `roll=branches`）。`outlier_ratio=max|.|/p99` 全部正常，排除离群点。

   **修复方案（低风险，可选实施）**：在 `preprocess` 的 `compute_transform` 前加一道 centerline↔壁面平移预对齐——当 `|centerline质心 − 壁面质心| > k·壁面对角线`（如 k=0.8）时，将 centerline 平移到壁面质心（或做 translation-only ICP）再配准。对 AG 及正常新队列（偏移 ~16–50% 对角线）是 no-op，只救这 6 例。**本轮未改代码**，仅给出方案待批。

2. **主轴歪斜（严重 3 例）**：`ILO/WEI_QING_FENG-1/before`（主轴与 Z 夹角 89°，几乎躺平）、`ILO/XIE_ZHI_FU-0/after`（41°）、`ILO/DONG_JIA_JU-1/after`（36°）。与 §6.2 的 `unit_extent_mismatch` 标记一致，根因为中心线只描远端一段 / 单位覆盖不一致，使主轴估计偏轴。→ 逐例复核单位因子与主轴。

**轻度歪斜（15–25°，9 例）判为正常**：AAA 瘤体/主动脉自然弯曲所致（如 `GAO_WEI_LI` 18.6°、`CAO_DIAN_HE` 18.0°），非配准错误，无需处理。

**未验证项**：X-Z 投影无法判定左右（L-R）翻转，探针标 `FLIP?`（roll_sign 不可靠）的 15 例需 X-Y 视图另行确认；但鉴于第一轮已证「标量 WSS 任务中绝对坐标几乎不贡献」，L-R 翻转对本任务风险较低，可作次优先。

**可视化 QA 净结论**：**约 150/159 单元朝向正确、可进入训练候选**；6 单元因原点错位须修复或剔除，3 单元须复核单位/主轴。缺陷集与探针 FAIL/warn 集一致，无新增系统性问题。

## 7. 后续数据补充方向（老师建议，暂记）

导师提出用**对抗生成网络（GAN）/ 扩散模型**快速生成训练几何以扩充数据集。与本审计的关系与前置条件：
- 真实可用样本（AAA 65 + ILO 106 + AG 61）应先**建立干净、已可视化验收的配准基准**，作为生成模型的训练/条件来源与保真度评估的 ground truth。
- 生成几何若要产 WSS 标签，仍需跑 CFD 或训练一个「几何→WSS」代理；单纯生成表面点云不自带 WSS，需明确标签来源。
- 生成数据的坐标框架必须与真实数据同一配准口径，否则混训会引入朝向不一致。
- 建议顺序：先用真实新队列做 §4.3 的病例数 learning curve，确认「数据量」确实是当前瓶颈后，再投入生成式扩充；若瓶颈在协议/表示，生成更多同构数据收益有限。
