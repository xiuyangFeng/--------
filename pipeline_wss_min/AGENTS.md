# pipeline_wss_min — Agent 指令

本目录为 **WSS-only 最小化数据线**（`x,y,z -> wss` 单头），与 V3P / `pipeline/` / `data_new/` **完全独立**。

## 推进记录（必做）

修改本目录代码、配置、QA 脚本，或更新 WSS 最小化相关文档后，**必须**在文首同步更新：

`docs/02-推进与变更/WSS最小化_代码修改与实验推进记录.md`

每条记录至少包含：**本次主要修改**、**对应代码/文档**、**推进到实验步骤**、**当前状态判断**。最新条目在最上。

V3P / 训练主线变更写入 `docs/02-推进与变更/代码修改与实验推进记录.md`，**不要**把 WSS-min 细节写进该大日志。

## 约束

- 产物输出到 `data_wss_min/`、`outputs/wss_min/`，不改动既有 V3 数据与训练产物。
- 配准/坐标口径变更后需全量重跑 `preprocess`；混用新旧 bundle 会导致朝向不一致。
- 批量 preprocess / 集群作业按 `cluster.mdc` 提交；WSS **训练侧**对比脚本见 `wss.mdc`（未明确要求不代跑）。
