输入检查（上传后几秒内）

这一类是 STL 本身的问题，重试不会改变结果；修正几何后重新上传。判据见输入说明第 2 节。

报错原文原因怎么办
开口数 N ≠ 5；需要主动脉入口与四个髂动脉出口，且切口保持开放。开放边界环的数量不是 5。大于 5：分支残端没封闭或表面有破洞；小于 5：端口没切开（导出的是封闭面），或一侧髂内闭塞只剩 3 个出口封闭多余残端、补洞；在入口和四个髂支末端切开。三出口几何目前不支持
有 N 个连通片；较小部分占总面积 x%，可能含断裂分支，不能自动删除。表面不是一整块，除最大一块外其余部分合计超过总面积的 1%在分割软件里检查断开处（常见于细小髂内动脉），连成一整块后重新导出
换算后的整体尺寸超出工具预检范围（包围盒对角 50–1500 mm）；请重新核对单位或血管范围。按所选单位换算后，整体尺寸不像腹主—髂动脉核对导出时的单位，重新上传并选对单位；检查是否导出了整张 CT 或只导出了一小段
表面含退化面片或无效面积，请修复后重新导出。有面积为 0 或无法计算面积的三角面在网格软件里删除退化面片后重新导出
表面含重复三角面，请修复后重新导出。同一个三角面出现了两次，常见于合并多个网格删除重复面片后重新导出
存在 N 条非流形边，请修复表面。有边连接了三个或更多面片，常见于两段血管粘连或合并网格没有焊接修复网格（分离粘连处、焊接重合顶点）后重新导出
边界含 N 个非环状连接点，不能视为有效开口。某个开口的边界不是一个简单的环，例如两个切口相碰，或切口边缘有悬挂的面片重新切开该处，使每个开口是一圈独立的边界
STL 文件为空、不可读或超过 128 MiB 上限。文件太小（不足一个 STL 头）、不存在或过大重新导出；过大时抽稀网格
STL 面片数超过 2,000,000 上限或没有面片。二进制 STL 的面片数为 0 或超过 2,000,000抽稀到 2,000,000 面以内，或检查导出是否为空
STL 面片数超过 2,000,000 上限。面片过多抽稀网格；一般几万到几十万面足够
STL 二进制长度不匹配，或 ASCII 格式不正确。文件被截断、不是 STL，或 ASCII 格式有误重新导出为二进制 STL
无法读取 STL，请导出有效的 ASCII 或二进制 STL。文件结构无法解析重新导出；换用二进制 STL
STL 坐标含 NaN/Inf 或维数不正确。有无效坐标修复网格后重新导出

需要你确认的提示（任务暂停在「确认输入」）

提示原文原因怎么办
自动单位有多个合理候选，请确认 STL 原始单位。按 mm 和按 cm 换算，尺寸都说得通对照影像里的血管尺寸，选实际单位后勾选确认
自动单位没有唯一的合理候选，请明确选择 mm、cm 或 m。mm、cm、m 都不能让尺寸落进 50–1500 mm，或按尺寸自动建议的单位不在其中选实际单位；若三种单位都不对，检查导出范围
自动单位接近尺寸判定边界，请确认 STL 原始单位。换算后尺寸靠近 50 mm 或 1500 mm 的边界核对「换算后尺寸 · mm」后确认
有 N 个连通片；删除小片将移除 x% 的面积，请核对后确认。有小碎片，面积合计不超过 1%确认碎片不是断开的血管分支后，勾选删除孤立片并确认

只提示、不阻断

提示原文原因怎么办
N 条内部边的相邻面片绕序不一致，建议复核法向。部分面片朝向与邻居相反可以继续；方便时在网格软件里统一法向
N 个面片极度狭长，建议复核网格质量。形状很差的细长三角面可以继续；中心线提取失败时先重划网格

自动命名未满足已校准的 95% 自动门控，请结合原始影像核对开口名称。不是错误：自动命名需要人工核对对照影像核对四个出口的名称，必要时用互换按钮改正，然后确认
拓扑不是 1 入口 → 2 髂总 → 各 2 出口（髂总 N 条，出口 [ … ]），无法自动命名中心线树不是「主动脉分成左右髂总、每侧再分成两支」的形状，常见于入口选错或某个开口位置不对先检查入口是否是主动脉近端，错了就「重新选择入口」；形状本身不对时修正 STL
四个出口必须分别且唯一对应左外、左内、右外、右内。出口命名有重复或缺漏每个出口各选一个不同的名称
髂总 N 下面的两个出口 [ … ] 不在同一侧；同一侧必须是 左内+左外 或 右内+右外同一条髂总下面的两个出口被命名成了不同侧同侧两个出口应为「左内 + 左外」或「右内 + 右外」；用「左右互换」整体对调
入口必须是当前几何中有效的开口编号。所选入口编号不在本几何的开口里在入口下拉框里重新选择
请确认出口命名及其对计算的影响。没有勾选确认勾选确认后再提交

计算过程

报错原文原因怎么办
GPU 显存不足，已改用 CPU 重试。显卡显存不够，程序已自动改用 CPU不用处理，只是耗时变长
内存不足，请稍后重试。服务器内存暂时不够稍后点「重试任务」
磁盘空间不足，请联系维护者清理后重试。服务器磁盘已满联系维护者
计算环境缺少必要模块，请联系维护者。服务安装不完整联系维护者
计算未完成，请重试；如仍失败，请向维护者提供诊断编号。未归类的内部错误点「重试任务」；仍失败时把页面上的诊断编号发给维护者
输入检查尚未通过，不能开始预测。输入检查没有通过就进入了计算回到「确认输入」完成确认；仍出现时联系维护者
必须确认出口命名后才能开始预测。出口还没确认在出口确认页确认后再计算
历史任务缺少发布包指纹，不能安全重试。旧任务没有记录所用模型的指纹重新上传同一个 STL 新建任务
绑定的发布包指纹已变化，不能继续重试。任务所用的模型文件已被替换用「用其他发布包重跑」新建任务，原结果保留
仅失败、取消或中断的任务可以重试。任务正在排队、计算或已完成不需要重试；已完成的任务要换模型请用「用其他发布包重跑」
